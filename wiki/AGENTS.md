# Dear Human Wiki

- 이 디렉토리는 게임과 독립적으로 실행·빌드하는 세계관 위키 프로젝트다. `content/articles/*.md`가 위키 본문의 원본이다.
- 사용자는 docs와 다른 문서를 모두 새로 쓰라고 지시했다. docs를 그대로 렌더링·복사하거나 빌드할 때 docs를 읽어 문서를 덮어쓰지 않는다.
- 기존 `../docs/15-worldbuilding.md`는 최초 집필의 설정 근거다. 문서의 sources에는 근거와 절을 기록한다. 기존 docs의 제작 지침과 런타임 구현 기록을 세계의 역사로 섞지 않는다.
- 세계관 변경은 위키 문서에서 명시적으로 편집한다. 기존 docs와 설정이 달라지면 어느 쪽을 바꿀지 작업 범위에 따라 함께 기록한다. 동기화는 자동으로 수행하지 않는다.
- 확정, 보완안, 미정을 구분한다. 사용자 지정 전제와 이번에 채택한 날짜는 확정으로, 베스퍼 지명·물리 수치·기관 세부는 보완안으로 표시한다.
- 제작자 전용 비밀은 `visibility: "creator"` 문서로 분리한다. 기본 열람·검색·추천·역링크·연표에서 제외한다. 이 기능은 스포일러를 줄이는 표시 기능이며 보안·접근통제 기능이 아니다.
- 최초 버전은 의존 패키지가 없는 정적 서비스다. 외부 서비스나 게임 파일이 없어도 실행·빌드돼야 한다. `npm run check`와 필요한 짧은 브라우저 확인을 사용하고 게임 전체 검사를 실행하지 않는다.
- 사용자 요청으로 나무위키를 참고한 문서 중심 화면을 사용하되, 메인 테마는 우주 분위기의 딥 네이비(#172b4a)와 차가운 블루다. 밝은 본문·분류 상자·본문 앞 목차·오른쪽 탐색 패널을 사용하며 어두운 테마는 밤하늘 계열의 네이비를 쓴다. 연표는 연도별 선·노드와 날짜/사건명만 표시하며 클릭하면 개별 문서로 이동한다. 긴 사건 설명을 연표에 다시 펼치지 않는다.
- 인물 문서는 첫머리 목차와 오른쪽 프로필 신상표를 사용한다. 프로필은 각 문서 front matter의 `profile`에 명시하고 미정인 이름·계급·나이를 새로 지어내지 않는다. 클론의 외형상 나이와 각성 후 기간을 구분한다. 모바일은 목차 다음 프로필 순서로 표시하며, 관계·서사 문서에는 인물 신상표를 자동 적용하지 않는다.
