## 003: 기본 대기 ↔ 사격 대기 흐름 (2026-11-13)

사용자 요청 원문: “지금 수정한 작업들 스프라이트로 만들어주고, 동작에 규칙을 추가해 줄게. 총을 꺼내면 '기본 대기 -> 사격 시 조준 대기로 변경 및 사격 -> 사격 중지 시 사격 대기 -> 5초 간 정지해 있으면 기본 대기로 변경' 이 흐름을 따라 가도록 프로토타입에 추가해줘.”

- **그림:** 새 [sprite_005](../../../art/characters/clone_01/motion/glb_model_001/sprite_005/README.md)의 6개를 쓴다. 전환 4개(내림→조준, 조준→내림, 쌍권총 대기→조준, 쌍권총 조준→대기)와 쌍권총 대기로 끝나는 꺼내기·넣기다. 004의 `rifle_aim_idle`·`dual_idle_high`도 새로 불러온다(리안 21개 동작).
- **흐름 (무기를 든 동안):**
  - **기본 대기:** 꺼낸 직후의 자세다. 소총은 `rifle_idle`, 쌍권총은 쌍권총 대기 `dual_idle_high`.
  - **사격:** A·S를 누르면 먼저 조준 자세로 올린다(내림→조준 / 쌍권총 대기→조준). 그다음 A는 단발, S는 누르는 동안 풀오토다.
  - **사격 대기:** 사격이 끝나면 머무는 자세다. 소총은 `rifle_aim_idle`, 쌍권총은 쌍권총 조준 대기 `dual_idle`.
  - **5초 정지:** 사격 대기에서 5초(`AIM_HOLD`) 동안 움직이지도 쏘지도 않으면 내린다(조준→내림 / 쌍권총 조준→대기). 이후 기본 대기다.
  - **넣기·바꾸기:** 사격 대기에서 X로 넣거나 1·2로 무기를 바꾸면 먼저 내린 뒤 넣는다.
  - **걷기:** 무장 걷기·달리기 동작은 조준한 모습이라 사격 대기로 취급한다. 멈추면 사격 대기이고 5초 뒤 내린다.
  - **화면 표시:** 상태 줄에 (기본 대기)·(사격 대기 · n초 후 기본 대기)를 보여 준다.
- **확인:** `?debug` 주소에서만 `window.__move`(player·keys·update·onKeyDown)를 노출한다. 이것으로 1/30초씩 직접 돌려 확인했다.
  - 소총: 꺼내기 → 기본 대기 → A(올리기 → 단발) → 사격 대기 → 5.2초 뒤 내리기 → 기본 대기 → S(올리기 → 풀오토) → 사격 대기 → 걷기 → 정지 → 2(내리기 → 소총 넣기 → 쌍권총 꺼내기)
  - 쌍권총: 기본 대기 → A(올리기 → 단발) → 사격 대기 → 5초 뒤 내리기 → S → 사격 대기에서 X(내리기 → 넣기)
  - 실제 키 입력으로 꺼내기도 확인했다. 내장 브라우저 창이 숨겨지면 requestAnimationFrame이 멈춰 실시간 타이밍은 재지 못했다. 동작감은 사용자 검수 대기다.
- **남은 점:**
  - 조준 대기 루프 중간에서 내리기·사격으로 넘어가면 호흡만큼(약 1cm) 튈 수 있다.
  - 쌍권총 사격 첫 키와 조준 대기가 최대 1.7cm·2.2° 다르다.
  - 걷기 시작·멈춤의 자세 전환 동작은 없다.

## 002: 리안 무기 꺼내기·넣기·사격 (2026-11-13)

사용자 요청 원문: “이제 프로토타입용 2d 스프라이트를 다시 만들거야. 리안 기준으로 만들거고 들어갈 모션은 사격 동작에 포함되어있는 동작, 맨손 걷기, 달리기, 대기1 을 추가할 거야. 키보드 자판 1을 누르면 소총을 꺼내고, 2를 누르면 쌍권총을 꺼내, x키를 누르면 무기를 꺼내거나 넣을거야. 꺼내는 무기는 마지막 들고있던 무기고, default는 1번 무기야. a키를 누르면 단발 사격, s키를 누르면 풀오토를 사용할거야. 30fps 기준으로 스프라이트를 만들고 프로토타입에 적용해줘. 프로토타입 폴더는 js-prototype으로 이름을 바꿔서 작업해줘”

- **폴더:** `game/prototype`을 `game/js-prototype`으로 바꿨다(git mv). 라이브러리 링크(`game/app.js`의 `jsPrototypes`, `index.html`)도 새 주소로 바꿨다.
- **그림:** 리안은 [sprite_004](../../../art/characters/clone_01/motion/glb_model_001/sprite_004/README.md)(30fps)의 15개 동작을 쓴다. 맨손 대기 1·걷기·달리기, 소총 대기·이동 사격·꺼내기·넣기·조준 사격·풀오토, 쌍권총 대기·걷기·달리기·사격·꺼내기·넣기다. 다른 대원은 이전처럼 `sprite_001`(12fps) 맨손 동작만 있다.
- **조작 (리안):**
  - **1:** 소총(AR-12)을 꺼낸다. 쌍권총을 들고 있으면 먼저 넣고 꺼낸다.
  - **2:** 쌍권총(HP-14T)을 꺼낸다. 소총을 들고 있으면 먼저 넣고 꺼낸다.
  - **X:** 맨손이면 마지막에 들었던 무기를 꺼내고(처음은 1번 소총), 무기를 들고 있으면 넣는다.
  - **A:** 단발이다. 소총은 ‘조준 사격’(`gunplay`)을 한 번 재생하고, 쌍권총은 ‘쌍권총 사격’ 앞 0.5초(오른쪽 1발 + 왼쪽 1발)를 재생한다.
  - **S:** 누르는 동안 풀오토다. 소총은 `rifle_full_auto`(750 RPM), 쌍권총은 `dual_fire`를 반복한다.
- **제작 판단 (사용자 검수 대기):**
  - 꺼내기·넣기·사격 중에는 이동 입력을 받지 않고 감속해 선다. 동작 중에는 다른 무기 키를 무시한다.
  - 소총을 든 상태에는 달리기 동작이 없어 Shift를 무시하고, 걷기는 ‘이동 사격’(`shoot_rifle`)을 쓴다.
  - 무장 걷기·달리기는 시간 기준으로 재생한다(속도에 비례). 발 미끄러짐은 측정하지 않았다.
  - 사격 후에는 소총 대기(낮춘 자세)로 바로 돌아간다. 조준 자세에서 낮춘 자세로 넘어갈 때 그림이 끊긴다.
  - 총구 화염·소리·탄약·장전 키는 없다.
- **확인:** 내장 브라우저에서 키 이벤트로 확인했다. 1→꺼내기→소총 대기, A 단발, S 풀오토, 2(소총 넣기→쌍권총 꺼내기), 쌍권총 걷기·달리기·단발, X 넣기·다시 꺼내기(마지막 무기)의 상태 전환이 맞고, 라이브러리 iframe 진입도 된다. 동작감은 사용자 검수 대기다.

## 001: 좌우 이동 (2026-11-12)

2026-11-12 사용자 요청(“방향키로 좌우로 움직이는 간단한 프로토타입”)으로 만든 독립 페이지다. 처음 주소는 `/prototype/move/index.html`이었다.

- **조작:** ← → 이동, Shift를 누른 채 달리기, 키를 떼면 감속 후 대기. 화면 오른쪽 위에서 캐릭터를 고른다.
- **그림 (001 당시):** 각 캐릭터 GLB에서 이미 렌더한 우측면 스프라이트(`glb_model_001/sprite_003`(리안)·`sprite_001`(나머지)의 `idle`·`walk`·`run`, 200px/단위, 12fps, 제자리)를 그대로 그렸다. 왼쪽은 좌우 반전이다. 페이지는 렌더·생성을 하지 않는다.
- **단위:** 1.0 = 캐릭터 키(약 1.65m). 화면 높이에 3.2단위가 보인다.
- **속도:** 리안 `version04.glb`의 제자리 걷기·달리기에서 딛고 있는 발이 뒤로 미끄러지는 속도를 재서 정했다. 걷기 0.69단위/s(약 1.14m/s), 달리기 2.25단위/s(약 3.71m/s)다.
  - 맨손 걷기·달리기 프레임은 시간 대신 **이동 거리**로 넘겨 가속·감속 중에도 발이 미끄러지지 않게 한다.
  - 가속 6, 감속 9단위/s²이고, 1.3단위/s를 넘으면 달리기 그림이다.
- **무대:** 평지 ±12단위(약 ±20m) 안에서 움직이고 끝에 빨간 표시가 있다. 뒤 건물 두 겹은 시차로 움직여 이동감을 준다. 카메라는 캐릭터를 부드럽게 따라간다.
- **확인 (001):** 내장 브라우저에서 걷기·달리기·왼쪽 이동·정지 상태 전환과 속도 표시, 다섯 캐릭터 불러오기, 콘솔 오류 없음을 확인했다. 다른 캐릭터의 걷기·달리기 속도는 리안 값을 그대로 써서 발이 조금 미끄러질 수 있다.
- **라이브러리 진입:** 2026-11-13 사용자 요청(“라이브러리 페이지에서 접근할 수 있도록 해줘. 탭은 js-prototype으로”, 이어서 “캐릭터 탭에 추가하지 말고 왼쪽 사이드 바에 추가해”)으로 샘플 라이브러리 왼쪽 사이드바 맨 아래에 `js-prototype` 묶음을 추가했다. 주소는 `#/prototypes/move`이고, 캐릭터 페이지 대신 이 페이지를 iframe으로 띄운다. 다른 항목으로 옮기면 iframe을 비운다. 새 프로토타입은 `game/app.js`의 `jsPrototypes` 표에 추가한다.
