# 이동 프로토타입 001

2026-11-12 사용자 요청(“방향키로 좌우로 움직이는 간단한 프로토타입”)으로 만든 독립 페이지다. 주소: `http://127.0.0.1:4173/prototype/move/index.html` (`?c=clone_01|iren|moa|yuna|sena`).

- **조작:** ← → 이동, Shift를 누른 채 달리기, 키를 떼면 감속 후 대기. 화면 오른쪽 위에서 캐릭터를 고른다.
- **그림:** 각 캐릭터 GLB에서 이미 렌더한 우측면 스프라이트(`glb_model_001/sprite_003`(리안)·`sprite_001`(나머지)의 `idle`·`walk`·`run`, 200px/단위, 12fps, 제자리)를 그대로 그린다. 왼쪽은 좌우 반전이다. 페이지는 렌더·생성을 하지 않는다.
- **단위:** 1.0 = 캐릭터 키(약 1.65m). 화면 높이에 3.2단위가 보인다.
- **속도:** 리안 `version04.glb`의 제자리 걷기·달리기에서 딛고 있는 발이 뒤로 미끄러지는 속도를 재서 걷기 0.69단위/s(약 1.14m/s), 달리기 2.25단위/s(약 3.71m/s)로 정했다. 걷기·달리기 프레임은 시간 대신 **이동 거리**로 넘겨 가속·감속 중에도 발이 미끄러지지 않게 한다. 가속 6, 감속 9단위/s², 1.3단위/s를 넘으면 달리기 그림.
- **무대:** 평지 ±12단위(약 ±20m) 안에서 움직이고 끝에 빨간 표시가 있다. 뒤 건물 두 겹은 시차로 움직여 이동감을 준다. 카메라는 캐릭터를 부드럽게 따라간다.
- **확인:** 내장 브라우저에서 걷기·달리기·왼쪽 이동·정지 상태 전환과 속도 표시, 다섯 캐릭터 불러오기, 콘솔 오류 없음을 확인했다. 다른 캐릭터의 걷기·달리기 속도는 리안 값을 그대로 써서 발이 조금 미끄러질 수 있다. 점프·앉기·사격·충돌·전환 동작(멈춤·방향 전환 애니메이션)은 없다. 동작감은 사용자 검수 대기다.
