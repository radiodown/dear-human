# 소대원 일러스트 003 · 동아시아계 인상

> 사용자가 얼굴의 미모와 헤어를 반려해 [004](../squad_illustration_004/README.md)에서 얼굴·머리를 새로 디자인한다. 아래는 이전 시도의 입력·결과 기록이다.

사용자는 002의 얼굴이 너무 서양인처럼 보인다고 평가했다. 최신 003은 **네 명 모두 동아시아계 얼굴 인상**으로 수정하고, **25~26세 외형·신형 근미래 화기·병과별 제복·돌격 이렌만 가터벨트**라는 기존 방향을 유지한다.

| 인물 | 유지할 병과·제복 | 얼굴 표현 방향 |
|---|---|---|
| 세나 | 저격·관측 / 은회색 낮은 포니테일·경량 장갑·정찰 망토·바지 | 차분한 눈매와 부드럽게 좁아지는 타원형 윤곽 |
| 모아 | 지원화기 / 적갈색 땋은 머리·하중 지지 장비·바지 | 젊은 볼 윤곽과 편안한 눈매·작은 미소 |
| 유나 | 방패·진입 / 밝은 금발 보브·전면 방호·바지 | 짧고 부드러운 타원형 윤곽과 또렷한 눈매 |
| 이렌 | 돌격 / 짧은 짙은 갈색 머리·장갑 하의·가터벨트·스타킹 | 절제된 눈빛과 부드러운 젊은 얼굴·각성 후 경험과 외형 나이 구분 |

리안의 채택 원화는 공통 화풍과 동아시아계 인상의 참고다. 네 명의 얼굴은 서로 다른 인물로 제작하며 리안과 같은 유전 원형이라고 확정하지 않는다. 인종적 인상은 아트 방향이며 작중 국적·혈통·생산권의 새 설정을 뜻하지 않는다. 얼굴·머리·성격과 세부 장비는 사용자 검수 대기다.
