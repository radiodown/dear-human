# 소대원 콘셉트·일러스트 002

001의 노화된 인상과 구식 화기를 사용자가 반려해 다시 제작하는 시안이다. **네 명 모두 외형상 25~26세**, **신형 근미래 화기**, **가터벨트는 돌격 이렌에게만** 적용한다. 나머지 세 명은 병과에 맞는 바지형 제복이다. 이렌의 약 7년 활동 기간과 친구의 사망 이력은 유지하며 외모의 노화로 표현하지 않는다.

| 인물 | 콘셉트·제복 | 장비 | 가터벨트 |
|---|---|---|---|
| 세나 | 은회색 낮은 포니테일·가벼운 정찰 망토·슬림한 전술 바지·경량 장갑 | 신형 정밀 사격 소총·광학 장비 | 없음 |
| 모아 | 적갈색 땋은 머리·하중 지지 하네스·강화 어깨·튼튼한 전술 바지 | 신형 지원화기·밀폐형 탄약 모듈 | 없음 |
| 유나 | 밝은 금발 보브·전완과 흉부 방호·짧은 망토·방호 바지 | 각진 복합재 물리적 방패·신형 보조 화기 | 없음 |
| 이렌 | 짧은 짙은 갈색 머리·분절 돌격 장갑·짧은 장갑 하의·스타킹 | 신형 돌격 소총 | 허리에서 스타킹으로 이어지는 가터 스트랩 |

검정·건메탈과 절제된 금장, 현실적인 애니메이션 인물 비례와 시네마틱 3D 렌더 질감은 리안과 공유한다. 얼굴은 젊은 성인으로 만들고 과도한 흠집·녹·금장 장식을 줄인다. 역할·나이 방향·이렌의 서사를 제외한 얼굴·머리·성격·세부 장비는 사용자 검수 대기다.
