# 유나 · 밝은 금발·채택 얼굴 전신 008

사용자가 [밝은 금발 얼굴 샘플 008](../face_blonde_sample_008/source/portrait.png)을 채택하고 “이걸로 전부 변경해서 다시 생성”하도록 지시했다.

- [전신 원본](source/illustration.png): 기존 전신 006을 편집 대상으로 사용해 채택한 새 얼굴·밝은 금발·피부 표현을 적용했다. 전투복·물리 방패·권총·자세·전신 구도는 시각적으로 유지한다.
- [얼굴 아이콘 원본](source/icon.png): 채택 초상을 정사각형으로 파생한 별도 생성본. 위키 공통 인물 둘러보기·Last Card 구성원 표시에서도 재사용한다.
- 내장 image_gen 2회(전신 1회·아이콘 1회). 원본은 바이트 변경 없이 보존하며 정확한 영어 입력은 [전신](records/prompt.md)·[아이콘](records/icon-prompt.md), 시간·해시는 [생성 기록](records/generation.json)에 저장한다.
- 얼굴·금발 방향은 사용자 채택이다. 새 전신과 아이콘의 얼굴 일치도·장비 세부는 사용자 검수 대기이며 의상 밖/안 픽셀 동일성을 보장하지 않는다.
- 기존 006·흑발 아이콘·중단된 007·과거 원화와 생성 기록은 이전 버전으로 보존한다. 기존 모션·게임 구현·다른 인물은 변경하지 않는다.
- 이미지 출력 직접 확인과 파일 크기·해시 기록만 수행한다. 브라우저·전체 게임 테스트는 실행하지 않았다.
