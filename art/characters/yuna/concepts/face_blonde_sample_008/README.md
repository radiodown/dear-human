# 유나 · 밝은 금발·얼굴 재설계 샘플 008

후속 사용자 지시로 이 샘플의 금발·얼굴 방향이 채택됐다. [전신·아이콘 008](../illustration_008/README.md)에 적용했으며 아래 내용은 샘플 제작 당시의 기록이다.

사용자 요청: 미국인으로 변경한 유나의 외형도 수정한다. 현재 분위기를 유지하면서 밝은 금발과 전면 수정한 얼굴의 샘플을 먼저 제작한다. 백발 요청은 사용자의 밝은 금발 정정으로 대체됐다.

- [최종 검토 샘플](source/portrait.png): 밝은 금발 반묶음, 따뜻한 피부·갸루 메이크업 분위기와 방호복 컨셉을 유지하며 얼굴형·눈·코·입과 미소를 재설계한 상반신 초상.
- [첫 시도](source/first-pass.png): 기존 얼굴 인상이 많이 남아 얼굴 재설계를 강조한 두 번째 생성을 진행했다. 두 출력 모두 원본 바이트 그대로 보존한다.
- 내장 image_gen 2회. 얼굴의 변경 정도·미감은 사용자 검수 대기이며 기존 전신 006과 위키 아이콘을 교체하지 않는다. 이 샘플로 혈통·출생지·성격을 새로 확정하지 않는다.
- [첫 영어 입력](records/prompt.md) · [얼굴 수정 영어 입력](records/prompt-face-revision.md) · [생성 시간·해시](records/generation.json).
- 공통 미리보기: `http://127.0.0.1:4173/#/samples/characters/yuna?rev=face_blonde_sample_008`.
- 출력 이미지를 직접 확인하고 크기·해시를 기록했다. 브라우저·전체 검사·게임 테스트는 실행하지 않았다. 전신 적용·모션 제작은 없다.
