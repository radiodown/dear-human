# 유나 · 전신 일러스트 006

사용자가 [얼굴 샘플 006](../face_gyaru_sample_006/source/portrait.png)의 약간 까무잡잡한 갸루 얼굴을 채택하고 전신 적용을 지시했다.

- [전신 원본](source/illustration.png): 기존 전신 005를 편집 대상으로, 채택 초상을 얼굴 참조로 사용한 내장 image_gen 전신 편집 1회.
- 기존 흑발 반묶음·방호복·바지·권총·방패·자세·전신 구도를 시각적으로 유지하며, 피부색과 눈매·메이크업·입술·얼굴 옆 점을 참조 초상에 맞췄다. 의상과 장비의 픽셀 동일성은 보장하지 않는다.
- 얼굴 방향은 사용자 채택, 새 전신의 세부 일치도는 확인 대기다. 다른 인물이나 기존 게임·모션을 변경하지 않는다.
- 위키 `yuna`의 현재 전신과 얼굴 아이콘, 공통 미리보기의 `illustration_006`에 반영한다. 얼굴 아이콘은 채택 초상에서 정사각형으로 파생한 내장 image_gen 편집 1회를 추가 사용했으며, [아이콘 원본](source/icon.png)과 [입력](records/icon-prompt.json)·[생성 기록](records/icon-generation.json)을 보존한다. 이전 원화와 아이콘은 보존한다.
