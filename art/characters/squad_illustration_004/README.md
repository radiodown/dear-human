# 소대원 일러스트 004 · 미모와 새 헤어 디자인

사용자가 003의 얼굴과 머리스타일을 반려해, 네 명의 얼굴·머리를 새로 디자인한다. **25~26세 미모의 아시아계 성인 여성**이라는 방향을 사용하며 기존 신형 화기·병과별 제복·이렌만 가터벨트인 구성은 유지한다.

| 인물 | 미인상 | 새 헤어 시안 |
|---|---|---|
| 세나 | 차갑고 청초한 미인 | 애쉬브라운 긴 생머리 반묶음·얇은 시스루뱅 |
| 모아 | 따뜻하고 화사한 미인 | 다크브라운 긴 웨이브·자연스러운 사이드 가르마 |
| 유나 | 산뜻하고 또렷한 미인 | 윤기나는 흑발 하이 포니테일·깔끔한 이마와 가는 옆머리 |
| 이렌 | 단아하고 세련된 미인 | 윤기나는 흑발 쇄골 길이 레이어드 컷·옆으로 넘긴 앞머리 |

얼굴은 기존 얼굴을 보존하지 않고 리안의 채택 원화와 어울리는 고급 게임 주연급 미모를 목표로 새로 설계한다. 맑고 표현력 있는 눈매·조화로운 이목구비·부드러운 윤곽·젊은 피부를 사용하며, 굳은 인상·노화·지나친 각짐을 피한다. 머리색과 스타일도 각 인물의 새 시안으로 구분한다. 특정 실존 인물을 모사하지 않는다.

외형의 최종 미감과 채택 여부는 **사용자 검수 대기**다. 이렌의 각성 후 약 7년 활동 기간과 기존 친구·전임 지휘관 사망 이력은 유지하며, 미인상은 성격·새 혈통·생산권을 확정하는 설정이 아니다.
