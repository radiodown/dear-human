## 보정

- 정수리 뼈: 머리 꼭대기 1.00m보다 `mixamorig:HeadTop_End` 끝이 1.123m(`Head` 끝 1.012m)로 약 12cm 나와 있었다. 아렌과 같은 방법으로 `Head`의 시작점·방향(쉬는 자세 회전)은 그대로 두고 `Head` 0.900→0.947m, `HeadTop_End` 0.947→0.995m로 같은 길이로 나눴다(glTF가 끝 뼈 길이를 저장하지 않아 다시 불러와도 머리 안에 남도록). `HeadTop_End`는 가중치 0이다.
- 가슴: 가슴판 정점의 가중치가 아래쪽은 골반(`Hips`)·허리(`Spine`) 약 30%, 위쪽은 어깨(`Shoulder`) 50% 이상이라 팔을 들면 가슴판이 팔 쪽으로 끌려 올라가 찌그러지고(달리기 12프레임), 팔을 모으면 양쪽 가슴판이 안으로 눌렸다(겁먹음 20프레임). 가슴 앞면(높이 0.70~0.81m, 좌우 ±0.085m 안, 몸 앞쪽 절반) 정점 1,042개(완전 적용 481개)를 흉곽 뼈로 바꿨다: 아래쪽 `Spine1`·`Spine2` 반반 → 위쪽 `Spine2` 85%·`Spine1` 15%. 겨드랑이·위아래·뒤쪽 경계 2cm는 원래 가중치와 섞어 이음매가 없다.
- 확인(원본과 다시 불러온 보정본 비교): 가슴판이 `Spine2` 기준으로 밀리는 최대/평균 거리 다이브 54.6/7.1→10.8/2.2mm, 겁먹음 42.8/11.2→23.8/6.2mm, 달리기 23.1/7.5→10.6/3.4mm, 걷기 8.6/2.0→3.5/1.0mm. 가슴 밖 정점은 네 동작 모든 프레임에서 변화 0.006mm 이하. 가슴 확대 전후 렌더로 겁먹음·달리기의 찌그러짐 감소를 눈으로 확인했다. 남은 움직임은 아래 가슴이 허리 굽힘을 따르는 정도이며 딱딱함·자연스러움은 사용자 검수 대기다. Blender에서 보이는 `Icosphere`는 가져오기 도구의 뼈 표시용이다.

## 3D 탭 (‘GLB 모델’)

- `game/glb-model-lab.js`의 `MODELS.moa`가 이 GLB를 Three.js로 재생한다. 리안·아렌과 같은 오른쪽 옆 정사영 카메라(화면 높이 1.3·시점 0.5), ‘제자리’, 속도·좌우 반전. 탭 이름은 걷기·달리기·다이브·겁먹음. 내장 브라우저에서 모아 페이지 표시·네 동작 재생만 확인했다.

## 대기·사격 동작 추가 (2026-11-11)

- 사용자 지시: “wait라는 glb 파일 … 대기 모션이 2개 있어. 이것들을 각 캐릭터들에 추가할 수 있어?” → “shoot에 gunmotion 넣었어 … 4가지 모션 적용되는지 확인해주고 적용된다면 페이지에 추가해줘”(Mixamo FBX, 방식 A).
- 원본: `shoot/wait.glb`(유나 모델·리그, `idle.001` 369프레임 15.3초·`wait.001` 145프레임 6.0초, SHA-256 `8f8c1427ff270df7…`)와 `shoot/gunmotion/`의 Mixamo FBX 4개(메시 없음·Mixamo 표준 캐릭터·T 포즈·30fps·뼈 이름 `mixamorig11:`·cm 단위): `Female Peek And Aim.fbx`(2.6초, `50a289f1…`)·`Gunplay.fbx`(0.57초, `47884699…`)·`Gunplay_auto.fbx`(0.2초, `fcb91c0e…`)·`Shoot Rifle.fbx`(0.93초·골반 1.78m 전진, `1ac2f33a…`).
- 방법: 캐릭터마다 기본 자세가 달라(유나 A 포즈 73°, 다른 대원·리안 거의 T 포즈 6~10°, Mixamo 원본 T 포즈) 키 값 복사로는 팔이 60° 넘게 어긋난다. 뼈마다 원본 뼈의 공간 방향을 따르도록 `T = S·Rs⁻¹·A·Rt`(S 원본 자세, Rs/Rt 원본/대상 기본 자세, A 대상→원본 기본 자세 뼈 방향의 최단 회전)로 옮기고, 골반 이동은 골반 높이 비율(사격 동작은 약 0.60~0.63)로 줄였다. 사격 동작은 24fps로 다시 뽑았다. 도구는 [`tools/glb_retarget/retarget_glb_clips.py`](../../../../../tools/glb_retarget/retarget_glb_clips.py)(GLB 원본)와 [`retarget_mixamo_fbx.py`](../../../../../tools/glb_retarget/retarget_mixamo_fbx.py)(FBX 원본, 뼈 이름 앞부분 무시).
- 바닥: 대기 동작은 원본 유나의 동작별 가장 낮은 지점(중앙값 0.5mm / −3.0mm)에 맞춰 골반 높이를 일정하게 올렸고, 메시가 없는 사격 원본은 대상 메시의 동작별 가장 낮은 지점 중앙값을 0에 맞췄다(결과 ±3.5mm 이내).
- 결과 파일: `shoot/moa_rig_wait.glb`(대기 2개 추가) → `shoot/moa_rig_gun.glb`(사격 4개 추가)이며, 이 폴더의 `source/moa_rig.glb`를 `_gun` 내용으로 교체했다(이전 내용은 git 기록). 기존 동작은 다시 불러와 비교한 메시 차이 0.0071mm 이하로 그대로다.
- 3D 탭 이름: `idle.001` 대기 1 · `wait.001` 대기 2 · `peek_aim` 엄폐 조준(원본처럼 등을 돌린 채 시작해 몸을 돌려 조준하고 돌아옴) · `gunplay` 조준 사격 · `gunplay_auto` 연사(0.2초 반복) · `shoot_rifle` 이동 사격(앞으로 이동, 탭의 ‘제자리’로 고정). 사격 동작에는 아직 총이 없고 손 모양만 있다.
- sprite_001 스프라이트: 대기 1(`idle`, 185장, 200px/m 프레임 49×206, WebP `52ba6480…`)·대기 2(`wait`, 73장, 56×202, `4dca46e5…`)를 200·100px/m로 추가했다(12fps, 제자리). 사격 동작 스프라이트는 총을 붙인 뒤 렌더하려고 아직 만들지 않았다.
- 대기 동작 렌더 다섯 명 합계 약 29분, 비용 없음. 다섯 명·원본의 같은 프레임 렌더 대조, 탭 표시·재생만 확인했고 동작은 사용자 검수 대기다.
