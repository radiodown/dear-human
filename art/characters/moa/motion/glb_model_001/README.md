## 보정

- 정수리 뼈: 머리 꼭대기 1.00m보다 `mixamorig:HeadTop_End` 끝이 1.123m(`Head` 끝 1.012m)로 약 12cm 나와 있었다. 아렌과 같은 방법으로 `Head`의 시작점·방향(쉬는 자세 회전)은 그대로 두고 `Head` 0.900→0.947m, `HeadTop_End` 0.947→0.995m로 같은 길이로 나눴다(glTF가 끝 뼈 길이를 저장하지 않아 다시 불러와도 머리 안에 남도록). `HeadTop_End`는 가중치 0이다.
- 가슴: 가슴판 정점의 가중치가 아래쪽은 골반(`Hips`)·허리(`Spine`) 약 30%, 위쪽은 어깨(`Shoulder`) 50% 이상이라 팔을 들면 가슴판이 팔 쪽으로 끌려 올라가 찌그러지고(달리기 12프레임), 팔을 모으면 양쪽 가슴판이 안으로 눌렸다(겁먹음 20프레임). 가슴 앞면(높이 0.70~0.81m, 좌우 ±0.085m 안, 몸 앞쪽 절반) 정점 1,042개(완전 적용 481개)를 흉곽 뼈로 바꿨다: 아래쪽 `Spine1`·`Spine2` 반반 → 위쪽 `Spine2` 85%·`Spine1` 15%. 겨드랑이·위아래·뒤쪽 경계 2cm는 원래 가중치와 섞어 이음매가 없다.
- 확인(원본과 다시 불러온 보정본 비교): 가슴판이 `Spine2` 기준으로 밀리는 최대/평균 거리 다이브 54.6/7.1→10.8/2.2mm, 겁먹음 42.8/11.2→23.8/6.2mm, 달리기 23.1/7.5→10.6/3.4mm, 걷기 8.6/2.0→3.5/1.0mm. 가슴 밖 정점은 네 동작 모든 프레임에서 변화 0.006mm 이하. 가슴 확대 전후 렌더로 겁먹음·달리기의 찌그러짐 감소를 눈으로 확인했다. 남은 움직임은 아래 가슴이 허리 굽힘을 따르는 정도이며 딱딱함·자연스러움은 사용자 검수 대기다.
