# 모아 · 얼굴·헤어 확대 샘플 007

[최신 샘플](source/portrait.png) · [헤어 수정 전](source/previous-hair.png) · [얼굴 프롬프트](records/prompt.md) · [헤어 프롬프트](records/prompt-modern-hair.md) · [생성 기록](records/generation.json).

사용자가 006의 얼굴이 나이 들어 보이고, 새 확대 샘플의 헤어도 할머니 같다고 지적해 얼굴과 헤어를 차례로 수정했다. 백발·푸른 눈·러시아계 인상은 사용자 지정이다. 볼의 볼륨과 부드러운 턱선을 둔 새 얼굴, 옆 볼륨을 줄인 직선적 생머리 중단발과 얇은 시스루뱅은 사용자가 채택했다.

내장 image_gen 얼굴 재설계 1회·헤어 국소 편집 1회. 원본은 바이트 변경 없이 보존한다. 사용자 지시에 따라 [전신 007](../illustration_007/README.md)에 얼굴·헤어를 적용했으며, 위키 얼굴 아이콘은 이 정사각형 초상을 그대로 사용한다. 얼굴·헤어 방향은 채택됐고 새 전신의 세부 일치도는 확인 대기다. 유나·아렌·세나·리안·모션·게임은 유지한다.
