# 모아 · 앞뒤좌우 전신 002

사용자 요청으로 현재 외형을 정면·후면·좌측면·우측면에 적용했다. 리안과 기존 원화·모션·게임은 보존한다.

- [정면](source/front.png) · [후면](source/back.png) · [좌측면](source/left.png) · [우측면](source/right.png).
- 최신 얼굴·헤어와 기존 복장·중립 자세를 참조해 각 방향을 내장 image_gen으로 생성했다.
- 첫 후면·양측면에 잘못 생긴 긴 망토는 별도 편집으로 제거하고 초안을 보존한다.
- 좌·우는 화면에서 바라보는 방향이다. 얼굴·장식·파우치·체형과 방향별 세부 일치도는 사용자 검수 대기다. 정확한 3D 회전·동일한 투영이나 픽셀 일치를 보장하지 않는다.
- [실제 생성·입력/출력 해시](records/generation.json)와 `records/prompt_*.json`·`records/prompt_*.md`에 정확한 입력을 보존한다. 비용과 정확한 모델 식별자는 도구가 제공하지 않아 미기록이다.
- [표시 검수 기록](reviews/verification.json).
- 위키 프로필·방향별 갤러리에 적용하고 공통 미리보기 `http://127.0.0.1:4173/#/samples/characters/moa?rev=turnaround_002`에서 전체·개별 방향을 본다.
