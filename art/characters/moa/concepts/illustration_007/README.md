# 모아 · 채택 얼굴·헤어 적용 전신 007

사용자가 [얼굴·헤어 확대 샘플 007](../face_redesign_007/source/portrait.png)을 채택해 전신에 적용했다. 백발·푸른 눈·러시아계 인상, 젊고 부드러운 얼굴, 직선적인 생머리 중단발과 얇은 시스루뱅을 사용한다.

[전신 원본](source/illustration.png) · [정확한 영어 프롬프트](records/prompt.md) · [도구 입력](records/prompt.json) · [생성 시각·해시](records/generation.json).

기존 006의 전신·장비를 편집 대상으로, 채택 초상을 얼굴과 헤어의 기준으로 사용한 내장 image_gen 편집 1회다. 원본은 바이트 변경 없이 보존하며 의상·장비의 픽셀 동일성은 보장하지 않는다. 얼굴·헤어 방향은 사용자 채택, 새 전신의 세부 일치도는 확인 대기다.

위키의 모아 전신은 007로, 얼굴 아이콘은 채택한 정사각형 초상 원본으로 갱신한다. 이전 004~006과 icons-001 기록·이미지는 보존한다. 다른 대원·모션·게임은 변경하지 않는다. 러시아계 인상만으로 작중 국적·혈통을 새로 확정하지 않는다.
