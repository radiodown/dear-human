# Dear Human Wiki

유나의 현재 전신은 `yuna-illustration-006.png`이며, 얼굴 아이콘은 채택 갸루 초상에서 파생한 정사각형 `yuna-icon-006.png`다. 다른 네 명의 위키 아이콘은 001을 유지한다. 유나의 005와 기존 icons-001 원본·기록은 이전 버전으로 보존한다.

소대와 구성원은 `#/article/last-card`에서 열람한다. **Last Card는 정식 소대명이 아닌 별명**이다. 전투 비용이 크게 들거나 일반 부대로 수행할 수 없는 임무에 투입된다. 기존 강화 클론 특수작전 소대와 같은 부대이며 정식 이름은 미정이다. 이전 `#/article/lumen-platoon` 주소는 새 문서로 이동한다. 소대 정보표와 인간 지휘관·아렌·세나·모아·유나·리안 6명의 바로가기를 제공한다. 전체 정원·하위 편제는 미정이다. 개별 인물 문서의 공통 둘러보기는 현재 대원을 강조하며 원래 프로필·전신 원화·장비 갤러리를 유지한다.

머리말의 `unit`은 소대 정보와 `members`의 `article`, `role`, `description`을 선언한다. `unitPage`는 소대 문서 연결, `avatar`는 아이콘의 `src`, `alt`, `width`, `height`다. 인물 목록은 소대 문서에서 한 번 정의하며, 공개 문서에서 제작자 전용 인물을 노출하지 않도록 검사한다. 지휘관은 외형 미정이므로 추상 표식으로 표시한다.

클론 5명의 위키 아이콘 001은 최신 인물 원화를 참조한 내장 image_gen 파생 시안이며 사용자 검수 대기다. 표시용 이미지는 `public/assets/characters/icons-001/`, PNG 원본·참조 사본·영어 입력은 `content/media/squad-icons-001/`, 실제 생성 시각·SHA-256·참조·표시 경로는 `content/media/squad-icons-001.json`에 보존한다. 기존 원화의 채택 상태나 게임 에셋을 바꾸지 않는다.

무기 원화는 `#/article/clone-special-weapons`의 장비 갤러리와 각 무기 문서에서 본다. 문서 머리말의 `illustrations` 배열은 위키 내부 이미지의 `src`, `title`, `alt`, `caption`, `width`, `height`와 선택 항목 `article`을 사용한다. 이미지는 원본 비율로 표시하고 누르면 원본을 연다. 현재 목록과 해시·검수 상태는 `content/media/weapon-concepts-001.json`에 기록한다. 권총의 길이 조정과 유탄발사기의 근미래 외형 보완은 생성 도구 거부로 미완료다.

게임 미리보기와 독립적으로 실행하는 세계관 위키 프로젝트다. 기존 제작 docs를 바탕으로 **위키 전용 문서를 새로 집필**했다. docs를 웹에 그대로 표시하거나 자동 변환하지 않는다.

## 실행

Node.js 22 이상이 필요하며 설치할 외부 패키지는 없다.

```powershell
cd wiki
npm run dev
```

기본 주소: **http://127.0.0.1:4174**. 게임의 4173 포트와 분리돼 있다. `npm run start`도 같은 독립 서버를 실행한다. 서버 종료는 터미널에서 `Ctrl+C`를 사용한다.

다른 포트는 `npm run dev -- --port 4180`으로 지정한다. 외부 인터페이스에 바인딩할 때는 `HOST` 환경변수를 사용한다. 로컬 서버에는 별도의 인증 기능이 없으므로 기본값은 루프백이다.

## 구조

```text
wiki/
  content/
    articles/          위키용으로 새로 쓴 개별 Markdown 문서
    categories.json    분류와 소개
  public/              화면·스타일·검색·Markdown 표시
  scripts/             독립 서버·검사·정적 빌드
  .openai/hosting.json 별도 Sites 서비스 식별자와 배포 설정
  package.json         이 프로젝트의 실행 명령
```

실행·검사·빌드는 `wiki/` 안의 파일만 사용한다. 이 폴더를 별도 위치로 복사해도 동작하며 게임 서버와 기존 docs 파일은 필요하지 않다. 개발 서버는 요청할 때 위키 콘텐츠를 다시 읽으므로 문서 수정 후 새로고침하면 반영된다.

## 기능

2026-11-09 화면 개편: 나무위키의 문서 중심 구조를 참고한 상단 메뉴·검색, 밝은 문서 영역, 분류 상자와 오른쪽 탐색 패널을 사용한다. 사용자 요청으로 메인 색상은 우주 분위기의 딥 네이비(#172b4a)와 차가운 블루로 정리했다. 어두운 테마는 밤하늘 계열의 네이비 배경을 사용한다. 본문 목차는 글 앞에 놓이고 절에는 번호가 표시된다. 사이트의 이름과 문서는 Dear Human 고유 콘텐츠를 유지한다.

- 문서 제목·별칭·요약·본문 통합 검색과 검색 주소 복원
- 다섯 분류, 문서별 주소, 관련 문서와 역링크
- 개별 문서 사건 데이터를 연도별로 묶는 세로 타임라인과 시대별 필터. 날짜·사건명만 간단히 표시하고 사건을 클릭하면 관련 문서로 이동한다.
- 확정·보완안·미정의 구별, 개별 문서 안의 미정 사항 안내
- 기본 열람에서 비밀 문서를 제외하는 제작자 설정 전환
- 목차 이동, 주소 복사, 개별 Markdown 내려받기
- 인물 문서 첫머리의 목차와 우측 프로필 상자. 모바일에서는 목차 다음에 프로필을 표시한다. 프로필은 인물 문서에만 명시적으로 지정한다.
- 모바일 탐색 메뉴, 밝은/어두운 테마, 인쇄 스타일

제작자 설정은 **스포일러를 줄이기 위한 표시 기능**이다. 클라이언트 데이터와 배포 파일에 비밀 설정도 포함되므로 보안이나 권한 분리 기능으로 취급하지 않는다. 서비스 자체는 Sites의 소유자 전용으로 생성했다. 공개 전환 전에 별도 공개용 빌드가 필요하다면 비밀 문서를 빌드 산출물에서 제거하는 작업을 먼저 해야 한다.

## 위키 문서 편집

`content/articles/`에 독립 문서를 작성한다. 머리말 값은 JSON 문자열·배열 문법을 사용하는 제한된 front matter이며 본문은 Markdown이다.

```markdown
---
slug: "example"
title: "예시 문서"
category: "history"
summary: "이 문서가 설명하는 내용."
status: "보완안"
visibility: "reader"
updated: "2026-11-09"
aliases: ["별칭"]
sources: ["최초 집필 근거와 절"]
---
# 예시 문서

본문에서 [[ai-war]] 또는 [[ai-war|AI 전쟁]]처럼 연결한다.

## 설명

위키만 읽어도 이해할 수 있게 작성한다.
```

분류 ID는 `world`, `history`, `people`, `places`, `technology`다. 상태는 `확정`, `보완안`, `미정`이다. `visibility: "creator"`이면 기본 열람에서 숨긴다. 사건이 있는 문서는 머리말에 `events` 배열을 추가한다.

```json
[{"date":"2114-11-21","label":"베스퍼 도착","description":"본편 시작."}]
```

본문은 제목·단락·목록·인용·표·강조·코드·위키 링크를 지원한다. 임의 HTML과 스크립트는 실행하지 않는다. 일반 Markdown 외부 링크나 이미지는 이 첫 버전의 표시 문법에 포함하지 않는다. 제목 아래 목차와 역링크는 자동으로 만들어진다.

인물 문서는 머리말에 `profile`을 추가하면 오른쪽 신상표가 표시된다. `subtitle`, `description`, `note`와 `[항목명, 값]` 쌍의 `fields`를 사용한다. 아직 정하지 않은 정보는 `미정`으로 적으며 인물 분류의 관계·서사 문서에 프로필을 자동으로 붙이지 않는다.

인물 이미지는 머리말의 선택 항목 `portrait`에 `src`, `alt`, `caption`, `width`, `height`를 지정한다. `src`는 `public/` 아래의 `assets/` 경로이며 PNG·JPEG·WebP를 지원한다. 프로필 제목 아래에 비율을 유지해 표시하고 누르면 원본을 크게 연다. 히로인에는 채택 외형 원화를 수정 없이 복사했으며, 출처와 해시는 `content/media/heroine-appearance.json`에 기록했다. 게임의 원본 파일이나 서버를 실행 시 참조하지 않는다.

```json
{"subtitle":"인물의 역할","description":"간단한 인물 설명.","fields":[["이름","미정"],["소속","확정된 소속"]],"note":"정보의 기준 시점."}
```

## 설정의 근거와 갱신

최초 편찬의 주된 근거는 기존 `docs/15-worldbuilding.md`이며, 초기 적은 11번·채택 외형은 23번 문서를 보조 근거로 삼았다. 집필 근거는 개별 문서의 `sources`에 남긴다. 웹 서비스에서 기존 docs 경로를 여는 기능은 없으며, 원본 docs를 배포하거나 런타임에 읽지 않는다.

설정이 바뀌면 해당 위키 문서와 관련 문서를 명시적으로 편집한다. docs와 위키 사이에 자동 동기화나 자동 덮어쓰기는 없다. 개별 항목의 `status`는 중심 전제의 상태이며, 본문에서 이름·사건·세부 제도 등의 미정 사항을 따로 표시한다. 역사적 날짜와 작중 인물이 아는 정보, 플레이어에게 공개할 순서를 구분한다.

## 확인과 빌드

```powershell
npm run check
npm run build
```

검사는 문서 메타데이터, 분류, 내부 링크와 JS 구문을 확인한다. 빌드는 `public/`과 위키 콘텐츠만으로 `dist/`를 만들며 정적 호스팅에 사용할 수 있다. 게임 테스트나 이미지 생성은 실행하지 않는다. 빌드된 정적 파일의 직접 주소는 `/#/article/ai-war`처럼 해시 경로를 사용한다.
