# 모아 · 백발 생머리 중단발 006

최신은 [팔자주름 제거 수정본](source/illustration-no-folds.png)이다. [정확한 영어 입력](records/prompt-no-nasolabial-folds.md)과 [생성 기록](records/generation-no-folds.json)을 보존한다. 검토 주소는 `http://127.0.0.1:4173/#/samples/characters/moa?rev=illustration_006_no_folds`다.

사용자 지정: 백발·푸른 눈·러시아계 인상, 어깨에 닿는 스트레이트 중단발. 나이 들어 보인다는 후속 피드백에 따라 볼의 볼륨과 눈 밑·입가 명암을 정리해 25~26세 인상의 얼굴로 수정했다.

[최신 샘플](source/illustration.png) · [얼굴 보정 전](source/previous-face.png) · [얼굴 보정 영어 프롬프트](records/prompt-younger-face.md) · [처음 영어 프롬프트](records/prompt.md) · [생성 기록](records/generation.json).

기존 004를 대상으로 내장 image_gen 편집 1회, 얼굴 나이 인상 보정 1회. 원본은 바이트 변경 없이 보존한다. 원래 의상·지원화기·포즈·전신 구도를 시각적으로 유지하며 픽셀 동일성을 보장하지 않는다. 눈·헤어·얼굴 미감은 사용자 검수 대기다. 러시아계 인상은 외형 방향이며 국적·혈통을 새로 확정하지 않는다.

강한 애니풍 전환은 사용자 취소로 반영하지 않았다. 유나 006·아렌 005와 기존 모션·게임은 유지한다. 005는 취소된 백발 웨이브/애니풍 시도 기록이다. 이 버전은 별도 검토 샘플이며 위키의 기존 이미지·아이콘을 교체하지 않는다.
