## 보정

- 정수리 뼈: `mixamorig:HeadTop_End` 끝이 1.123m로 머리 꼭대기 1.00m보다 약 12cm 나와 있었다. 다른 대원과 같은 방법으로 `Head`의 시작점·방향은 그대로 두고 `Head` 0.900→0.947m, `HeadTop_End` 0.947→0.995m로 같은 길이로 나눴다. 다시 불러와 원본과 비교한 메시 차이는 네 동작 최대 0.003mm, 바뀐 뼈는 두 개뿐이다.
- 가슴: 앞면이 이미 `Spine1`/`Spine2`에 85% 이상 묶여 있고 동작 중 밀림도 작아(겁먹음 최대 30.8mm) 고치지 않았다.
- 어깨 망토: 달리기 옆모습에서 팔을 따라 늘어나 보였으나 가중치 측정이 팔 정점과 섞여 확정하지 못했고 수정하지 않았다.
- 앞머리·뺨 텍스처: Tripo가 정면 원화를 투영해 넓적한 앞머리 띠 위 가닥 사이에 피부색을, 뺨 피부 위에 머리카락 줄을 함께 구웠다. 자동 보정(피부색 부분 투명 처리 + 뺨 줄무늬 덮기)을 여러 번 시험했으나 뒤쪽 면에도 원화가 투영돼 있어 자국이 남아 적용하지 않았다. 사용자가 Blender 텍스처 페인트(복제 브러시 등)로 직접 고쳤다.

## 덧칠 결과 확인 (`sena_rig_painted.glb`)

- 칠하기 전(`sena_rig_fixed`)과 비교: 텍스처 4096² 중 0.39%(65,933텍셀)가 바뀌었고 함께 저장한 `shoot/sena_tex_painted.png`와 픽셀 단위로 같다. 뼈 65개 위치 동일, 네 동작 메시 차이 0.0mm, 내보내기에 `Icosphere`(Blender 가져오기의 뼈 표시용) 없음.
- 오른쪽 뺨 줄무늬와 얼굴 양옆 가닥의 분홍빛은 사라졌다. 남은 점: 왼쪽 볼(정면 기준 화면 왼쪽)에 복제 원본 무늬로 보이는 옅은 얼룩, 이마 위쪽 앞머리에 결이 엇갈린 격자 무늬. 사용자가 이대로 적용을 지시했다.
