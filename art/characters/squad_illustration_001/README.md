# 핵심 소대원 일러스트 001

> **사용자 반려.** 무기가 너무 구식이며 전체적으로 40세처럼 보인다는 평가로 [002](../squad_illustration_002/README.md)에서 외형 25~26세·신형 화기·병과별 제복으로 다시 제작한다. 최신 가터벨트 적용 대상은 이렌만이다. 아래는 변경 전 시도 기록이다.

세나·모아·유나·이렌의 콘셉트와 개별 전신 일러스트를 제작하는 첫 시안이다. 사용자 지정 역할과 기존 서사는 유지하며 머리·눈·체형·의상 변형·표정·성격 묘사는 검수 전 보완안이다.

리안의 채택 원화를 공통 화풍·제복 참고로만 사용한다. 새 얼굴과 실루엣을 가진 별개의 클론들이며, 리안의 외형이나 원본을 교체하지 않는다.

| 인물 | 확정 역할 | 외형·성격 시안 |
|---|---|---|
| 세나 | 저격 | 은회색 낮은 포니테일·회색 눈·가벼운 어깨 망토. 조용한 관찰과 절제된 호기심. |
| 모아 | 분대지원화기 | 적갈색 땋은 머리·탄탄한 체격·탄약 파우치와 경기관총. 동료의 상태와 보급을 세심하게 살핌. |
| 유나 | 방패·진입 | 밝은 금발 보브·짧은 망토·물리적 방패. 짧고 분명하게 말하며 주위를 살피는 태도. |
| 이렌 | 돌격·연장자 | 외형상 32세 기본안·짧은 짙은 갈색 머리·성숙한 얼굴·오래 관리한 장비. 절제된 보호 본능과 피로. |

이렌은 친구와 전임 지휘관을 잃었고 리안은 친구의 결원을 충원했다. 이를 새 사망 장면·고정된 적개심·전임자와의 연애로 확대하지 않는다. 다른 인물의 정확한 나이·공식 코드·생애 날짜와 총기 모델·방패 성능은 미정이다.

내장 image_gen을 인물당 한 번씩 사용한다. 영어 프롬프트 전문과 정확한 도구 입력은 각 인물 폴더의 `records/prompt.md`·`prompt.json`에 보관한다. 원본 PNG는 `source/illustration.png`, 생성 시각·파일 해시·크기와 검토 결과는 기록 파일에 남긴다. 실제 모델명·비용이 도구에서 제공되지 않으면 미공개로 기록한다.

정지 콘셉트 아트이며 모션·리그·전투 기능은 없다. 최종 외형은 사용자 검수 대기다.
