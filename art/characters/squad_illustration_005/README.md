# 이렌·유나 일러스트 005 · 얼굴과 헤어 수정

사용자가 두 인물의 얼굴과 헤어를 다시 요청해 이렌·유나만 수정한다. 세나·모아의 최신 원화는 004를 유지한다.

| 인물 | 헤어 방향 | 얼굴 방향 |
|---|---|---|
| 이렌 | 턱선 아래에서 반듯하게 끝나는 깔끔한 흑발 생머리 단발·정돈된 옆가르마 | 단아하고 세련된 25~26세 아시아계 미인상 |
| 유나 | 옆가르마를 준 긴 흑발 생머리 반묶음·낮게 정리한 윗머리 | 맑은 눈매와 화사한 표정의 25~26세 아시아계 미인상 |

이렌은 레이어드·웨이브를 줄이고 단정한 원랭스 단발로 바꾼다. 유나는 기존 하이 포니테일을 다른 실루엣으로 바꾸는 보완 시안이다. 두 인물 모두 얼굴 비례와 눈매·표정도 함께 수정한다. 구체적인 얼굴·헤어와 미감의 채택 여부는 사용자 검수 대기다.

기존 신형 근미래 장비·병과별 제복·전신 구도는 시각적으로 유지한다. 이렌만 장갑 하의와 가터벨트·스타킹을 착용하고 유나는 방호 바지와 물리적 방패를 유지한다. 나이·활동 기간·친구와 전임 지휘관의 사망·충원 서사는 바꾸지 않는다.
