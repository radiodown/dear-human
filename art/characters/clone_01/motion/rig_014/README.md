- [정확한 영어 JSON 프롬프트](records/prompt_support_hand_closed_grip.json) · [동일 제출문 MD](records/prompt_support_hand_closed_grip.md) · [실제 생성 기록](records/generation.json).

모델명과 비용은 도구가 반환하지 않아 null이다. 실제 호출은 28.487초였다. 원화 채택·손 크기·손목 연결·무기와의 겹침은 미검수다. 장전 손 3종은 별도 미제작 상태다.
