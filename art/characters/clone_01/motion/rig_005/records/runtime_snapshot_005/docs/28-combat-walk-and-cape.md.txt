# 28. 전투 보행·체중 이동·망토 보정 05

[문서 목록](../README.md) · 파츠 외형은 [26](26-side-parts-and-shoulder-contact.md)의 그림을 재사용한다. 사용자의 최신 지시에 따라 이번 작업은 **파츠 모션만** 수정했으며 플랜 B 모션은 변경하지 않았다. 같은 [캐릭터 페이지의 이동 사격](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=walk_fire)에서 재생한다.

## 보행에서 바꾼 부분

짧은 보폭, 높은 발 들기, 큰 수직 흔들림, 거의 수직인 몸통이 결합돼 종종걸음처럼 보였다. 하체를 더 빨리 반복하는 대신 한 걸음의 거리를 늘리고 체중을 낮게 싣도록 조정했다.

| 항목 | 보정 04 | 보정 05 |
|---|---:|---:|
| 양발 한 주기 | 1.08초 | 1.24초 |
| 분당 걸음 수 | 약 111 | 약 97 |
| 한 걸음 이동 거리 | 56.16 | 79.36 |
| 발 들기 높이 | 16 | 9 |
| 골반의 주기적 상하 폭 | 5.5 | 2.5 |
| 이동 사격의 자세 | 거의 직립 | 골반을 낮추고 상체를 앞으로 기울임 |

거리 단위는 리그 논리 픽셀이다. 접지한 발의 월드 이동을 상쇄하는 기존 계산과 발바닥 접촉, 앞쪽으로 굽는 무릎은 유지했다. 골반이 발 교대에 맞춰 앞뒤로 이동하며 착지 때 조금 낮아진다. 이동 사격의 측정된 골반 낮춤은 대기 대비 약 8.6~11.1, 몸통 전경은 약 8.2~9.3도다.

상체를 기울여도 총이 같은 각도로 아래를 향하지 않게 조준축을 분리했다. 개머리판 접점은 어깨를 따라 이동하고 양손 IK는 총의 두 손잡이에 붙는다. 사격 중 반동을 포함한 총구 시각 각도는 검사 구간에서 수평 기준 약 -0.33~0.73도였다. 단발·연사 입력에 맞춰 자세가 부드럽게 낮아졌다가 돌아온다.

이는 지지발과 자세 곡선으로 체중 이동을 표현한 절차적 애니메이션이다. 질량을 가진 전신 강체와 지면 반력을 푸는 물리 시뮬레이션이나 실제 모션캡처를 적용한 것은 아니다.

## 망토를 여러 장 만들 것인가

추가 그림은 **주름의 겹침과 안감 노출이 크게 바뀔 때** 도움이 된다. 이 캐릭터라면 정지형·뒤로 펼친 형태·안으로 접힌 형태의 3개를 먼저 준비하고, 어깨 고정점·길이·재질·금장 위치·캔버스를 맞추는 구성이 적절하다. 이 장수와 구성은 프로젝트용 제안이며 공식 도구의 필수 규칙은 아니다. 서로 다른 실루엣을 무조건 알파로 섞으면 잔상이 생길 수 있으므로 형태를 정렬한 뒤 변형과 교체 방식을 시험해야 한다.

공식 [Spine 메시 설명](https://en.esotericsoftware.com/spine-meshes)은 이미지에 메시를 만들고 정점을 변형하는 방식을, [이미지 시퀀스 설명](https://en.esotericsoftware.com/spine-regions#Sequence)은 같은 크기의 여러 이미지를 순서대로 쓰는 기능을 설명한다. 이번 구현은 이 두 표현 방식을 비교할 때 참고했으며 실제 런타임에 Spine을 연결한 것은 아니다.

이번에는 새 그림을 생성하지 않고 기존 망토의 움직임부터 보정했다. 이전에는 보행 중에도 작은 일정 변위만 남아 거의 고정된 형태였다. 현재 `game/animation/cape.js`는 길이가 고정된 10개 구간을 계산하고 위쪽 2개 구간을 고정한다. 아래쪽은 이동 속도와 걸음 위상, 작은 반동에 감쇠 각도 스프링으로 반응한다. 각 구간의 반응 속도가 달라 자락에 지연이 생긴다. 이동을 멈추면 뒤로 끌린 형태가 즉시 직립으로 바뀌지 않고 가라앉는다.

망토 메시의 중심선 길이를 유지해 자락을 옆으로 당길 때 수직으로 늘어나는 현상을 줄였다. 고정 속도의 보행에서도 자락은 계속 움직인다. 현재 시험의 자락 수평 변위 범위는 망토 로컬 좌표 약 -49.3~-41.8이다. 어깨 이동을 제외한 값이다. 주름 뒤집힘·안감·신체 충돌·월드 방향 전환의 천 관성까지 푸는 시스템은 아니다. 추가 망토 이미지는 미제작 상태다.

## 검증과 산출물

- [새 리그와 기록](../art/characters/clone_01/motion/rig_005/README.md): 원본 이미지 재사용, 배치 정의, 보행 레시피, 검토 기록.
- [시뮬레이션 결과](../art/characters/clone_01/motion/rig_005/tests/simulation-metrics.json): 기존 검사와 전투 자세·망토 검사를 포함해 17개 통과.
- [브라우저 입력 확인](../art/characters/clone_01/motion/rig_005/reviews/browser-interactions.json): 재생/일시정지, 실제 연사 탄약 변화, 정지 전환과 좌우 반전 확인. 일시정지한 캔버스는 두 번 캡처해 동일함을 확인했다.

내장 브라우저 연결 오류에 대한 대체 경로로 로컬 Chrome과 Python Playwright를 사용했다. CSP 우회 없이 같은 앱을 열었다. 새 보행·망토의 전체 예술적 품질과 사용자 채택은 별도이며 수치 검사만으로 자연스럽다고 판정하지 않는다. GIF와 새 캐릭터·망토 이미지는 생성하지 않았다.

```powershell
npm --prefix game run check
npm --prefix game test
python -X utf8 tools/agent_pipeline.py --root . docs-check
python -X utf8 tools/agent_pipeline.py --root . catalog-check
```

새 수치는 rig_005/tests에 저장한다. rig_004의 당시 수치와 코드 스냅샷은 보존한다. 게임 1스테이지·도구 최종 선정·세부 갑옷 교체 범위는 이번 변경에 포함하지 않는다.
