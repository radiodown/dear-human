# 플랜 D · 로컬 3D

사용자 요청에 따라 웹 플랜 A/B/C와 분리한 네이티브 개발 경로다. 실행 코드는 [native/plan-d](../../../../../native/plan-d/README.md)에 있다.

- [architecture_002](architecture_002/README.md): 현재 공통 이동 코어·플랫폼/렌더러 인터페이스·Metal/D3D12 설정 분리. SDL 없는 코어 빌드와 최소 이동 검사·기존과 동일한 Mac 화면을 확인했다. 실제 Windows 실행은 미확인이다.
- [preparation_001](preparation_001/README.md): 환경 구축 → 21개 관절 뼈대 → 기본 도형 렌더링. macOS Metal의 세 화면을 짧게 실행·캡처했다. 중립 마네킹이며 채택 캐릭터 외형·완성 모션은 아니다.

새 시도와 후속 렌더 피드백은 새 버전 폴더에 보존한다. 기존 A/B/C·캐릭터 원화·파츠·검수 기록은 덮어쓰지 않는다.
