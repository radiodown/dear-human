# 정지 떨림 보정 / 보행 찰랑거림 001

2026-11-07. 사용자: “머리가 왜 가만히 있질못해?”, “걸을때 자연스러운 찰랑거림이 목표임”.

바람 기본값을 OFF로 바꿨다. U 또는 --wind로 명시적으로 켤 수 있다. 기존 긴 머리 004·몸·외부 비교 샘플은 유지한다.

원래 솔버는 부모 입자의 보정을 아래쪽 rest-shape 목표에 반복 전달해 바람을 꺼도 원래 헤어 메시가 1초 간격으로 약 3~4cm씩 계속 바뀌었다. 접촉 속도 처리만 바꿔서는 해결되지 않았다. 형태 복귀를 머리 좌표 기준 목표로 바꾸고 뿌리에는 강하게, 끝에는 약하게 적용했다. 반복 충돌 투영 중 Verlet 이전 위치를 계속 바꾸던 처리도 한 스텝 끝에서 한 번만 적용한다. 속도 감쇠 계수는 4.5에서 8/s, 형태 복귀 계수는 반복당 .0025 + .0175 × rootWeight²다.

시간 기반 흔들기나 강제 정지 타이머를 추가하지 않았다. 실제 보행/이동의 머리·몸 충돌 형상 변화에 따른 지연과 감쇠다. 정지 중에도 물리 계산은 유지한다.

`walk-and-stop-check.cpp`와 실제 출력 `walk-and-stop-check.txt`는 이번 긴 머리의 정지→제자리 걷기→정지, 방향 전환/이동→정지 및 기존 구/상자 접촉만 확인한다. 머리 좌표에서 보행 중 메시 차이 최대 약 9.37mm, 멈춘 뒤 1초간 차이는 약 2~3μm였다. 숫자는 이번 입력 경로의 최대 정점 변화이며 위상 지연 시간을 측정한 결과나 모든 자세/삼각형의 무관통 판정이 아니다. 자연스러움은 사용자 시각 검수 대기다. Windows/전체 프로젝트 검사는 수행하지 않았다.

Scene.before.hpp와 HairDynamics.before.cpp는 변경 전 소스다. 005 최초 보고서와 이전 캡처는 당시 바람 ON/이전 솔버 결과로 보존한다.
