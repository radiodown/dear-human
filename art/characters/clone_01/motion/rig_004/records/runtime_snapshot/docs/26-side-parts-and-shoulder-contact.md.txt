# 26. 측면 파츠 재제작과 견착 보정 04

[문서 목록](../README.md) · 이전 시험은 [24](24-motion-rig-test.md), 모션 자료 조사는 [25](25-human-motion-research.md)다. 현재 공통 미리보기는 rig_004를 재생한다. 외형 채택 원화 reference_003_3d와 세계관 15는 유지한다.

## 변경 이유

사용자가 기존 보행의 인체 비율, 파츠 겹침, 견착 자세를 다시 지적했다. 기존 수치 검사 통과만으로 시각적 문제가 해결된 것으로 판단할 수 없다. 정면에 가까운 몸통과 다른 각도의 팔다리를 섞는 구성을 중단하고, 같은 캐릭터의 측면 전투 기준 자세부터 다시 만들었다.

rig_002는 현재 화면에서 사용하지 않는다. 기존 이미지·검수 기록과 당시 코드 스냅샷은 비교용으로 보존하고, 목록에는 사용자 시각 검수에서 반려된 버전으로 기록했다. 새 산출물은 [rig_004](../art/characters/clone_01/motion/rig_004/README.md)에 모았다.

## 파츠와 인체 연결

| 대상 | 이번 처리 |
|---|---|
| 기준 자세 | 오른쪽 측면 전신을 새로 생성하고 그 구도의 머리·어깨·골반·무릎·발목 위치로 보정 |
| 몸통·허리·하의 | 한 장의 연결된 의상 레이어로 사용해 흉갑·벨트·골반 중복과 틈 제거 |
| 어깨·팔 | 상완에 어깨 장갑을 포함, 별도 어깨 장갑을 덧그리지 않음 |
| 앞뒤 팔다리 | 별도 그림을 사용하며 단순 어둡게 복제하는 방식을 중단 |
| 손 | 방아쇠 손과 아래에서 받치는 손을 별도 이미지·손목·파지점으로 정의 |
| 머리·머리카락 | 목은 칼라 안에 들어가게 배치, 뒷머리는 뒤쪽에서 연결 |
| 망토 | 측면 망토 한 겹만 배치, 중복 앞 망토 레이어 제거 |

생성 도구가 시트의 셀 경계를 정확히 지키지 않았다. 셀 전체의 알파 경계만 측정하면 머리에 아래쪽 제복 칼라가 섞이고 뒷머리에 망토 어깨가 섞였다. 실제 파츠별 UV 영역을 다시 지정했다. 최초 몸통에는 팔이 남아 있어 그 셀을 제외하고, 팔 없는 몸통을 별도 생성했다. 원본 PNG는 수정하지 않았다.

각 이미지의 가로세로 비율을 유지한다. 기준 자세의 약 7.5등신과 균형 잡힌 허벅지·정강이 길이를 출발점으로 사용한다. 이 수치는 시각 검수를 대체하지 않는다. 앞뒤 부츠는 원본 비율을 유지하면서 폭과 발목에서 밑창까지의 높이를 맞춰 접지 계산과 화면이 일치하게 했다.

## 견착과 반동

M16 데이터에 `stock` 소켓을 추가했다. 몸통의 `stockPocket`에 개머리판 접점이 오도록 총 위치를 역산하고, 그 접점 주위로 총구가 들리게 한다. 몸통·어깨가 함께 반동을 받으므로 총만 뒤로 미끄러지며 어깨를 관통하던 독립 이동을 제거했다. 일반 장전과 빈 탄창 장전 때는 의도적으로 견착을 낮춘다.

두 손은 총의 주 손잡이·보조 손잡이 위치에서 손목 오프셋을 뺀 뒤 IK로 연결한다. 머리 위치와 기울기, 총 높이도 조립 화면에서 보정했다. 사격 시 어깨 접점과 손 접점이 함께 유지되는지 검사한다. 손가락·볼·장갑을 정밀한 3D 접촉으로 푸는 시스템은 아니다.

접점 구성은 미 육군의 [USAMU 사격 교육 사례](https://www.army.mil/article/75586/usamu_trains_soldiers_in_advanced_marksmanship_skills)를 참고했다. 이 사례는 개머리판을 같은 어깨 위치에 놓고 볼을 개머리판에 안정적으로 대는 설명을 제공한다. 해당 사례의 무릎쏴 자세를 서 있는 게임 캐릭터의 관절 각도로 복사한 것은 아니다. 현재 게임의 위치·각도는 측면 그림과 조립 화면에서 별도로 조정한 값이다.

## 실제 확인과 재현

기존 사이트의 [캐릭터 모션](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle)과 [M16](http://127.0.0.1:4173/#/samples/weapons/m16_basic?motion=idle)이 같은 리그를 쓴다. 화면 아래의 기준 자세·머리/망토·팔다리·몸통 링크로 새 원본을 확인한다. 정적 외형 탭의 버전 선택에도 측면 기준 자세를 추가했다. 사용자 채택 기본 원화는 그대로 기본 선택이다.

```powershell
python tools/preview_server.py --port 4173
npm --prefix game run check
npm --prefix game test
python -X utf8 tools/agent_pipeline.py --root . docs-check
python -X utf8 tools/agent_pipeline.py --root . catalog-check
```

시뮬레이션 15개는 손 도달, 고정 스텝, 장전 시간, 반동 방향, 무릎 굽힘, 발 접지, 정지 전환, 이미지 비율, 100회 무기 교체와 견착 접점 유지를 검사한다. 새 결과는 rig_004의 tests 디렉터리에 기록한다. 과거 rig_002의 수치를 이번 결과로 덮어쓰지 않는다.

브라우저 연결 오류로 내장 브라우저 자동 조작은 실행하지 못했다. 로컬 Chrome의 실제 앱에서 대기·보행 두 구간·첫 반동·빈 탄창 장전·좌우 반전/소켓 표시·좁은 화면을 정지 캡처해 확인한다. [검토 기록](../art/characters/clone_01/motion/rig_004/reviews/review.json)에 캡처 조건과 범위를 남긴다. 정지 캡처는 전체 애니메이션의 자연스러움이나 실제 입력 조작 검증을 의미하지 않는다. GIF는 추가 생성하지 않는다.

## 남아 있는 한계

이번에는 몸통·허리·하의를 하나의 의상 세트로 묶었다. 무기 교체는 독립적으로 가능하지만, 흉갑·벨트·하의를 각각 교체하려면 이 구도에서 가려지는 부분까지 갖춘 추가 레이어가 필요하다. 같은 원화를 다시 분리할 때 관절 주위의 안쪽 면을 포함해 준비한다.

보행은 절차적 2D 키 곡선과 IK다. 실제 모션캡처·Spine·2dimg2motion·PixelFX를 이번 보정에서 사용한 것으로 기록하지 않는다. 왼쪽은 오른쪽 그림을 반전하며 장비의 반대쪽을 새로 그린 것은 아니다. 정밀 손가락 장전, 표정·깜빡임, 부위별 의상 교체, 전체 보행의 최종 사용자 검수와 도구 확정은 후속이다.
