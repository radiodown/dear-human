## 변경한 시점

카메라는 바닥의 수평선보다 위로 약 30° 올라가 캐릭터를 내려다보도록 요청했다. 좌우 방향은 기존처럼 오른쪽을 유지한다. 정수리·어깨 장갑·M16 윗면과 군화의 윗면, 화면상 높이가 다른 양발로 깊이를 표현한다. 정확한 카메라 행렬을 가진 3D 렌더가 아니므로 각도를 측정해 보장하는 결과는 아니다.

기존 그림의 정수리·어깨·총 윗면을 새로 그린 결과다. CSS 기울이기·수직 압축·2D 리그 카메라로 시점을 흉내 내지 않았다. 원본을 자르거나 정렬·크기 보정·색 제한·알파 정리하지 않았으며 512/384/256px 선택은 기존 페이지의 표시 크기만 바꾼다. 고정 픽셀 격자·팔레트를 강제한 최종 게임용 도트로 보고하지 않는다.

## 확인과 한계

한 번의 필요한 JS 구문 확인과 짧은 Windows Chrome 표시 확인을 했다. 새 버튼·직접 주소·새로고침 복원·배경/표시 크기·정측면 비교·기존 경계 걷기로 전환과 복귀·500px 화면을 확인했다. 앱 내 브라우저는 연결 초기화에서 `sandboxPolicy` 누락으로 실패해 별도 로컬 Chrome을 사용했다. 전체 테스트·전체 프레임 검사·GIF는 실행하지 않았다.

원본보다 정수리의 면적과 갑옷/총의 세부 묘사가 달라 보인다. 투영에 따른 변화와 생성기의 비례·그림체 변화를 분리해 사용자 검수가 필요하다. 옆면 기준과 모든 부위의 크기 일치나 실제 3D 투영 일치를 통과시킨 결과는 아니다. 이 정지 기준의 채택 전에는 종속 키포즈·중간 프레임을 만들지 않았다.

변경 전 표시 소스·목록·안내는 `records/runtime_snapshot_before/`, 변경 후 표시 소스는 `records/runtime_snapshot_after/`에 보존한다. 기존 플랜 B 프레임·입력 사격·공통 파츠·플랜 E는 변경하지 않았다.
