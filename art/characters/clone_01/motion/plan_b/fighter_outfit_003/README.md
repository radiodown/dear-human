## 의상 대조와 반영

기준은 [채택 일러스트](source/reference-approved.png)이며 [정면 샘플](source/reference-front.png)로 의상 구조를 보충했다. 정측면 샘플도 분석 때 확인했지만 생성 입력은 편집 대상·채택 원화·정면 샘플의 세 장이다. 일러스트의 소총/헬멧·정면 자세·배경·사실적 렌더 재질은 복사하지 않았다.

| 부위 | 이전 도트 기준 | 일러스트의 구조 / 이번 보완 |
|---|---|---|
| 흉갑 | 둥근 두 판과 단순한 복부 장갑 | 검은 중앙 흉갑과 옅은 회색 바깥 인셋, 절제된 금색 경계 |
| 몸통 | 장비 없는 단순한 분할 면 | 가슴 아래 가로 스트랩·버클, 어두운 허리 연결부와 세로 금색 이음선 |
| 허리/골반 | 단일 벨트 | 높이가 다른 벨트·버클과 각진 허리 파우치 |
| 스커트 | 넓게 벌어진 연속 삼각 주름 | 두께가 있는 겹친 사각/짧은 사다리꼴 장갑 조각, 중앙 하의 패널과 측면 패널 |

새 그림에서는 흉갑 회색 인셋과 가슴 아래 벨트·허리 세로선, 양옆 파우치, 여러 줄로 겹친 장갑 하의가 읽힌다. 얼굴·머리·총과 팔·망토·다리의 전체 배치도 시각적으로 비슷하게 유지됐다. 생성 편집이므로 의상 바깥의 모든 픽셀이 동일하다고 보장하지 않는다.

## 표시와 확인

같은 캐릭터 페이지에 ‘기준 일러스트와 의상 비교’와 ‘의상 보완 전후 비교’를 제공한다. 일러스트 대조는 전체 그림을 자르지 않고 contain으로 맞춰 보여 주며, 동일 스케일의 신체 측정용 도면은 아니다. 이전12°와30° 원본·기록·주소는 이전 버전 목록에 유지한다.

필요한 JS 구문 한 번과 짧은 Windows Chrome에서 표시/주소/복원·배경/표시 크기·일러스트/전후 비교·이전12° 전환·500px를 확인했다. 앱 내 브라우저의 기존 연결 초기화 오류로 별도 로컬 Chrome을 사용했다. [브라우저 기록](reviews/browser.json), [PNG/알파 확인](reviews/structure.json), [시각 관찰](reviews/visual.json)을 분리했다. 전체 검사·GIF·모션 생성은 실행하지 않았다.

일러스트의 모든 문양·미세 리벳·파우치 수·천 겹침을1:1로 옮기지는 않았다. 장갑 하의의 두께/길이·가림, 흉갑 인셋·스트랩 위치·파지/견착과 외형 일치도는 사용자 검수 대기다. 원본의 정확한3D 투영·고정 팔레트/픽셀 격자·모션 품질을 통과시킨 결과가 아니다.

변경 전 표시 소스/목록/안내는 `records/runtime_snapshot_before/`, 변경 후 표시 소스는 `records/runtime_snapshot_after/`에 보존한다. 기존 PNG·검사·플랜 B 입력 사격·공통 파츠·플랜 E는 유지한다.
