# 플랜 B · 빠른 연사002

[조작](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b) · [개발 기록](../../../../../../docs/plan-b-input-fire-002.md) · [즉시 이동 사격](reviews/immediate-walking-shot.png) · [500px 앉아쏴](reviews/narrow-kneeling-shot.png)

발사 시계를 발걸음에서 분리했다. 단발/연사의 첫 발은 즉시, 연사는 파츠의 M16 설정과 같은100ms 간격(1× 초당10발)이다. 걷기는 기존95ms/01~12 순서를 유지하며 버튼을 놓으면 추가 발사 없이 마지막 복귀만 마친다.

기존005/006/007 전신 PNG와 반동 포즈를 변형 없이 재사용하고, 실제 발사 이벤트에 공통 MUZZLE_LIGHT 기반의 Canvas 도트 섬광을 그린다. 현재 포즈의 총구점은 위쪽 알파 외곽에서 읽는다. 원본의 발사광 그림은 실시간 반동에서 제외하고 수동 검토용으로 유지한다. 새 이미지 생성/PNG 수정·GIF·카탈로그 갱신은 없다. 별도 상체 리그·물리 반동·캐릭터 재조명·탄약/명중·소리는 없다.

[발사 시계 검사](tests/cadence.json), [실제 Chrome 측정](reviews/browser.json), [읽기 전용 총구점 확인](records/muzzle-alpha-review.json), [소스·의존 해시](records/implementation.json)와 records의 변경 전/후 런타임을 보존한다. 경계/기본 걷기와 앉아쏴에서 평균 간격 약101~103ms, 각 약1.15초 누름에12발, 해제 뒤 추가 발사 없음과 보행 순서 유지를 확인했다. 초기 준비 대기 타임아웃도 별도로 보존하며 전체 초기화 경합이나 전체 게임 검사 통과를 뜻하지 않는다.

오른쪽 M16 외곽 기반의 총구 근사다. 기존 발/머리/망토/윤곽 변화와 새 섬광·포즈 전환의 자연스러움은 사용자 검수 대기다. 이전001의0.57초 대기와 느린 연사 기록은 이력이며 현재 규칙은002를 따른다.
