# 12° 모션 004 · 사용자 지시로 중단

사용자가 도트의 요소 수를 줄이고 더 심플하고 슬림한 자세별 정지 원화부터 만들도록 지시해 이 모션 작업을 중단했다. 이후 모션 생성·중간 프레임·패킹·재생 연결을 계속하지 않는다. 사용자에게 완성 모션으로 납품하거나 아트 채택 결과로 취급하지 않는다.

이미 생성된 자료와 다섯 개의 패킹된 클립은 기록으로 보존했다. 앉기/앉아쏴는 최종 패킹·브라우저 검수가 끝나지 않았고, 앞선 앉기 시도의 접지 문제도 남아 있다. 목록에는 등록하지 않았다. 실험 중인 세 표시/재생 소스는 `records/runtime_snapshot_at_user_stop/`에 보존하고 변경 전 소스로 돌려, 이 미완성 모션의 탭과8프레임 재생 확장은 현재 페이지에서 제거했다. 기존14프레임 모션과 이전 정지 시안은 유지한다.

후속 작업은 [simple_poses_005](../simple_poses_005/README.md)의 **정지 원화만**이다. 모션은 아직 제작하지 않는다. [중단 기록](records/user_stop.json)을 따른다.
