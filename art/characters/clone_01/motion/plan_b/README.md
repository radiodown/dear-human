# Plan B — 2dimg2motion

최신 발사 속도는 [빠른 연사002](input_fire_002/README.md)다. 첫 발은 즉시, 연사는1× 초당10발로 걷기 속도와 분리했다. 기존 그림은 유지하고 발사 이벤트의 총구 효과를 별도로 표시한다. 필요한 Chrome 실측은 약101~103ms이며 이전001의 발 디딤 대기 제한은 해제했다.

사격 조작은 [입력 사격001](input_fire_001/README.md)을 따른다. 단발 한 발·누르고 연사/Space·발사 횟수를 같은 탭에서 사용하고 입력 전에는 쏘지 않는다. 걷기는 순서를 이어가며 다음 발 디딤에 발사하고, 앉아쏴는 즉시 발사 후 대기로 복귀한다. 원본 PNG 구간에 따른 입력 대기/연사 속도 제한은 기록에 남겼다.

동작 선택은 [동작 탭001](ui_tabs_001/README.md)을 따른다. 파츠와 같은 탭으로 경계 걷기·이동 사격·앉아쏴·기본 보행/사격을 바로 전환하며 이전 버전은 펼쳐서 본다. 기존 모션과 직접 주소는 유지한다.

최신 걷기는 [pixel_guard_007](pixel_guard_007/README.md)의 경계 걷기·경계 이동 사격이다. 골반부터 상체를 앞으로 숙이고 무릎을 낮춘 채 전방 시선·수평 M16·양발 교차를 유지한다. 같은 페이지 기본은007 경계 걷기이며006 앉아쏴도 선택한다. 필요한 PNG/짧은 Chrome만 확인했고 발 높이4~5px·망토/윤곽·자연스러움은 검수 대기다.

최신 전투 모션은 [pixel_combat_006](pixel_combat_006/README.md)의 이동 사격·앉아쏴다. 같은 페이지에서12개 움직이는 포즈를 반복하고 발사 자세/다음 반동 프레임을 비교한다. 005 양발 교차를 유지하며 낮은 무릎 지지와 어깨/흉곽·머리/망토 반응을 새로 생성했다. 필요한 PNG/Chrome 재생만 확인했고 최종 아트 검수는 대기다.

최신은 [다리 교차005](pixel_walk_005/README.md)다. 사용자 지적으로 004는 양발 교대·교차 실패로 반려했다. 새 기준에서 두 다리의 명암을 고정하고 반대 발의 접촉/지지/교차를 새로 생성했다. [같은 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=pixel_005&motion=walk)에서 12개 움직이는 포즈만 반복한다. 아래004의 생성·재생 확인은 이력이며 교차 품질 통과를 뜻하지 않는다.

최신 **재생 가능한 도트 보행**은 [pixel_walk_004](pixel_walk_004/README.md)다. 도트 003 기준 외형을 입력 보드 편집으로 유지하며 4개 키포즈·8개 중간 프레임을 생성해 14프레임으로 연결했다. [같은 캐릭터 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=pixel_004&motion=walk)에서 자동 재생한다. PNG/Chrome 재생 확인과 최종 아트 채택을 구분하며, 약 3px 발 높이 변화·망토·루프 연결은 검토 대기다. 아래 003과 001/002 실패 기록은 이력이다.

최신 시도는 [도트 단순화 `pixel_walk_003`](pixel_walk_003/README.md)다. 장식·재질 세부를 줄인 기준 외형 1장과 걷기 키포즈 4개를 생성했다. 기준 외형 채택은 사용자 검수 대기이며 키포즈는 머리·상체·총의 크기 변화로 반려해 중간 프레임은 만들지 않았다. [같은 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=pixel_003)에서 새 정지 이미지와 이전 보행 기록을 선택한다.

최신 판정: `walk_001`은 기준 이미지와 머리·몸통·총 비례가 달라 **크기 검수 실패**다. `walk_002`에서 공식 규약을 재학습하고 키포즈 1시트를 재생성했지만 동일 비례 검사를 통과하지 못했다. 두 시도는 실패 기록이며 크기가 보정된 완성 모션은 아직 없다. 재검토 기준은 프로젝트 `img2mo-knowledge/failures.md`, 실제 판정은 각 버전의 `reviews`에 보관한다.

사용자 지시로 플랜 B를 가동했다. 2dimg2motion의 **전신 키포즈 재생성 → 모델 중간 프레임 → 투명 PNG 시퀀스** 경로를 사용한다.

- 첫 작업: `walk_001`, M16 준비 자세의 오른쪽 측면 제자리 보행 14프레임.
- 입력: 기존 `rig_004/source/side_master.png`를 재사용하며, 채택 외형은 `reference_003_3d`다.
- 도구: [2dimg2motion](https://github.com/WU-HAOTIAN34/2dimg2motion), 커밋 `d4d73e243b6ff64b7cbb3879e45e951f972a7e62`.
- 이미지 제작은 내장 image_gen, 로컬 Python/Pillow는 표준화·셀 분리·동일 비율 정리·패킹·검사에만 사용한다.
- 원본과 프롬프트·실제 생성 기록은 `walk_001/source`와 `walk_001/records`, 납품 프레임은 `walk_001/output`에 구분한다.
- 기존 사용자 지시에 따라 GIF는 생성하지 않고 공통 캐릭터 페이지에서 PNG 프레임을 재생한다.
- 플랜 A 파츠 리그 및 기존 채택 파일을 대체하지 않는다. 이 버전은 총이 전신 프레임에 포함된 플랜 B 검토본이다.

진행 상태와 검수는 `walk_001/records/generation.json` 및 `walk_001/reviews`에 기록한다.
