## 수정과 보존

기존 30° 그림을 편집 대상으로, 원래007 정측면은 외형·성인 비례의 보조 참조로 넣었다. 강한 정수리/어깨 윗면 노출을 줄이고 얼굴·흉갑 앞면·양팔을 더 읽기 쉽게 만들었다. 총과 시선은 오른쪽을 유지하며 두 손 파지와 견착을 표현한다. 몸의 전면을 보여 주는 회전과 카메라 내려보기 각도를 별개로 요청했다.

기존30°는 덮어쓰지 않고 ‘이전 버전·기준 외형’에 남겼다. 새 기준에서 ‘30°와 격투게임식 시점 비교’를 펼치면 나란히 볼 수 있다. 기존30° 직접 주소는 그대로 복원되며 해당 비교는 정측면↔30°로 돌아간다. 표시 크기·배경 조절은 같은 코드를 재사용한다.

## 확인과 남은 검수

필요한 JS 구문 한 번과 짧은 Windows Chrome에서 이미지 표시·선택/주소/새로고침 복원·30° 전환/비교 복원·표시 크기/배경·500px를 확인했다. 앱 내 브라우저는 앞서 확인된 연결 초기화 오류(`sandboxPolicy` 누락)로 사용할 수 없어 별도 로컬 Chrome을 썼다. 전체 검사·GIF·다른 모션 생성은 실행하지 않았다.

가슴/얼굴/발 간격의 그림과 자세가 함께 바뀌므로 이전 이미지의 정확한 3D 재투영·모든 부위 비례 일치로 보고하지 않는다. 고정 팔레트·단일 픽셀 격자도 강제하지 않았다. 얼굴·흉갑·파지/견착·몸의 튼 정도와 얕은 내려보기의 자연스러움은 사용자 검수 대기다. 이전30°와 과거검사·기존 프레임/입력 사격·파츠·플랜 E는 보존한다.

변경 전 소스·목록·안내는 `records/runtime_snapshot_before/`, 변경 후 표시 소스는 `records/runtime_snapshot_after/`에 보존한다.
