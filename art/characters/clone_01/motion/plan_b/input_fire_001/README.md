# 플랜 B · 입력 사격001

[재생·조작](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b) · [개발 기록](../../../../../../docs/plan-b-input-fire-001.md) · [실제 단발 화면](reviews/walk-single.png) · [500px 앉아쏴](reviews/narrow-kneeling.png)

단발은 한 발, ‘누르고 연사’/Space는 누르는 동안 반복한다. 실제 발사 횟수와 준비/발사/반동 상태를 표시한다. 버튼 밖 해제·포커스/화면/탭 이동에도 입력을 해제하고 마지막 반동만 마친다. 입력 없이 자동 사격하지 않는다.

005/006/007의 기존 PNG/atlas를 그대로 재사용했다. 걷기 인덱스는 이어가면서 다음02/08에 한 발을 발사하고 뒤 두 반동 포즈 후 발사 없는 걷기로 돌아온다. 앉아쏴는05/11에서 즉시 시작하고 반동 뒤 기준00으로 돌아온다. 포즈 비교·프레임 조작은 실제 발사 횟수에 포함하지 않는다. 생성 호출·새 그림/변형·GIF·카탈로그 갱신은 없다.

[구현·의존 파일 해시](records/implementation.json), records의 변경 전/후 런타임 소스, [작은 제어 검사](tests/controls-smoke.json), [필요한 Chrome 검토](reviews/browser.json)를 보존한다. 첫 검토 도구의 output 읽기 오류는 browser-harness-output-read.json에 별도로 남겼다. 최종 검토의 페이지 오류는 없었으며 전체 게임/문서/목록 검사 묶음은 수행하지 않았다.

이동 사격 입력은 다음 발 디딤까지1×에서 약0.57초 기다릴 수 있다. 연사 속도도 원본 보행/반동 구간에 제한되며 자유로운 발사율 제어는 아니다. 기존 윤곽/망토/발 높이 변화·전환 자연스러움은 사용자 검수 대기다. 실제 탄약/명중·독립 FX나 소리는 없다.
