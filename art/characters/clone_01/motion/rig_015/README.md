# clone_01 · 전신 사격 폼 연결 파트 015

[구현 기록](../../../../../docs/firing-form-application-001.md) · [사격 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire)

014의 닫힌 파지 손과 rig_004의 원본 몸통을 이어 사용한다. [파트 정의](rig/body_parts.json)는 흉곽–허리 사이의 .405/.445/.485 구간에 메시 정점을 추가한 네 의상 부착물이다. 바스트·흉갑은 흉곽을 따라 강체 회전하고, 몸통 아래쪽은 허리와 연결된다. 원본 PNG·알파·가로세로 비율은 변경하지 않았다.

[작성 레시피](recipe/build_body_parts.py)는 이전 011의 UV 작성 방식을 새 버전으로 보존하고 연결 행과 부착 정보만 수정했다. `--connect`는 공통 rig_005의 네 의상 파트만 갱신한다. 머리 바인딩과 사격 폼 설정은 별도로 공통 정의/코드에 등록한다. 이미지 생성·검사 도구가 아니며 새 모델 호출이나 프롬프트는 없다.

허리·흉곽·어깨와 양팔 기준 포즈는 `game/animation/firing-form.js`를 게임/미리보기에서 공유한다. 사용자 요청에 따라 개발 연결만 수행했으며 테스트·브라우저 검수는 실행하지 않았다. `verification`은 `untested`, 아트는 사용자 검수 대기다.
