# 플랜 G · Saltline 횡스크롤 001

2026-11-12 사용자 요청으로 Saltline 단일 HTML을 직접 분리해 플랜 G를 만들었다. [구현·조작·제약](../../../../../../game/plan-g/README.md)을 따른다.

원본 Three.js r180·재질·환경·무기·소리를 사용한다. 임시 전신, 58m 좌우 이동 구간, 별도 측면 추적 카메라, 원본 이동/점프/사격/장전을 연결했다. 원본 적·임무 코드는 보존했으며 현재 횡스크롤 시안에는 미연결이다. 리안 원화와 기존 F를 변경하지 않는다.

원본은 `source/`, 입력 요청과 산출물 해시는 `record.json`에 보존한다. 외부 이미지·모델·모션 생성은 0회, 총 작업 시간·비용은 별도 측정하지 않았다. 구문 확인만 실시했고 브라우저 도구 연결 오류로 실제 재생과 미감은 untested·검수 대기다.
