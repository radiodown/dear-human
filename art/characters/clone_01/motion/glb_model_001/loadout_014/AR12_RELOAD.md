## 동작

전체 재생 속도를 일괄 올리는 대신 각 구간의 시간을 다시 설계했다. 길이는 3.4초 → **2.65초**, 표본은 30Hz → **60Hz·160개**다. 기존 35° 총 기울기와 오른손 고정, 왼손 탄창 밑면 받침, 안정된 팔꿈치 방향·전완 회전 분담을 유지한다.

| 구간 | 시간 | 변화 |
|---|---|---|
| 총 기울이기·탄창 잡기 | 0.08~0.48초 | 짧게 준비하고 잡은 자세 유지 |
| 탄창 빼기 | 0.53~0.70초 | 빠르게 당긴 뒤 0.07초 멈춤 |
| 허리로 회수·교체 | 0.77~1.15초 | 빠른 회수 후 잠깐 정지, 1.10초 동일 자세에서 메시 교대 |
| 새 탄창 올리기·정렬 | 1.15~1.51초 | 1.46초 도착 후 0.05초 정렬 정지 |
| 삽입·밀어 넣기 | 1.51~1.82초 | 0.19초 삽입, 1.72초 짧은 2.6° 총 반응과 0.004단위 밀착 동작 |
| 손 복귀·견착 | 1.83~2.55초 | 왼손을 먼저 복귀하고 총을 신속하게 다시 세움 |

013의 탄창 표시/위치 분리 원칙을 그대로 적용한다. 숨긴 탄창만 총으로 돌아가며, 두 메시가 정확히 같은 자세일 때 1.10초와 1.90초에 표시를 바꾼다. 참고의 리듬을 현재 전신 리그에 적용했으며 영상의 무기·시점·노리쇠 조작을 그대로 복제한 것은 아니다.
