# 리안 AR-12 장전 016 · 손의 연속 동작

2026-11-13 사용자 피드백: “장전하는 손이 자동차 조립기계처럼 움직이고 사람 같지 않다.” [014](../loadout_014/AR12_RELOAD.md)의 직선 이동과 구간별 완전 정지를 줄이고, 팔·손목·손가락의 동작을 겹쳐 연결했다.

[장전 보기](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=glb&loadout=ar12_rupture&clip=rifle_reload)

## 변경

- **이동 경로:** 탄창 추출 → 허리 교체 → 재삽입을 하나의 접선이 연속인 Hermite 곡선으로 연결했다. 몸 바깥쪽으로 완만하게 돌아오며 기존 중간 정지 두 곳을 통과한다. 총에 들어가는 마지막 구간은 탄창 삽입 축을 따른다.
- **팔과 손목:** 팔꿈치를 손 이동과 다른 시점에 약하게 접고 펴며 왼쪽 어깨도 따라간다. 손목의 작은 각도 조절은 손바닥 접점을 중심으로 한다. 접근/복귀도 완만한 곡선이며, 손목 방향 전환을 위치 이동과 조금 엇갈리게 했다.
- **손가락:** 기존 뼈의 굽힘 축을 이용해 잡기 전/놓을 때 손가락을 펴고 순차적으로 다시 감는다. 엄지 5°, 나머지 관절 10~14° 범위의 보조 움직임이다. 원래 파지와 피부 가중치는 유지한다.
- **몸과 총:** 상체는 손의 회수를 따라가고 머리는 조금 늦게 따라본다. 삽입 반응을 1.5°의 짧은 총 움직임으로 완화했다. 전체 2.65초·60Hz·160표본과 오른손 고정·35° 기울기는 유지한다.
- **탄창 연속성:** 기존/새 탄창이 동일한 연속 경로를 공유한 채 1.10초에 교대한다. 숨긴 탄창만 총으로 돌려놓고 1.90초 장착 위치에서 다시 교대한다.

별도 연사 작업이 015를 사용하여 이번 장전은 **016**으로 분리했다. 015의 `rifle_full_auto`를 노드 호환성을 확인한 뒤 입력/출력 트랙 값을 그대로 복사해 016에 보존한다. 원본 007의 6개 동작·바이너리, 014, 015와 공통 사격 효과를 보존한다.

## 검증

- [실제 Chromium AnimationMixer](reviews/magazine_continuity.json): 240Hz·637표본, 탄창 공백/중복/중간 크기 0, 교대 위치 오차 10⁻¹⁵ 미만. 최대 1/240초 이동은 014의 0.00537 → 0.00353이다.
- [리그 검사](reviews/rig_checks.json): 원본 6개 동작 정의/바이너리 일치. 60Hz 표본에서 발 위치 오차 약 10⁻⁸, 운반 중 손바닥 접점 오차 4.5×10⁻⁸, 왼팔/손 최대 회전 변화 5.47° 미만. 왼손 15개 관절의 굽힘/펴기 변화를 확인했다.
- [실제 공유 뷰어](reviews/viewer.json): 016 로딩, 0.25× 재생, 동작 전환 후 장착 탄창 복원, 페이지 오류 없음. 8개 클립이 로딩된다.
- [8개 연속 자세](reviews/motion_sequence.png), 허리/삽입 자세, 정면/측면 및 교대 전후 캡처를 보존하고 확인했다.

**사람다운 느낌과 세밀한 손가락/의상 접촉은 사용자 검수 대기**다. 손바닥 목표점 검증은 피부 표면 전체의 무관통 검사나 실제 물리 파지를 뜻하지 않는다. 허리의 두 탄창 교체는 동일 형상 메시 전환이며 새 파우치 장비나 노리쇠 동작은 추가하지 않았다.
