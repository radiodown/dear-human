## sprite_003 · 완전 우측면·제자리 다시 렌더 (현재 기본)

- 사용자 지시(2026-11-11): 기존 걷기·달리기를 완전 우측 모습으로 다시 만들고, 아직 스프라이트가 없는 다이브·겁먹음을 추가한다. 탭에서 숨긴 두 달리기 클립은 제외했다. 브랜치 `glb-sprites`.
- 도구: `tools/glb_sprites/render_glb_sprites.py`(Blender 5.2.3 헤드리스, EEVEE 32샘플, `Standard` 색 변환). 정사영 카메라를 정확히 −X 축에 두고 +X를 보게 해 캐릭터의 오른쪽 옆면이 보이고 화면 오른쪽을 향한다(두 GLB 모두 가져오기 후 −Y가 정면). 조명은 GLB 탭과 비슷하게 카메라 쪽 위 주광(태양 2.6)·뒤쪽 테두리광(0.9)·회색 환경광이다.
- 게임용 최적화(사용자 지시 “추천대로 다 수정해줘”, 2026-11-11): 처음 만든 512px·24fps·빈 공간 포함 PNG 시트는 메모리에 풀면 리안 약 240MB·몬스터 약 216MB여서 다시 만들었다. ① 리안과 몬스터 공통 100px/m(4배로 렌더 후 선형 밝기·곱한 알파로 면적 평균 축소) ② 24fps 중 한 장 건너 12fps, 반복하지 않는 동작은 실제 마지막 자세를 덧붙임 ③ 동작마다 모든 프레임을 합친 영역(+1px)으로 자르고 `manifest.json`의 `crop`(기준 칸 안 위치)·`groundY`(바닥선)·`originX`(모델 원점)로 같은 자리에 맞춤 ④ 시트는 무손실 WebP(`spritesheet.webp`, 8열). `frames/`는 잘라낸 같은 프레임의 PNG다. 512px 원본은 남기지 않았고 같은 명령으로 다시 만들 수 있다(폭사 난수도 고정 시드).
