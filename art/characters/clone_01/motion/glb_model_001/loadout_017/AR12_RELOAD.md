# 리안 AR-12 낙하 장전 017 · 제작 중간 기록

2026-11-13 빈 탄창 버리기·빈손 허리 이동·새 탄창 장착을 제작한 중간 버전이다. 현재 적용/검증 결과와 최종 제작 코드는 [019](../loadout_019/AR12_RELOAD.md)를 따른다.

017은 기존 015 연사를 포함한다. 동시 연사 작업이 017 제작 중 스냅샷을 사용해 018을 만들었으므로, 현재 보존한 017 파일은 018 기록의 당시 입력 해시와 다르다. 018은 보존하며 최종 장전과 018 연사 트랙을 다시 합친 019가 현재 결과다.

`before/`는 이번 장전 변경 전의 제작/검사 코드와 뷰어다. `reviews/`의 리그/직접 GLB 렌더·낙하 결과는 현재 017 확인에 사용했으나 당시 공유 뷰어는 018로 전환되어 뷰어 버전 검사에서 중단됐다. 017을 공유 뷰어 검증 완료로 표시하지 않는다. 최종 뷰어·전환 검사는 019에서 완료했다.
