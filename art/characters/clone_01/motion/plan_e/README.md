# 플랜 E · 3D 동작 → 2D 스프라이트

2026-11-08 팀 결정으로 시작했다. 3D 모델로 동작을 만들고, 오프라인에서 저해상도 도트 스프라이트로 렌더링해 웹 게임에서 재생한다. 팀 지시로 범위는 3D → 2D까지이며 게임에는 2D 스프라이트만 들어간다. 현재 입력 모델은 플랜 D의 GLB다.

- [sprite_004](sprite_004/README.md): 현재. [원화 투영 모델 003](model_hull_003/README.md): 팔다리 분리, 망토 흔들림, 사격 자세 다리, 금색 복원. 사용자 검수 대기.
- [sprite_003](sprite_003/README.md): 이전. [원화 투영 모델 002](model_hull_002/README.md)로 렌더한 장전·8방향, 205px. 사용자 검수 대기.
- [sprite_002](sprite_002/README.md): 이전. M16A1 실루엣으로 다시 만든 총, 망토(뼈 3개)·긴 머리카락(뼈 2개) 스프링 흔들림. 사용자 검수 대기.
- [sprite_001](sprite_001/README.md): 이전. 장전 54프레임과 같은 자세 8방향. 임시 상자 M16. 사용자 검수 대기.

## 다음 단계: 원화 수준 모델

001·002 검수에서 품질이 낮다고 판정됐고, 원인은 코드로 만든 플랜 D 모델이다. 도트 밀도 2배와 명암 단계 시험도 원본 렌더의 한계를 넘지 못했다.

1. 생성기 API 키 확보 (Hyper3D 권장: 4방향 입력 가능). 애드온 기본 무료 체험 키는 `API_INSUFFICIENT_FUNDS`로 거부됐다.
2. Blender MCP `generate_3d`로 `concepts/turnaround_001/source`의 front·left·back·right를 입력해 생성한다.
3. 생성 모델에 21관절 리그(플랜 D와 같은 뼈 이름)를 붙인다.
4. `tools/plan_e/render_sprites.py --glb <새 모델>`로 sprite_003을 만든다.

새 시도는 새 버전 폴더에 만들고 이전 결과를 덮어쓰지 않는다.
