# 플랜 E · 3D→도트 스프라이트 004

[원화 투영 모델 003](../model_hull_003/README.md)으로 렌더링한 장전·8방향 스프라이트다. [sprite_003](../sprite_003/README.md)의 남은 한계를 보정했다.

```
Blender -b --factory-startup --python tools/plan_e/render_sprites.py -- \
  --glb art/characters/clone_01/motion/plan_e/model_hull_003/source/clone_01_hull.blend \
  --out art/characters/clone_01/motion/plan_e/sprite_004 \
  --exposure 0 --stance 1 --twist 0.35 --colors 32 --ppm 96
```

| 항목 | 003 | 004 |
| --- | --- | --- |
| 다리 | 선 자세 (`--stance 0`) | 사격 자세로 벌림 (`--stance 1`) |
| 망토 | 흔들림 없음. 엉덩이 아래 망토 끝 이동 1px | 스프링 체인 연결. 이동 4px (5가지 위치) |
| 금색 팔레트 | 따뜻한 색 2개, 베이지에 가까움 | 따뜻한 색 8개, 채도 1.6배 복원 (예: 221,164,115) |
| 대각선 (8방향) | 얼굴이 두 겹으로 보임 | 줄어듦 |

렌더 스크립트 변경:
- 몸통은 정점 수가 가장 많은 메시로 고른다. 팔다리 메시가 따로 있어도 몸통을 바르게 찾는다.
- 몸통에 `plan_e_cape` 그룹이 있으면 재질 대신 그 그룹으로 망토 정점을 고른다. 체인에 넘기기 전에 다른 변형 가중치를 모두 지운다.
- 팔레트를 구할 때 채도 상위 4% 픽셀을 6번 더 넣고, 따뜻한 계열 팔레트 색의 채도를 1.6배로 되살린다. 플랜 D 모델을 다시 렌더해도 팔레트가 바뀐다 (커밋된 sprite_001·002는 그대로 둔다).

렌더 시간은 약 89초다.

## 확인한 범위

- 003과 같은 프레임을 확대해서 나란히 비교했다. 다리 사이에 회색 면이 생기지 않고, 금장이 금색으로 보인다.
- 망토 끝 이동 폭을 픽셀로 쟀다 (엉덩이 아래 구간의 가장 뒤쪽 열).
- 미리보기 탭의 기본 버전을 004로 바꿨다.

## 남은 한계

- 손가락이 움직이지 않는다 (모델에 손가락 뼈가 없음).
- 머리카락은 망토와 함께 움직인다.
- 장전 동작에서는 몸이 크게 움직이지 않아 망토 흔들림이 작다.
- 동작의 자연스러움과 아트 채택은 사용자 검수 대기다.
