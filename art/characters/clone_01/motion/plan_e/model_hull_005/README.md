[004](../model_hull_004/README.md)에서 다리가 여러 개로 보이던 문제를 고쳤다. 만드는 방법은 004와 같다.

- 기록: `records/build.json`

## 다리가 여러 개로 보이던 원인과 수정

| 원인 | 수정 |
| --- | --- |
| 다리를 좁게(망토 앞 x > −0.10, 측정 반지름) 잘라 내서, 종아리 뒤·뒤꿈치 가장자리가 몸통에 남아 다리 그림이 그려진 채 서 있었다 | 치마 아래(z < 0.88)에서 망토 앞은 다리와 빈 공간뿐이라고 보고 몸통에서 모두 비운다 |
| 실루엣 교차가 망토 옆자락을 측면 원화의 다리 위치까지 부풀려, 그 면에 다리가 그려졌다 | 치마 아래 x > −0.06은 좌우 위치와 관계없이 몸통에서 비운다 |
| 몸통용 원화의 다리 자리를 채우는 함수가 캐릭터 안쪽 색만 쓰도록 바뀐 뒤, 양옆이 배경인 넓은 다리 영역을 채우지 못해 원래 다리 그림이 남아 있었다 | 가까운 범위(24px)만 주변 색으로 채우고, 남는 부분은 캐릭터의 어두운 색(25 백분위, 망토 검정)으로 채운다. 넓게 퍼뜨리면 금색 테두리가 번지므로 넓은 범위는 쓰지 않는다 |
| 측면 원화에는 앞쪽 다리만 있어서 뒤쪽 다리에도 같은 그림이 입혀져 복제처럼 보였다 | 플랜 B처럼 뒤쪽 다리는 0.5배, 뒤쪽 팔은 0.72배로 어둡게 그린다 |

다리 캡슐은 측정 반지름보다 1.2cm 크게 잡아 다리 가장자리가 몸통에 남지 않게 한다. 망토 가장자리가 다리에 딸려 오지 않도록 다리 영역은 x > −0.10까지만 둔다.
