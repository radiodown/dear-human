# 플랜 E · 3D→도트 스프라이트 001

플랜 D의 clone_01 3D 모델에 자세를 지정하고, Blender에서 저해상도로 렌더링해 도트 스프라이트로 만든 첫 실험이다. 게임에는 PNG 시트만 들어가며 3D 런타임은 사용하지 않는다.

- 입력 모델: `plan_d/hair_006/source/clone_01.glb` (21관절, sha256은 `records/recipe.json`)
- 생성 도구: `tools/plan_e/render_sprites.py`, Blender 5.2.3 LTS 헤드리스, EEVEE
- 실행 시간: 약 51초 (Mac, 62프레임)
- 미리보기: `./run.sh` 실행 후 [플랜 E 탭](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=e&clip=reload)

## 결과

| 클립 | 프레임 | 기본 속도 | 캔버스 |
| --- | --- | --- | --- |
| `output/reload` 장전 | 54 | 15fps (3.6초) | 137×137px |
| `output/turnaround` 같은 자세 8방향 | 8 | 4fps | 137×137px |

장전 순서: 조준 → 총을 들어 기울임 → 탄창 잡기 → 탄창 분리·낙하 → 새 탄창 → 삽입·밀어 넣기 → 노리쇠 멈치 → 조준 복귀.

## 변환 방식

1. 4배 해상도(548px)로 렌더링한다.
2. 4×4 블록을 알파 가중 평균으로 줄이고, 알파 0.5 기준으로 투명/불투명을 나눈다.
3. 모든 클립에서 공통 팔레트 24색을 k-means로 구해 같은 색만 사용한다.
4. 바깥쪽에 1px 어두운 외곽선을 더한다.

미터당 64px이며 캐릭터 키는 약 118px이다. 카메라는 정사영, 아래로 8°다.

## 알려진 한계

- 총은 상자 조합으로 만든 임시 M16이다. 기존 웹 M16 원화와 외형이 다르다.
- 3D 모델 자체의 외형 품질(얼굴·갑옷 세부·망토 고정)은 플랜 D 기록과 같은 검수 대기 상태다.
- 망토와 머리카락은 뼈에 고정되어 있어서 장전 중 흔들림이 없다.
- 떨어지는 탄창은 바닥에 닿기 전에 스프라이트에서 사라진다. 게임에서는 별도 파편 객체로 처리하는 것을 전제로 한다.
- 손가락은 따로 움직이지 않으며, 손 방향은 최소 회전으로만 맞췄다.
- 확인 범위: 렌더 결과를 확대해서 직접 보고, 미리보기 탭에서 재생되는지 확인했다. 동작의 자연스러움과 아트 채택은 사용자 검수 대기다.
