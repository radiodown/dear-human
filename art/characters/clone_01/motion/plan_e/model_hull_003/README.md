# 플랜 E · 원화 투영 모델 003

[002](../model_hull_002/README.md)의 한계 가운데 다리 분리, 망토 흔들림 준비, 대각선 이음매를 보정했다. 만드는 방법과 관절 좌표는 002와 같다.

- 생성: `tools/plan_e/build_hull_model.py --out art/characters/clone_01/motion/plan_e/model_hull_003` (약 17초)
- 결과: `source/clone_01_hull.blend` — 몸통(약 22만 면), 팔 2개(각 약 3만 면), 다리 2개(각 약 5.6만 면), 21관절 리그. `source/`는 git에 넣지 않고 같은 명령으로 다시 만든다.
- 기록: `records/build.json`

## 002와 달라진 점

| 항목 | 002 | 003 |
| --- | --- | --- |
| 다리 | 몸통 메시에 가중치로만 연결. 다리를 벌리면 망토와 이어진 면이 늘어나고 회색이 드러남 | 망토 앞·치마 아래 영역을 별도 다리 메시로 분리. 좌우 다리는 중심선에서 나눔 |
| 몸통용 원화 | 팔 부분만 지움 | 팔과 다리 부분을 지움. 지운 자리는 캐릭터 안쪽 색으로만 채움 (002는 배경 회색이 섞임) |
| 망토 | 몸통과 한 덩어리 | 등 뒤(x < −0.075)·옆(\|y\| > 0.19)·어깨 아래 정점을 `plan_e_cape` 그룹으로 표시. `render_sprites.py`의 망토 스프링 체인이 사용 |
| 원화 섞기 | 면 방향 가중치 4제곱 | 8제곱. 대각선에서 얼굴이 두 겹으로 보이는 현상이 줄어듦 |

## 남은 한계

- 대각선 방향에는 여전히 경계가 있다. 대각선 원화가 없으면 완전히 없앨 수는 없다.
- 긴 머리카락은 망토 영역과 겹쳐서 망토와 함께 움직인다. 따로 흔들리지 않는다.
- 다리 사이의 발밑에 원화 바닥 그림자 색이 조금 남아, 정면·3/4 시점에서 회색이 보일 수 있다. 측면에서는 보이지 않는다.
- 손가락 뼈가 없어서 손가락은 움직이지 않는다.
