# 플랜 E · 3D→도트 스프라이트 002

[sprite_001](../sprite_001/README.md)의 남은 한계 가운데 임시 M16과 고정된 망토·머리카락을 보정했다. 입력 모델, 장전 키포즈, 변환 방식, 캔버스(137px, 미터당 64px)는 001과 같다.

- 생성 도구: `tools/plan_e/render_sprites.py`, Blender 5.2.3 LTS 헤드리스. 실행 시간 약 52초 (Mac, 62프레임)
- 미리보기: [플랜 E 탭](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=e&clip=reload)의 기본 버전. 001은 같은 탭의 버전 선택에서 볼 수 있다.

## 변경 내용

| 항목 | 001 | 002 |
| --- | --- | --- |
| M16 | 상자 12개 | M16A1 비율의 측면 실루엣: 운반 손잡이·가늠자, 원통 총열 덮개·델타 링, 경사진 가늠쇠, A1 개머리판, 기울어진 손잡이, 휘어진 30발 탄창 |
| 총 재질 | 금속성 .4, 회색으로 보임 | 금속성 .2, 거의 검정 |
| 망토 | 흉곽에 고정 (몸통과 함께 강체 회전) | 뼈 3개 체인, 중력 방향으로 늘어지고 몸통 회전을 따라 늦게 움직임 |
| 긴 머리카락 | 머리에 고정 | 뼈 2개 체인, 같은 방식 |

망토와 머리카락은 GLB 원본을 바꾸지 않는다. 렌더할 때만 체인 뼈를 추가하고 해당 정점의 가중치를 체인으로 옮긴다. 체인은 몸통의 좌우 회전만 따르는 기준 형태로 당기는 스프링(망토 강성 30·감쇠 4, 머리카락 45·5)이며, 각 마디는 기준 위치보다 앞으로 나오지 않게 막아 몸을 뚫지 않게 했다. 망토의 금색 테두리는 갑옷과 재질을 공유해서, 등 뒤(x < −0.12)·어깨 아래의 것만 망토로 옮겼다.

## 확인한 범위

- 렌더 결과를 확대해서 직접 봤다. M16 형태와 망토 늘어짐, 8방향의 일관성을 확인했다.
- 엉덩이 아래 구간에서 망토 뒤쪽 끝이 움직인 폭: 001은 2px(3가지 위치), 002는 4px(5가지 위치)다. 장전 동작은 몸 이동이 작아서 흔들림도 작다.
- Chrome에서 미리보기 탭의 재생과 버전 전환을 확인했다.

## 남은 한계

- 손가락: 모델의 손이 뼈 하나라서 쥐는 동작을 만들 수 없다. 손가락 뼈와 가중치가 있는 모델이 필요하다.
- 플랜 B와 같은 장전 동작 비교: 플랜 B 프레임을 만드는 image_gen 도구가 이 작업 환경에 없어서 진행하지 못했다.
- 망토는 다리·총과의 실제 충돌을 계산하지 않는다. 기준보다 앞으로 나오지 않게만 막는다.
- 떨어지는 탄창은 바닥 근처에서 스프라이트에서 사라진다(게임에서 별도 파편으로 처리하는 것을 전제로 한다).
- 3D 모델 외형과 동작의 자연스러움은 사용자 검수 대기다.
