# 플랜 E · 원화 투영 모델 002

`concepts/turnaround_001`의 4방향 원화(정면·좌·후면·우)만으로 만든 clone_01 3D 모델이다. 유료 생성 서비스나 외부 업로드 없이 Blender 기본 기능으로 만든다.

- 생성: `tools/plan_e/build_hull_model.py` (Blender 5.2.3 헤드리스, 약 15초)
- 결과: `source/clone_01_hull.blend` — 몸통(약 22만 면), 왼팔·오른팔(각 약 3만 면), 21관절 리그
- 몸통용 그림: `source/body_{front,left,back,right}.png` (팔 부분을 지운 원화)
- 기록: `records/build.json` (원화 보정값, 관절 좌표, 면 수, 시간)

## 만드는 방법

1. 원화 테두리에서 배경을 채워 실루엣을 분리한다. 실루엣 안쪽의 회색 금속은 지워지지 않는다.
2. 네 실루엣 안에 모두 들어가는 칸만 남겨 입체를 깎는다. 단면은 정면·측면 폭에 맞춘 둥근 형태로 만들고, 바닥 그림자는 발 주변만 남기고 잘라 낸다.
3. 원화에서 잰 어깨·팔꿈치·손목·손 관절을 따라 팔을 별도 메시로 잘라 낸다. 몸통에 쓰는 원화에서는 팔 부분을 주변 색으로 채워, 팔을 들었을 때 몸통에 팔 그림이 남지 않게 한다.
4. 각 면이 향하는 방향의 원화를 투영한다. 원래 위치와 법선을 속성으로 저장해서, 리그가 메시를 움직여도 그림이 붙어 있다. 원화의 명암을 그대로 쓰기 위해 조명은 계산하지 않는다.
5. 플랜 D와 같은 21관절 이름으로 리그를 만들어 `render_sprites.py`가 그대로 자세를 잡는다.

## 한계

- 대각선 방향에는 원화가 없어서 정면·측면 그림이 섞인다. 얼굴이 겹쳐 보이거나 경계가 생긴다.
- 망토는 몸통과 한 덩어리다. 망토와 머리카락은 흔들리지 않는다.
- 다리를 크게 벌리면 다리 사이의 메운 면이 드러나 회색이 보인다. 그래서 sprite_003은 원화의 선 자세(`--stance 0`)를 쓴다.
- 손가락은 따로 움직이지 않는다.
- `source/` 폴더는 약 36MB다. 같은 명령으로 15초 안에 다시 만들 수 있다.
