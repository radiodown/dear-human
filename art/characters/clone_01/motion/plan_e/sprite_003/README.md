# 플랜 E · 3D→도트 스프라이트 003

[원화 투영 모델 002](../model_hull_002/README.md)로 렌더링한 장전·8방향 스프라이트다. 001·002의 플랜 D 모델 대신, 4방향 원화로 만든 모델을 사용한다.

```
Blender -b --factory-startup --python tools/plan_e/render_sprites.py -- \
  --glb art/characters/clone_01/motion/plan_e/model_hull_002/source/clone_01_hull.blend \
  --out art/characters/clone_01/motion/plan_e/sprite_003 \
  --exposure 0 --stance 0 --twist 0.35 --colors 32 --ppm 96
```

| 항목 | 002 | 003 |
| --- | --- | --- |
| 모델 | 플랜 D (코드로 만든 도형) | 원화 4장 투영 모델 |
| 캔버스 | 137px, 미터당 64px | 205px, 미터당 96px (캐릭터 키 약 168px) |
| 팔레트 | 24색 | 32색 |
| 노출 | .6 | 0 (원화 명암 그대로) |
| 상체 비틀기 | 1배 | .35배 (비틀면 등과 망토가 너무 많이 보임) |
| 다리 | 사격 자세로 벌림 | 원화의 선 자세 |

장전 동작(54프레임, 15fps), M16, 탄창 처리는 002와 같다. 렌더 시간은 약 66초다.

## 확인한 범위

- 같은 프레임을 002와 나란히 놓고 확대해서 봤다. 얼굴, 금장, 망토 독수리 문양이 도트에서도 읽힌다.
- 미리보기 탭의 기본 버전을 003으로 바꿨다.

## 남은 한계

- 금색이 팔레트에서 베이지 쪽으로 바랜다.
- 망토·머리카락 흔들림이 없다 (모델에서 망토가 몸통과 한 덩어리).
- 대각선 방향(8방향의 3/4 시점)은 이음매가 보인다.
- 동작의 자연스러움과 아트 채택은 사용자 검수 대기다.
