# 플랜 E · 3D→도트 스프라이트 007 · M16 디테일

[sprite_006](../sprite_006/README.md)과 같은 측면 9개 동작(+장전)이다. 뛰며쏴 전방 기울기 시도(c682f9e)는 사용자 지시로 되돌렸고(28baa36), 이번에는 M16만 다시 만들었다. 사용자 확인에 따라 M4가 아니라 프로젝트 기준인 M16을 유지했다.

```
Blender -b --factory-startup --python tools/plan_e/render_sprites.py -- \
  --glb art/characters/clone_01/motion/plan_e/model_hull_005/source/clone_01_hull.blend \
  --out art/characters/clone_01/motion/plan_e/sprite_007 \
  --exposure 0 --stance 1 --twist 0.35 --colors 32 --ppm 96 --gun-light 0.45
```

렌더 시간은 약 363초다.

## M16 변경

| 항목 | 006 | 007 |
| --- | --- | --- |
| 길이 | 개머리판 끝 −0.36 ~ 총구 0.735 (1.1m) | 실제 M16A1 치수: −0.345 ~ 0.645 (0.99m), 개머리판~손잡이 0.33m |
| 재질 | 검정·모서리 회색 2종 | 리시버(양극 산화)·수지(개머리판·손잡이·총열 덮개)·강철(총열·가늠쇠)·밝은 소부품 4종 |
| 모서리 | 각진 상자 | 1.6mm 베벨로 모서리가 빛을 받음 |
| 부품 | 상자 위주 | 속이 빈 운반 손잡이, 가늠자 드럼, 장전 손잡이, 볼트 멈치, 조정간, 핀 2개, 방아쇠울, 총열 덮개 홈 7줄, 델타 링, A자 가늠쇠·대검 꽂이, 새장형 소염기(홈 3줄), 앞뒤 멜빵 고리, 탄창 리브·바닥판 |
| 밝기 | 조명 1배, 갑옷보다 밝은 회색 | 조명 0.45배(`--gun-light`), 갑옷과 같은 검은 톤 + 위쪽 조명으로 윗면 하이라이트 |

- 원화 투영 모델은 발광 재질이라 조명이 총·탄창에만 영향을 준다. 그래서 조명 세기를 따로 조절하는 `--gun-light` 옵션을 만들었다.
- 팔레트에 무채색 회색 3단계를 고정으로 넣었다. 핀·가늠쇠 같은 작은 밝은 부품은 픽셀이 적어 자기 색을 얻지 못하고, 가장 가까운 금색·살색에 배정되어 주황 점으로 찍혔기 때문이다.
- 총구 화염 위치를 새 소염기 끝(0.645)으로 옮겼다.

## 확인한 범위

- 같은 프레임(견착 대기, 서서쏴, 달리기, 장전)을 006과 나란히 놓고 도트를 6배 확대해 봤다. 총이 실제 비율로 짧아졌고, 총열 덮개 홈·A자 가늠쇠·소염기가 도트에서 읽힌다.
- 원본 해상도에서 운반 손잡이의 빈 공간, 장전 손잡이, 탄창 리브를 확인했다.

## 남은 한계

- 볼트 멈치·조정간·핀은 대부분 손과 팔에 가려 도트에서는 거의 보이지 않는다.
- 총 길이가 10cm 줄어 동작별 손 위치는 그대로지만, 화면에서 총구가 006보다 짧게 보인다.
- 동작의 자연스러움과 아트 채택은 사용자 검수 대기다.
