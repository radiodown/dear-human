# 플랜 E · 3D→도트 스프라이트 007

[sprite_006](../sprite_006/README.md)의 측면 9개 동작에서 **뛰며쏴**를 사용자 요청대로 앞으로 더 기울였다. 모델은 [원화 투영 모델 005](../model_hull_005/README.md)이고, 명령은 006과 같다.

## 뛰며쏴 변경

| 항목 | 006 | 007 |
| --- | --- | --- |
| 상체 숙임 | 15° (달리기와 같음) | 20° |
| 엉덩이부터 몸통 전체 기울임 | 없음 | 16° (`pose_body(hip_lean=16)`, 골반·허리·흉곽·목에 더함) |
| 골반 위치 | 그대로 | 6cm 앞으로 (`pelvis_forward`) — 앞발 위로 무게 이동 |
| 망토 공기 저항 | 2.4 m/s 기준 | 3.6 m/s 기준 — 망토가 뒤로 끌림 |

시선과 총구는 수평을 유지한다. 처음에는 상체 숙임만 15°/22°/28°로 비교했지만, 머리는 앞으로 나가도(15°→28°에서 원본 렌더 기준 29px) 망토와 긴 머리카락이 수직으로 늘어져 등 윤곽이 바뀌지 않았다. 그래서 망토가 매달린 어깨를 포함해 엉덩이부터 기울였다. 엉덩이 기울임 0°/10°/16°를 비교해 16°를 골랐다.

## 캔버스

몸이 앞으로 나가면서 총구 화염이 캔버스 오른쪽 끝에서 잘렸다. 한 동작만 카메라를 옮기면 동작을 바꿀 때 캐릭터 위치가 튀므로, 모든 클립의 캔버스를 오른쪽으로 16cm 넓혔다(205×205px → 221×205px). 미터당 96px과 캐릭터 위치는 그대로이며, 견착 대기 첫 프레임의 머리 위치가 006과 픽셀 단위로 같은 것을 확인했다.

나머지 8개 동작과 장전은 006과 같은 설정으로 다시 렌더했다(팔레트는 전체 클립에서 다시 계산된다).

## 확인한 범위

- 006과 007의 뛰며쏴를 도트 크기로 나란히 비교했다. 007은 몸 전체가 대각선으로 기울고 총구 화염이 잘리지 않는다.
- 동작의 자연스러움과 아트 채택은 사용자 검수 대기다.
