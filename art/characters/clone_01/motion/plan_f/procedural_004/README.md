# 플랜 F 004 카메라 시점 조절

2026-11-12 KST · 구현 인계, 브라우저 검수 대기.

[실행](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=f) · [이전 003 사격 자세·반동](../procedural_003/README.md)

사용자 요청은 “시선을 조절할수있는 레벨 추가”이며, 후속 답변으로 **카메라 시점 조절**을 확인했다.

기존 플랜 F 화면 아래에 좌우 회전 −90~90°, 위아래 각도 0~60° 슬라이더를 추가했다. 수평 0°에서 값을 올리면 내려다본다. 기본 시점 버튼은 좌우 0°·높이 8.3°로 복원한다. 정사영 크기를 유지하며 카메라가 기존 추적 중심 주위를 돌도록 구현했다. 훈련장 벽 뒤로 들어가지 않도록 좌우 범위를 제한했다.

카메라는 시뮬레이션 갱신과 분리돼 일시정지 중에도 조절할 수 있다. 기존 처음으로 버튼은 동작만 초기화하고 선택한 시점은 유지한다. 값은 브라우저 저장소 `dear-human:plan-f:camera:v1` 및 URL `fYaw`·`fPitch`에 저장한다. 주소에 값이 있으면 주소를 우선하며 없으면 브라우저 저장값을 사용한다. 잘못된 수치는 기본값으로 대체하고 범위를 제한한다.

캐릭터의 눈·머리·총 방향이나 사격 모션을 변경하는 조작은 아니다. 기존 JS 생성 모델·배경·광원·사격/반동·입력은 재사용한다. 이전 003 소스는 `../procedural_003/source_snapshot/`에 원래 상대 경로를 유지해 보존했다.

[제작 기록](record.json)에 소스 해시와 시각을 남겼다. AGENTS.md의 사용자 검증 인계 지침에 따라 이번 변경의 자동 테스트·브라우저 캡처는 실행하지 않았다. 기존 003 검사 통과를 004 시점 조절의 검증으로 취급하지 않는다. 새 이미지·모델 생성 호출은 0회이며 총 시간·비용은 측정하지 않았다.
