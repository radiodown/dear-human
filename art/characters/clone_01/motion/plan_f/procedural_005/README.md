# 플랜 F 005 C키 앉기·이동 방향 바라보기

2026-11-12 KST · 구현 인계, 동작·브라우저 검수 대기.

[실행](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=f) · [이전 004 카메라](../procedural_004/README.md)

사용자 요청: “C를 누르면 앉게 해줘. 그리고 캐릭터는 정면을 보게 해줘.” 후속 정정: “캐릭터가 정면으로 보라는것은 이동하는 방향을 보라는 뜻이었어”. 정면은 **이동 방향**으로 구현하며 화면을 바라보는 해석은 적용하지 않는다.

C키를 한 번 누르면 앉고 다시 누르면 일어선다. 키를 누르고 있을 때 발생하는 반복 입력은 무시한다. 화면의 앉기 C / 일어서기 C 버튼도 같은 전환을 사용한다. 골반을 0.34m 낮추고 뒤로 이동시키면서 상체 전경·무릎 굽힘을 연결한다. 전환은 고정 스텝에서 부드럽게 보간하며, 앉은 상태의 최고 이동 속도는 서 있을 때의 절반이다. 총·양손·반동은 기존 어깨와 손 접점 계산을 따라가므로 앉기 중에도 발사 입력을 사용할 수 있다.

캐릭터 기준 전방을 오른쪽 이동 시 +X, 왼쪽 이동 시 −X로 맞췄다. 몸·머리·총은 이동 방향을 따르고, 멈추면 마지막 방향을 유지한다. 양쪽 이동키를 함께 누르면 이동과 방향 변경을 멈춘다. 머리는 몸통의 숙임·비틀림을 역보정해 이동 방향의 수평 시선을 유지하고 작은 반동 지연만 남긴다. 발은 캐릭터 전방을 따라 움직이며 기존의 비스듬한 0.8rad 방향 대신 ±90°를 사용한다. 카메라 시점은 별도로 유지하므로 시점 조절에 따라 다른 면이 보인다.

앉을 때 길어진 망토 아래 부분은 월드 바닥 높이로 제한하고 캐릭터 뒤로 밀어 지면 아래로 내려가는 것을 줄였다. 단순 위치 보정이며 천의 자기 충돌·몸과의 충돌이나 사실적인 접힘 시뮬레이션은 아니다. 발이 멀리 뻗는 이동 자세에는 작은 골반 낮춤을 추가했다.

일시정지 상태에서 앉기 버튼/C를 누르면 시뮬레이션 시간을 진행하지 않고 선택한 자세로 즉시 바꾼다. 처음으로 버튼은 서 있는 기본 자세·오른쪽 방향으로 초기화하며 카메라 설정은 유지한다. 앉기 선택은 탭 왕복 중 유지하지만 새로고침 시 초기화한다.
