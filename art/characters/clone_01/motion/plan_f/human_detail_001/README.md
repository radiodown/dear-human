사용자 요청: “이제 그방식대로 캐릭터를 디테일하게 표현해줘”. SALTLINE 손의 곡면 생성·파지와 로봇의 코드 골격을 전신에 확장하는 분석에 따라 리안의 생성 형상과 표면 변형을 개선했다. 캐릭터 선택·시점·진행 방향·게임 규칙은 기존 계약을 사용한다.

## 적용한 형상과 구조

- **몸통–어깨–팔–골반–다리:** 독립된 팔다리 외피를 제거하고, 해부학적 타원체와 굵기가 변하는 캡슐의 연속 장에서 외피를 생성한다. 같은 격자 모서리의 정점을 공유하는 marching tetrahedra로 분기 부위를 연결한다. 초기 한 번 계산하며 저장 모델·정점 덤프를 읽지 않는다.
- **13개 전신 뼈:** 골반·흉곽·목/머리 기준, 양 상완·전완·손, 양 허벅지·종아리. 부위별로 최대 네 뼈 가중치를 생성하고 기존 자세 드라이버를 계층 골격으로 변환한다. 피부/제복은 GPU 스키닝을 쓰고 갑옷·벨트·장비는 기존 강체 프레임을 따른다.
- **관절 보정:** 양 팔꿈치·무릎에 생성한 반경 보정 델타를 두고 현재 굽힘에 따라 혼합한다. 손목 가까이는 손 뼈로 가중치를 넘겨 소매와 손의 방향 전환을 연결한다.
- **얼굴:** 코의 다리·끝·콧방울, 안와·광대·턱·입 주변을 단면 변위로 설계했다. 아몬드 형태의 눈 표면, 상하 눈꺼풀·속눈썹·눈썹, 입술의 면과 입술선, 귀 테두리·안쪽 굴곡을 추가했다. 뺨은 약한 정점 색 변화, 눈은 물리 재질 하이라이트를 사용한다.
- **머리:** 검은 장발과 앞머리를 유지하고 납작한 띠 대신 두께가 있는 곡선 다발로 생성한다. 뒤쪽 23개 움직이는 다발과 앞/옆머리를 구성하고 기존 후행 반응을 연결했다.
- **손:** 손바닥·커프·패드·봉제선과 세 마디 손가락 다섯 개. 양손 각각 15개 손가락 뼈를 코드로 생성했다. 주손 파지·보조손 받침·탄창·노리쇠·파우치 교체 중 놓기 프리셋과 검지 방아쇠 동작을 연결했다.
- **제복/장비:** 칼라 자수·버클·후면/측면 하의 패널·소매 봉제선·전완 스트랩·가터 버클·홀스터·군화 옆선을 추가했다. 하의 패널은 이동/앉기 상태에 맞춰 제한된 회전으로 열린다.

## 설계에서 구체화한 선택

분석 문서는 단면 경계를 명시적으로 연결하는 패치를 제안했다. 이번 몸통의 어깨·골반 분기는 **연속 장을 하나의 표면으로 추출하는 방식**으로 구현했다. 손·머리·입술에는 단면/곡선 방식을 사용한다. 이는 구들을 겹쳐 렌더하는 방식이 아니라, 합쳐진 장에서 실제 연결된 외피 메시를 생성하는 방식이다. 격자 해상도에 따른 시작 시간과 세부 손실은 측정/검토가 필요하다.

전신 기준 격자는 72×100×24셀이다. 외피 생성 결과의 정점/삼각형 수나 프레임 속도는 이번에 실행 측정하지 않았다. 평소 프레임에서는 골격·형태 보정량만 변경하며 외피 토폴로지를 다시 생성하지 않는다. 작은 관절 보정의 노멀은 기본 스키닝 노멀을 사용해 정밀한 보정 노멀은 후속 과제다.

기존 상완/전완/허벅지/종아리 그룹은 장비와 IK 프레임으로 유지하고, 이 그룹들이 새 스키닝 골격을 구동한다. `createLian()`의 `root`, `muzzle`, `ejection`, `pose` 계약을 유지해 기존 미리보기·총구 효과와 연결한다. 손가락 자세는 렌더 시 상태를 읽기만 하며 별도의 장전 시계를 만들지 않는다.

## 유지한 동작과 남은 한계

이동·C 앉기·일반/빈 탄창 장전·단발/연사·0.25×·정지·카메라 슬라이더를 기존 플랜 F에서 사용한다. 배경·현재 무기 디테일·반동 개선·A~E/GLB·플랜 G는 이번 작업에서 수정하지 않았다. 기존 발 위상 모션과 IK를 사용하며 월드 접지 추적, 별도 쇄골/척추 다분절, 전완 twist 보조 뼈와 천 충돌 전체를 구현한 것은 아니다.

얼굴 미감, 어깨/골반 큰 굽힘, 손가락의 실제 표면 접촉, 팔 도달 범위, 머리/망토/장갑판/하의의 관통은 사용자 검수가 필요하다. 연결 외피가 있다는 사실만으로 모든 자세에서 피부 틈과 간섭이 없다고 판단하지 않는다. 손바닥과 얼굴·머리는 별도 메시이며 부츠·칼라·장갑 경계는 겹침으로 연결한다.

사용자의 기존 “검증은 내가할게 개발만해봐” 방침에 따라 새 자동 테스트·구문 검사·목록/문서 검사·브라우저 캡처는 실행하지 않았다. 이전 버전의 검사 결과를 이번 결과의 통과로 사용하지 않는다.
