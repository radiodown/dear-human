# 플랜 F 007 · 컨테이너 표면 질감

[실행](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=f) · [이전 006](../procedural_006/README.md)

사용자 요청: SALTLINE의 컨테이너 질감 구현 설명 후 “플랜 F에 적용”. 현재 장전까지 구현된 006을 기준으로 배경 컨테이너와 생성 재질을 추가했다.

## 적용

- 6.06 × 2.59 × 2.44m 컨테이너 3개를 이동 통로 뒤에 배치했다. 적갈색·청회색·올리브색 도장과 서로 다른 고정 시드를 사용한다. 기존 작은 상자를 대체하고 격납고 벽을 뒤로 옮겼다.
- 측면·끝판·지붕·문을 연속된 철판 메시로 생성한다. 기본 주름 간격 .278m / 깊이 .036m, 국소 찌그러짐, 모서리 프레임·코너 블록·문 잠금봉·손잡이를 더했다.
- 각 컨테이너의 색상 / ORM(음영·거칠기·금속성) / 노멀맵을 1024 × 512 크기로 한 번 생성한다. 큰 얼룩·작은 부식·도장 벗겨짐·윗부분 녹물·하단 오염을 같은 손상 마스크로 연결한다. 도장과 녹은 비금속, 노출된 철판만 높은 금속성을 갖는다.
- 주름 골·찌그러짐에는 정점 색으로 추가 음영을 준다. 물류 표지는 Canvas로 만들고 실제 평판 표지로 부착한다. 표면에 맞춰 휘어지는 로고 데칼은 이번 범위에 없다.
- ‘젖은 표면’ 스위치는 기존 바닥과 컨테이너 도장의 젖음 강도를 함께 바꾼다. 컨테이너는 거칠기를 낮추고 색을 어둡게 해 기존 PMREM 환경과 조명에 반응한다. 별도 실시간 평면 반사나 물방울 시뮬레이션은 아니다.
- 캐릭터·무기 재질, 이동·앉기·사격·장전·시점 제어는 기존 구현을 사용한다. 컨테이너는 배경이며 새 충돌·엄폐 기능을 추가하지 않는다.

## 참고와 구현 차이

로컬 Saltline `index.html`, 고정 커밋 `09c51774cd77aad750bd2d6c42af2b1020cb668d`의 `zA`(철판·찌그러짐·색·표지), `Uo`(주름 치수), `Gg`(색/ORM/노멀 생성), `h3`(재질 셰이더 확장)를 참고했다. 원본 번들·브랜드·이미지·모델을 복사하지 않고 플랜 F 모듈로 새로 구현했다.

원본은 GPU 렌더 타깃으로 맵을 생성한다. 이번 구현은 기존 플랜 F 방식에 맞춰 **JavaScript CPU 계산 → DataTexture → Three.js 물리 기반 재질**을 사용한다. 따라서 Saltline의 전체 재질 시스템을 그대로 이식한 것은 아니다. 3종 × 3장 맵의 RGBA8 기본 데이터는 약 18MiB이며 mipmap을 포함한 GPU 저장은 약 24MiB 수준이다. 기동 지연과 프레임 성능은 측정하지 않았다.
