# 플랜 F · SALTLINE 방식 총기 디테일 001

사용자 요청: SALTLINE의 총 표현 설명에 이어 “플랜 F 에도 그걸 답습하여 만들어줘”. 로컬 고정 커밋 `09c51774cd77aad750bd2d6c42af2b1020cb668d`의 `w_`(총 형상), `dm`(재질·손·기계 동작), `Bf`(표면 셰이더), `U_`(조준기)를 정적으로 참고했다. 원본 번들·총 메시를 복사하거나 GLB로 변환하지 않고 플랜 F의 전신 리그와 기존 총 길이에 맞춰 별도 모듈로 작성했다.

## 적용

- 총몸을 윤곽선 돌출과 분리 벽으로 구성하고 탄피 배출구를 실제 구멍으로 만든다. 노리쇠는 별도 움직이는 메시다.
- 총열 덮개는 구멍이 뚫린 여덟 면으로 조립한다. 레일의 톱니·측면 레일·나사·선택 레버·가스관·가늠쇠 받침을 추가했다.
- 총열·칼라·총구 제동기는 단면 회전과 분리 리브로 만든다. 총구와 제동기 슬롯은 열려 있다. 개머리판도 구멍을 가진 윤곽선과 고무 패드로 구분한다.
- 구부러진 탄창·리브·바닥판·급탄부 탄약을 만들고 기존 손 부착 장전에 연결했다. 탄창 교체 중에는 새 탄창의 탄약을 표시한다. 실제 잔탄 보충은 기존대로 장전 완료 시점이다.
- 아노다이징 금속·인산염 느낌 강철·폴리머·고무·황동을 별도 PBR 재질로 구성했다. 물체 좌표 기반 입자/미세 긁힘과 거칠기 변화를 셰이더로 추가하고 문자는 CanvasTexture로 생성한다. 총기 전용 빗물 누적/젖음은 이번 범위에 포함하지 않는다.
- 조준기는 속이 빈 프레임·반투명 유리·발광 점으로 구성한다. 점은 유리 앞의 단순 표식이며 SALTLINE의 광학/시차 보정을 완전히 재현한 것은 아니다.
- 발사 후 0.072초 노리쇠 왕복, 마지막 탄의 후퇴 잠금, 빈 장전 조작에 따른 해제, 방아쇠와 오른손 검지 동작을 추가했다. 장전 손잡이는 기존 키프레임을 따른다.
- 겹친 화염 면과 순간 조명, 월드 좌표 탄피 배출·중력·단순 바닥 튀김, 연사 후 잔연기를 추가했다. 탄피 36개·연기 24개·탄도 18개 고정 풀을 재사용한다. 배경/인물과의 탄피 충돌은 구현하지 않았다.
- 고정 부품은 재질별로 병합하고 움직이는 탄창·노리쇠·방아쇠를 분리한다. 형상은 초기화 시 한 번 생성한다.

## 연결과 보존

`weapon-definition.js`가 개머리판·양손·탄창·손잡이·총구·배출구 좌표를 소유한다. 기존 개머리판과 양손 좌표를 유지하며 `weapon-pose.js`와 `reload-pose.js`가 이를 참조한다. 카메라, 이동 방향, C 앉기, R 일반/빈 장전, 30발·예비탄 무제한, 반동·합성 음향·0.25×·일시정지는 기존 경로를 공유한다.

구현은 `weapon-build.js`, `weapon-materials.js`, `weapon-motion.js`, `weapon-definition.js`에 분리했다. `model-build.js`는 총을 조립하고 `model.js`는 같은 전신 자세 평가 끝에서 기계 동작을 적용한다. `effects.js`와 `index.js`는 최종 월드 총구/배출구로 효과를 발생시킨다. 포즈 재평가만으로 기계 시간이 진행하지 않는다.

이 작업의 변경 전 소스는 `../procedural_006/source_snapshot/`에 보존했다. 작업 중 별도로 추가된 컨테이너 007 및 전신 모션 변경은 제거하지 않았다. 버전 번호 충돌을 피하기 위해 이 작업은 `weapon_detail_001`로 분리하고 인계 시점의 실행 소스를 이 폴더의 `source_snapshot/`에 저장한다. 동시 작업의 변경 내용을 총기 작업의 성과로 기록하지 않는다.

## 검수 상태

사용자의 기존 “검증은 내가할게 개발만해봐” 지침에 따라 테스트·구문 검사·문서/목록 검사·브라우저 캡처를 실행하지 않았다. 소스 열람과 카탈로그 조회만 수행했다. 이전 passed 기록을 이 결과에 사용하지 않는다.
