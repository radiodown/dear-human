## 참고 소스와 적용

로컬 [Saltline 고정 커밋](https://github.com/realcodebear/saltline-fable-5.2/tree/09c51774cd77aad750bd2d6c42af2b1020cb668d)의 `index.html`을 정적으로 조사했다. [조사 기록](saltline-research.json)에 파일 해시·식별자·문자 오프셋을 남겼다. 원본 게임을 실행해 장면을 시각 비교하지는 않았다.

| 원본에서 확인한 구조 | 플랜 F 적용 |
|---|---|
| `$` / `ue`의 일반·빈 탄창 손 키프레임, `le`의 위치 lerp·쿼터니언 slerp, `Yo`의 부드러운 시간 보간 | 전신 인물에 맞춘 손 목표와 회전 키프레임을 새로 정의하고 양팔 IK로 연결 |
| `magout` / `magin` 사이에 탄창을 보조 손 변환에 부착 | 총에 장착된 탄창과 손에 든 탄창을 구분하고 손→탄창의 단일 부착 변환 사용 |
| `reloadW` / `rackW`와 `nu`의 총 위치·회전 혼합 | 총을 가슴 앞쪽으로 낮추고 기울인 뒤 복귀. 오른손은 손잡이 유지 |
| 위상을 한 번만 발행하는 이벤트와 일반 2.1초·빈 탄창 2.72초 | 60Hz 고정 시간에서 분리·삽입·추가 조작 소리 큐. 프로젝트 기본안에 맞춰 2.2초 / 2.8초 |
| 삽입 큐에서 탄수 보충, 장전 중 발사 차단 | [프로젝트 장전 규약](../../../../../../docs/22-weapon-reloading.md)에 따라 완료 시 탄수를 한 번 보충하고 다음 틱부터 발사 허용 |

원본의 1인칭 전용 무기·손 메시나 번들 코드를 이식하지 않았다. 기존 플랜 F의 코드 생성 총·인물·재질을 재사용하고 `reload.js` / `reload-pose.js`로 구현했다.

## 동작과 조작

**R키 또는 장전 R 버튼**으로 시작한다. 동작 확인용 샘플이므로 만탄에서도 일반 장전을 재생한다. 키를 길게 누르거나 R을 연타해도 진행 중인 장전을 다시 시작하지 않는다.

일반 장전은 총을 낮춤 → 왼손 탄창 접근 → 분리 → 허리 파우치 쪽에서 교체 → 삽입·확인 → 앞손잡이 복귀 순서다. 빈 탄창 장전은 삽입 뒤 노리쇠 손잡이를 당겼다 놓는 동작을 추가한다. 분리된 탄창은 손과 같은 회전을 사용하며, 파우치 교체 구간에는 잠깐 숨겨 새 탄창을 꺼내는 것으로 표현한다. 바닥에 버리는 탄창 물리는 추가하지 않았다.

| 주요 시점 | 동작 |
|---|---|
| 0~0.40초 | 총을 낮추고 탄창을 잡음 |
| 0.48초 | 장착 탄창에서 손에 든 탄창으로 전환 |
| 0.90~1.04초 | 파우치 쪽 탄창 교체 |
| 1.42초 | 삽입·장착 탄창 복원 |
| 1.60초 | 삽입 확인 |
| 일반 2.20초 | 손·총 복귀와 장전 완료 |
| 빈 탄창 2.08~2.31초 | 노리쇠 손잡이 당김·복귀 |
| 빈 탄창 2.80초 | 손·총 복귀와 장전 완료 |

탄창은 30발이고 발사 성공마다 1발을 소비한다. 예비탄은 무제한이다. 0발에서 발사를 시도하면 빈 탄창 장전이 시작된다. 장전 중에는 사격·단발 예약을 막으며 방아쇠를 놓으면 완료 후 자동 발사하지 않는다. 방아쇠를 계속 누르면 완료 다음 틱부터 연사를 재개한다. 탄창 삽입은 시각 큐이며 실제 보충은 전체 동작 완료 시 수행한다.

이동·C 앉기·좌우 전환과 같은 장전 시간을 공유한다. 장전 중 이동 속도는 기존의 75%이며 앉기 속도 감소와 함께 적용된다. 오른손은 총을 잡고 왼손은 현재 상체·총의 좌표에서 계산하므로 자세 전환과 방향 전환에 같이 따라간다. 망토·다리·기존 반동은 기존 경로를 재사용한다.

HUD에 잔탄·예비탄과 장전 단계·진행률을 추가했다. **총기 소리**를 켜면 분리·삽입·확인·노리쇠 조작음을 코드로 합성한다. 0.25×는 시간 큐·탄창·손·총을 함께 늦추며 소리 자체의 길이/음높이는 변경하지 않는다. 일시정지·탭 숨김은 장전 진행을 멈추고, 처음으로는 장전을 취소하고 30발·기본 자세로 초기화한다. 정지 상태에서 새 장전을 요청하면 단발 버튼과 마찬가지로 재생을 시작한다.

## 인계와 보존

005 소스는 `../procedural_005/source_snapshot/`에 원래 상대 경로로 보존했다. [제작 기록](record.json)에 입력·소스 해시·실제 기록 시각을 남겼다. 사용자 검증 인계 지침에 따라 새 테스트·브라우저 캡처를 실행하지 않았으며 과거 003 검사 통과를 이번 장전의 검증으로 사용하지 않는다.

손가락별 파지·손목과 탄창의 표면 간섭·파우치 교체 가림·서기/앉기/이동 조합은 시각 검수 대기다. 기존 팔꿈치 IK·손 모양을 사용하며 새로 물리적 탄창 인벤토리나 약실 +1발을 시뮬레이션하지 않는다. 자동 생성 이미지·외부 모델·모션 파일 호출은 0회, 총 작업 시간·비용은 측정하지 않았다.
