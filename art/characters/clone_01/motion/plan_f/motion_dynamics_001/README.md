# 플랜 F 반동·역동 모션 001

2026-11-12 KST · 구현 인계, 동작·브라우저 검수 대기.

[실행](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=f) · [기존 장전](../procedural_006/README.md)

사용자 요청: “반동이나 캐릭터 모션이 역동적이게해줘”. 기존 모델·카메라·조작을 사용하며 반동, 보행, 앉기, 장전과 후속 머리/망토 움직임을 조정했다.

## 변경 동작

- 발사 반동: 작은 단조 복귀를 감쇠 진동으로 바꿨다. 첫 발은 더 큰 충격을 주고, 연사에는 작은 결정론적 강약과 좌우 비틀림을 더한다. 총의 빠른 들림/뒤밀림, 어깨와 골반의 늦은 반응, 작은 되튐과 복귀를 나눴다. 앉아 쏠 때는 충격을 조금 줄인다.
- 전신 반응: 상체 뒤밀림·골반 낮춤·팔꿈치 열림·머리 지연을 연결했다. 출발/감속과 방향 전환에는 몸의 기울기·비틀림을 가산한다. 얼굴은 진행 방향을 유지하면서 작은 반동 반응만 남긴다.
- 보행: 한 주기의 62%를 지지, 38%를 발 회수로 나누고 뒤꿈치 접지→발끝 밀기→들어 올리기를 연결했다. 보폭과 위상 속도는 함께 조정하며 앉아 이동하면 보폭과 발 들림을 줄인다. 발을 딛는 순간의 하중을 골반/몸통으로 전달한다.
- 앉기: 즉시 빠르게 내려가던 지수 보간을 속도를 가진 감쇠 스프링으로 바꿔 가속·감속을 만든다. 낮은 자세에 도달할 때 작은 하중 반응을 추가한다. 일시정지 C 조작은 기존처럼 자세를 즉시 바꾸되 스프링 상태도 함께 맞춘다.
- 장전: 탄창 분리·삽입·확인·노리쇠 이벤트에 총과 몸의 짧은 충격을 더했다. 파우치를 오가는 손에는 작은 곡선 경로를 더했으며 손에 든 탄창도 같은 변환을 따른다. 장전 시간·탄수 보충 시점은 유지한다.
- 후속 움직임: 몸의 충격과 출발/감속을 머리카락·망토가 늦게 따라오도록 연결했다. 망토의 바닥 제한은 서기/이동에도 적용한다.

`motion.js`는 감쇠 진동과 지지/회수 발 경로를 계산한다. 상태는 `simulation.js`의 고정 60Hz 갱신에서만 진행하며 `model.js`와 `reload-pose.js`는 표시 자세를 평가한다. 이전과 같은 단발·0.25×·C 앉기·R 장전·일시정지 조작으로 검토할 수 있다. 발사 간격·탄창 용량·카메라 설정은 이 변경으로 조정하지 않는다.

## 구현 수치와 한계

총의 반동 입력은 이전 80에서 첫 발 130 / 연사 112를 기본으로 바꿨고, 작은 강약 변화와 앉기 배율을 적용한다. 총구 회전 계수는 이전 0.072에서 0.115rad, 상체 회전 반응은 이전 0.07에서 0.18rad 계수로 늘렸다. 이는 연출용 수치이며 실제 총기나 인체 물리의 측정값이 아니다.

총·오른손·장전 왼손·탄창은 기존 접점 경로를 공유한다. 다리 길이보다 발 목표가 멀어지지 않도록 두 다리 도달 길이로 골반의 최대 높이를 제한한다. 이 제약은 메시의 모든 간섭이나 발의 완전한 지면 고정을 보장하지 않는다. 시작/정지 시 발 경로 혼합, 갑옷·손목·망토 간섭, 반동 강도와 모션 미감은 시각 검수 대기다.

공유 작업 폴더에 함께 반영된 컨테이너 및 무기 기구부·효과 연결을 보존했다. 숫자형 절차 모델 버전과 별도로 `motion_dynamics_001`에 이 모션 변경을 기록한다. 변경 전 006 소스는 `../procedural_006/source_snapshot/`, 현재 통합 소스 사본은 `source_snapshot/`이다. 이 폴더는 보존용 소스이며 독립 실행 배포물이 아니다. 실제 재생은 기존 공통 샘플 경로를 사용한다.

[제작 기록](record.json)에 변경 범위·소스 해시·시각을 남겼다. 사용자 검증 인계 지침에 따라 자동 테스트·브라우저 캡처는 실행하지 않았고 과거 검증을 이번 모션의 통과로 표시하지 않는다. 외부 이미지·모델·애니메이션 생성 호출은 0회, 총 작업 시간·비용은 측정하지 않았다.
