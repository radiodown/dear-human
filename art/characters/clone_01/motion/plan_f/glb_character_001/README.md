## 적용

기존 [리안 GLB](../../glb_model_001/source/version04.glb)의 메시·내장 텍스처·65관절 Mixamo 뼈대만 불러온다. 원본을 재생성하거나 수정하지 않고 높이 1.70m로 정규화한다. 사용자 요청에 따라 캐릭터에 한해 플랜 F의 외부 GLB 미사용 원칙을 대체한다.

- `game/plan-f/glb-character.js`: GLTFLoader 비동기 로딩, bind pose 복원, 실제 관절 길이/손바닥 기준 추출, F 자세→GLB 뼈대 연결. 저장된 노드 자세 대신 inverse bind matrix를 기준으로 삼는다.
- `game/plan-f/model.js`: 기존 동작 계산을 공유하며 외부 리그·어깨/골반/손바닥 기준을 받는다. 별도 인수를 주지 않으면 기존 생성 캐릭터를 그대로 만들 수 있다.
- `game/plan-f/index.js`: F 탭을 열 때 캐릭터 로딩을 기다린 뒤 씬을 시작한다. 로딩 메시지·재시도와 탭 이탈 중 로딩 처리, 최초 중립 자세를 연결한다.
- F의 기존 코드 생성 소총·탄창·총구 효과·컨테이너·조명·후처리·합성 소리와 시뮬레이션을 사용한다. 이동·앉기·사격·일반/빈 장전·30발 탄약·0.25×·정지·중립 보기·카메라 조작을 같은 컨트롤에 연결한다.
- GLB 내장 애니메이션은 재생하지 않는다. 별도 GLB 무기나 무장 loadout을 불러오지 않는다. 이번 작업은 캐릭터 외형과 뼈대의 교체다.

## 자세 연결

GLB를 바인드 자세로 복원한 뒤 실제 골반·어깨·손목·무릎·발목 좌표와 뼈 길이를 기록한다. F가 계산한 골반 이동을 적용하고 척추 세 관절에 몸통 회전을 나눠 준다. 머리의 이동 방향 시선 보정과 양팔/양다리 IK를 원래 뼈대에 전달한다. 뼈의 자식 위치와 스케일을 늘려 접점을 맞추지 않는다.

오른손은 방아쇠, 왼손은 받침/장전이다. 검지·중지·소지의 바인드 좌표에서 손바닥 기준을 구하고, 기존 F의 손 접점을 실제 손목 목표로 변환한다. 무기가 팔 길이 밖에 있으면 총 전체를 도달 범위로 보정한 뒤 손·탄창·총구를 계산한다. 손가락은 F의 파지/장전 위상에 맞춰 원래 GLB 손가락 뼈를 회전시킨다.

원본 GLB의 일체형 의상·머리카락·망토는 기존 스킨 가중치를 따라 움직인다. 이전 생성 캐릭터의 별도 머리카락/망토 버텍스 애니메이션은 이 모델에 적용하지 않는다. 새 천 시뮬레이션·충돌 처리는 없다.

## 기록과 검수 상태

상태는 **untested · 사용자 검수 대기**다. AGENTS.md의 “검증은 내가할게 개발만해봐” 후속 지침에 따라 자동 테스트·구문 검사·문서/목록 검사·브라우저 실행/캡처를 하지 않았다. 기존 파일·카탈로그·재사용/의존 관계 조회와 소스/GLB 구조 읽기만 수행했다. 과거 F 검사 결과를 이 GLB 연결의 통과 결과로 사용하지 않는다.

실제 화면 로딩·텍스처·그림자, 좌우 이동·앉기·사격·일반/빈 장전·정지/재개·중립 보기 복귀, 양손 파지·손목 회전·발 접지·의상/망토 관통은 사용자 확인이 필요하다. 무기 도달 보정은 정밀 견착이나 무관통을 보장하지 않는다.

`before/`에는 변경 전 F 소스·공통 HTML·규칙·문서·카탈로그, `source_snapshot/`에는 적용 소스를 보존한다. `record.json`에는 원본과 파일 해시·재사용 관계·시간을, `recipe.json`에는 입력과 제작 범위를 기록한다. 이미지/모델 생성 도구 호출과 별도 유료 API 사용은 없다. 실제 작업 시간은 기록된 시작/종료 시각의 차이이며 인건비·토큰 비용은 측정하지 않았다.

원본 GLB·기존 생성 캐릭터 소스·다른 플랜·GLB/스프라이트 탭은 변경하지 않는다. 이 작업과 동시에 진행된 다른 GLB 장전/효과 수정은 본 버전의 산출물이 아니다.
