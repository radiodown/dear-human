# 앉아쏴 클론 이미지 001

사용자의 “그냥 이미지로 앉아쏴 자세의 클론을 그려줘” 요청으로 제작한 단독 일러스트다. 채택 외형 `reference_003_3d`를 참고해 M16을 견착한 한쪽 무릎 자세로 생성했다.

- [이미지](source/kneeling_fire.png)
- [정확한 영어 JSON 프롬프트](records/prompt.md)
- [생성 기록](records/generation.json)

버전 `kneeling_fire_001` · 사용자가 이 그림을 앉아쏴 자세의 정답 기준으로 채택했다. [별도 채택 기록](records/pose_reference_adoption.json)과 [파츠 모션의 문제 분석](../../../../../docs/kneeling-image-parts-analysis-001.md)은 당시 상태로 보존했다. 이후 [앉아쏴 017](../../../../../docs/kneeling-image-application-017.md)에 전용 자세·기존 UV 부착물과 바닥 망토를 연결했다. 런타임 결과는 `untested`·사용자 검수 대기이며 기존 외형 채택 원화는 유지한다. 사용자 검증 인계 지시에 따라 테스트·구문/문서/목록 검사·브라우저 검수를 실행하지 않았다.
