# 아렌 · 고유 얼굴 재설계 시안 011

사용자가 010의 “너무 똑같음”은 이전 시안이 아니라 **레아 세이두 본인과 너무 닮았다**는 뜻이라고 확인했다. 배우의 얼굴을 직접 재현하지 않고 차분하고 부드러운 분위기만 남기는 새 얼굴 시안이다.

- [생성 원본](source/portrait.png): 조금 길어진 타원형 얼굴, 또렷한 아몬드형 눈, 섬세한 콧선·중간 볼륨의 입술로 얼굴 구조를 새로 설계했다. 짙은 갈색 깔끔한 단발·녹갈색 눈·자연스러운 피부 질감을 유지했다.
- 내장 image_gen 1회. 입력에서 배우 이름과 이미지 참조를 모두 제외하고 독자적인 얼굴 구조를 명시했다. 닮은 정도·미모·나이·숙련감은 사용자 검수 대기이며 완전한 비유사성을 보장하지 않는다.
- [정확한 영어 JSON](records/prompt.json) · [영어 MD](records/prompt.md) · [실제 시간·해시](records/generation.json) · [표시 확인](reviews/verification.json).
- 공통 미리보기: `http://127.0.0.1:4173/#/samples/characters/iren?rev=face_original_sample_011`.
- 프랑스 국적·외형상 25~26세·분대장/돌격·연장자의 경험은 유지했다. 기존 전신 005·위키 전신/아이콘·다른 대원·모션·게임은 보존한다. 010은 배우 본인과 과도하게 닮았다는 반려 기록으로 남긴다.
- 새 상반신 생성이므로 의상 세부는 기존 전신과 다르다. 출생지·혈통·새 흉터·추가 전투 사건을 도입하지 않는다.
