# 아렌 · 프랑스 방향 새 얼굴 샘플 009

현재 상태: 사용자에게 “쌔보이는데 미녀는 아니야”라는 피드백을 받았다. 후속 [010](../face_french_beauty_sample_010/README.md)은 사용자가 지정한 레아 세이두 느낌으로 다시 그린다. 국적 프랑스는 유지하며 아래는 최초 제작 기록이다.

사용자가 프랑스 방향을 선택해 국적 설정과 새 상반신 얼굴 시안을 작업했다. 추천 조합인 짙은 갈색의 깔끔한 단발·녹갈색 눈에, 앞서 요청한 전장 경험·자연스러운 피부 질감·침착함을 함께 적용했다.

- [검토용 원본](source/portrait.png): 기존 얼굴을 참조하지 않고 새 생성한 25~26세 목표의 성인 여성 상반신. 짙은 갈색 원랭스 단발·녹갈색 눈·자연스러운 피부 질감·차분한 표정을 사용한다.
- 내장 image_gen 1회. 출력 원본 바이트를 그대로 보존했다. 신규 생성으로 검정·건메탈·금장 전투복의 세부도 이전 전신과 다르며 정확한 의상 보존을 주장하지 않는다.
- [정확한 영어 JSON](records/prompt.json) · [영어 MD](records/prompt.md) · [실제 시간·해시·시각 확인](records/generation.json) · [해당 페이지 확인](reviews/verification.json).
- 공통 미리보기: `http://127.0.0.1:4173/#/samples/characters/iren?rev=face_french_sample_009`.
- 아렌의 국적은 프랑스로 문서에 반영했다. 출생지·혈통·국적 취득 경위는 미정이며 외형상의 디자인 선택과 구분한다.
- 새 얼굴의 미모·나이·숙련감은 사용자 검수 대기다. 기존 전신 005·위키 전신과 얼굴 아이콘은 이전 외형으로 표시해 보존하며 모션·게임·다른 대원은 유지했다.
- 위키 본문은 독립적으로 수정했으며 docs 자동 복사·동기화를 추가하지 않았다. 변경 전 문서와 목록은 `records/before/`에 보존했다.
