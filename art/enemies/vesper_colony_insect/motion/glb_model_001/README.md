# vesper_colony_insect · GLB 모델 001

[illustration_001](../../concepts/illustration_001/source/illustration.png)을 바탕으로 사용자가 Tripo로 만든 메시에 직접 리깅한 mob 모델이다. 사용자 지시로 다리 대칭을 보정하고 제자리 걷기 클립을 넣었다. 미리보기 사이트의 ‘베스퍼 군락형 곤충’ 페이지 → ‘GLB 모델’ 탭(`#/samples/enemies/vesper_colony_insect?plan=glb`)이 `game/glb-model-lab.js`로 재생한다. 페이지를 열어도 렌더나 변환은 실행되지 않는다.

## walk / walk_fast 클립

수치와 키 테이블은 [records/motion.json](records/motion.json)에 있다(세 클립 공통 생성 스크립트 [tools/build_walk.py](tools/build_walk.py)).

- `walk_fast`는 사용자 지시(“2배정도 빠른 움직임”)로 추가했다. 보폭·발 들림·접지 비율·몸통/배 흔들림은 `walk`와 같고 한 주기만 12프레임(0.5초)이다. 제자리 클립이므로 실제 이동 속도도 보폭/주기 기준 2배(.26/초)에 해당한다.

- 24프레임·24fps·1초 루프, 제자리(몸은 이동하지 않고 발이 뒤로 밀림). Blender 5.2 헤드리스, [tools/build_walk.py](tools/build_walk.py).
- 교대 4족 보행: A조 L1·R2·L3·R4 / B조 R1·L2·R3·L4, 위상차 .5. 보폭 .13, 발 들림 .055, 접지 비율 .62.
- 다리마다 발끝 IK(체인 3, `_01`은 고정), 맨 뒤 다리는 `_03` 끝에서 발끝까지 잠근 보조 뼈로 목표를 잡았다. 매 프레임 포즈 행렬을 저장한 뒤 IK·보조 뼈를 지우고 위치/쿼터니언 키로 구웠다. glb에는 원래 뼈만 남는다.
- 몸통(`tripo::Root`) 상하 .006·좌우 기울기 1.2°·회전 1°, 배 4마디의 지연 흔들림, 입틀(`bone_30`/`tripo::Spine_2`) 4° 개폐.
- 측정: 접지 발끝 IK 오차 0, 무릎이 고관절 아래로 꺾인 프레임 0. `walk`는 정지 프레임 8장(측면·3/4 위)만 확인했다([records/walk_frames.png](records/walk_frames.png), version04 단계에서 렌더했으며 같은 수치의 `walk`다). `walk_fast`도 IK 오차 0·무릎 뒤집힘 0이며 웹 탭 재생만 확인했다.

## pounce (덮치기) 클립

- `pounce_fast`(빠른 덮치기)는 사용자 지시(“덮치기도 두배 정도 빠르게”)로 같은 키 테이블을 한 프레임 걸러 샘플링해 0~17프레임·0.71초로 만든 클립이다(스크립트의 `POUNCES`). 자세·높이·전진 거리는 같고, 아래 프레임 번호는 `pounce`(1.42초) 기준이다. 1프레임짜리 순간(덮침 21, 뒷다리 이륙 13·13.5)은 앞뒤 프레임으로만 표현된다. 두 클립 모두 웹 탭에서 화면을 넓힌다.

- 사용자 지시(“앞다리를 들고 점프해서 덮치는 공격”, 실제 전진 0.5m). 0~34프레임(1.42초), 루트(`tripo::Root`) 이동을 클립에 포함한다(root motion). 웹 탭은 이 클립에서만 화면을 넓히고(`clipView`: 높이 1.3, 중심을 앞쪽 .3) 끝나면 처음 자리로 돌아가 반복한다.
- 단계: 위협·준비 0~11(몸 −6.5cm·앞들림 18°·뒤로 3.5cm, 앞다리 한 쌍을 어깨 위로 높이 들어 벌림, 배 11° 들어올림, 입틀 벌림) → 도약 11~14(뒷다리가 마지막까지 바닥을 참: 2쌍 13, 3쌍 13.5, 4쌍 14) → 공중 14~20(최고 +17cm, 앞다리를 앞으로 뻗고 나머지는 몸 쪽으로 접음, 앞숙임으로 전환) → 덮침 20~22(앞다리를 착지 지점보다 8cm 앞에 내리찍고 몸 −5cm 눌림, 입틀 닫음) → 회복 22~34(앞으로 0.5m 옮겨 선 자세로 복귀).
- 측정: 발끝 IK 오차는 공중에서 앞다리를 뻗는 4프레임만 1cm를 넘고 최대 4.1cm(프레임 20, 닿지 않는 목표를 향해 뻗은 상태)이며 접지 중에는 0. 측면 10장 렌더([records/pounce_frames.png](records/pounce_frames.png))와 웹 탭 0초/1초 장면만 확인했다.
- 1차 렌더에서 앞다리가 창처럼 앞으로만 뻗어 보여, 들어 올린 발 목표를 몸 기준 (−.14, ±.14, +.42)로 옮기고 도약 높이 .11→.17, 웅크림 −.05→−.065로 키웠다.

## death (사망) 클립

- 사용자가 추천안 1번(경련 후 주저앉으며 다리 오그라들기)을 골랐다. 0~37프레임(1.54초), 반복하지 않는다. 웹 탭은 `once` 설정으로 한 번 재생 → 마지막 자세 1초 유지 → 처음부터 다시 재생한다.
- 단계: 피격 0~3(뒤로 4cm 밀리며 앞들림 10°, 입틀 벌림) → 버팀 3~10(앞다리부터 미끄러지며 4.5° 옆으로 기욺) → 주저앉음 10~17(몸 −20.5cm, 배 마디가 늘어짐, 17~22 작은 튀어오름 뒤 정착) → 오그라듦 17~29(다리 쌍마다 1프레임씩 늦게; 앞다리는 머리 옆에 붙어 있어 몸 쪽으로 접으면 머리 위로 솟으므로 머리 앞 바닥에 구겨지게, 나머지는 몸 옆 높이로 접음) → 경련 31~37(오른쪽 앞다리·왼쪽 3번 다리·오른쪽 2번 다리와 배 끝이 차례로 움찔).
- 측정: 바닥 침투는 쓰러지는 동안 다리 끝 최대 2.4cm, 마지막 자세에서 맨 뒤 다리 2.7cm. 마지막 자세의 가장 낮은 몸통 정점 4.4cm·입틀 1.8cm(입틀이 몸통보다 아래로 처져 있어 처음에는 바닥을 파고들어 머리를 3° 들었다). 맨 뒤 다리는 뼈가 부족해 오그라든 목표에 최대 21cm 못 미친다. 측면 10장 렌더([records/death_frames.png](records/death_frames.png))와 웹 탭 한 번 재생/유지/재시작만 확인했다.

## 폭사 (웹 탭 전용 효과)

- 사용자 지시(“초록색으로 하고 터지면 연기처럼 사라지게, 폭사 탭을 추가하고 5발 정도”). GLB 클립이 아니라 `game/glb-burst-fx.js`의 Three.js 스프라이트 효과이며, 탭의 `extras.explode` 설정으로 ‘폭사’ 버튼을 만든다. 이 폴더의 `mob.glb`는 바꾸지 않았다.
- 몬스터는 `walk`를 반복한다. 화면 클릭·F·‘사격’ 버튼마다 카메라 쪽 몸통 표면의 임의 지점에 흰 노란 섬광·불꽃 6개·초록 체액 18방울(중력, 바닥에 닿으면 1.4초 뒤 사라짐)·초록 물보라를 내고 몸이 0.18초 움찔한다.
- 5발째(사용자 수정 지시 “몸이 크게 뒤집히면서 폭사”): 0.42초 동안 몸통 중심을 축으로 머리가 들리며 뒤로 153° 뒤집히고 30cm 떠오르며 14cm 밀려나고 부풂 → 거꾸로 뒤집힌 공중에서 초록 섬광과 체액 70방울을 사방으로 뿌리고 연기 28덩이(부풀며 위로 떠오르다 1.2~2초에 사라짐)가 퍼지는 동안 모델이 0.35초에 걸쳐 더 돌며(총 198°) 떨어지기 시작하고 투명해져 사라짐 → 효과가 끝나고 1초 뒤 다시 나타나 체력 5발로 돌아온다. ‘다시’ 버튼은 즉시 되살린다. 뒤집혀 떠오르는 동작이 잘리지 않게 폭사 모드만 화면 높이 1.5·시점 높이 .5로 넓힌다(`clipView.explode`).
- 체액 색은 #9be34a·#6fc72e·#4f9e1f, 연기는 회녹색 3종이며 이미지 파일 없이 캔버스 원형 그라데이션으로 만든다. 내장 브라우저에서 피격·터짐·연기·재등장과 다른 탭 복귀만 확인했다. 게임용 2D 스프라이트 효과·실제 무기/명중 판정·소리는 없다.

## 남은 문제 (사용자 검수 대기)

- `leg_last`는 무릎 아래 뼈가 없어 아래 마디가 통째로 움직인다.
- 배 뒤쪽 `abdomen_04` 웨이트가 좌우 비대칭(L 281 / R 670 정점)이다.
- 머리 쪽 `bone_30`·`bone_31`·`bone_33`·`tripo::Spine_2`는 이름 미정리.
- 장면에 `Icosphere` 보조 오브젝트가 함께 들어 있다(웹 탭에서도 보일 수 있음).
- 동작의 자연스러움·속도는 사용자 검수 대기이며 스프라이트 시트는 아직 만들지 않았다.
