# 기본 샘플 메뉴 연결 001

사용자 요청으로 `http://127.0.0.1:4173/`의 왼쪽 메뉴에 **베스퍼 크리처 · 4방향**을 추가했다. 메뉴를 누르면 같은 크리처 페이지의 최신 4방향 버전을 열고, 버전 선택에서 기존 배경 포함 원화도 볼 수 있다.

기존 예정 군집생물과 새 크리처의 메뉴 선택 강조를 대상 ID별로 구분했다. 크리처 페이지의 소개도 원화·앞뒤좌우 보기로 맞췄다. 이미지·프롬프트·게임 전투는 그대로다.

변경 전 표시 소스는 `runtime_snapshot_before_navigation_001`에 보존했다. JavaScript 구문 검사와 로컬 Chrome에서 기본 주소→새 메뉴→4방향 표시·원화 선택·기존 예정 적 메뉴를 확인했다. [검토 기록](../reviews/navigation-001.json) · [화면](../reviews/navigation-001.png). 초기 검토 스크립트의 해시 이동 대기는 상태 확인으로 보완했다.
