# 유나 이미지 기준 물리 방패 003

사용자가 첨부한 유나 이미지 속 방패를 외형 기준으로 지정했다. 로컬 유나 일러스트 005가 첨부 이미지와 시각적으로 일치함을 확인한 뒤 해당 원본을 내장 `image_gen.imagegen`의 유일한 참조로 사용했다. 사용자의 채택 범위는 방패 디자인이며 캐릭터 얼굴·머리·전투복 전체의 검수 상태를 확대 변경하지 않았다.

상단 운반 손잡이, 직사각 관측창, 우측 상단 원형 부품, 길고 좁은 각형 몸체, 겹친 장갑 패널, 금색 모서리·중앙 세로선과 금색 날개 문장을 살린 단독 원화다. 원본에서 손에 가린 손잡이 일부와 보이지 않는 면은 생성 도구가 재구성했다. 원화 추출과 재묘사이므로 픽셀 동일성·정확한 3D 비례는 보장하지 않는다. 분리 원화의 원본 일치도는 사용자 검수 대기다.

이전 독립 시안 001·002와 유나 인물 원본은 덮어쓰지 않는다. 002의 은색 독자 문장은 현재 방패 기준에서 사용하지 않고 유나 이미지의 금색 문양을 따른다. 문양을 별도 국가·정체·제국과 UE의 관계 설정으로 확대하지 않는다. 방호 등급·무게·치수와 게임 기능은 미정 그대로다.
