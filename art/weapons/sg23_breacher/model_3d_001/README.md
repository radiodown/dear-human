# SG-23 브리처 · 3D 모델 001

- 사용자 지시(2026-11-11): “shoot 폴더에 gun 폴더 추가했어. 무기들 라이브러리에 올려줘. 정확한 이름은 위키 페이지에서 확인해”.
- 이름: 위키 문서 [`weapon-sg23-breacher`](../../../../wiki/content/articles/weapon-sg23-breacher.md)의 제목 **SG-23 브리처**. 분대장 아렌의 부무장으로 제안한 대구경 전투 산탄총.
- 사용 대원: 아렌 · 대구경 전투 산탄총 (부무장).
- 원본: `shoot/gun/sg-23.glb` 사본 `sg-23.glb`(SHA-256 `fdad6c5aab16002f…`). 사용자가 Tripo로 만든 정적 메시 1개와 2048² 기본색 텍스처 1장, 뼈·애니메이션 없음.
- 크기: Tripo가 가장 긴 변을 0.998m로 맞춘 정규화 크기이며 바닥(z=0)에 놓여 있다. **실제 축척은 아직 정하지 않았다**(캐릭터 손에 붙일 때 정한다). 손 부착 기준점(`socket_*`)도 아직 없다.
- 라이브러리: 사이드바 ‘무기’ 그룹의 `sg23_breacher` 페이지. 원화 탭은 위키 원화 [`wiki_concepts_001/sg23-breacher_007`](../../wiki_concepts_001/sg23-breacher_007/source/illustration.png)를 보여 주고, ‘무기 모델 3D’ 탭이 이 GLB를 연다. 팔레트는 텍스처에서 밝기 구간별 중앙값 4색과 채도 상위 색 1개를 뽑았다.
- 내장 브라우저에서 목록 표시·페이지 이동·3D 표시만 확인했다. 원화와의 일치도·외형은 사용자 검수 대기다.
