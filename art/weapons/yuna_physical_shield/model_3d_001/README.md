# 유나의 물리 방패 · 3D 모델 001

- 사용자 지시(2026-11-11): “shoot 폴더에 gun 폴더 추가했어. 무기들 라이브러리에 올려줘. 정확한 이름은 위키 페이지에서 확인해”.
- 이름: 위키 문서 [`yuna`](../../../../wiki/content/articles/yuna.md)의 제목 **유나의 물리 방패**. 유나가 방패·진입 역할에 쓰는 물리 방패. 유나 일러스트 속 디자인(상단 손잡이·관측창·각형 흑색 장갑판·금색 세로선·금색 날개 문장)을 따른다.
- 사용 대원: 유나 · 물리 방패.
- 원본: `shoot/gun/shield.glb` 사본 `shield.glb`(SHA-256 `5d2b09087168b6fd…`). 사용자가 Tripo로 만든 정적 메시 1개와 2048² 기본색 텍스처 1장, 뼈·애니메이션 없음.
- 크기: Tripo가 가장 긴 변을 0.998m로 맞춘 정규화 크기이며 바닥(z=0)에 놓여 있다. **실제 축척은 아직 정하지 않았다**(캐릭터 손에 붙일 때 정한다). 손 부착 기준점(`socket_*`)도 아직 없다.
- 라이브러리: 사이드바 ‘무기’ 그룹의 `yuna_physical_shield` 페이지. 원화 탭은 위키 원화 [`wiki_concepts_001/yuna-physical-shield_003`](../../wiki_concepts_001/yuna-physical-shield_003/source/illustration.png)를 보여 주고, ‘무기 모델 3D’ 탭이 이 GLB를 연다. 팔레트는 텍스처에서 밝기 구간별 중앙값 4색과 채도 상위 색 1개를 뽑았다.
- 내장 브라우저에서 목록 표시·페이지 이동·3D 표시만 확인했다. 원화와의 일치도·외형은 사용자 검수 대기다.


## model_3d_002 · 실제 크기와 손 부착 기준점 (2026-11-11)

- 사용자 지시: “무기 크기랑 기준점 먼저 해줘”(총 든 기본 동작 준비). 위키에는 구경만 있고 길이·무게는 미정이라, 참고한 실제 총 치수에 대구경을 반영한 **높이 0.95m**(진입용 방패)로 제안했다. 사용자 검수 대기다.
- [`tools/weapons/size_tripo_weapons.py`](../../../../tools/weapons/size_tripo_weapons.py)가 `shoot/gun` 원본을 불러와 원점(가운데·바닥) 기준으로 균일 배율 0.9519을 적용하고(크기 0.418 × 0.143 × 0.950m, 길이·폭·높이) 빈 노드 기준점을 넣어 [`model_3d_002/yuna_physical_shield.glb`](model_3d_002/yuna_physical_shield.glb)로 내보낸다. 기준점은 1mm 눈금 측면 렌더에서 읽은 정규화 좌표에 같은 배율을 곱했다.
- 기준점(m, Blender 좌표: +X 총구, −Y 측면 카메라 쪽, +Z 위): 손잡이 (0.000, 0.081, 0.523), 팔뚝 (0.000, 0.081, 0.362).
- Tripo 방패 뒷면에는 손잡이가 없어 뒷면 중앙에 왼손 손잡이(높이 0.55)와 팔뚝(높이 0.38) 위치를 잡았다. 앞면은 캐릭터 정면과 같은 −Y를 향한다.
- 파일은 실제 미터 크기다. 캐릭터 손에 붙일 때는 캐릭터 축척(키 1.0 단위 ≈ 1.65m → 0.606배)을 곱한다. 9개 측면 렌더에 기준점 색 점을 찍어 위치만 확인했다.
