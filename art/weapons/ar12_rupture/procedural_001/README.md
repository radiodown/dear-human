# AR-12 럽처 · Saltline 참고 코드 모델 001

2026-11-12 사용자 요청으로 제작한 무기 단독 미리보기용 모델이다. 추가 확인에서 사용자가 **무기 단독 미리보기에 추가**를 선택했다.

[단독 미리보기](http://127.0.0.1:4173/#/samples/weapons/ar12_rupture?plan=weapon-3d&weapon3d=ar12_rupture_saltline)에서 `AR-12 럽처 · Saltline`을 선택한다. 기존 `AR-12 럽처` 항목은 Tripo GLB 003이다. 서버가 실행 중이어야 한다.

- 약 0.85m 실루엣, 넓은 각형 리시버, 큰 곡선 탄창, 긴 관통 통풍구 핸드가드, 접철식 개머리판의 힌지와 열린 골격, 두꺼운 각형 총구 장착물.
- 베벨 단면·회전체·재질별 메시 결합, 금속/폴리머/고무/유리, 절제된 AR-12 표기. 외부 모델·텍스처 다운로드 없이 JavaScript에서 생성한다.
- 탄창·노리쇠·방아쇠는 별도 그룹이다. 회전·측면·위 보기·실제 크기 비교와 손잡이/받침손/견착/총구/탄창 기준점 5개를 지원한다.
- 힌지와 조작부는 외형 표현이다. 접철·분해·장전 재생은 이번 무기 단독 뷰어에 구현하지 않았다. 실제 무기 제작용 치수·설계가 아니다.

## 출처와 구현

로컬 고정 소스 `game/plan-f/reference/saltline-fable-5.2/index.html`(커밋 `09c51774cd77aad750bd2d6c42af2b1020cb668d`)와 분리본 `game/plan-g/saltline/weapon.js`의 `xr`, `Cn`, `w_`, `dm`을 정적으로 참고했다. 실제 구멍을 포함한 단면 돌출·회전 단면·재질 분리를 적용한다. PAC-9 전체 형상을 복제하지 않고 위키의 AR-12 실루엣으로 새로 구성했다. 기존 F의 `geometry.js`와 `weapon-materials.js`, 로컬 Three.js r187을 재사용한다. Saltline 출처·크레딧은 기존 reference README를 따른다.

구현은 `game/weapons/ar12-rupture.js`, 연결은 `game/weapon-model-lab.js`다. 단독 모델만 추가했으며 F/G·캐릭터 무장·기존 GLB는 변경하지 않았다. 카탈로그의 원화는 기존 001 참고 이미지이며 새 모델 렌더가 아니다. 새 모델의 외형이 원화와 정확히 일치한다고 보장하지 않는다.

## 보존과 검수

`before/`에 변경 전 뷰어를, `source_snapshot/`에 모델·뷰어·공유 의존 파일을 보존한다. 입력·출력 SHA-256과 도구·비용/시간 미측정 항목은 `record.json`에 기록한다. 새 이미지 생성 호출은 없다.

사용자의 기존 “검증은 내가할게 개발만해봐” 지침에 따라 자동 테스트·구문/문서/목록 검사·브라우저 캡처는 실행하지 않았다. **untested / 사용자 외형·실행 검수 대기**다. 목록·재사용·영향 조회만 수행했다. 회전 시 구멍·반사·측면 비례·기준점 위치의 실제 화면 확인은 남아 있다.
