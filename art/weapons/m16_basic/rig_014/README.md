# M16 · 감싸 쥔 손 접점 014

[실제 무기 데이터](rig/weapon.json) · [손 원화/바인딩](../../../characters/clone_01/motion/rig_014/README.md) · [구현 기록](../../../../docs/35-closed-handguard-grip.md)

같은 M16 원화와 개머리판·조준·총구 소켓을 재사용한다. 감싸 쥔 손의 지지 접점을 핸드가드 하단 (.63, .48)에서 축 (.63, .34)으로 옮겼다. 손가락은 가까운 면에, 보이지 않는 엄지는 반대편에 놓인다. 개발 연결이며 사용자 검수 대기다.
