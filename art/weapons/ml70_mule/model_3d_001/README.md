# ML-70 뮬 · 3D 모델 001

- 사용자 지시(2026-11-11): “shoot 폴더에 gun 폴더 추가했어. 무기들 라이브러리에 올려줘. 정확한 이름은 위키 페이지에서 확인해”.
- 이름: 위키 문서 [`weapon-ml70-mule`](../../../../wiki/content/articles/weapon-ml70-mule.md)의 제목 **ML-70 뮬**. 모아의 부무장인 다목적 유탄발사기형 런처.
- 사용 대원: 모아 · 다목적 유탄발사기형 런처 (부무장).
- 원본: `shoot/gun/ml-70.glb` 사본 `ml-70.glb`(SHA-256 `86e391511f0283f2…`). 사용자가 Tripo로 만든 정적 메시 1개와 2048² 기본색 텍스처 1장, 뼈·애니메이션 없음.
- 크기: Tripo가 가장 긴 변을 0.998m로 맞춘 정규화 크기이며 바닥(z=0)에 놓여 있다. **실제 축척은 아직 정하지 않았다**(캐릭터 손에 붙일 때 정한다). 손 부착 기준점(`socket_*`)도 아직 없다.
- 라이브러리: 사이드바 ‘무기’ 그룹의 `ml70_mule` 페이지. 원화 탭은 위키 원화 [`wiki_concepts_001/ml70-mule_007`](../../wiki_concepts_001/ml70-mule_007/source/illustration.png)를 보여 주고, ‘무기 모델 3D’ 탭이 이 GLB를 연다. 팔레트는 텍스처에서 밝기 구간별 중앙값 4색과 채도 상위 색 1개를 뽑았다.
- 내장 브라우저에서 목록 표시·페이지 이동·3D 표시만 확인했다. 원화와의 일치도·외형은 사용자 검수 대기다.


## model_3d_002 · 실제 크기와 손 부착 기준점 (2026-11-11)

- 사용자 지시: “무기 크기랑 기준점 먼저 해줘”(총 든 기본 동작 준비). 위키에는 구경만 있고 길이·무게는 미정이라, 참고한 실제 총 치수에 대구경을 반영한 **0.85m**(MGL급 회전식 유탄발사기 약 0.8m)로 제안했다. 사용자 검수 대기다.
- [`tools/weapons/size_tripo_weapons.py`](../../../../tools/weapons/size_tripo_weapons.py)가 `shoot/gun` 원본을 불러와 원점(가운데·바닥) 기준으로 균일 배율 0.8517을 적용하고(크기 0.850 × 0.235 × 0.341m, 길이·폭·높이) 빈 노드 기준점을 넣어 [`model_3d_002/ml70_mule.glb`](model_3d_002/ml70_mule.glb)로 내보낸다. 기준점은 1mm 눈금 측면 렌더에서 읽은 정규화 좌표에 같은 배율을 곱했다.
- 기준점(m, Blender 좌표: +X 총구, −Y 측면 카메라 쪽, +Z 위): 개머리판 (-0.422, -0.002, 0.179), 손잡이 (-0.170, -0.002, 0.064), 받침손 (0.328, -0.002, 0.106), 총구 (0.425, -0.002, 0.221), 탄창 (0.085, -0.020, 0.149).
- 파일은 실제 미터 크기다. 캐릭터 손에 붙일 때는 캐릭터 축척(키 1.0 단위 ≈ 1.65m → 0.606배)을 곱한다. 9개 측면 렌더에 기준점 색 점을 찍어 위치만 확인했다.
- 좌우(Y) 위치 보정(사용자 지적 “hmg 기준점이 이상해. 오브젝트를 벗어났어”): 측면 렌더로는 앞뒤·위아래만 읽혀 처음에는 모든 기준점이 y=0이었는데, Tripo 모델은 경계 상자 가운데에 놓여 있어 HMG-15는 탄통 때문에 몸통 중심이 y≈+0.07m라 손잡이·총구·받침손이 몸통 밖에 떠 있었다(HP-14T 오른쪽 총구도 밖). 기준점마다 그 (x, z)에서 Y 방향으로 광선을 쏴 몸통 양쪽 표면의 가운데로 옮겼다(열린 끝은 안쪽으로 4mm까지 비켜 측정). 다시 잰 결과 몸통 밖 기준점 0개.
