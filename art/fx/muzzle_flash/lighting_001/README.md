# 총구 화염과 캐릭터 조명 · lighting_001

[구현·인계](../../../../docs/33-muzzle-light-on-character.md) · [같은 캐릭터 사격 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire)

발사 이벤트의 .055초 타이머와 실제 총구 소켓을 사용하는 코드 기반 WebGL 효과다. 피부·장갑·금속·천의 응답을 나누고 거리·방향·시간으로 감쇠하는 빛을 기존 원본 RGB에 더한다. 별도의 모델 호출·래스터 이미지 생성·PixelFX 출력은 하지 않았다.

- [프로필](profile.json): 기간·색·거리·재질 응답과 표면 근사 방식.
- [제작 레시피](records/recipe.json): 실제 코드·입력의 해시, 의존 버전, 미검증 상태.
- [공통 셰이더와 설정](../../../../game/animation/muzzle-light.js): 게임/미리보기에서 재사용하는 실제 소스.
- [렌더러](../../../../game/animation/webgl-character.js): 파트 재질·회전·좌우 반전을 전달하며 원본 알파로 조명을 가린다.

원화의 기존 조명에 더하는 2D 표면 근사이며 실제 노멀맵·동적 그림자는 없다. 사용자 지시로 테스트·문서/목록 검사·브라우저 검수는 실행하지 않았고 `verification`은 `untested`다. 시각 강도·재질·과노출과 기기 성능은 사용자 검수 대기다. 독립 효과 페이지는 만들지 않고 기존 캐릭터 페이지에 연결했다.
