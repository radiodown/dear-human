# GLB 총구 화염·섬광·잔연기 001

2026-11-12 사용자 요청: GLB 사격에 불꽃과 총격 이펙트 추가.

기존 공통 3D 모델 탭에서 **실제 무기를 장착한 사격 클립**에 적용한다. `game/glb-gun-fx.js`가 생성한 부드러운 화염 텍스처를 교차 면 두 장에 표시하고, 총구의 점광원이 총과 인물에 짧은 주황 반사광을 만든다. 연기는 발사 지점에 남아 앞으로 나아가며 상승·소멸한다. GIF·외부 이미지·생성 API는 쓰지 않는다.

- [리안 AR-12 사격](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=glb&loadout=ar12_rupture&clip=gunplay)
- [리안 쌍권총 사격](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=glb&loadout=hp14t_gemini&clip=dual_fire)
- ‘총구 효과’ 체크로 on/off. `gunFx=0` 주소값으로 꺼진 상태를 공유할 수 있다.

## 타이밍과 범위

| 클립 | 발사 시점(클립 시간) |
|---|---|
| `gunplay` 조준 사격 | 3/24초 |
| `gunplay_auto` 연사 | 2/24초 |
| `shoot_rifle` 이동 사격 | 5/24초 |
| `dual_fire`, `dual_kneel_fire` | 0초부터 0.25초 간격, 오른손/왼손 교대 |

기존 소총 클립의 총구 반동 상승 직전 프레임과 쌍권총 생성기의 교대 발사 큐를 따른다. 화염은 65ms, 연기는 약 0.4초의 **애니메이션 시간**을 사용하므로 0.25×·정지·재시작과 함께 움직인다. 모델/무장/동작 전환 때 이전 효과를 정리한다. 대기·장전·맨손·사격 클립이 없는 유나 권총 동작에는 불꽃을 만들지 않는다. 리안뿐 아니라 같은 사격 클립을 가진 아렌·세나·모아의 현재 긴 총 조합에도 공통 적용한다.

GLTFLoader에서 같은 이름의 뼈/메시가 `weapon`/`weapon_1`으로 구분되는 것을 처리하며, **메시 로컬 +X 끝부분**에서 총구 중심을 찾아 매 프레임 무기 변환을 따른다. 쌍권총은 두 무기를 각각 계산한다. 이것은 총구 미리보기 효과이며 탄도·탄피·명중·총성·게임 피해 처리를 추가한 것은 아니다.

## 검수와 기록

`python tools/glb_retarget/review_gun_fx.py`로 로컬 4173 서버의 실제 공유 뷰어를 확인했다. 검수용 응답에서만 디버그 참조를 추가하며 제품 코드에는 넣지 않는다.

- 발사 전/도중/후, 멈춘 프레임의 효과 고정, 연사/이동 사격, on/off, 장전·대기 억제.
- 쌍권총 좌우 교대·앉아 사격·카메라 좌우 반전·0.25× 재생.
- 맨손 전환 시 잔여 효과 정리, 아렌/세나/모아 6개 긴 총의 총구 부착.
- [확인 결과](reviews/viewer.json): 페이지 오류 없음. `reviews/`에 화염·연기·쌍권총 캡처를 보존한다.
- `source_snapshot/`에 효과/뷰어/HTML/검수 도구를 고정 보존하고 [제작 기록](record.json)에 SHA-256을 기록한다. 유료 호출 없음. 수작업 소요 시간은 미측정이다.

**효과의 크기·색·밝기는 사용자 검수 대기**다. 총구 위치는 메시 끝의 추정치이므로 향후 총 형상이 바뀌면 다시 확인해야 한다. 다른 기기에서의 성능·전체 모션 회귀 검사는 수행하지 않았다.
