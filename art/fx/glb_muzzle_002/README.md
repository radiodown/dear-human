# GLB 총구 화염·불티·연기 002

2026-11-12 사용자 피드백: 기존 총구 불빛이 소박하고 삐죽삐죽함. 대화에 첨부한 6개 총구 화염 예시의 흰 중심·주황빛 확산·가는 불티·흐르는 연기를 참고했다.

`game/glb-gun-fx.js`의 공통 GLB 사격 효과를 개선했다. 뾰족한 다각형 대신 Canvas 방사 그라데이션을 겹쳐 흰 중심과 넓은 주황색 가스를 만들고, 교차 평면과 작은 청백색 총구 빛으로 표시한다. 길이 비례 크기를 약 두 배로 늘리고 네 가지 고정 시드 질감을 발사마다 교대한다. 참고 이미지를 잘라 쓰거나 생성 API로 제작한 텍스처가 아니라 런타임 코드 생성이다.

- 화염 85ms, 12개 금색 불티 140ms, 가는 리본 형태 연기 약 550ms. 모두 애니메이션 시간 기준이다.
- 불티는 발사별 한 LineSegments에 묶고 총구의 발사 순간 위치에서 앞으로 퍼진다. 연기도 발사 위치에서 떠오르며 옅어진다. 만료·동작/무장 전환·효과 끄기에서 개별 자원을 정리한다.
- 기존 총구 부착·사격 큐·쌍권총 좌우 교대·0.25×/정지·효과 on/off를 유지한다. 공통 GLB 무장 사격에 적용하며 리안 장전 013은 그대로다.
- [리안 AR-12 사격 보기](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=glb&loadout=ar12_rupture&clip=gunplay)

## 검증 및 보존

`node --check game/glb-gun-fx.js`와 `python tools/glb_retarget/review_gun_fx.py glb_muzzle_002`를 실행했다. 실제 공유 뷰어 Chromium 검사 결과는 [viewer.json](reviews/viewer.json)의 22개 항목이며 페이지 오류가 없다. 발사 전/중/후, 연사·이동 사격, 정지 시 입자 위치 유지, 끄기·장전·맨손 시 효과 정리, 쌍권총 교대·앉아 사격·카메라 반전·느린 재생, 아렌/세나/모아의 6개 긴 총 부착을 확인했다. [확대 화염](reviews/rifle_closeup.png)과 [잔연기](reviews/rifle_smoke.png) 등을 직접 보고 중심부 폭과 연기 결을 한 차례 더 보정했다.

이전 001은 별도 보존하며 `before/`에 변경 직전 효과와 검증 도구, `source_snapshot/`에 새 효과·검증 도구·현재 연결 파일을 보존한다. [record.json](record.json)에 입력/출력 SHA-256을 기록한다. 유료 API 호출 0회, 수작업 소요 시간 미측정.

**화염의 미감·크기·밝기는 사용자 검수 대기**다. 참고 이미지와의 동일 재현이나 실제 체적 유체 효과를 의미하지 않는다. 느린 기기의 성능 검증은 별도로 수행하지 않았다.
