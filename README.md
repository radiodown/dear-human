> 프로젝트명: Dear Human · 사전 가능성 검증용 프로젝트 문서 · 작성일 2026-11-06

**Dear Human(디어 휴먼)**은 유나이티드 어스 출범 초기, 같은 우리은하 안의 먼 식민행성 **베스퍼**에 부임한 인간 지휘관과 그에게 배속된 여성 클론들의 이야기를 다루는 2D 횡스크롤 액션 슈터다. 지구에서 약 180광년 떨어진 행성까지 초기형 워프선으로 수개월을 항해하며, 현지에서는 인간과 클론이 자연 대기를 호흡할 수 있다. 플레이어는 지휘관이며 전투 화면에서는 배속 클론 한 명을 조작한다. 초기 프로토타입은 M16과 미확인 군집생물의 근접 개체 1종으로 1스테이지를 구성하고, **캐릭터 생성 애니메이션, 이동 중 기본 사격, 이펙트 연동이 실제 플레이에서 성립하는지** 검증한다.

실행 플랫폼은 **웹 브라우저**다. 초기 우선순위는 **발사 반동, 고개·머리카락 흔들림, 바스트 모핑, 플레이어 혈액과 군집생물 진액 피격 효과**다. 권장 구성은 **Phaser 4.2.1 + TypeScript + Vite**, **파츠형 공통 리그 + 분리 무기·갑옷 외형 + 양팔 IK**로 캐릭터를 재사용한다. 제작 도구는 Spine Professional을 권장하며 무기를 바꿔도 전신을 재생성하지 않는 것이 기본 조건이다. 상세 규약은 16, 도구 조사는 12 문서를 먼저 본다.

초기 조작 클론 **clone_01**의 외형·화풍은 최신 첨부 이미지 기준으로 변경했다. **검은 긴 생머리·짙은 눈·매우 하얀 쿨톤 피부, 검정/건메탈 전술 갑옷·망토·가터·높은 장갑 군화와 사실적인 3D 렌더 질감**을 따른다. 이전 분홍 머리 제복과 중단 시험은 사용자 요청으로 삭제했다. 게임은 2D·분리 파츠 방식을 유지하며 실제 3D 모델로 전환한 것은 아니다. 참고 JSON의 장군 계급·미래형 소총·배경은 게임의 클론 신분·초기 M16·베스퍼를 변경하지 않는다. 상세 외형은 [02](docs/02-world-and-art.md), 실제 시안·영어 JSON 프롬프트·사용자 참고 JSON은 [23](docs/23-character-appearance-review.md)을 본다.

캐릭터·무기·파츠·모션을 실제 제작할 때는 **하나의 통합 샘플 사이트에 대상별 페이지를 갱신**한다. 기존 결과·버전을 먼저 확인하고 변경 부위만 다시 만들어 중복 생성과 설명 비용을 줄인다. 첫 실제 에셋부터 미리보기에 등록하며 상세 규약은 [18](docs/18-preview-library-and-reuse.md)을 따른다.

현재는 설계 문서·에이전트 스킬·검사/조회 CLI 외에 정적 캐릭터 시안과 로컬 통합 샘플 셸이 있다. [아트 보관함](art/README.md)에 원본·영어 JSON 프롬프트·MD·생성 기록을 모았다. 사용자가 새 3D풍 전술 갑옷 외형을 채택했다. 이전 자료는 삭제했고 같은 사이트에 분리 파츠·자체 WebGL 리그·M16으로 대기·제자리 보행·사격·이동 사격·장전 초안을 연결했다. [모션 테스트](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle)와 [현재 측면 파츠·견착 보정과 한계](docs/26-side-parts-and-shoulder-contact.md)를 확인한다. 제작 도구의 최종 채택과 실제 전투·1스테이지는 후속이다.

프로젝트 루트에서 `python tools/preview_server.py --port 4173`을 실행하면 [캐릭터 샘플](http://127.0.0.1:4173/#/samples/characters/clone_01)을 볼 수 있다. 로컬 Chrome 캡처로 실제 표시를 확인했다. 버튼·키보드·포인터·탭 전환의 자동 조작과 하드웨어 성능 검수는 미완료다.

사용자 지시로 **플랜 B · 2dimg2motion**을 가동했다. [별도 폴더](art/characters/clone_01/motion/plan_b/README.md)의 M16 보행 14프레임 `walk_001`은 사용자 지적 후 **크기·비례 검수 실패**로 판정했다. [기존 캐릭터 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&motion=walk)에 실패 상태를 표시한다. 공식 규약 재검토 후 `walk_002` 키포즈를 한 차례 재생성했으나 비례 검수에서 반려했으며, 수정된 완성 모션은 아직 없다. [실제 실행 기록과 승인 조건](docs/27-plan-b-2dimg2motion.md)을 따른다.

타격감은 **발사·명중도·스침·치명타·대미지 숫자·재질별 튐·폭발·사망·소리·카메라**를 한 결과에 연결해 검증한다. 명중도는 탄도 산포에, 실제 맞은 위치는 피격 등급에 반영하는 안이다. [19 전투 피드백](docs/19-combat-feel-and-damage.md)을 따른다.

스토리는 **컷신과 미연시식 대화**로 진행하고 모든 연출은 스킵할 수 있어야 한다. 초기에는 첫 임무의 도입·종료 장면을 넣고, 관람·스킵 모두 동일한 전투 상태와 결과로 이어지게 한다. 구현·입력·통합 샘플 규약은 [21. 스토리와 스킵](docs/21-story-and-skipping.md)에 정리한다.

**재장전과 장전 모션도 초기 필수 범위**다. 총기마다 탄창·장전 방식·일반/빈 탄창 시간·손동작을 설정한다. 초기 M16은 30발 탄창과 무제한 예비탄을 기본안으로 삼아 탄창 교체를 검증하며, 캐릭터 공통 리그와 보행은 재사용한다. [22. 총기별 재장전](docs/22-weapon-reloading.md)을 따른다.

## 읽는 방법

세계관은 15, 캐릭터 외형은 02, 적 구성은 11을 읽는다. 제작·검수 흐름은 18, 구조와 도구 선택은 16 → 17 → 12 → 13 → 14 순서로 읽는다. 게임 범위와 플레이는 01 → 03, 개발 구조는 04와 07, 에셋 제작은 05와 06을 본다. 작업 착수 전에는 08의 실험과 09의 단계 순서를 확인한다.

문서의 결정 상태는 다음과 같다.

- **요구사항:** 게임명 **Dear Human**. 유나이티드 어스 출범 초기의 근미래 성간항해, 같은 우리은하 안의 먼 식민행성, 인간과 클론이 호흡 가능한 자연 대기, 지휘관과 배속 클론의 관계는 15를 따른다. 최신 첨부의 검은 긴 머리·짙은 눈·차분한 성인 인상·전술 갑옷·망토·높은 장갑 군화와 3D 렌더 질감을 기준으로 한다. 강한 타격감, 명중률과 피격 차이, 일반/크리티컬 대미지 표시, 폭발·파편·다양한 사망·속도감. 캐릭터·무기별 통합 샘플과 기존 산출물 재사용, 파츠형 캐릭터·독립 무기·부위별 갑옷 외형. 웹 구현, 반동·머리 흔들림·바스트 모핑·혈액/진액 우선. 1스테이지, 조작 클론 1명, M16, 초기 근접 적 1종, 횡이동, 여러 비활성 스킬 슬롯, 2dimg2motion·PixelFX 활용.
- **제안 기본값:** 2114년·베스퍼 동부 개척권·지구에서 약 180광년·편도 6~10개월의 초기형 워프·기술과 제도 세부, 미확인 군집생물이라는 자체 적 가칭, 외형상 만 24세·165cm·세부 치수는 최신 외형 검토 후 결정, Phaser 4.2.1·TypeScript·Vite, Spine 기반 공통 파츠 리그·양팔 IK·보조 모션, 스킬 슬롯 4개, 조작·전투·웨이브 수치. 기존 픽셀 아트·64px 크기는 모션 가독성 비교 후 선택한다.
- **미검증:** 도구가 이 캐릭터에 충분한 품질을 내는지, 제작 시간·비용, 실제 성능. 검증 기록을 확보하기 전에는 확정하지 않는다.

컷신·대화로 스토리 진행과 전체 연출 스킵은 사용자 요구사항이다. 도입/종료의 분량, 입력 키, 데이터 형식, 이번 실행의 스토리 표시 설정은 초기 구현을 위한 제안 기본값이다.

제안 기본값의 수치 원본은 [07 문서](docs/07-data-and-assets.md)다. 도구의 외부 기능 설명과 이 프로젝트에서 새로 정한 규칙은 각 파이프라인 문서에서 구분한다.
