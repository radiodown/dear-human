# 크기 일관성 실패 — Plan B

공식 기준: 2dimg2motion 커밋 `d4d73e243b6ff64b7cbb3879e45e951f972a7e62`의 SKILL.md, references/keypose-redraw.md, references/motion-prompt-patterns.md 및 skills/img2mo-std/SKILL.md를 다시 확인했다.

1. 같은 PNG 캔버스·총 높이·발 기준선은 같은 캐릭터 크기를 증명하지 않는다. walk_001은 이 구조 검사만 통과하고 머리·몸통·총 비례 변화를 허용한 실패 사례다.
2. 생성 전 표준화한 기준 이미지를 모든 생성 단계에 넣는다. 그 기준에 대해 머리 크기, 어깨~벨트 길이, 흉갑 폭, M16 길이와 인물 중심을 비교해 공통 키포즈를 먼저 승인한다.
3. 무릎을 굽혀 실루엣 높이가 낮아지는 것은 정상일 수 있다. 그 자세를 원래 총 높이까지 키우면 머리·몸통·총도 커진다. 전체 외곽 높이만 보고 크기를 맞추지 않는다.
4. 프레임마다 크기·중심을 자동 맞춤해 실패를 숨기지 않는다. 하나의 공통 배율과 정렬 기준을 사용하고, 원본 시트의 크기·비례·중심이 다르면 재생성한다. 후처리 보정으로 키포즈를 새로 만들지 않는다.
5. 키포즈가 바뀌면 종속 중간 프레임을 다시 생성한다. 키포즈 크기 검수가 실패한 상태에서 14프레임을 패킹하지 않는다.
6. 공식 검증기는 파일 수·RGBA·기준선·키프레임 동일성을 확인한다. 최종 크기·동일성·연속성은 대조 시트와 재생 검수가 별도로 통과해야 한다. `passed`를 전체 품질 통과로 표현하지 않는다.

walk_002는 기준 이미지를 같은 배치로 복사한 크기 안내판도 입력했지만, 키포즈의 머리·상체 비례 차이가 남아 승인하지 않았다. 안내판이 크기 일관성을 보장한다고 가정하지 않는다. 중간 프레임·완성 모션은 미제작이다.

## 004 · 다리 교대와 교차 실패

사용자는 pixel_walk_004를 “다리가 전혀 교차하질않아서 엄청어색해”라고 지적했다. 02/08 접촉과 05/11 패싱에서 같은 다리 배치가 거의 반복되고 앞/뒤 다리의 명암 표지가 유지되지 않는다. 프레임 수·실제 canvas 변화·접촉/패싱 실루엣만으로 양발 교대를 통과시키지 않는다.

- 두 다리를 각각 같은 고관절에서 무릎–발목까지 추적한다. 앞쪽 다리는 밝은 전경, 뒤쪽 다리는 어두운 후경으로 일관되게 구분한다.
- 02와08에서는 같은 다리의 발 앞뒤 순서가 뒤집혀야 한다. 05와11에서는 지지 다리와 회수 다리가 서로 바뀌어야 한다.
- 회수 발이 접지 다리의 뒤에서 몸 아래를 지나 앞으로 나오는 교차가 두 반주기 모두 보여야 한다. 같은 무릎 들기를 두 번 반복한 시트는 반려한다.
- 004의 기존 PNG/브라우저 통과는 교대/교차 품질 통과가 아니다. 새 판정은 005의 rejection-of-004 기록에 분리한다.
