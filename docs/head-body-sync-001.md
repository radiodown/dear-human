# 머리·몸통 동작 연결과 별도 바운스 제거 · head_body_sync_001

사용자 요청: “머리하고 몸하고 뭔가 동작이 같이 일어나지 않고 바운스가 있으면 어색해”. [같은 파츠 페이지의 달리기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run) · [이동](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=walk) · [뛰며쏴](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run_fire)에서 확인한다.

기존에도 머리 위치는 몸통의 목 부착점을 따라갔지만, 회전은 몸통의 .28만 전달했다. 달리기는 여기에 실제 몸통 회전 전체를 상쇄하는 보정을 더해 머리 각도를 고정했다. 활동감 보정의 흉곽에는 골반의 접지 움직임과 다른 위상의 상하 이동도 별도로 더해져 있었다. 몸통은 흔들리는데 머리의 각도는 버티는 움직임과, 위아래로 따로 움직이는 상체가 함께 보일 수 있는 구조였다.

`gaitBody()`가 지속적인 기본 숙임과 발걸음/호흡의 순간 회전량을 구분해 출력한다. 달리기의 시선 보정은 지속적인 숙임·수동 허리각만 상쇄하며, 현재 프레임의 몸통 회전은 머리에 그대로 전달한다. 별도의 머리 추종 지연이나 추가 바운스 스프링을 만들지 않았다. 정면을 보는 기본 방향과 작은 피격/발사 고개 반응은 유지한다. ‘고개’ on/off는 이 추가 반응을 제어하며 기본 목 연결은 유지한다.

`secondary-motion.js`에서 발걸음에 따라 흉곽만 위아래로 움직이던 추가 항을 제거했다. 느린 호흡과 골반의 착지 압축·체공/발 회수는 유지하고, 몸에 따로 얹었던 상하 바운스를 걷어냈다.

공통 리그의 `headFrame`이 머리의 월드 위치·각도를 한 번 계산하고, 눈 위치와 WebGL의 머리/뒤 머리카락이 이를 공유한다. 렌더러에서 머리 각도를 따로 재조립하지 않는다. 뒤 머리카락은 기존 원화 등록각을 유지하고 머리 뿌리에 붙으며, 끝의 기존 반응만 이어 쓴다. 카메라도 같은 머리 깊이를 투영한다. 렌더/pose 호출은 상태를 변경하지 않는다.

앉아쏴 017의 눈·총 정렬은 기존 `kneelingHead()`의 제한된 보정을 유지한다. 비사격 달리기 총구 아래 35°·완전 대기 아래 58°와 두 대기, 사격의 전방 수평·9개 동작의 조절/저장·발 접지/뼈 길이·현재 손/망토를 이어 쓴다. 원화·플랜 B/C·GIF는 이번 범위가 아니다.

필요한 변경 JS 구문, 짧은 머리/몸통 상대 회전·목 부착점·손/총/다리 접점 확인을 수행했다. 같은 표본에서 달리기의 머리–몸통 상대 회전 변화는 이전 약 8.18°에서 약 .014°로 줄었다. 이는 머리와 몸통이 함께 회전한다는 수치이며 사용자의 자연스러움 채택을 대신하지 않는다. 큰 달리기 허리각에서도 지속적인 숙임을 상쇄해 정면 기본 시선을 유지하는지 확인했다.

Chrome에서는 이동·달리기·뛰며쏴·앉아쏴를 짧게 재생하고, 실제 표시 머리가 공통 프레임과 일치하는지 확인했다. 일시정지 화면도 고정됐다. [수치 기록](../art/characters/clone_01/motion/rig_005/tests/head_body_sync_001/sync-smoke.json) · [Chrome 기록](../art/characters/clone_01/motion/rig_005/reviews/head_body_sync_001/browser.json).

처음의 긴 사격 표본은 탄약 소진 뒤 자동 장전까지 포함했다. 해당 임시 장전 손 경로의 최대 접점 오차 약 .699는 변경 전/후 동일했으며 별도 예비 기록에 보존했다. 최종 동기화 표본은 탄약 소진 전의 짧은 사격 구간으로 구분했다. 이 작업에서 장전 손/도달 문제를 해결했다고 보고하지 않는다.

변경 전 5개 소스는 `runtime_snapshot_before_head_body_sync_001`에 보존했고, 새 레시피/인계 및 tests/reviews는 `head_body_sync_001`로 분리했다. 과거 `untested`와 검사 결과는 유지한다. 전체 검사 묶음·문서/목록 검사는 실행하지 않았다. 머리/목의 실제 연결 실루엣, 남은 접지 기반 움직임의 자연스러움과 큰 수동 설정에서의 가림은 사용자 검수 대기다.
