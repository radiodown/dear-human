# 플랜 B · 전투 모션006

사용자가 플랜 B에서도 앉아쏴·쏘면서 걷기를 역동적으로 표현하도록 요청했다. 005 도트 캐릭터를 재사용해 **이동 사격과 앉아쏴 두 PNG 모션**을 새 버전으로 만들고 기존 캐릭터 페이지에 연결했다. 두 동작 모두 몸의 준비·발사·반동·복귀, 머리/망토 지연 반응과 발사광을 모델로 생성했다.

| 모션 | 실제 움직임 | 자동 반복 |
|---|---|---|
| 이동 사격 | 밝은 전경A/어두운 후경B의 양발 교차, 발사 시 어깨·흉곽 반응, 다음 프레임의 반동과 조준 복귀 | 01~12, 약1.005초, 02/08 발사 |
| 앉아쏴 | 낮은 무릎/앞발 지지와 견착, 상체 밀림·복귀, 머리 끝과 바닥 망토 반응 | 01~12, 약1.085초, 05/11 발사 |

각각 512×512 RGBA 14장이다. 00/13은 동일한 기준 이미지로 보존하고 실제 반복은 생성한 12개 움직이는 포즈만 사용한다. 앉아쏴는 이미 무릎을 꿇은 상태의 반복 사격이며 서기↔앉기 전환 클립은 없다.

## 제작과 크기/자세 확인

이동 사격은 005의 승인한 네 걷기 키포즈를 같은 크기·위치로 복사한 입력 보드에서 생성했다. 첫 시트는 상체/총 크기와 발 높이가 흔들려 반려했고, 상체 이동과 머리/망토 움직임을 제한한 두 번째 시트를 채택해 중간 프레임으로 진행했다. 02/08의 밝은 다리 전후 순서 반전과 05/11의 반대 지지·교차는 유지한다.

앉아쏴 기준은 005 외형과 사용자 채택 `kneeling_fire_001` 자세 그림을 참조했다. 접지 무릎은 낮은 골반보다 조금 앞, 앞발은 바닥에 두고 뒷정강이를 뒤로 접는다. 총은 거의 수평이며 볼·어깨·개머리판과 양손을 같이 작성했다. 받침 팔꿈치–앞무릎 접촉은 강제하지 않는다. 망토는 길이를 줄이지 않고 바닥에 펼친다.

첫 기준은 머리/총 비례가 달라 반려했다. 수정한 머리/총 비례의 두 번째 기준에 전체 캔버스 표준화와 고정 바닥 이동만 적용한 뒤 네 키포즈와 여덟 중간 프레임을 생성했다. 앉은 몸의 외곽 높이를 서 있는 몸 높이까지 확대하지 않았다.

모델 호출은 실패 시도 포함 총9회다. 채택 원본과 반려 원본, 정확한 영어 JSON/MD, 실제 도구 시간과 의존 파일 해시는 `records`에 보존한다. 도구가 제공하지 않은 모델 ID·seed·실제 과금은 null이다. 키포즈는 같은 시트에서 네 개씩 생성하고 시각 확인 후 종속 중간 프레임을 생성했다.

로컬 Python/Pillow는 입력 보드 구성, 전체 시트 공통 표준화, 같은 크기 셀 분리, 미세 alpha≤8 잡음 정리, PNG 패킹과 비교판에만 사용한다. 포즈 합성·절차적 보간·잘라낸 다리 변형·개별 크기/중심/발 높이 맞춤은 없다.

## 같은 페이지의 재생

‘플랜 B · 도트 모션’의 동작·버전에서 두 모션과 기존 걷기를 선택한다. 기본은006 이동 사격이다. 두 비교 버튼은 각 모션의 실제 발사 포즈에서 정지한다. 다음 프레임으로 반동 최고점/복귀를 살피고 속도·배경도 바꿀 수 있다. `./run.sh`로 예제 서버를 실행한다.

공통 `FrameSequence`에 선택적인 프레임별 시간을 추가했다. 발사광은45ms, 뒤따르는 반동/복귀는 더 길게 두어 박자를 나눈다. 이전 manifest는 기존 균일 프레임 시간을 사용한다. 파츠 리그의 사격/활동감 코드는 이번 작업에서 수정하지 않았다.

## 실제 확인과 한계

새 두 JS의 구문과 각 모션의 PNG 계약을 확인했다. [짧은 macOS Chrome 검토](../art/characters/clone_01/motion/plan_b/pixel_combat_006/reviews/browser.json)에서 두 atlas의 실제 canvas 변화·01~12 반복·발사/반동 비교·정지/한 프레임·느린 재생·배경·동작 전환·500px 표시·기존005 선택을 확인했고 페이지 오류는 없었다. [실제 발사와 다음 반동 자세](../art/characters/clone_01/motion/plan_b/pixel_combat_006/reviews/browser-combat-comparison.png)를 보존한다. 전체 게임·문서/목록 검사 묶음·GIF는 실행하지 않았다.

최종 아트 채택과 자연스러움은 사용자 검수 대기다. 움직이는 불투명 발 외곽의 높이는 이동 사격 약4px, 앉아쏴 약3px 변한다. 무릎/앞발/개머리판의 완전 고정, 망토/모발의 물리 접촉이나 매 프레임 같은 윤곽을 보장하지 않는다. 총·발사광·조명이 전신 PNG에 포함되며 실제 탄약/명중 판정·독립 무기 교체는 연결하지 않았다.

공식 검증기의 엄격한 모든 프레임 발 기준선 일치와 GIF 납품은 통과하지 않았다. 원시 검사 결과는 각 모션의 `reviews/structure.json`에 남겼다. GIF는 자동 생성하지 말라는 사용자 지시로 만들지 않았으며 PNG/Chrome 표시 통과를 전체 공식 납품·최종 아트 승인으로 보고하지 않는다.
