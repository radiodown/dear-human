# 플랜 B · 단발과 누르고 연사001

[문서 목록](../README.md) · [같은 캐릭터 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b) · [버전·실제 검토 기록](../art/characters/clone_01/motion/plan_b/input_fire_001/README.md)

플랜 B의 자동 사격 반복을 입력으로 제어하도록 바꿨다. 주요 다섯 탭에서 ‘단발’은 한 번의 발사/반동/복귀, ‘누르고 연사’와 Space는 누르는 동안 반복한다. 입력 전에는 발사하지 않으며 실제 발사 횟수와 대기/발사/복귀 상태를 표시한다. 단발 준비·반동 중에는 단발 버튼을 잠시 비활성화해 클릭이 뒤로 쌓이지 않는다. 일시정지 상태에서 사격 버튼을 누르면 재생을 이어서 시작한다.

마우스를 버튼 밖에서 놓아도 포인터 캡처로 연사를 해제한다. 포인터 취소·캡처 해제·키 놓기·창 포커스 이탈·페이지 숨김·모드/동작 전환에도 입력을 해제한다. 해제 뒤에는 추가 발사 없이 현재 반동만 마친다. 파츠 리그의 입력과 충돌하지 않도록 플랜 B가 보이고 입력 필드/다른 버튼에 초점이 없을 때만 전역 Space를 받는다.

game/animation/sequence-fire.js가 발사 요청·누름·발사 횟수와 원본 반동 구간을 관리하고, 공통 FrameSequence가 실제 PNG를 선택한다. 기존005/006/007 atlas를 메모리에서 재사용하며 별도 이미지 생성·PNG 변형·파츠 리깅은 없다. 기존 manifest·카탈로그·과거 검수 기록도 변경하지 않았다. 변경 전/후 코드와 입력 manifest 해시는 버전 records에 보존한다.

경계 걷기/사격은007의 발사 없는 걷기와 이동 사격을 같은 프레임 번호로 사용한다. 기본 걷기/사격은005 걷기와006 이동 사격을 사용한다. 발사 요청은 다음02/08 발 디딤에 소비하고 그 프레임과 뒤의 두 반동/복귀 포즈만 사격 atlas로 표시한다. 나머지는 발사 없는 걷기다. 보행 인덱스를00/01로 되돌리지 않는다. 걷기와 사격의 시간은 준비된 PNG 구간을 사용하므로 발사 순간에는 원본45ms/반동 시간이 적용된다.

앉아쏴는006의 깨끗한00 기준에서 대기한다. 입력 즉시05 또는11에서 발사하고 뒤의 두 반동/복귀 포즈를 재생한다. 연사 중에는 두 발사 포즈를 번갈아 쓰고 손을 떼면 마지막 복귀 뒤00으로 돌아온다. 두 클립은 원본 시간 기준 약285ms/265ms다. 프레임 슬라이더·교차/발사 자세 비교 버튼은 원래 PNG 검토 기능으로 유지하며 이 조작은 발사 횟수에 포함하지 않는다. 검토 후 재생하면 입력 대기로 돌아온다. 이전 반려 버전은 원래의 표시 전용 반복을 유지한다.

필요한 변경 JS 구문, 작은 입력/발사 횟수/보행 순서 검사, [Mac Chrome 실제 입력 검토](../art/characters/clone_01/motion/plan_b/input_fire_001/reviews/browser.json)를 수행했다. 한 발 뒤 추가 발사가 없는 것, 누름 반복·버튼 밖 해제·키보드·포커스 이탈, 앉아쏴 즉시 발사/복귀, 포즈 검토 비집계, 같은 탭/이전 탭 재선택과500px 표시를 확인했다. 첫 브라우저 시도에서 output 요소를 input 전용 읽기로 호출한 검토 코드 오류는 별도 기록으로 보존하고, 해당 읽기를 수정한 후 필요한 같은 검토를 완료했다. 전체 게임·문서/목록 검사 묶음·GIF는 실행하지 않았다.

전신 PNG 방식의 범위를 유지한다. 이동 사격은 발 디딤에 묶여 입력 후1×에서 최대 약0.57초 대기할 수 있고, 연사 간격도 보행/원본 반동 시간에 제한된다. 독립적인 임의 발사율이나 실제 M16 발사율 구현이 아니다. 기존005↔006/007 사이의 윤곽·머리/망토·발 높이 변화와 전환의 자연스러움은 아트 검수 대기다. 독립 총구 FX·모발/천 물리·탄약/명중 판정·소리는 추가하지 않았다.
