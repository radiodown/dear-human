# 19. 타격감·명중도·대미지·폭발·사망 연출

[문서 목록](../README.md) · 타격감·명중률·대미지 숫자·일반/크리티컬 구분·다양한 사망·폭발·속도감은 사용자 요구사항이다. 아래 판정 방식과 수치는 구현 제안이며 미검증이다.

## 1. 전투 표현의 목표

한 발의 결과를 **총의 반동·화염·총성 → 실제 탄도 → 재질별 충돌·몸 반응 → 대미지 숫자 → 해당하는 사망**으로 읽히게 한다. 효과의 양뿐 아니라 반응 시점·방향·소리·잔흔을 맞춘다.

빗나감, 스침, 일반 명중, 크리티컬, 약점 명중, 폭발은 다른 강도로 표현한다. 실제 결과를 먼저 계산하고 연출이 이를 표시한다. 큰 이펙트 때문에 피해가 추가되거나, 사망 연출이 길어서 다음 적을 못 맞히는 구조를 만들지 않는다.

## 2. 초기 범위

M16 한 자루와 군집생물 1종으로 명중도·스침·일반/크리티컬·대미지 표시를 검증한다. 적 사망은 기본 쓰러짐·치명타 마무리·폭발 마무리의 3개 반응 프로필을 준비한다.

폭발은 통합 샘플에서 **폭발 중심·범위·가림·거리 감쇠·파편·숫자·사망**까지 검증한다. 실제 수류탄 투척·새 폭발 무기·추가 스테이지를 이번에 함께 만든다는 뜻은 아니다. 초기에는 폭발 샘플 트리거를 사용한다.

명중도·치명타는 초기 전투 검증에 포함한다. 스킬은 계속 비활성 슬롯만 유지한다. 갑옷 외형도 현재 cosmetic_only이며 방어력·관통 계산은 추가하지 않는다.

## 3. 명중률 스탯과 실제 탄도

기본안은 **명중도 스탯이 탄의 산포를 바꾸고 실제 교차로 피격을 결정**하는 방식이다. 조준 입력은 기존의 좌우 방향을 유지한다. 자유 각도 조준은 추가하지 않지만 실제 탄도는 산포로 약간 기울어진다.

```text
A = clamp(base_accuracy - movement_penalty - current_bloom, 0, 1)
half_spread_deg = (1 - A) * max_spread_deg
shot_angle = facing_angle + seeded_uniform(-half_spread_deg, half_spread_deg)
```

M16 제안값은 기본 명중도 0.90, 이동 페널티 0.15, 연사 bloom은 발마다 0.02·최대 0.20, 최대 산포 반각 10도다. 정지 첫 발은 ±1도, 이동 첫 발은 ±2.5도, 이동하며 최대 연사는 ±4.5도다.

현재 bloom으로 탄도를 정한 뒤 이번 발의 bloom을 더한다. 마지막 발에서 0.15초 후 초당 0.4의 속도로 bloom을 회복한다. 발사 입력을 빠르게 떼고 눌러도 발사 간격·bloom을 초기화하지 않는다.

0.90은 모든 거리·모든 적에게 정확히 90%가 맞는다는 보장이 아니다. 실제 명중률은 적 크기·거리·이동·연사를 포함한 실측값으로 따로 기록한다. 페이지에는 명중도 스탯과 실측 명중률을 구분한다.

가장 가까운 유효 Hurtbox 또는 벽에서 탄도와 판정을 함께 끝낸다. 근접 겹침 보호 선분도 같은 원칙을 적용한다. 판정이 빗나갔는데 화면에서는 몸을 관통해 보이는 가짜 MISS 표현을 만들지 않는다.

## 4. 맞은 위치와 크리티컬

적의 기본 Hurtbox 안에 core와 weakspot 영역을 데이터로 둔다. 먼저 가장 가까운 대상 하나를 정하고 그 대상 안에서 사선이 지나는 영역을 평가한다. 실제 충돌점은 바깥 표면에 유지하며, 위치 분류를 위해 같은 대상 내부의 사선 구간을 확인한다.

| 결과 | 조건 | 피해·연출 |
|---|---|---|
| 빗나감 | 적 Hurtbox와 교차 없음 | 적 피해·액체·대미지 숫자 없음, 벽이면 벽 충돌 |
| 스침 | 외곽만 통과, core·weakspot 미통과 | 피해 ×0.5, 작은 갑각 조각·소량 진액·작은 숫자 |
| 일반 | core 통과, 약점 아님 | 기본 피해, 표준 진액·몸 반동·일반 숫자 |
| 크리티컬 | 일반 명중의 별도 치명타 판정 성공 | 피해 ×2, 강조 숫자·날카로운 피격음·추가 파편 |
| 약점 | weakspot 통과 | 확정 치명타, 약점 표기·집중된 충돌 강조 |

크리티컬 확률의 시작값은 0.10이다. 스침은 치명타를 굴리지 않는다. 약점은 확정 치명타이므로 확률 치명타를 다시 곱하지 않는다. 명중도 자체를 피해에 한 번 더 곱하지 않는다. 낮은 명중도에서도 실제로 중심을 맞혔다면 정상 피해를 준다.

초기 weakspot은 군집생물의 갑각 이음새를 나타내는 작은 고정 영역으로 제안한다. 자체 전투 규칙이며 영역은 미리보기에서 시각 위치와 맞춘다. 무기·갑옷 외형의 흔들림으로 Hurtbox를 임의로 바꾸지 않는다.

## 5. 피해와 숫자

```text
final_damage = round(base_damage * hit_quality_multiplier * critical_multiplier)
hp_loss = min(current_hp, final_damage)
overkill = max(0, final_damage - hp_loss)
```

M16은 스침 10, 일반 20, 크리티컬/약점 40을 시작값으로 둔다. HP 60 적의 ‘3발 처치’는 **일반 비치명 3발**의 기준이다. 스침·치명타가 섞이면 필요한 발수가 달라진다.

숫자는 최종 계산 피해 final_damage를 표시한다. 남은 HP가 5인 적에게 40이 계산되면 숫자는 40, 실제 HP 감소는 5로 기록한다. 처치·실제 체력 손실 통계에는 hp_loss를 사용한다.

| 숫자 프로필 | 표시 | 초기 수명 |
|---|---|---|
| 스침 | 작은 회색 숫자와 ‘스침’ | 약 0.4초 |
| 일반 | 흰색 숫자, 짧게 떠오름 | 약 0.45초 |
| 크리티컬 | 금색·약 1.35배 크기·‘치명’ 강조 | 약 0.65초 |
| 약점 | 치명타 숫자에 ‘약점’ 표시 | 약 0.65초 |
| 플레이어 피해 | 붉은 숫자·별도 위치 오프셋 | 약 0.45초 |

색만으로 구분하지 않고 크기·문구·짧은 튀어오름을 함께 쓴다. 생성 시 피격점의 월드 좌표를 저장하고 대상과 겹치지 않게 약간 흩어 띄운다. 초기 숫자 풀은 32개다. 상한 초과 시 오래된 일반 숫자부터, 없으면 가장 오래된 항목을 회수하고 실제 피해 로그는 보존한다.

## 6. 발사·피격의 재질과 강도

| 상황 | 시각 | 소리·몸 반응 |
|---|---|---|
| M16 발사 | 짧은 화염·실제 탄도·선택 탄피 | 총성·총/어깨 반동·머리/바스트 지연 |
| 갑각 스침 | 작은 갑각 조각·짧은 긁힘·적은 진액 | 가벼운 마찰음, 작은 밀림 |
| 생체 일반 명중 | 충돌점 분사·액적·짧은 색 변화 | 둔한 피격음, 빠른 몸 반동 |
| 치명타/약점 | 집중 스파크·더 뚜렷한 진액·짧은 강조 | 높은 강조음·강한 밀림, 연사 흐름 유지 |
| 벽 | 먼지·스파크·작은 부스러기 | 벽 재질음, 생물성 액체 없음 |
| 폭발 | 순간 섬광·팽창·파편·먼지·늦게 흩어지는 연기 | 폭발음·짧은 화면 충격·방사형 반응 |

혈액·진액은 [14](14-hit-effects.md)의 실제 피해 이벤트에서 한 번만 생성한다. 갑각 조각·파편은 표현 전용 풀을 쓴다. 잔해에 별도 피해를 붙이거나 무한히 쌓지 않는다. 사운드는 기본 발사·피격 재질·치명타·폭발 구분을 초기 검증에 포함한다.

## 7. 폭발 판정과 효과

폭발 샘플은 explosion_id 하나로 반경 안의 적 목록을 얻고 enemy_id별 한 번만 처리한다. 폭발 중심에서 Hurtbox의 최근접점까지 거리와 가림 선분을 함께 사용한다.

제안값은 기본 피해 60, 반경 120px, 가장자리 피해 배율 0.2다.

```text
0 <= d <= radius:
  damage = round(base_damage * (1 - (1 - edge_multiplier) * d / radius))
d > radius 또는 가림: 피해 없음
```

가림이 없으면 거리 0/60/120px에서 60/36/12 피해다. 범위 바깥은 0이며 가려진 대상은 이 기본안에서 피해가 없다. 폭발 피해는 적 한 종류라도 다수 대상에 각각 적용하고 숫자도 각각 표시한다.

첫 폭발 샘플은 적에게만 범위 피해를 주며 별도 직격 피해·확률 치명타를 더하지 않는다. 새 폭발 무기를 만들 때 직격+범위 중첩, 약점, 아군 피해는 무기 정의에 명시해야 한다. 큰 그림의 크기를 피해 반경으로 자동 사용하지 않는다.

## 8. 사망 표현

| 프로필 | 조건 | 표현 |
|---|---|---|
| normal | 일반/스침 마무리 | 방향성 몸 반응→쓰러짐, 소량 진액 |
| critical | 치명타/약점 마무리 | 강한 밀림·갑각 조각·강조 피격 후 쓰러짐 |
| explosive | 폭발 마무리 | 방사형 밀림·파편·진액과 먼지, 다른 종료 실루엣 |

선택 우선순위는 폭발 → 치명타/약점 → 일반이다. 같은 피해로 죽은 적에 사망·처치를 여러 번 발행하지 않는다. 과잉 피해는 추가 잔해 강도의 제한된 입력으로만 사용한다.

적의 전용 사망 포즈·클립과 재사용 파편 자산을 조합한다. 큰 연출 때문에 매번 전체 캐릭터를 다시 생성하지 않는다. 2dimg2motion 참고물을 사용할 때 도구의 기준 자세 복귀 프레임을 죽은 적의 마지막 자세로 재생하지 않도록 클립 구간을 명시한다.

HP 0 즉시 Hurtbox·AI·생존 집계에서 제외하고 연출만 남긴다. 연출 수명은 0.8~1.2초, 초기 동시 시체 상한은 8개로 제안한다. 구역 완료가 시체 제거를 기다리지 않게 한다.

## 9. 액션감과 속도감

일반 연사는 전역 정지 없이 입력·이동·사격을 이어간다. 치명타 마무리에는 사망 대상의 **표현 애니메이션만 약 0.02~0.03초 정지**하는 효과를 시험한다. 게임 시간·입력·발사 간격을 멈추지 않고, 연속 요청은 중첩하지 않는다.

카메라 충격의 시작 범위는 발사 0.25px/0.04초, 치명타 마무리 1px/0.06초, 폭발 2.5px/0.12초다. 연사 요청을 단순 합산하지 않고 진폭 상한·감쇠를 둔다. HUD는 흔들지 않으며 강도/끄기 옵션으로 가독성을 비교한다.

빠른 입력 반응, 짧은 반동 회복, 원거리 적을 읽을 여백, 짧고 분명한 피격음으로 속도감을 만든다. 이동 속도 120/160px·카메라 앞보기·효과 수명을 샘플에서 비교하되 현재 기본 속도는 실험 전 임의로 확정 변경하지 않는다.

## 10. 결과 계약과 재현

공통 CombatResolver가 명중 위치·피해·치명타·사망 이유를 계산한다. FeedbackDirector는 그 결과로 숫자·소리·입자·몸 반응·카메라·사망 프로필을 선택한다. 연출 코드가 독자적으로 다시 명중·치명타를 굴리지 않는다.

발사 기록에는 shot_id·weapon_id·명중도·bloom·산포각·시드·교차점·영역을, 피해 기록에는 damage_id·final_damage·hp_loss·is_critical·critical_source·overkill·피해 원인을 둔다. 폭발은 explosion_id와 각 대상 결과를 연결한다.

명중·치명타·표현의 난수 스트림을 분리한다. 입자 수나 소리 변형을 바꿨다고 전투 결과가 달라지지 않아야 한다. 같은 설정·게임 시간·시드로 재현한다.

## 11. 통합 샘플과 검증

기존 [18 샘플 사이트](18-preview-library-and-reuse.md)에 빗나감·스침·일반·치명타·약점·폭발·사망 비교 프리셋을 추가한다. 캐릭터·무기·효과·적의 결과를 같은 사이트에서 연결하고 새 사이트를 만들지 않는다.

일반 피해 기준 실험은 산포 0·치명타 확률 0의 진단 설정으로 수행한다. 각종 결과는 실제 교차·같은 CombatResolver로 재현하며 표시만 강제로 바꾼 가짜 검증을 만들지 않는다. 숫자·효과·소리·카메라를 따로 끄고 읽기 쉬운지 비교한다.

초기 검수는 [08](08-feasibility-and-qa.md)의 C 항목을 따른다. 아직 실제 효과 생성·사운드 제작·웹 구현은 하지 않았다. 수치와 데이터 예시는 [07](07-data-and-assets.md)에 둔다.
