# 14. 피격 효과: 혈액·군집생물 진액

[문서 목록](../README.md) · 피격 효과는 초기 핵심 구현이다. 아래 길이·색·입자 수는 제안값이다.

## 1. 표현 구성

피격은 **접촉 위치의 분사 → 짧은 색상 반응·몸의 반동 → 낙하 액적 → 제한된 바닥 잔흔**으로 구성한다. 플레이어는 붉은 혈액, 군집생물은 별도 팔레트의 점성 진액으로 구별한다.

군집생물 진액을 황록색으로 두는 것은 자체 적을 구별하기 위한 가독성 제안이다. 화염의 노란색과 구분되는 녹색·자주색 대안도 비교한다. 조작 클론은 생물학적 신체를 가진 성인이며, 붉은 혈액에는 human_blood 프로필을 사용한다.

## 2. 효과 프로필

| 프로필 | 분사와 액적 | 잔흔 | 반응 |
|---|---|---|---|
| `human_blood` | 붉은 짧은 부채꼴 분사, 작고 빠른 6~10개 액적 | 어두운 붉은 얼룩, 2~3초 | 실제 HP 감소 시 몸 반동·점멸 |
| `swarm_ichor` | 황록색 점성 분사, 크고 느린 4~8개 액적, 1~2개 짧은 실 모양 흔적 | 탁한 점액 얼룩, 3~5초 | 명중 시 국소 분사·갑각 색 반응 |
| `wall_dust` | 작은 파편·먼지·스파크 | 짧게 사라짐 | 생물성 액체 없음 |

분사 본체는 0.10~0.18초, 액적은 0.15~0.45초에서 시작한다. 진액은 색뿐 아니라 입자 크기·속도·항력·짧은 끈적임을 바꾼다. 전체 화면 유체 시뮬레이션은 필요하지 않다.

## 3. 도구 분담

- **PixelFX:** 화염·충돌 후보를 조정하고, actor에 의존하지 않는 커스텀 혈액·진액의 짧은 분사 시트를 만든다.
- **Phaser ParticleEmitter 또는 작은 액적 풀:** 방향·중력·수명·색과 초기 속도를 주어 낙하 액적을 재생한다. 엔진의 입자 풀을 사용할 수 있다. [공식 입자 문서](https://docs.phaser.io/phaser/concepts/gameobjects/particles).
- **재사용 Sprite 잔흔:** 액적이 바닥에 닿은 위치에 작은 얼룩을 놓고 수명 후 회수한다.
- **CharacterView:** 피격 반동·머리와 바스트의 작은 지연 반응·색상 반응을 표현한다.

PixelFX 시트에 이미 낙하 액적이 구워져 있으면 같은 액적을 런타임에 한 번 더 생성하지 않는다. 기본안에서는 분사 본체만 굽고 움직이는 액적은 런타임에서 처리한다.

## 4. 커스텀 효과 산출물

프로젝트에서 새로 작성할 효과 ID는 다음과 같다. PixelFX 기본 제공 ID라는 뜻이 아니다.

| 제작 ID | 게임 프로필 | 기준 출력 |
|---|---|---|
| `custom/human-blood-hit` | human_blood | 투명 PNG·프레임 JSON·피벗 |
| `custom/swarm-ichor-hit` | swarm_ichor | 투명 PNG·프레임 JSON·피벗 |
| `custom/m16-muzzle` | m16_muzzle | 총구 시작점이 원점인 짧은 화염 |

원본 `status/bleeding`은 actor 모양을 참조하는 지속 효과이므로 이 일회 분사와 구분한다. 독립형 커스텀 효과에서는 actor·지면 시연 없이 출력되는지 확인한다. 도구별 기능과 후보는 [06](06-pixelfx-pipeline.md)과 [12](12-web-tools-research.md)를 따른다.

## 5. 판정 이벤트

효과 기준 이벤트는 **실제 HP 감소가 발생한 `damage_applied`**다. damage_id·대상·final_damage·hp_loss·hit_quality·is_critical/critical_source·overkill·위치·방향·재질 프로필과 shot_id 또는 explosion_id를 연결한다. 숫자는 final_damage, 실제 체력 손실은 hp_loss를 사용한다. [19](19-combat-feel-and-damage.md)의 결과 계약을 따른다.

```text
사격 확정 → shot_fired → 화염·탄도·총 반동
직선 충돌 → hit_confirmed → 명중 기록 / 벽이면 wall_dust
적의 HP 감소 → damage_applied → 진액·색 변화·적 반동
플레이어의 HP 감소 → damage_applied → 혈액·피격 반동
HP 0 → entity_died → 사망·집계, 별도 중복 피격 금지
```

적의 진액을 `hit_confirmed`와 `damage_applied` 양쪽에서 생성하지 않는다. 무적 때문에 피해가 거부된 플레이어에게는 혈액이 나오지 않는다. 반복 접촉이 동일 damage_id를 재발행하지 않도록 한다.

스침은 작은 갑각 조각·적은 진액, 일반은 표준 분사, 치명타·약점은 강화된 분사·파편·소리·숫자를 조합한다. 재질과 피격 강도를 구분하고 같은 피해에 분사를 두 번 생성하지 않는다. 사망 파편은 별도 종료 연출이며 새로운 피해·대미지 숫자가 아니다.

## 6. 위치와 방향

총알 명중은 명중도 산포를 적용한 실제 직선 판정의 교차점을 사용한다. 근접 공격은 공격자 위치에서 대상 몸통 Hurtbox를 향한 선분과 표면의 교차점을 구해 사용한다. 부정확한 접촉이면 가장 가까운 몸통 표면점을 대체값으로 기록한다.

분사는 충돌 표면 바깥쪽과 입사 방향을 조합해 화면에서 읽히는 부채꼴로 정한다. 총구 위치나 캐릭터 중앙에 무조건 생성하지 않는다. 먼저 좌·우 각각의 테스트 영상으로 방향을 고정한다.

생성 시점의 위치·방향은 월드 좌표로 저장한다. 이후 대상이 반전하거나 카메라가 움직여도 액체가 같이 뒤집히거나 따라오면 안 된다. 몸에 남는 작은 상처 표시만 선택적으로 로컬 부착한다.

## 7. 낙하·잔흔

단일 지면 `y=300`에서 시작하므로 액적의 아래쪽이 지면을 통과할 때 바닥 위치를 계산하고 한 번만 잔흔을 생성한다. 벽·경계에 액체를 정교하게 바르는 기능은 후속이다. 액적에는 전투용 충돌체를 붙이지 않는다.

잔흔은 지면보다 위, 캐릭터보다 아래에 표시한다. 처음에는 개별 Sprite 풀을 사용해 수명·상한을 관리한다. 하나의 영구 RenderTexture에 계속 찍으면 개별 얼룩의 수명 관리와 무한 확대가 어려우므로 초기안에 넣지 않는다.

## 8. 초기 상한

| 종류 | 제안 상한 | 초과 시 |
|---|---|---|
| 짧은 생물성 분사 | 16개 | 오래된 동일 프로필 효과 회수 |
| 살아 있는 액적 | 128개 | 새 요청 일부 축소, 피해 판정은 유지 |
| 바닥 잔흔 | 48개 | 가장 오래된 잔흔 회수 |
| 총구 / 탄도 / 벽 충돌 | 4 / 8 / 16개 | 각 풀의 오래된 항목 회수 |

상한은 실제 성능 측정으로 조정한다. 낮은 품질 설정은 액적 수·잔흔 수명을 먼저 줄이고 반동·피격 분사 본체는 유지한다. 바스트·머리 흔들림도 독립적으로 켜고 끌 수 있게 만들어 품질과 비용을 비교한다.

## 9. 일시정지와 재시작

게임이 멈추면 스프링·분사 프레임·액적·잔흔 수명도 멈춘다. 숨겨진 탭에서 돌아왔을 때 오래된 시간만큼 액적을 한 번에 적분하지 않는다. 재시작 시 모든 효과를 반환하고 damage_id 중복 방지 상태도 초기화한다.

검수에서는 실제 HP 감소 1회당 분사 1회, 무적 중 혈액 0회, 좌우 분사 정렬, 바닥 잔흔 월드 고정, 상한 유지, 입력 중단 후 풀 복귀를 확인한다.
