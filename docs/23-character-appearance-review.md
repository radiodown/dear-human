# 23. 주인공 클론 외형 채택 기록

[문서 목록](../README.md) · 서사는 [15](15-worldbuilding.md), 컨셉은 [02](02-world-and-art.md), 실제 모션 시험은 [24](24-motion-rig-test.md)를 따른다.

## 1. 사용자 채택

사용자는 최신 첨부 이미지 기준화를 좋아한다고 평가하고 **이 외형을 컨셉 MD에 적용·모션 작업 재개·기존 자료 삭제**하도록 지시했다. 현재 채택 버전은 reference_003_3d다.

검은 긴 생머리와 앞머리·작은 옆머리 땋음, 짙은 눈, 매우 하얀 쿨톤 피부, 차갑고 차분한 성인 얼굴과 첨부의 비례를 유지한다. 검정/건메탈 전술 갑옷·옅은 회색 흉부 인셋·벨트/파우치·장갑 패널 하의·가터/허벅지 스트랩·스타킹·높은 장갑 군화·어깨 망토와 절제된 금장이 기준이다. 사실적인 애니메이션 인물 비례와 시네마틱 3D 렌더 재질을 유지한다.

참고 JSON의 장군 계급·미래형 소총·격납고 배경은 외형 참고다. 게임의 클론 신분·개발 ID clone_01·초기 M16·베스퍼 스테이지를 바꾸지 않는다. 3D 느낌은 화풍이며 실제 3D 모델이나 3D 게임으로 전환한 것이 아니다.

## 2. 보존한 기준

- [채택 원화](../art/characters/clone_01/concepts/reference_003_3d/source/appearance.png): 1024×1536 RGBA. SHA-256은 2db26f5c2a197b5bfaff2d1b9fe4d82c721783205c22f74946ba92c25f77483c로 유지했다.
- [제출 영어 JSON 프롬프트 MD](../art/characters/clone_01/concepts/reference_003_3d/records/prompt.md).
- [사용자 참고 JSON MD](../art/characters/clone_01/concepts/reference_003_3d/records/user_reference.md): 첨부 텍스트 원문과 동일한 JSON 파일을 함께 둔다.
- [생성 기록](../art/characters/clone_01/concepts/reference_003_3d/records/generation.json): 당시 생성 사실을 보존한다. 생성 당시의 검토 대기 상태를 소급 변조하지 않는다.
- [현재 채택 기록](../art/characters/clone_01/concepts/reference_003_3d/records/adoption.json): 이번 사용자 채택·모션 재개 지시를 따로 기록한다.

이미지는 대화 첨부를 직접 참고해 생성한 출력이다. 원본 첨부 이미지의 로컬 경로·바이트 해시는 제공되지 않았으므로 새 출력을 첨부 원본으로 표시하지 않는다. 모델 ID·seed·결제 비용은 도구에서 제공되지 않아 null이다. 참고 텍스트는 프로젝트에 복사돼 외부 첨부 폴더 없이 읽을 수 있다.

## 3. 이전 자료 정리

이전 분홍 머리 reference_002와 기존 외형으로 중단한 캐릭터/M16 rig_poc_001의 이미지·프롬프트·기록·빈 하위 폴더를 삭제했다. 샘플 목록의 이전 버전도 제거했다. 최신 채택 원화·사용자 참고 JSON·프로젝트 문서·공통 샘플 코드와 새 rig_002 산출물은 유지한다. 삭제된 이전 프롬프트를 현재 제작 조건으로 재사용하지 않는다.

## 4. 통합 샘플과 모션 재개

[채택 외형](http://127.0.0.1:4173/#/samples/characters/clone_01)과 [파츠 모션 시험](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle)을 같은 페이지에서 전환한다. reference_003_3d는 채택 원화이며 rig_002는 별도 모션 초안이다. 원화 채택이 파츠 연결·보행·파지·장전의 최종 채택을 뜻하지 않는다.

분리 캐릭터 파츠·독립 M16 본체/탄창·양팔 IK·반동·머리/머리카락·망토 메시·장전 초안이 준비됐다. 단단한 흉갑은 모핑하지 않는다. 소리·피해 판정·혈액/진액·PixelFX·실제 게임 씬은 아직 연결하지 않았다.

파일/문서·시뮬레이션 검사와 로컬 Chrome의 대기·이동 사격·장전·500px 폭 캡처를 확인했다. 실제 버튼·키보드·포인터/탭 전환의 자동 조작과 성능·전체 동작 시각 검수는 미완료다. 최종 측면 원화·손 모양·관절 가림·원화 일치도 보정과 도구 최종 판단은 [24](24-motion-rig-test.md)에 기록한다.
