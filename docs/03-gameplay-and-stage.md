# 03. 게임플레이와 스테이지

[문서 목록](../README.md) · 수치는 [07 데이터 규약](07-data-and-assets.md)의 제안 초기값이다.

## 1. 기본 플레이

이 문서의 ‘플레이어’는 전투 판정과 입력에서 조작하는 **배속 클론**을 뜻한다. 서사적 플레이어는 인간 지휘관이며, 직접 이동·사격 조작은 클론의 전투 수행을 표현한다. 첫 무대는 [15](15-worldbuilding.md)의 **베스퍼 동부 개척권 내 야외 검문소와 협곡 수송도로**다. 지상에서 자연 대기를 호흡하며 기본 제복으로 활동한다. 대피·보급 통로를 확보하는 임무를 세 전투 구역과 마지막 출구로 표현한다.

오른쪽으로 이동하다 전투 구역에 진입하면 양끝 경계가 닫힌다. 몰려오는 군집생물을 모두 처치하면 경계가 열리고 다음 구역으로 이동한다. 3개 전투 구역을 마친 후 출구에 도착하면 클리어다.

이 문서의 적 수·공격·웨이브는 초기 군집생물 프로토타입 기준이다. 게임 전체는 여러 종류의 적군을 포함하며, 스폰 배치는 `enemy_type_id`로 종류를 지정한다. 현재 모든 배치는 `swarm_creature_melee`만 사용한다.

이동은 좌우 한 축이다. 점프와 위아래 이동은 없다. 사격 방향은 마지막으로 입력한 이동 방향을 따른다. 마우스 위치는 조준에 사용하지 않는다.

## 2. 조작

| 입력 | 동작 |
|---|---|
| `A / D`, `← / →` | 왼쪽 / 오른쪽 이동 |
| `J` 또는 마우스 왼쪽 버튼 유지 | 기본 사격 연사 |
| `R` | 현재 총기의 설정에 따라 재장전 |
| `1 / 2 / 3 / 4` | 슬롯 위치 안내만 제공, 스킬은 실행되지 않음 |
| `Esc` | 플레이 중 일시정지 / 재개 |
| `Enter` | 시작 화면에서 시작, 결과 화면에서 재시작 |

스토리에서는 `Enter` / `Space` / 본문 클릭으로 현재 문장을 완성하거나 다음 문장으로 넘기고, `K` / 화면의 `스토리 스킵`으로 현재 장면 전체를 즉시 건너뛴다. `Esc`는 스토리 중에도 메뉴를 연다. 같은 입력이 전투 사격·결과 재시작으로 전달되지 않게 소비하고 새 누름부터 전투 입력을 받는다. [21](21-story-and-skipping.md)을 따른다.

좌우를 동시에 입력하면 이동을 멈추고 직전 바라보는 방향을 유지한다. 사격 입력 두 개를 함께 눌러도 발사 속도는 늘어나지 않는다. 기본 방향은 오른쪽이다.

이동하며 사격할 수 있고, 사격 때문에 이동이 멈추지 않는다. 이동을 멈추면 마지막 방향으로 정지 사격한다. 뒤로 걸으며 반대편을 조준하는 별도 조작은 없다.

## 3. M16 기본 사격

발사 간격은 0.1초, 1발 피해는 20, 최대 사거리는 560 논리 px다. M16은 30발 탄창을 사용하며 실제 발사마다 1발 소비한다. 예비탄은 초기 검증용으로 무제한이다. 첫 입력은 발사 가능하면 즉시 처리한다. 입력을 놓았다 다시 눌러도 기존 발사 대기시간은 유지한다.

`R`로 탄창에 탄이 남았으면 일반 장전 2.2초, 비었으면 빈 탄창 장전 2.8초를 시작한다. 0발에서 발사를 시도하면 자동 장전한다. 장전 중 사격은 막고 이동은 기본 속도의 75%로 허용한다. 적·피해·스폰은 계속 진행한다. 만탄에서 R은 무시하고, 장전 완료 때 부족한 탄수를 한 번 채운다. 총기별 방식·시간·모션과 취소·일시정지 규약은 [22](22-weapon-reloading.md)을 따른다.

판정은 순간 직선 충돌인 **히트스캔**으로 처리한다. 기본 좌우 조준축에 명중도·이동·연사 bloom의 산포를 더하고 실제 기울어진 사선에서 가장 가까운 적 또는 벽 하나에 맞고 종료한다. 관통·산탄·물리 탄환은 없다. 탄도 선과 판정은 같은 선분을 쓴다. 명중률·위치 등급·치명타 규칙은 [19](19-combat-feel-and-damage.md)을 따른다.

일반 군집생물의 체력은 60이다. M16의 일반 비치명 3발이 처치 기준이며 스침·치명타가 섞이면 발수가 달라진다. 제안 피해는 스침 10·일반 20·치명타/약점 40이다. 일반 명중의 치명타 확률은 10%, 약점은 확정 치명타이고 배율은 중복하지 않는다. 매 실제 피해에 최종 계산 피해 숫자를 표시하고 일반·치명타를 크기·색·문구로 구분한다.

매 발 반동이 발생하고 고개·머리카락·바스트가 작은 시간차로 따라 움직인다. 보행 애니메이션은 계속 이어진다. 변형된 최종 총구 위치와 발사선·화염을 맞추며, 공통 보행과 리그 동작을 발마다 다시 시작하지 않는다. 무기는 별도 파츠이며 두 손은 무기 손잡이 목표를 따른다. 같은 소총군의 무기 추가에 공통 보행·캐릭터 전체 원화를 다시 만들지 않는다. 세부 동작은 [13](13-secondary-motion.md), 장착·파지 규약은 [16](16-modular-character-and-weapons.md)을 따른다.

## 4. 피격과 사망

플레이어 HP는 100이다. 군집생물은 공격 거리 24px 안에서 플레이어를 향해 접촉 공격을 시도한다. 적 1개체의 공격 간격은 1초, 피해는 10이다. 플레이어가 피해를 받으면 전역 무적 시간이 0.75초 적용된다.

무적 시간 중의 적 공격 시도는 피해를 주지 않지만 해당 적의 공격 간격은 소비한다. 여러 군집생물이 동시에 닿아도 같은 물리 틱에서 플레이어의 피해는 한 번만 적용된다. 무적은 시각적인 점멸로 표시하고 입력은 계속 허용한다.

실제 HP가 줄어들 때 플레이어는 붉은 혈액과 짧은 몸 반동, 군집생물은 충돌점의 점성 진액을 표현한다. 액적과 바닥 잔흔은 수명·개수 상한을 둔다. 무적 중 거부된 피해에는 혈액을 생성하지 않는다. [14 피격 효과](14-hit-effects.md)의 공통 피해 이벤트를 사용한다.

군집생물은 일반 명중 시 사격 방향으로 최대 4px 밀리는 값을 기준으로 스침·치명타·폭발의 몸 반응 강도를 구분한다. 벽을 관통하지 않으며 긴 경직은 없다. 적끼리는 물리 충돌하지 않고 같은 지면에 겹칠 수 있다. 이것이 무리의 가독성을 해치면 간격 보정은 후속 검토한다.

HP가 0이 되면 즉시 사망 판정을 확정하고 입력·사격·추가 피해를 막는다. 군집생물은 사망 즉시 명중 대상과 생존 카운트에서 제외하고 일반·치명타·폭발 프로필의 0.8~1.2초 연출 후 제거한다. 초기 동시 시체 상한은 8개이며 구역 완료는 시체 제거를 기다리지 않는다. 플레이어 사망 시 실패 화면으로 전환한다.

폭발 샘플은 적에게 반경 120px·기본 피해 60·거리 감쇠·벽 가림을 적용하고 대상당 한 번만 처리한다. 초기에는 별도 직격 피해·확률 치명타를 중첩하지 않는다. 발사·폭발·피격음, 짧은 카메라 충격과 사망 대상의 표현 정지로 액션감을 검증하되 입력·게임 시간·연사 간격은 멈추지 않는다.

## 5. 스테이지 배치

스테이지 폭은 3840px, 지면 높이는 `y=300`이다. 좌표 원점은 스테이지 왼쪽 위이며 오른쪽이 +X, 아래가 +Y다. 플레이어 시작 발 위치는 `(96, 300)`이다.

| 구간 | X 범위 | 역할 |
|---|---|---|
| 진입 | 0~639 | 이동·사격 안내, 적 없음 |
| 전투 A | 640~1280 | 기본 전투 학습 |
| 연결 도로 | 1281~1599 | 이동·회복 동작 확인, HP 자동 회복 없음 |
| 전투 B | 1600~2240 | 후방 적 등장 |
| 연결 도로 | 2241~2559 | 다음 구역 이동 |
| 전투 C | 2560~3200 | 최종 무리 전투 |
| 출구 도로 | 3201~3839 | `x=3680` 출구 도달 시 클리어 |

전투 시작 트리거는 A `x=704`, B `x=1664`, C `x=2624`다. 최초로 오른쪽 경계를 통과할 때 한 번만 실행한다. 좌측 경계에서 충분히 들어온 뒤 닫히므로 플레이어가 경계에 끼지 않아야 한다.

카메라는 X축만 따라가며 스테이지 양끝에서 제한한다. 전투 중에는 해당 구역 중심에 카메라를 고정해 구역 전체와 양끝 경고를 보이게 한다. 카메라를 이동시켜도 스폰 위치와 판정 좌표는 월드 좌표를 유지한다.

## 6. 웨이브 구성

| 구역 | 배치별 적 수 | 합계 | 접근 방향 |
|---|---|---|---|
| A | 4 → 6 | 10 | 오른쪽 10 |
| B | 6 → 6 → 6 | 18 | 각 배치 오른쪽 4, 왼쪽 2 |
| C | 8 → 9 → 9 | 26 | 각 배치 오른쪽 5/6/6, 왼쪽 3/3/3 |

총 54마리다. 배치는 한 번에 전부 생성하지 않고, 정해진 순서대로 1.5초 간격으로 개체를 생성한다. 배치가 마지막 적까지 생성된 뒤 1.5초를 쉬고 다음 배치를 시작한다. 이전 배치의 생존 여부는 다음 배치 시작을 막지 않는다.

전투 시작 시 0.8초 동안 좌우 경고를 표시한 후 첫 적을 생성한다. 각 적은 좌측 경계 +32px 또는 우측 경계 -32px의 스폰 지점에 등장한다. 플레이어와 스폰 지점의 X 거리가 96px 미만이면 생성하지 않고 대기열에 남긴다. 반대편에 안전하게 생성할 수 있는 경우 그 위치를 사용한다. 두 위치 모두 안전하지 않으면 다음 틱에 재시도한다.

스테이지 동시 생존 적 상한은 20이다. 상한 도달로 보류한 적은 생성 완료로 세지 않는다. 재시도 시 몰아서 생성하지 않고 실제 생성 성공 시점부터 다음 생성 간격을 센다. 스폰 안전거리 보류에도 같은 원칙을 적용한다.

구역 완료 조건은 `해당 구역의 전체 배치 예약 완료 AND 미생성 대기 0 AND 생존 적 0`이다. 잠시 화면에 적이 없다는 이유로 경계가 열리면 안 된다. 사망 연출 중인 적은 생존 적이 아니다.

## 7. HUD와 결과 화면

- 좌측 상단: HP, 현재 구역, 전체 처치 수.
- 별도 무기 영역: 현재 탄수/탄창 용량·예비탄·장전 진행률·R 안내.
- 하단 중앙: 비활성 스킬 슬롯 4개와 `미구현` 표시.
- 시작 안내: 이동 키, 사격 키, 오른쪽 진행 방향.
- 전투 중: 접근 방향 경고, 남은 적 수. 남은 적은 생존 + 미생성 예약 수다.
- 결과: 클리어 / 실패, 플레이 시간, 처치 수, 재시작 안내.

스킬 슬롯은 기본 무기 상태를 표시하는 용도로 재사용하지 않는다. HUD가 총구와 적 접근 경고를 가리지 않도록 배치한다.

## 8. 게임 흐름

`READY → STORY(도입) → PLAYING → STORY(종료) → CLEAR → 새 스테이지`

`PLAYING → FAILED → 새 스테이지`, `PLAYING / STORY ↔ PAUSED(원래 상태 보관)`을 별도 경로로 둔다. 도입·종료에는 짧은 컷신과 미연시식 대화를 묶고 어느 시점이든 즉시 스킵할 수 있다. 시작 화면의 스토리 표시 끄기도 같은 완료 처리를 사용한다.

출구는 3개 구역 완료와 플레이어 생존을 모두 확인한다. 같은 틱에 출구 도착과 HP 0이 겹치면 실패를 우선한다. 결과는 한 번만 확정한다.

출구 성공 시 클리어 결과·통계를 먼저 고정하고 종료 스토리를 연다. 관람 또는 스킵이 끝나면 결과 화면을 표시한다. STORY 중 전투 판정·스폰·연사·전투 타이머는 정지하고 연출 시계만 진행한다. 스킵과 정상 완료는 같은 진행 플래그를 한 번만 적용한다. 자세한 상태·입력·취소 규약은 [21](21-story-and-skipping.md)을 따른다.

일시정지 중 이동·연사·스폰·무적 시간·효과 수명·플레이 시간이 멈춘다. 재개 후 밀린 발사나 스폰을 한꺼번에 처리하지 않는다. 창의 포커스를 잃으면 일시정지한다.

웹 탭이 숨겨지면 머리·바스트의 스프링과 액적·잔흔 시간도 정지한다. 복귀 때 큰 delta와 눌림 입력을 비워 모션이 폭발하거나 연사가 몰아서 발생하지 않도록 한다.

재시작은 스테이지 씬을 새로 구성하는 방식으로 제안한다. HP, 플레이어 위치, 카메라, 웨이브, 스폰 대기열, 발사 시간, 탄수·예비탄·장전 작업/손/탄창 표시, 이펙트, 처치·발사 통계를 모두 초기화한다.

스토리 작업도 취소하고 run_id·장면 완료 키·이번 스테이지 플래그를 초기화한다. 이전 실행의 대사/카메라 콜백은 새 실행에 영향을 주지 않는다. 이번 실행의 스토리 표시 설정은 유지한다.
