# 달리기·완전 대기 팔 자세 보정 · carry_arms_001

사용자 요청: “달리기에서 팔이 이상해”, “완전대기도 팔이꺽겨”. 같은 캐릭터 페이지의 [달리기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run) · [완전 대기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=relaxed)에 적용했다.

완전 대기는 총을 내리면서 주 손목이 어깨 뒤로 들어갔고, 조준 자세의 팔꿈치 가이드로 IK 해를 고르면서 상완이 앞으로, 전완이 뒤로 접혔다. 달리기도 총 지지점이 뒤에 있어 팔꿈치가 몸 뒤로 크게 벌어졌다.

`firing-form.js`의 달리기 총 지지점 보정은 (-4, 0)에서 (+4.5, -6)으로, 완전 대기 지지점은 (-24, +8)에서 (0, -6)으로 옮겼다. 수치는 상체 로컬 좌표이며 y는 아래 방향이다. 총구의 기존 아래 방향은 달리기 35°·완전 대기 58°로 유지한다. 총을 내리는 동안 팔꿈치는 손목 아래쪽의 같은 IK 분기를 사용해 전환 중 뒤집히는 선택을 막는다. 견착·사격·앉아쏴는 기존 가이드를 따른다.

총 높이·허리각 조절로 손이 팔의 도달 범위를 벗어나면 양쪽 손목의 도달 원이 겹치는 곳으로 총 전체 프레임을 최소 거리 이동한다. .75 논리 단위의 팔 펴짐 여유를 남긴다. 무기의 각도와 양손 접점은 유지하고 팔 길이를 늘리거나 손을 총에서 떼지 않는다. 큰 총 낮춤은 도달 범위에 따라 실제 이동이 제한될 수 있다. 이 보정은 낮춰 든 두 자세에만 적용하며 장전에는 적용하지 않는다.

기존 원본 팔/손 그림과 길이, 허벅지/보행·머리/몸통·스커트·동작별 조절은 이어 쓴다. 별도의 어깨 시점 원화나 실제 3D 관절/충돌을 추가한 결과는 아니다.

필요한 변경 JS 구문과 두 자세의 기본값·총 낮춤 18·허리/추가 숙임 조합 여섯 상태를 짧게 확인했다. 양손 접점·실제 팔 길이·무기 stock 접점이 유지됐고, 발사 준비/한 발/복귀에서 팔꿈치 분기 전환은 없었다. 첫 발은 .125초 뒤 총을 다 든 다음 발생했다. 기존 견착 대기·서서쏴·앉아쏴의 무기/머리/관절 목표는 보존 소스와 같았다. [수치 기록](../art/characters/clone_01/motion/rig_005/tests/carry_arms_001/carry-arms.json).
