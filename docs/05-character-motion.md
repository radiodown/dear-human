# 05. 파츠 원화·공통 리그와 2dimg2motion 활용

> 사용자 지시로 2dimg2motion을 **플랜 B**로 실행했다. 전신 보행 14프레임의 실제 생성·보관·재생·검수 결과는 [27](27-plan-b-2dimg2motion.md)을 따른다. 아래 파츠 리그의 첫 시험과 별도 경로다.

[문서 목록](../README.md) · 파츠·무기 계약은 [16](16-modular-character-and-weapons.md), 보조 모션은 [13](13-secondary-motion.md)을 따른다.

현재 사용자 채택 외형으로 분리 파츠·자체 JavaScript/WebGL 리그의 첫 모션 시험을 만들었다. 실제 산출물·검사 범위·미해결 보정은 [24](24-motion-rig-test.md)를 따른다. Spine·2dimg2motion·PixelFX는 이번 시험에서 사용하지 않았으며 도구의 최종 채택은 결과 평가 뒤 결정한다.

이 문서에서 제작하는 플레이어 캐릭터는 인간 지휘관에게 배속된 클론이다. 외형은 [02](02-world-and-art.md), 정체성과 생산·배속 배경은 [15](15-worldbuilding.md)를 따른다.

## 1. 플레이어의 제작 원칙

플레이어는 **무기를 분리한 공통 파츠 리그**로 제작한다. 몸통·머리·팔·손·하체와 공통 걷기·피격 동작은 캐릭터 자산이다. M16의 그림·소켓·반동은 무기 자산이다. 총을 든 완성 전신 PNG 시트를 플레이어 런타임의 기본안으로 쓰지 않는다.

추천 제작 도구는 Spine Professional이며 Phaser RigAdapter를 통해 장착·팔 IK·총구와 게임 판정을 연결한다. 자체 TypeScript 리그를 선택하더라도 같은 분리·좌표·재사용 계약을 지킨다.

## 2. 2dimg2motion의 역할

공식 도구는 기준 이미지에서 전체 자세를 생성해 14개 RGBA 프레임과 키포즈·검수 시트·GIF·manifest를 제작한다. 별도 이미지 생성 수단과 Python·Pillow가 필요하다. 실제 자세는 이미지 모델로 생성하고 스크립트는 정규화·패킹·검수를 담당한다. [공식 README](https://github.com/WU-HAOTIAN34/2dimg2motion/blob/main/README.md).

이 출력은 자동 파츠 분리·뼈대 추출·IK·Spine 애니메이션 데이터가 아니다. 플레이어에는 **기본 자세·보행·반동 타이밍의 참고**로 활용하고, 생성한 포즈를 보며 공통 리그의 키를 작성한다. 적은 생성 PNG 프레임을 그대로 런타임에서 사용할 수 있다.

도구의 원래 14프레임 납품·구조 검사는 생성 참고물과 적 시트에 적용한다. 플레이어 리그의 키 수나 애니메이션 길이를 14프레임으로 강제하지 않는다. 스크립트로 완성 자세를 흉내 내고 도구 생성이 성공했다고 기록하지 않는다.

## 3. 최초에 준비할 원본

| 항목 | 규칙 |
|---|---|
| 외형 | 02의 외형상 만 24세·검은 긴 생머리·짙은 눈·첨부 비례와 전술 갑옷·3D 렌더 질감 |
| 분리 원화 | 무기 없는 몸통, 머리·앞/뒷머리, 가슴/의복, 앞/뒤 상완·하완·손, 골반·다리·부츠 |
| 관절 | 어깨·팔꿈치·손목·목·허리의 겹침과 가려진 그림 보완 |
| 무기 | M16 본체·탄창·조작부를 분리, 손·팔·화염을 그림에 포함하지 않음 |
| 의복·갑옷 경계 | 기본 제복도 몸통·소매·어깨·하체·부츠 경계를 준비하고 장갑판은 별도 부착 |
| 좌표 | 공통 발 원점·리그 기준 크기, 무기는 자체 이미지 피벗·소켓 |
| 크기 비교 | 64px와 128px 표시에서 관절·머리·바스트 가독성 비교 |

완성 전신 그림에서 보이는 부분만 오려 붙이면 팔을 굽힐 때 구멍이 날 수 있다. 분리 레이어와 가려진 부분 보완을 최초 제작에 포함한다. 앞팔·뒤팔은 같은 형태의 재사용 여부를 실제 겹침에서 확인한다.

## 4. 공통 동작과 무기군 동작

| 구분 | 동작·데이터 | 재사용 범위 |
|---|---|---|
| 공통 하체 | idle, walk | 같은 캐릭터의 모든 무기 |
| 공통 몸 반응 | hurt, 머리·머리카락·바스트 보조 상태 | 무기와 별개로 재사용 |
| 양손 소총 자세 | hold_rifle_two_handed | 같은 파지 구조의 무기군 |
| 매 발 사격 | 무기별 반동 + 손잡이 IK | 기본 걷기를 초기화하지 않음 |
| 재장전 | 일반/빈 탄창 상체 동작·보조 손 목표 전환·분리 탄창 | 공통 하체·몸·팔 재사용, 무기별 접점·시간·필요 모션만 추가 |
| 무기별 보정 | 장착 오프셋·손목 각도·손 파츠 선택 | 특정 무기 또는 무기군 |
| 적 이동 | swarm_move 프레임 루프 | 초기 적 1종 |

기존 idle/walk/fire_stand/fire_move는 게임 상태 이름으로 유지할 수 있다. 리그에서는 하체 이동과 상체 파지·반동을 합성한다. 새 소총마다 같은 걷기·정지 전신 시트를 다시 만들지 않는다.

장전은 하체 idle/walk 위의 별도 상체 행동이다. 총을 지지하는 주 손과 탄창/조작부로 이동하는 보조 손을 분리하고, 완료 때 앞손잡이 IK로 복귀한다. 일반/빈 장전은 타이밍과 추가 조작을 구분한다. 탄약은 애니메이션 이벤트가 아닌 게임 상태가 반영한다. 모션·파츠·무기별 재사용 규약은 [22](22-weapon-reloading.md)을 따른다.

## 5. 제작·연결 순서

생성 전에 [18 통합 샘플](18-preview-library-and-reuse.md)에서 같은 캐릭터·파츠·모션의 기존 결과·검수·의존 버전을 확인한다. 재사용할 수 있는 결과와 바뀐 부위를 선택하고 필요한 작업만 수행한다.

1. 외형 기준과 무기 없는 분리 원화를 확정한다.
2. 2dimg2motion으로 필요한 키포즈·타이밍 참고물을 생성·검수한다.
3. 공통 뼈대·부착 파츠·가슴/의복 메시와 관절 겹침을 작성한다.
4. 하체 걷기와 기본 상체 자세를 리그에 작성한다. 갑옷 외형용 부착점·가림 영역·rigid/soft 모션 규약을 준비한다.
5. 별도 M16 그림의 주 손잡이·보조 손잡이·총구·배출구를 측정한다.
6. 무기 장착점을 먼저 계산하고 양쪽 팔을 손바닥 목표에 맞춘다.
7. 매 발 반동과 머리·머리카락·바스트 보조 반응을 연결한다. 일반/빈 장전 상체·보조 손 목표·분리 탄창·복귀를 만들고 동일한 장전 시간으로 재생한다.
8. 무기 없는 상태·M16·다른 길이의 진단 도형을 같은 캐릭터에 장착해 비교한다.
9. 좌우·이동 사격·피격·탭 복귀·부하를 검수한다.
10. 같은 캐릭터 샘플 페이지에 새 파츠·리그·모션·버전과 검수 상태를 등록한다. 첫 실제 원화부터 페이지를 제공하고 모션이 준비되면 기존 페이지에 추가한다.

현재 정적 외형 시안만 제작했다. 파츠·리깅·모션·게임 구현은 사용자 외형 평가 이후다. 각 단계의 시간·비용을 따로 측정한다. 실제 상태는 [23](23-character-appearance-review.md)을 따른다.

## 6. 모션 참고 요청 예시

이미지 프롬프트는 영어 JSON으로 작성하고 실제 제출본을 MD의 JSON 코드 블록에 보관한다. 아래는 외형 채택 이후 사용할 참고 요청의 예시이며 현재 실행한 모션 요청이 아니다.

```json
{
  "language": "en",
  "project": "Dear Human",
  "entity_id": "clone_01",
  "asset_type": "Motion pose and timing reference, not a runtime rig",
  "request": "Show a stable two-handed rifle stance and in-place walking in strict right-facing profile.",
  "constraints": [
    "Use the user-approved adult slender clone design and exact uniform.",
    "Keep the rifle grip, shoulders, elbows, torso and foot contacts readable.",
    "Preserve the straight pink medium bob, silver-gray eyes and shoulder-draped coat.",
    "No muzzle flash, tracer, blood or background.",
    "Follow the selected motion tool's documented frame and delivery workflow."
  ]
}
```

이 참고 이미지에 총이 보이더라도 최종 플레이어 파츠에는 총을 굽지 않는다. 생성 PNG에서 자동으로 리깅 애니메이션이 추출된다고 가정하지 않는다.

## 7. 적과 별도 프레임 제작

미확인 군집생물의 근접 개체는 [02](02-world-and-art.md)의 자체 실루엣에 따라 갑각·다리·발톱·꼬리의 연결과 개수를 고정해 생성한다. 적은 우선 일반 스프라이트로 재생하며 플레이어와 같은 무기 교체 리그를 강제로 만들지 않는다.

## 8. 검수·작업량 기록

캐릭터 파츠·리그·공통 보행의 버전을 고정한 뒤 새 무기 자산과 장착 데이터만으로 교체되는지 확인한다. 손잡이 접점·총구 오차 2px 이하, 관절 틈·팔 늘어남·총 휨 없음이 목표다.

다른 무기군에는 손 모양·상체 파지·재장전 동작을 추가할 수 있다. 이를 전신 재생성 비용과 구분해 기록한다. 최초 파츠 분리·리깅, 포즈 참고 생성, 공통 동작, 무기 1개 추가에 든 시간을 각각 측정한다. 갑옷은 부위별 추가 자산·관절 보정·가림 규칙의 비용을 따로 기록한다. [17](17-modular-armor-appearance.md)의 표준 체형 범위를 따른다.
