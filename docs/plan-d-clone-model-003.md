## 요청과 제작 범위

사용자는 이번 단계의 검증 목적이 “3D 모델링이 되는가”라고 명확히 하고 clone_01의 모델링을 입혀 달라고 했다. 기존 중립 마네킹을 비교용으로 보존하고, 채택 [reference_003_3d 원화](../art/characters/clone_01/concepts/reference_003_3d/source/appearance.png)와 [외형 규약](23-character-appearance-review.md)을 직접 보고 캐릭터 표면을 코드로 작성했다.

이번 결과는 **회전 가능한 실제 3D 메시와 뼈대 가중치를 가진 첫 모델 초안**이다. 원화의 얼굴 닮음·표면 디테일·사실적인 렌더 품질을 완성한 결과는 아니다. 원화를 자동으로 3D 복원하거나, PNG를 평면에 붙여 3D 모델로 표시한 결과도 아니다. 뒷면·숨겨진 부위는 단일 정면 원화에 없으므로 이번 메시의 해석이다.

## 실제 만든 모델

| 항목 | 구현 |
|---|---|
| 형상 | 28,334개 정점 / 44,768개 삼각형. 머리·체형·의상·장비의 실제 표면 |
| 얼굴 | 턱/볼/이마 곡면과 같은 표면에 합친 코, 별도 눈·눈꺼풀·눈썹·입술·귀 |
| 머리 | 검은 머리 캡·앞머리·옆머리·장발 가닥, 작은 옆머리 땋음 표현 |
| 상체 | 검정 내피·허리와 흉곽의 곡면, 곡면 흉갑·회색 인셋·하이 칼라·하네스·어깨/전완 장갑 |
| 하체 | 벨트·파우치·짧은 분할 스커트·가터/허벅지 스트랩·스타킹·무릎/정강이 장갑·장갑 군화 |
| 망토 | 양면의 실제 곡면, 주름 방향을 가진 형상, 절제된 금색 테두리·작은 날개 무늬 |
| 재질 | 피부·눈·머리·천·건메탈·회색 인셋·금장·가죽·스타킹·망토 등 15개 재질. 금속성/거칠기와 정점 색 |
| 리깅 | 기존 21개 관절. inverse bind와 정점 가중치의 CPU linear blend skinning. 부드러운 몸통/팔/다리와 단단한 장갑 부착 |
| 저장 | 같은 정점·삼각형·재질·가중치를 `clone_01.glb`로 내보냄 |

주요 작성 코드는 `native/plan-d/src/CloneModel.cpp`, 저장 코드는 `ModelExport.cpp`다. 네이티브 뷰어는 이 작성 코드에서 만든 메시를 캐시하고 현재 뼈대 변환을 적용한다. **현재 뷰어가 GLB를 다시 불러오는 로더를 구현한 것은 아니다.** GLB는 동일한 원본 메시와 리깅 데이터를 별도 도구에서 사용할 수 있도록 저장한 파일이다. 파일 안에는 스켈레톤과 가중치가 있고 구운 애니메이션 클립은 없다. 현재 보행은 기존 공통 시뮬레이션의 절차적 관절 움직임이다.

메시·스키닝·재질 채널은 SDL 없는 공통 C++ 코어에 두었다. 읽기 전용 RenderFrame과 Metal/D3D12 하단 구현의 분리는 유지한다. 네이티브 화면의 재질은 조명·스페큘러·림 반응을 이용한 단순 근사이며 완전한 PBR, 실제 그림자, 노멀맵·고해상도 텍스처를 구현한 것은 아니다. GLB에는 표준 metallic/roughness 재질 값을 저장한다. [glTF 스키닝/파일 규약](https://github.com/KhronosGroup/glTF/blob/main/specification/2.0/Specification.adoc)

## 보기와 비교

`native/plan-d/run.command` 실행 시 clone_01 모델을 기본 표시한다. `Q/E`는 360° 회전, `F`는 얼굴/전신, `M`은 중립 마네킹 비교, `W`는 기존 제자리 보행이다. `1/2/3` 뼈대/모델/겹쳐 보기와 일시정지·확대·시점 조작을 함께 사용한다. 기본 카메라는 yaw 65° / pitch 8°이고 기본 보기는 모델 단독이다.

## 실제 확인

Mac에서 빌드 후 전신 사선·얼굴 정면 확대·뒤쪽 사선을 실제 Metal 창에서 각 3프레임 실행·캡처했다. 추가로 90프레임의 짧은 제자리 보행에서 가중치로 변형되는 모델을 표시했다. 저장한 네 화면을 직접 확인했다. 처음의 상자형 흉갑과 분리된 구형 코는 시각 피드백 후 곡면 흉갑과 얼굴 표면 코로 보정했고 초기 이미지는 `attempt-*`로 보존했다.

GLB는 Khronos 공식 `gltf-validator` 2.0.0-dev.3.10으로 검사해 **오류 0 / 경고 0**이었다. [검사 결과 JSON](../art/characters/clone_01/motion/plan_d/clone_model_003/records/gltf-validation.json). 검사기의 `totalVertexCount`는 재질별 프리미티브가 같은 정점 접근자를 참조한 수를 합산한 값이다. 원본의 실제 저장 정점 수는 28,334이고 삼각형 수는 44,768이다. 형식 검사는 얼굴 닮음이나 의상 충돌의 시각 통과를 의미하지 않는다. [공식 검사기](https://github.com/KhronosGroup/glTF-Validator)

확인은 모델 파일의 유효성과 실제 렌더 피드백으로 제한했다. 전체 프로젝트 테스트·브라우저 검사·장시간 성능 검사·Windows 실행은 수행하지 않았다. 최초 C++ 빌드의 정수 `sin()` 오버로드에 의한 float 축소 오류는 수정한 뒤 빌드를 완료했다.

## 남은 품질과 기능

- 얼굴은 단순한 곡면과 특징점 수준이며 채택 원화의 인상·눈매·코·입의 재현도와 피부/머리 질감이 부족하다.
- 갑옷·파우치·장식은 단순화되어 있고 손과 의상 경계 일부는 추가 모델링이 필요하다. 고해상도 UV·텍스처·노멀맵은 없다.
- 머리와 망토는 입체 형상이지만 실제 천/머리카락 시뮬레이션·몸/다리와의 충돌 처리가 없다. 보행 중 의상 간섭을 최종 통과로 보고하지 않는다.
- M16·헬멧·견착·사격·장전·앉아쏴, 얼굴 표정과 손가락 전용 골격, GLB 가져오기, 구운 애니메이션 클립은 이번 범위 밖이다.
- 기존 21관절 좌표를 재사용한 프로토타입 비례다. 실제 키·최종 신체 치수 확정이나 원화 일치도 승인은 아니다.

현재 판정은 **3D 모델 생성·리깅 연결·네이티브 표시·유효한 GLB 저장 경로 확인 / 캐릭터 아트는 사용자 검수 대기**다. 기존 채택 원화·웹 A/B/C와 과거 결과를 보존하고 후속 결과는 새 버전에 남긴다.
