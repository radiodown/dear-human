# 모아 · 채택 얼굴과 헤어 적용 007

사용자가 모아의 새 얼굴과 **백발 생머리 중단발·얇은 시스루뱅** 샘플을 채택해 전신에 적용하도록 지시했다. 푸른 눈, 러시아계 인상과 25~26세의 젊고 부드러운 성인 외형을 유지한다.

얼굴·헤어 방향은 사용자 채택이며, [전신 007](../art/characters/moa/concepts/illustration_007/README.md)의 세부 일치도는 확인 대기다. 위키 전신·얼굴 아이콘과 미리보기 현재 버전을 갱신한다. 기존 의상·지원화기·장비·포즈는 시각적으로 유지하고, 다른 대원·서사·게임·모션은 변경하지 않는다.

이전 004의 다크브라운 긴 웨이브·아시아계 인상과 006의 나이 들어 보이는 얼굴·헤어는 모아의 현재 외형으로 사용하지 않는다. 이전 원본·정확한 입력·피드백 기록은 보존하며 러시아계 인상으로 국적·혈통을 확정하지 않는다.
