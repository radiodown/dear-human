# 수직 시점 · 살짝 내려다보는 측면 001

[문서 목록](../README.md) · [12° 미리보기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle&viewPitch=12) · [0° 정측면](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle&viewPitch=0)

사용자가 정측면에서 조금 아래를 내려다보는 수직각 변경을 요청했다. 같은 캐릭터·무기 페이지의 공통 파츠 렌더러에 기본 **12°**, 범위 **0~20°**의 카메라 하향각을 개발 연결했다. 슬라이더와 ‘정측면 0°’·‘위에서 12°’ 버튼으로 재생·일시정지 중 비교한다. URL의 `viewPitch`로 각도를 공유하며 생략하면 12°다.

현재 상태는 `untested`·사용자 검수 대기다. 기존 “검증은 내가할게 개발만해봐” 지시에 따라 테스트·구문 검사·문서/목록 검사·브라우저 검수/캡처를 실행하지 않았다.

## 구현 범위

- [공통 카메라](../game/animation/side-camera.js)는 원래 2D 포즈의 복사본에 앞뒤 깊이를 부여한 뒤 `screenY = y·cos(pitch) + z·sin(pitch)`로 정사영한다. 좌우 진행축은 유지한다. 프레임마다 별도 확대/중심 맞춤을 하지 않는다.
- 몸통·흉갑·허리·스커트의 공통 경계는 같은 깊이를 사용한다. 팔다리는 가까운 쪽 +8, 먼 쪽 -8이며 팔꿈치 깊이는 어깨에서 손목으로 이어진다. 양손·총·탄창·개머리판 접점·총구는 +8을 공유한다. 기존 IK 수치와 소스 소켓은 그대로 사용한다.
- 머리카락의 위 5/8과 망토의 위 1/5은 부착 깊이를 고정한다. 아래로 갈수록 각각 최대 -3, -7의 깊이로 완만하게 이어진다. 기존 보조 모션을 재사용한다.
- 바닥 격자와 발 아래 타원도 같은 카메라로 투영한다. 타원은 접지 가독성을 위한 표시이며 실제 3D 투영 그림자가 아니다. 0°에서는 기존 측면 바닥 선을 사용한다.
- 총구 화염과 조명 중심에 같은 깊이/각도를 적용하고 셰이더의 근사 표면 방향도 카메라 각도만큼 돌린다. 발사 타이머·재질·원본 알파·그리기 순서는 기존 것을 사용한다.
- 분리 파츠 보기는 원본 비교용 0°로 표시하고 각도 조작을 잠근다. 조립 보기로 돌아가면 선택한 각도를 복원한다.

## 한계와 인계

기존 측면 PNG를 깊이가 있는 평면으로 배치한 작은 각도 비교다. 실제 3D 모델·새 윗면 그림·카메라에 따른 새로운 가림 순서는 없다. 머리 정수리·흉갑 상면·어깨/소총 윗면이 새로 보이는 진짜 시점 원화 변경으로 해석하지 않는다. 큰 각도에서의 평면감·연결부 가림과 무기/얼굴 관계는 사용자 화면 검수가 남아 있다. UI의 접점 오차 수치는 기존 2D 리그 공간 기준이며 화면 품질 통과를 뜻하지 않는다.

이 작업은 그림·GIF·플랜 B/C를 생성하거나 변경하지 않는다. 현재 작업 폴더의 손·앉아쏴·달리기 코드를 재사용하며 해당 동작을 검증한 것으로 보고하지 않는다.
