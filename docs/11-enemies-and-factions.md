# 11. 적군과 세력

[문서 목록](../README.md) · 세계관·정치적 관계·첫 임무는 [15. 세계관](15-worldbuilding.md)을 따른다. 이 문서는 적의 제작 범위와 전투 역할을 관리한다.

## 1. 확정된 방향과 현재 범위

**Dear Human**은 인간 지휘관과 배속 클론이 근미래의 성간 식민행성 베스퍼에서 전투하는 횡스크롤 액션 슈터다. 베스퍼는 같은 우리은하 안의 먼 행성이며 인간과 클론이 자연 대기를 호흡할 수 있다. 최초 검증용 적은 자체 가칭인 **미확인 군집생물**이다. 여러 적을 추가할 수 있는 구조를 준비하되 첫 제작은 근접 개체 하나에 집중한다.

현재 프로토타입에서는 갑각·발톱을 가진 근접 개체 `swarm_creature_melee` **1종만** 제작·생성한다. 이름과 구체적 생김새는 보완 제안이며, 기존 근접 무리 전투와 생물성 진액 효과의 검증 목적을 이어받는다. 총 54마리·동시 생존 상한 20의 1스테이지 규칙을 적용한다.

이 문서의 후속 후보는 추가 방향을 기록한 것이며 현재 구현 범위를 늘리지 않는다. 현재 판정은 모두 미검증이다.

## 2. 세력 관계와 현장 위협의 구분

플레이어는 유나이티드 어스 식민지 개척 부대의 인간 지휘관이고 전투 조작 인물은 그에게 배속된 클론이다. 클론전쟁의 잔당 소탕과 정착민 보호가 부대의 임무지만, 모든 클론과 식민지 주민을 적으로 취급하지 않는다. 정치적 배경과 각 집단의 역사 원본은 15번 문서에 둔다.

첫 검문소에서 싸우는 군집생물은 협곡 수송도로와 시설에 유입된 생물성 위협이다. 기원·의도·지휘 체계는 미정이며, `unknown_swarm`은 관측용 데이터 분류다. 토착 생물인지 인간의 개척과 관련된 것인지는 별도 사건으로 남긴다. 클론 반란군과 동맹이거나 같은 원인으로 생겼다고 설정하지 않는다. 각 적은 외형·행동·접근 방식으로 구별하고 설정상의 규모와 실제 전투 난이도는 별도로 조정한다.

| 집단 | 15번 문서의 기준 | 적으로의 적용 |
|---|---|---|
| 유나이티드 어스 개척 부대 | 인간 지휘관·배속 클론·지원 인력의 소속 | 현재 플레이어 측. 인물별 행동과 상부 명령은 별도 서사로 판단한다. |
| 무장 클론 잔당 | 전쟁을 계속하거나 무력으로 시설을 확보하는 집단 | 후속 적 후보. 실제 적대 행위가 있는 집단에 한한다. |
| 도피 클론·공동체 | 군과 생산시설을 떠나 생존하는 개체들 | 존재만으로 적이 되지 않는다. 무장 잔당과 구분한다. |
| 정착민·민간 노동자 | 식민지의 생활과 개척을 이어 가는 사람들 | 보호 대상. 빈곤이나 정부 비판만으로 적으로 분류하지 않는다. |
| 미확인 군집생물 | 베스퍼의 야외 수송도로에 유입된 현장 위험이라는 보완안 | 현재 검증용 적 1종. 기원은 미정이다. |

전쟁 당시 클론의 본래 수명은 80~90년이므로, 현재의 잔당에는 당시부터 살아 있는 개체가 포함될 수 있다. 전후 생산 개체는 인간이 의도적으로 수명을 5~10년으로 제한했지만, 지휘관들은 이를 기술적 결함으로 알고 있다. 후속 생산 여부는 집단별로 정하고 잔당 전체를 후속 개체로만 설명하지 않는다. 생존 계통과 비공개 정책의 원본은 15번 문서에 둔다.

## 3. 적군 구성안

| 구분 | 세력·종류 | 전투에서의 역할 | 현재 상태 |
|---|---|---|---|
| 초기 | 미확인 군집생물 / 근접 개체 | 무리 접근과 근접 압박 | 이번 구현 대상 1종 |
| 후속 후보 | 군집생물 / 원거리 개체 | 접근 적 뒤에서 사격 압박 | 종별·행동 미정, 미구현 |
| 후속 후보 | 군집생물 / 대형 개체 | 큰 실루엣과 긴 처치 시간 | 종별·행동 미정, 미구현 |
| 후속 후보 | 적대 행위가 확인된 무장 클론 잔당 | 인간형 사격·엄폐·전술 압박 | 15의 전후 집단을 활용, 행동·에셋 미구현 |
| 후속 후보 | 원격 조종·절차식 개척 설비·보안 기계의 통제 장애 | 장갑·기계 파편·규칙적인 접근 | AI 실체화 금지 아래의 장비, 원인·행동 미확정·미구현 |

기계형 적이라는 이유만으로 AI가 탑재되어 있다고 설정하지 않는다. AI가 몸을 가진 적을 추가한다면 15번 문서의 실체화 금지를 위반한 사건으로 별도 설정해야 하며, 현재 적 후보에 불법 AI 세력을 확정하지 않는다.

원거리·대형·특수 접근이라는 역할은 향후 검토할 아이디어다. 현재 적의 원거리 총알, 방어력, 비행, 보스, 집단 지휘 시스템은 추가하지 않는다. 군집생물 전체를 하나의 이동 방식이나 체력으로 정의하지 않는다. 초자연적 세력이나 별도의 우주 역사는 추가하지 않는다.

## 4. 첫 군집생물의 제작 기준

- **ID:** 종류 `swarm_creature_melee`, 세력 `unknown_swarm`.
- **실루엣:** 낮게 숙인 몸통, 분절 갑각, 낫 모양 발톱, 긴 꼬리. 상세 색상은 [캐릭터·아트 설정](02-world-and-art.md)을 따른다.
- **이동:** 지면 위에서 플레이어에게 수평 접근. 제자리 달리기 애니메이션을 사용하고 실제 점프·도약·벽 타기는 하지 않는다.
- **공격:** 가까운 거리의 발톱 접촉 피해. 전용 복잡한 공격 모션은 첫 검증에 필수가 아니다.
- **판정:** 몸통 중심 Hurtbox 하나를 사용한다. 긴 꼬리와 발톱 때문에 멀리서 피해를 받지 않도록 한다.
- **표현:** 갑각·다리·발톱·꼬리의 형태를 모션 전체에서 유지한다. 실제 피해에 swarm_ichor 프로필의 진액 분사·액적·잔흔을 적용한다. 분사 시트는 swarm_ichor_hit다.
- **수치:** HP 60, 이동 48px/초, 공격 피해 10. 일반·스침·치명타의 피해·재질 반응과 일반/치명/폭발 사망을 구분한다. 3발 처치는 M16 일반 비치명 기준이다. 모든 수치의 원본은 [07](07-data-and-assets.md)이다.

갑각·다리·발톱·꼬리는 자체 근접 적을 읽기 쉽게 만드는 시각 요소다. 특정 외부 작품의 종족·역사·전투 규칙을 설정으로 가져오지 않는다.

## 5. 다른 적을 추가하는 방법

1. 세력과 개체 종류, 전투 역할을 정한다. 기존 적과 무엇이 다르게 읽혀야 하는지 먼저 기록한다.
2. 새 `enemy_type_id`의 정의를 만든다. EnemyFactory의 뷰 생성 등록·행동 컨트롤러·모션·피격 프로필을 연결한다.
3. 공통 Hurtbox·HP·사망 이벤트를 제공하고 EnemyCatalog에 등록한다.
4. 스테이지 배치의 `enemy_type_id`로 해당 종류를 지정한다. 서로 다른 배치가 다른 종류를 선택할 수 있다.
5. 기본 사격·적 수 집계·스폰 안전거리·일시정지·재시작이 같은 경로로 동작하는지 확인한다.
6. 새로운 공격 방식이나 이동 축이 필요하면 해당 범위를 별도 설계하고 검증한다.

현재는 작은 종류 ID 매핑 하나로 시작한다. 미래의 모든 AI를 미리 작성하거나 빈 적 클래스를 다수 만들지 않는다. 서로 다른 종류가 같은 웨이브에 들어가는 실제 혼합 전투 검증은 두 번째 적을 추가하는 시점에 한다.

## 6. 데이터와 검증 연결

개체 종류는 `enemy_type_id`, 개별 생성 개체는 `enemy_id`, 세력은 `faction_id`로 구분한다. 스폰과 전투 집계는 종류와 상관없이 공통 경로를 사용한다. 세력 ID만으로 임의의 피해 배율이나 우호 관계를 만들지 않는다.

이번 스테이지 데이터의 모든 배치는 `swarm_creature_melee`를 명시해야 한다. 잘못된 ID가 있으면 시작 전 검증에서 오류로 드러나야 한다. 종류 등록이 누락됐는데 예약을 삭제해 구역 완료 조건을 우회해서는 안 된다.
