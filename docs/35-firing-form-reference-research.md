# 35. 첨부 사진 기준 사격 폼 재연구

[문서 목록](../README.md) · [현재 자세 013](34-running-fire-without-eye-aim.md) · 2026-11-07 조사

이번 요청은 사격 폼의 재연구다. 사용자 첨부 사진, 공개 공식 교범의 본문, 현재 리그 소스를 비교했다. **런타임·모션·파츠·총구 조명은 변경하지 않았다.** 사용자 지시에 따라 테스트·문서/목록 검사·미리보기 캡처도 실행하지 않았다. 아래의 사진 해석, 교범 근거, 프로젝트 보정 제안을 구분한다.

## 첨부 사진에서 읽을 형태

다음은 사진의 화면상 형태에 대한 관찰이다. 한 장의 사진으로 실제 무게중심, 발바닥 압력, 관절의 깊이와 정확한 각도를 측정한 결과가 아니다. 사진을 캐릭터 외형이나 무기 변경 지시로 해석하지 않는다.

| 부위 | 사진에서 보이는 관계 | 게임용 자세의 기준 |
|---|---|---|
| 발·무릎 | 두 발이 앞뒤로 어긋나 있고 양쪽 무릎이 굽혀져 있음 | 발 접점을 먼저 두고 골반 높이와 다리 굽힘을 함께 작성 |
| 골반·가슴 | 골반에 비해 어깨와 가슴이 전방에 있음 | 골반 이동과 흉곽 기울기를 별도로 조절하되 전신 실루엣으로 연결 |
| 머리·목 | 얼굴은 전방을 향하며 어깨와 총 가까이에 있음 | 목 뿌리·어깨·총 높이를 먼저 맞추고 머리 보정은 작게 사용 |
| 어깨·개머리판 | 개머리판 끝이 어깨 부근에서 몸과 만남 | 접점 좌표뿐 아니라 실제 그림의 접촉 면과 겹침도 확인 |
| 앞쪽 받침 팔 | 손목보다 팔꿈치가 아래에 있어 총 아래로 지지하는 형태 | 손 목표와 함께 팔꿈치의 아래쪽 실루엣을 작성 |
| 방아쇠 쪽 팔 | 앞쪽 팔과 다른 굽힘·가림을 가짐 | 양팔을 동일한 접기 형태로 다루지 않고 각각 기준 포즈를 작성 |
| 받침 손 | 앞쪽 덮개 부근을 아래/옆에서 감싸는 형태 | 손바닥의 받침과 손가락이 덮개를 감싸는 앞뒤 가림을 함께 표현 |

사진은 완전한 측면 정투영 자료로 보기는 어렵다. 두 어깨 사이 거리, 팔의 단축, 발의 간격을 사진 픽셀 그대로 측면 리그에 옮기지 않는다. 기존 캐릭터의 화면 방향으로 투영한 실루엣이 필요하다.

## 확인한 공식 근거

1. [미 육군 TC 3-22.9, Rifle and Carbine](https://rdl.train.army.mil/catalog-ws/view/100.ATSC/492701D5-25E9-40A7-9498-74C22831F268-1463059585416/tc3_22x9c3.pdf): 본문 2016-05-13, Change 3 표지 2019-11-20. 6-1~6-3의 안정성·다리·견착·머리 관계와 6-16의 서서쏴 설명을 확인했다. 교범은 앞뒤 발과 작은 무릎 굽힘, 전방으로 기울인 상체, 가능한 곧은 머리와 연결된 견착을 다룬다. 이 자료를 모든 인물에 동일한 각도를 적용하라는 규정으로 사용하지 않는다.
2. [미 해병대 MCRP 8-10B.2, Rifle Marksmanship](https://www.marines.mil/portals/1/Publications/MCRP%208-10B.2.pdf?ver=2017-03-15-112143-047): 본문은 MCRP 3-01A의 2012-10-11 판이며 2016-05-02 명칭 변경 문서가 앞에 있다. 6-3~6-7, 6-29~6-30, 10-1~10-2를 확인했다. 머리를 총 쪽으로 과하게 내리는 대신 총·견착을 눈높이와 연결하고, 받침 손·팔꿈치·어깨 접촉을 함께 다룬다. 서 있는 자세도 전투용과 훈련용의 실루엣이 다르므로 섞어서 단일 정답으로 만들지 않는다.

두 자료는 판본을 명시한 공개 참고다. 2026년의 최신 훈련 규정 전체를 확인했다는 뜻은 아니다. 본문은 웹에서 확인했지만 PDF 그림 캡처는 403/시간 초과로 확보하지 못했다. 따라서 교범의 Figure 6-9/6-33을 실제로 눈으로 비교했다고 기록하지 않는다. 시각 분석 대상은 사용자 첨부 사진이며 교범은 본문 근거다.

## 현재 코드에서 재검토할 구조

이 절은 소스 읽기에 근거한 개발 판단이다. 최신 화면을 재검수한 결과와 구분한다.

- `gait.js`는 골반 이동과 상체 기울기를 계산하고 `rig-core.js`는 골반 위 34의 허리축에서 상체를 회전시킨다. 의상 분리는 있지만 발목–무릎–골반–흉곽의 연결을 목표 실루엣으로 함께 맞추는 과정은 없다. 허리 회전값만 더하는 보정으로는 사진의 전신 형태를 충분히 작성하기 어렵다.
- `proportions.js`의 어깨·목 기준점과 `headAim`은 고정 보정값이다. 어깨·개머리판·볼 접촉을 먼저 배치한 뒤 눈을 맞추는 전신 제약으로 풀고 있지는 않다. 눈–조준선 오차가 작아도 자연스러운 자세가 완성됐다는 뜻은 아니다.
- 양팔은 각각 같은 방향의 두 뼈 IK로 손 목표를 맞춘다. 현재 손/총 접점이 맞는 것과 팔꿈치·상완의 깊이·어깨 외형이 맞는 것은 별개다. 팔꿈치 기준 포즈와 IK 혼합이 필요하고, 깊이 변화가 크면 단축된 파츠 시점도 필요하다. 2D IK 유도점 하나로 실제 3D 회전을 해결한다고 가정하지 않는다.
- 고개 회전은 상체 회전의 .65, 기본 자세와 별도 머리 보정의 조합이다. 이 값들은 기존 프로젝트의 작성값이다. 교범이나 사진에서 측정한 인체 상수로 취급하지 않는다.
- 첫 연사에 한 번 뒷발을 다시 짚는 `RearBrace`는 이미 반복 발사마다 실행되지 않도록 되어 있다. 이는 사용자가 요청한 작은 연출이다. 정착된 포즈를 교범과 비교할 때 이 반응을 필수 인체 동작으로 간주하지 않는다.

## 이후 보정의 우선순위

1. **발·골반 실루엣:** 두 발 접지, 무릎 굽힘, 골반 높이/전후 위치를 하나의 기준 포즈로 정한다. 바닥에서 떠 있지 않고 상체를 받을 수 있는 형태가 우선이다.
2. **흉곽·어깨·목 뿌리:** 흉곽 전경과 어깨의 전방 위치를 함께 작성한다. 어깨 장갑 그림의 중심과 실제 상완 관절을 구분하고, 머리와 견착점이 같은 상부 몸통 배치를 따르게 한다.
3. **총–몸 접촉:** 개머리판이 몸에 닿는 면과 볼·목·조준기 높이의 관계를 먼저 맞춘다. 총 전체를 위아래로 옮기거나 머리 하나만 누르는 보정으로 끝내지 않는다.
4. **양팔·손:** 앞쪽 팔의 지지 실루엣과 뒤쪽 팔의 자연스러운 굽힘을 따로 작성한 뒤 손 접점에 IK를 연결한다. ‘총열 받침 손’의 정확한 대상은 핸드가드이며 손바닥 접점과 손가락 가림을 함께 본다.
5. **전환·반동:** 먼저 정착 포즈를 잡은 다음 기존 준비–발사 전환과 작은 회복을 얹는다. 기존 .12초 준비 시간과 뒷발 반응은 프로젝트 연출이며 공식 교범의 수치로 보고하지 않는다.

권장 작성 순서는 `발 접지 → 골반 → 흉곽·어깨·목 뿌리 → 개머리판/총 → 손·팔꿈치 → 머리의 작은 보정`이다. 이는 게임 리그 작업 순서에 대한 제안이며 실제 사격 절차를 설명한 것이 아니다. 흉갑은 rigid, 허리 연결 천은 soft, 스커트는 골반에 남기는 현재 파트 구분을 이어 사용한다.

## 뛰며쏴와 새 사진의 관계

첨부 사진은 우선 서서 조준하는 폼의 시각 참고로 다룬다. 앞선 사용자 지시인 **뛰며쏴의 눈높이 조준 해제**는 유지한다.

013은 비조준 전환량으로 `eyeAim`을 줄이는 동시에 총 받침을 (-13.5, 4)에서 (-10.5, 20)으로 내린다. 이는 당시 구현 선택이며 ‘눈높이 조준을 안 한다’는 요구에서 이 하강량까지 필수로 도출되는 것은 아니다. 후속 보정에서는 **시선/조준 모드와 총 지지 위치를 별도 설정**으로 다루는 편이 적절하다. 정면을 보는 뛰며쏴에서도 몸–총–양손의 연결은 유지한다. 이 결론은 프로젝트 해석이며 교범이 해당 게임용 뛰며쏴를 권장한다고 해석하지 않는다.
