## 변경

- 구/벽돌 접촉 시연·주변 소품 6종·받침대를 네이티브 장면에서 제거했다. 소품 로딩과 GPU 텍스처 의존성, B/T/L 조작, 외부 장애물 옵션과 이동 차단도 제거했다. 기존 외부 원본/라이선스와 이전 결과는 기록으로 보존했다. 바닥 격자는 위치 확인용으로 남긴다.
- 몸·갑옷·망토·21관절과 기존 긴 머리의 길이를 유지한다. 기본 선택은 긴 머리 006, 외부 헤어 5개는 N으로 비교할 수 있다. 바람은 기본 OFF다.
- HeadModel.cpp로 두상/얼굴을 분리했다. 둥근 두상과 부드러운 볼·턱, 완만한 콧대/코끝, 눈의 곡면·눈꺼풀·짙은 홍채·가느다란 눈썹, 곡면 입술을 작성했다. 피부색/홍조는 머리 정점에만 적용해 몸의 재질을 바꾸지 않는다.
- 정면 머리 표면의 UV 경계가 아니라 기하학적 이음새에서 나뉘던 노멀을 연속 표면 미분으로 계산한다. 작은 두 미분 벡터를 그대로 외적하면 길이가 normalize 임계값보다 작아져 얼굴 굴곡이 사라지던 계산도 수정했다. 헤어 표면에도 같은 수정이 적용된다.
- 앞머리를 11개 곡면 묶음으로 정리하고 얇은 보조 잔머리를 줄였다. 기존 atlas 8개 타일의 머리결은 재사용하고 앞머리 전용 고밀도 4개 타일을 추가했다. 1536×1024, 1,782개 절차적 섬유 경로이며 원본 004 atlas는 덮어쓰지 않는다. 속은 촘촘하고 끝 8%에서 개별 모발이 나뉜다. 중간 시도의 불투명 덩어리는 최종본에서 사용하지 않는다.
- 머리·목·상부 몸통·양쪽 어깨 장갑·상완·등/망토 근사 형상만 헤어 가이드 접촉에 사용한다. 좁은 목과 어깨를 분리해 몸통 하나의 큰 캡슐로 밀어내던 부분을 조정했다. 005 idle_001의 머리 기준 형태 복귀, 끝의 약한 강성, 스텝당 한 번의 접촉 속도 처리를 유지한다.

## 현재 조작

F 얼굴 확대 / H 머리 전용·전신 / N 외부 헤어 비교 / W 제자리 걷기·정지 / P 헤어 물리 / C 몸 접촉 / U 바람 / G 몸 충돌 형상 / Q·E 회전 / Space 일시정지. B/T/L과 외부 물체 시연은 제거했다.

## 필요한 확인과 한계

Mac 증분 빌드·Metal 정면/사선 얼굴 및 전신 PNG, 기존 긴 머리의 걷기→정지/방향 전환→정지와 몸 접촉의 짧은 수치 확인만 수행했다. [실제 기록](../art/characters/clone_01/motion/plan_d/hair_006/records/walk-body-check.txt): 머리 기준 보행 중 정점 변화 최대 약 9.36mm, 멈춘 뒤 1초간 변화 약 1~8μm, 근사 가이드 몸 관통은 해당 정지 조건에서 ON 0 / OFF 약 11.12cm였다. 후자는 가이드의 근사 충돌 수치이며 실제 모든 머리카락 삼각형의 무관통/미끄러짐 완성 판정이 아니다.

[현재 모델](../art/characters/clone_01/motion/plan_d/hair_006/source/clone_01.glb)은 59,366정점/95,744삼각형, [헤어](../art/characters/clone_01/motion/plan_d/hair_006/source/hair.glb)는 19,425정점/27,952삼각형이다. 같은 네이티브 원본에서 내보냈으며 이번에는 별도 형식 검증기를 반복 실행하지 않았다. Export는 현재 자체 캐릭터의 정지 리그 전용이며 선택한 외부 헤어나 물리 프레임은 내보내지 않는다.

얼굴·두상·앞머리는 새 3D 초안으로 사용자 외형 검수 대기다. 참고 이미지의 사실적 질감/닮음까지 완료한 결과가 아니다. 피부 텍스처·SSS·자체 그림자, 모발끼리/실제 천/삼각형 단위 충돌, Windows 실행은 남아 있다. 전체 테스트·웹 검수·GIF·문서 검사·성능 측정은 하지 않았다.

변경 전은 hair_006/records/runtime-before.tar.gz, 최신 소스/atlas/모델과 레시피는 hair_006에 분리한다. A/B/C와 이전 채택 원본은 변경하지 않는다.
