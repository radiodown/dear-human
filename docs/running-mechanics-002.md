# 달리기 미세 보정 002 · 허리 15°·정면 시선·정면 총구

[문서 목록](../README.md) · [달리기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run) · [뛰며쏴](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run_fire) · [이전 001](36-running-mechanics.md)

사용자가 허리를 약 15° 숙이고 정면을 응시하며 총구를 정면으로 유지하는 달리기와 추가 미세 보정을 요청했다. `running_mechanics_002`는 같은 페이지의 달리기·뛰며쏴·Shift 이동을 수정한다. 기존 파츠와 현재 작업 폴더의 사격 폼·손·앉기·천·카메라를 재사용한다.

달리기가 완전히 전환되면 골반에 대한 허리 기본 숙임은 15°이며, 하중 반응은 약 ±.17°다. 기존 허리 슬라이더는 추가 숙임을 계속 더한다. 머리는 실제 몸통 각도를 역보정해 원본의 정면 등록각을 유지하고, 사격에 의한 머리 반응은 15%만 남긴다. 머리카락은 기존의 머리 부착 변환을 공유한다. 눈을 총의 조준선으로 끌어오지 않는다.

총은 현재 지지 높이와 같은 stock·손·총구 소켓을 사용하며 허리 숙임과 독립적으로 기본 총신 각도를 수평 0으로 전환한다. 달리기 중 총 반동 각도는 최대 .012rad로 줄인다. 장전 시 총을 내려 조작하는 기존 동작은 이어 사용한다. ‘총 낮춤’ 높이 조절은 이번 수정에서 변경하지 않았다.

| 작성 수치 | 001 | 002 |
|---|---:|---:|
| 이동 속도 | 260 | 245 |
| 양발 한 주기 | .90초 | .84초 |
| 지지 비율 | .44 | .45 |
| 최대 발 들림 | 42 | 32 |
| 착지 시 골반 낮춤 | 10.5 | 8.5 |
| 지지 중 추가 압축 | 6 | 4 |
| 골반 전후 진폭 | 3.2 | 1.1 |
| 골반 회전 진폭 | .020rad | .008rad |

수치는 작성값이며 재생 측정이나 검수 통과 결과가 아니다. 이전의 큰 보폭과 회수 높이를 줄이고 교대 주기를 조금 빠르게 했다. 수평 발 회수는 여러 Hermite 구간 대신 접지 속도와 경계 가속도를 잇는 하나의 5차 곡선이다. 발 들림은 회수 40%에서 정점에 이르는 단일 비대칭 곡선으로 바꿨다. 중간 키마다 수직 속도가 0이 되던 멈칫거림을 줄이고, 발끝 각도도 작게 조정했다. 기존 고정 길이 다리 IK와 `RunFootContacts`의 접지 이력, 접지 이동 폭에서 속도를 역산하는 프로필은 재사용한다.

변경 전 두 소스는 [별도 스냅샷](../art/characters/clone_01/motion/rig_005/records/runtime_snapshot_before_running_mechanics_002/index.json)에 보존했다. [레시피](../art/characters/clone_01/motion/rig_005/records/running_mechanics_002.json)와 [개발 인계](../art/characters/clone_01/motion/rig_005/records/development_handoff_running_mechanics_002.json)에 현재 소스와 의존 파일 해시를 기록했다. 001의 레시피·기록·스냅샷은 수정하지 않았다.

사용자의 검증 인계 지시에 따라 테스트·구문/문서/목록 검사·브라우저 캡처를 실행하지 않았다. 현재 상태는 `untested`·사용자 검수 대기다. 15° 실루엣, 시선·총구 방향, 착지와 회수의 자연스러움, 접지 전환과 다리 도달 범위는 실제 재생 검수가 남아 있다. 후속 검사 출력은 `tests/running_mechanics_002`, `reviews/running_mechanics_002`로 분리해야 하며 이번에는 검사 도구의 기본 경로를 바꾸지 않았다. 새 이미지·프롬프트·GIF·플랜 B/C 작업은 수행하지 않았다.
