# 앉아쏴 · 첨부 사진 기반 자세 보정 001

[문서 목록](../README.md) · [같은 캐릭터 페이지의 앉아쏴](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=kneel_fire)

사용자의 한쪽 무릎을 대고 사격하는 사진을 형태 참고로 삼아 기존 `kneel`·`kneel_fire`를 개선했다. 외형·무기 변경 지시로 해석하지 않는다. 현재 작업 폴더의 받침 손 변경을 유지하며 별도 작업 ID `kneeling_reference_001`에 기록한다. 사용자 지시인 “검증은 내가할게 개발만해봐”에 따라 테스트·문서/목록 검사·브라우저 캡처를 실행하지 않았고 상태는 `untested`·사용자 검수 대기다.

## 사진에서 읽은 관계와 그림 판단

사진에서는 앞쪽 발바닥과 뒤쪽 무릎이 몸을 받치고, 뒤쪽 발은 접혀 있다. 골반은 낮고 앞쪽 허벅지는 앞으로 뻗으며 정강이는 비교적 세워져 있다. 상체는 조금 앞으로 기울고 총은 대체로 수평이며 어깨·머리·양손이 같은 견착 위치에 모인다. 한 장의 사선 사진으로 정확한 관절 각도나 하중을 측정한 것은 아니다.

기존 측면 기준 그림과 `rig_004`의 허벅지·정강이·부츠 파츠를 직접 열어 확인했다. 이 파츠와 기존 허리축·의상 메시를 회전·연결해 기본 실루엣을 수정할 수 있으므로 이번에는 새 래스터 그림을 생성하지 않았다. 사진의 군복·남성 체형·배경은 이식하지 않는다. 현재 작업 폴더에서 연결된 받침 손도 교체하거나 되돌리지 않는다.

깊이 접힌 무릎 안쪽, 골반·스커트의 압축 주름, 바닥에 눕는 망토에는 전용 그림이 없다. 이번 작업에서 새 그림이 반드시 필요하다고 확정하지 않으며 사용자 화면 검수 후 해당 부위만 판단한다. 팔꿈치를 앞무릎에 붙이는 별도 접촉 제약과 실제 천 충돌도 구현하지 않았다.

## 개발 변경

- **지지점부터 계산:** 뒷무릎 관절 중심의 작성 목표를 `(-28, -16)`으로 둔다. Y=0이 바닥이며 -16은 기존 무릎 장갑의 여유를 둔 작성값이지 측정·검증된 충돌 반경이 아니다. 뒤꿈치를 들어 발끝을 세우고, 뒷무릎–발목 거리 76과 바닥의 발끝 접촉을 함께 만족하도록 뒷발 위치를 계산한다.
- **골반과 다리:** 골반 X는 기본 -6, 조준 시 전방으로 최대 1.2 이동한다. 골반 높이는 별도 고정값 대신 뒷무릎을 중심으로 한 길이 76의 허벅지 원호에서 계산한다. 반동에 따른 작은 골반 이동도 같은 원호에 반영한다. 앞발은 X=61에 평평하게 놓아 앞허벅지가 앞으로 향하고 정강이가 세워지도록 작성했다. 양다리는 기존 방향의 IK·길이·그림 비율을 유지한다.
- **상체와 견착:** 앉기 기본 전경 .11 rad에 눈 조준량에 따라 .12 rad까지 더한다. 골반 호흡 상하 이동은 정착 자세에서 제거하고 작은 호흡 기울기만 남긴다. 기존 허리축·어깨 `stockPocket`·무기 `stock`·양손 소켓을 함께 사용한다. 기존 머리/볼 조준 보정을 이어 사용한다.
- **반동과 첫 발:** 완전히 앉으면 골반/상체의 반동 이동을 서 있는 상태의 55%, 총의 반동 각도를 70%로 줄인다. 앉는 전환량 .985에서 최종 지지 자세가 되며, 입력 발사는 이 값을 넘고 기존 조준 준비·.12초 준비가 끝난 뒤 허용한다. 직접 `fire()`를 호출하는 내부 이벤트 경로는 그대로다.
- **같은 페이지:** `kneel`·`kneel_fire` 진입점을 유지한다. 뼈대·소켓을 켜면 뒷무릎 목표와 바닥 기준을 표시하고, 정착에 가까울 때 목표 대비 실제 관절 오차를 보여준다. 이 값은 무릎 장갑 그림의 접촉·가림이나 아트 품질 통과를 뜻하지 않는다.

## 저장과 남은 확인

[사진 분석](../art/characters/clone_01/motion/rig_005/records/kneeling_reference_001/reference_analysis.md), [레시피](../art/characters/clone_01/motion/rig_005/records/kneeling_reference_001/recipe.json), [개발 인계](../art/characters/clone_01/motion/rig_005/records/kneeling_reference_001/handoff.json)에 변경과 소스 해시를 보관한다. 사용자 첨부 사진은 대화에서 확인했으며 로컬 원본 파일·촬영자·라이선스는 제공되지 않았다. 사진을 저장한 것으로 기록하지 않는다.

기존 `runtime_snapshot_013`은 다른 받침 손 작업에서 사용 중이어서 덮어쓰지 않는다. 별도 `runtime_snapshot_before_kneeling_reference_001`에 이번 보정 전 기준을 보존했다. 해당 인덱스는 `gait.js`·`rig-core.js`의 복원 기준과 다른 파일의 저장 시점을 구분한다. 과거 레시피·프롬프트·검수 결과는 변경하지 않았다.

무릎 장갑의 실제 접촉 면, 앞발 전체 접지, 골반/스커트 가림, 팔꿈치 실루엣, 견착·볼·조준선 관계, 앉기/일어서기와 연속 사격은 사용자 검수가 남아 있다. 망토의 바닥 접힘은 기존 구현의 한계로 남는다. 이후 승인된 검사 출력은 `tests/kneeling_reference_001`·`reviews/kneeling_reference_001`로 분리하며 이번에는 해당 검사나 렌더를 실행하지 않았다.
