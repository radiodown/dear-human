# 플랜 B · 앞으로 숙인 경계 보행007

[문서 목록](../README.md) · [산출물·정확한 프롬프트](../art/characters/clone_01/motion/plan_b/pixel_guard_007/README.md) · [경계 걷기](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=guard_007&motion=walk) · [경계 이동 사격](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=guard_007&motion=walk_fire)

사용자가 “경계하면서 걷는듯이 좀더 앞을 숙이고” 걷도록 요청했다. 기존005의 도트 외형과 양발 교차를 재사용하고, **골반에서 상체를 앞으로 기울인 낮은 경계 걷기**를 새로 생성했다. 어깨와 머리가 골반보다 앞에 놓이고, 무릎을 부드럽게 굽힌 채 작은 보폭으로 전진한다. 시선은 앞을 보고 M16은 거의 수평이다. 다리가 몸 아래에서 교차하는05/11에도 낮은 상체 자세를 유지한다. 같은 자세의 이동 사격도 함께 만들었다.

[005와007의 기준 자세 비교](../art/characters/clone_01/motion/plan_b/pixel_guard_007/reviews/posture-before-after.png)에서 상체 숙임과 낮춘 무릎을 비교한다. 목만 숙이거나 다리를 변형한 결과가 아니라 내장 image_gen으로 전신 자세를 다시 그렸다. 목표 상체 숙임은 약20~25°이며 정확한 관절 각도 검사는 아니다.

두 동작은 각각512×512 RGBA14장, 실제 반복은01~12의12포즈다. 걷기 반복은1.14초, 이동 사격은1.005초이고02/08에 발사광이 있다. 00/13은 동일한 새 기준 이미지로 남겨 실제 반복에서 제외한다. 이동 사격에서는 발사 다음 포즈의 어깨·개머리판 반동과 복귀, 머리/망토의 지연 반응에도 전경을 유지하도록 생성했다.

기준1회, 두 동작의 키포즈2회와 중간 프레임4회로 총7회 호출했다. 키포즈의 상체·총 비례와 전경 유지, 밝은 전경A/어두운 후경B의 전후 순서 반전·반대 교차를 먼저 시각 확인한 후 중간 프레임을 생성했다. 실제 제출한 영어 JSON/MD, 생성 원본·입력 보드, 호출 시간과 해시는 버전 폴더에 보존한다. 모델 ID·seed·실제 비용은 제공되지 않아 null이다.

입력/시트의 전체 공통 표준화와 동일 셀 분리, alpha≤8 잡음 정리·PNG 패킹만 수행했다. 기준 이미지는 키포즈 생성 전에 전체 캔버스 표준화와 수직2px 이동을 한 번 적용했다. 왼쪽 위 고립된 모서리 조각 제거 범위는 baseline-normalization.json에 기록했고 원본은 보존한다. 개별 포즈의 크기·중심·발 정렬이나 다리 변형·포즈 보간은 없다.

기존 캐릭터 페이지 ‘플랜 B · 도트 모션’의 기본을007 경계 걷기로 연결한다. 같은 목록에서007 이동 사격,006 앉아쏴와 이전 버전도 선택한다. 교차/발사 비교 버튼과 기존 정지·한 프레임·속도·배경 조절을 재사용하며 공통 FrameSequence의 추가 변경은 없다. `./run.sh`로 로컬 서버를 실행한다.

변경한 JS 구문·두 동작의 PNG 계약과 [짧은 Mac Chrome 실제 재생](../art/characters/clone_01/motion/plan_b/pixel_guard_007/reviews/browser.json)을 확인했다. 실제 canvas 변화와01~12 반복, 양쪽 교차/발사 자세 정지·한 프레임 이동,500px 걷기 표시,006 앉아쏴/005 선택과 새 기본 진입을 확인했고 페이지 오류는 없었다. [걷기 표시](../art/characters/clone_01/motion/plan_b/pixel_guard_007/walk/reviews/browser-action.png)와 [경계 사격](../art/characters/clone_01/motion/plan_b/pixel_guard_007/walk_fire/reviews/browser-pose-02.png)을 보존한다. 전체 게임·문서/목록 검사 묶음·GIF는 실행하지 않았다.

아트 채택과 자연스러움은 사용자 검수 대기다. 움직이는 불투명 발 외곽 높이는 걷기4px·이동 사격5px 변하고 망토/윤곽 변화도 남는다. 지면/모발/천의 물리 접촉을 보장하지 않는다. 발사광과 무기는 전신 PNG에 포함되며 실제 명중/탄약 로직이나 무기 교체는 없다. 공식의 엄격한 모든 발 기준선 일치·GIF 납품 통과로 보고하지 않는다. 원시 검사 이슈는 각 동작의 reviews/structure.json에 그대로 기록했다.
