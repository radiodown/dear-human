# 사진 기반 사격 폼 적용 · 015

[문서 목록](../README.md) · [연구 근거](35-firing-form-reference-research.md) · [사격 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire)

사용자가 사진 기반 사격 폼 연구를 적용하라고 요청했다. 기존 공통 rig_005에 전신 자세·흉곽/어깨 축·팔꿈치 기준 포즈와 독립적인 달리기 총 높이를 연결했다. 새 이미지를 생성하지 않았으며 014의 닫힌 파지 손과 M16 접점, 기존 무릎 접지·달리기 접지와 총구 조명을 재사용한다. 사용자 검증 인계 지시에 따라 테스트·문서/목록 검사·브라우저 검수는 실행하지 않았다. `verification`은 `untested`다.

## 전신과 상체

대기와 정지 사격의 발을 앞 26 / 뒤 -24에 함께 두어 준비할 때 발이 옆으로 미끄러져 벌어지지 않게 했다. 사격 준비량에 따라 골반을 뒤쪽으로 옮기고 낮추며, 양다리 IK가 같은 발 접점을 유지한다. 서서쏴의 골반 이동은 x=-3, 내려가는 양은 총 12다. 기존 달리기의 접지/체공·보폭 및 앉아쏴의 고정 무릎 원호는 이어 사용한다.

기존 허리축 위에 **흉곽 축**과 **어깨 기준축**을 추가했다. 흉곽은 허리 위 20에서 작은 전경과 전방 이동을 가지며 목 뿌리와 어깨를 함께 배치한다. 허리 전경은 정지 사격에서 .185rad, 흉곽 추가 전경은 .025rad다. 어깨와 총 받침은 같은 어깨 기준축을 따른다. 이는 게임용 작성값이며 사진에서 측정하거나 교범이 지정한 관절 각도가 아니다.

몸통 메시의 .405/.445/.485 세로 구간에 연결 정점을 추가했다. 위쪽 몸통은 흉곽을, 아래쪽은 허리를 따르며 사이가 연속적으로 변형된다. 바스트·흉갑은 흉곽에 붙은 강체로 유지하고 기존 독립 상대각을 이어 쓴다. 허리 연결 천과 골반의 스커트 연결도 유지한다. [015 파트 정의](../art/characters/clone_01/motion/rig_015/README.md)는 기존 원본 UV를 사용하며 새 몸통 PNG나 이면 그림을 생성한 결과가 아니다.

## 견착·머리·양팔

조준 시 총 받침 목표는 몸통 로컬 (-11.5, -5)이며 대기 위치에서 준비량에 따라 전환한다. 골반·흉곽·어깨의 변환을 함께 적용한 접점이다. 총과 양손 목표·총구는 이 하나의 무기 변환을 사용한다. 총을 몸과 따로 움직여 머리에 맞추는 보정은 추가하지 않았다.

머리의 추가 이동은 (1.2, 1.8), 추가 회전은 .002rad로 줄였다. 상체 회전의 전달 비율은 .65에서 .28로 줄이고 런타임과 파트 바인딩 양쪽에 같은 값을 저장했다. 고개를 더 숙여 눈높이 오차를 숨기는 보정 대신, 흉곽·견착·목 뿌리의 배치를 함께 변경했다. 눈–조준선의 실제 표시와 볼/개머리판의 접촉 품질은 사용자 검수 대기다.

양팔에는 서로 다른 어깨 기준 팔꿈치 가이드와 작성된 투영 길이를 적용했다. 앞쪽 팔의 가이드는 아래/전방, 방아쇠 쪽은 몸 가까운 아래쪽이다. 두 뼈 IK의 두 해 중 기준 포즈에 가까운 해를 선택하되 손 접점은 같은 무기에 남긴다. 길이는 원래 36/40 이내에서 작성하며 손이 멀다는 이유로 자동으로 늘리지 않는다. 이는 기준 포즈로 유도한 2D IK이며 완전한 3D 팔 회전이나 FK/IK 혼합 편집기를 구현했다는 뜻은 아니다. 장전 중에는 기존 팔 경로·전완 전환과 몸통 뒤 가림을 유지한다.

## 뛰며쏴의 별도 총 높이

눈높이 조준 해제는 그대로 유지한다. 총을 낮추는 정도는 `setRunCarryDrop()`과 페이지의 **달리기 총 낮춤**으로 별도 조절한다. 범위는 0~18 논리 단위, 기본 6이며 `carryDrop` URL 값에 저장한다. 0이어도 달리기 시선은 정면을 유지한다. 이전 013의 16 단위 하강을 비조준 모드의 필수 조건으로 고정하지 않는다. 조절은 재생 중 부드럽게, 일시정지 중 즉시 적용한다.

## 인계

- 공통 구현은 `game/animation/firing-form.js`, `gait.js`, `rig-core.js`, `waist.js`, `proportions.js`와 같은 페이지의 렌더러/UI다.
- [레시피](../art/characters/clone_01/motion/rig_005/records/firing_form_015.json)와 [인계 기록](../art/characters/clone_01/motion/rig_005/records/development_handoff_015.json)에 입력·의존 버전·코드 해시·검수 대기를 저장한다.
- 수정 전 작업 폴더의 코드는 `runtime_snapshot_before_firing_form_001`에 보존했다. 별도로 먼저 저장한 `runtime_snapshot_014`도 유지한다. 기존 원화·프롬프트·연구 기록·검사 결과는 소급 수정하지 않았다.
- 기존 검사 도구의 다음 출력 폴더만 `tests/firing_form_015`, `reviews/firing_form_015`로 분리했다. 새 검사를 작성하거나 실행하지 않았다.
- 사진과의 실루엣, 어깨/볼 접촉, 팔꿈치·손 가림, 천의 접힘과 자세 전환은 사용자 검수가 남아 있다. 현재 좌표 연결을 시각 검수 통과로 보고하지 않는다.
