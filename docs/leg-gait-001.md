# 허벅지 폭과 걷기·달리기 폼 보정 · leg_gait_001

사용자 요청: “허벅지 다리가 너무 두꺼워. 그리고 걷고 뛰는 폼이 이상해”. [이동](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=walk) · [달리기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run)에서 기존 파츠를 재사용한다.

허벅지는 원화의 가로세로 비율로 표시할 때 현재 몸통에 비해 넓었고, 움직이는 양쪽 고관절의 전후 간격도 12 논리 단위였다. 기존 걷기는 골반을 낮게 유지하고 발을 멀리 내밀어 무릎이 계속 굽었다. 달리기도 허벅지가 뒤로 펴지는 구간이 부족하고 회수 발/무릎이 높아 들렸다.

사용자의 체형 보정 지시에 따라 `LEG_SHAPE.thighWidth=.76`으로 허벅지의 가로 폭만 24% 줄였다. 이는 이번 요청에 따른 명시적 렌더링 폭 보정이다. 원본 PNG, 허벅지 뼈 길이, 무릎 장갑·정강이·군화의 크기는 유지한다. 허벅지 소스를 재사용하는 무릎 안쪽 연결 천도 같은 폭으로 표시한다. 몸통·머리·팔이나 프레임 전체의 크기는 바꾸지 않는다.

걷기/달리기에서는 고관절의 로컬 x를 +2/-2로 모으고 높이를 맞춘다. 기존 대기와 완전히 앉은 자세의 관절 목표는 유지한다. 기존 스커트의 골반 연결·양쪽 다리 덮임 계산은 새 다리 자세를 그대로 이어 쓴다.

| 작성 항목 | 이전 | 이번 |
|---|---:|---:|
| 걷기 속도 / 한 주기 | 108 / 1.40초 | 100 / 1.12초 |
| 걷기 지지 비율 | .68 | .62 |
| 걷기 발 들림 기본 / 추가 100% | 6.5 / 4.5 | 5.5 / 2 |
| 걷기 접지 궤적 중심 | 0 | -8 |
| 걷기 골반 기준 / 보행 굴곡 | 7 + bob | -2 + bob×.30 |
| 달리기 속도 / 한 주기 | 245 / .84초 | 245 / .74초 |
| 달리기 지지 비율 | .45 | .40 |
| 달리기 발 들림 기본 / 추가 100% | 32 / 12 | 30 / 6 |
| 달리기 접지 궤적 중심 | 0 | -18 |
| 달리기 접지 골반 낮춤 / 압축 | 8.5 / 4 | 4 / 2.5 |
| 달리기 밀어내기 골반 상승 | 0 | 3 |

걷기는 골반을 높여 지지 다리가 펴지고, 짧아진 보폭과 낮은 발 회수로 이어진다. 달리기는 착지 발을 몸 아래에 가깝게 두고 뒤쪽 접지를 더 남겨 뒷다리를 밀어낸다. 지지 후반에 골반을 올리고 체공에서 다음 착지로 이어 주며, 두 구간의 수직 속도를 연결한다. 발목은 초기 뒤꿈치 회수와 발끝 밀기를 더 분명하게 했다. 보행에 얹었던 상체 허리 흔들림도 줄였다. 추가 흉곽 상하 바운스는 다시 넣지 않았다.

다리의 최대 도달에는 .5 논리 단위의 여유를 두고 골반 높이를 제한해, 끝까지 잠기는 무릎과 도달 초과를 줄인다. 이 제한은 동작 강도 0%의 이동에도 적용한다. 발 접지 이력은 기존 고정 스텝에서만 갱신하며 pose/렌더는 상태를 바꾸지 않는다.

0~150% 동작 강도는 새 체형·기본 보행 위에 추가 반응을 조절한다. 화면의 0% 버튼을 ‘추가 반응 0%’로 고쳐 현재 동작 강도의 의미를 명확히 했다. 동작별 허리각/총 높이/반응 저장값은 유지한다. 비사격 달리기 총구 아래 35°·완전 대기 아래 58°와 사격 방향, 머리/몸통 연결, 017의 앉아쏴 관절 목표는 이어 쓴다. 플랜 B/C의 동작·UI는 이번 수정 대상이 아니다.

필요한 변경 JS 구문과 0/100/150%의 짧은 이동·달리기·이동 사격·뛰며쏴 접지/뼈 길이/도달 확인을 수행했다. 걷기↔달리기↔정지 전환, 골반 지지/체공의 속도 연결, 기존 대기·완전 대기·앉아쏴의 관절 목표도 확인했다. [수치 기록](../art/characters/clone_01/motion/rig_005/tests/leg_gait_001/gait-smoke.json).

Chrome에서는 보존 소스와 보정 소스를 따로 불러 걷기·달리기의 한 주기 0/25/50/75%를 비교하고 각각 짧게 재생했다. 바뀐 주기를 같은 경과 시간으로 맞추지 않고 고정 스텝으로 해당 위상까지 진행했으며, 개별 파츠나 포즈를 정렬하지 않았다. 표시 허벅지 폭은 이전의 .76배, 길이는 동일했다.
