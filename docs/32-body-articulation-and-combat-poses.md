# 32. 몸통·바스트·허리·스커트 분리와 전투 자세 011

[문서 목록](../README.md) · [이전 010](31-waist-axis-and-new-parts.md) · [견착 대기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle)

사용자는 허리 부분을 만들고 스커트·몸통·바스트를 나눠 숙일 수 있도록 요청했다. 이어 자연스러운 견착 대기, 앉아쏴, 더 빠르게 뛰면서 쏘는 모션과 총열 아래를 받치는 손을 요청했다. 이 변경은 기존 rig_005 공통 재생에 연결한 **011 개발 인계**다. 사용자가 검증을 맡겠다고 했으므로 추가 테스트·문서/목록 검사·브라우저 캡처는 실행하지 않았다. `verification`은 `untested`다.

## 네 의상 파트와 관절

rig_004의 `body_core.png`와 원본 가로세로 비율을 재사용한다. 새 래스터 몸통을 생성하거나 원본을 자르지 않고, 텍스처의 실제 삼각형 영역을 별도 부착물로 나눴다. [작성된 파트](../art/characters/clone_01/motion/rig_011/rig/body_parts.json)와 [재생용 정의](../art/characters/clone_01/motion/rig_005/rig/parts.json)에 정점·삼각형·부착 축을 저장한다.

| 파트 | 부착과 역할 |
|---|---|
| `torso_shell` | 허리축을 따르는 몸통. 흉갑 영역은 구멍으로 제외하며 주변 천의 경계만 흉갑을 따라감 |
| `bust_armor` | 바스트·흉갑의 독립 축. 기본은 몸통과 함께 회전하고 상대각 ±5° 조절 가능. 형태와 크기는 유지 |
| `waist_cloth` | 두 벨트 사이 연결부. 상단은 상체, 하단은 골반을 따라 Hermite 곡면으로 연결 |
| `skirt_core` | 하부 벨트·파우치·스커트. 골반과 허벅지 쪽에 남으며 끝단 천만 작은 보조 반응 |

허리축은 골반 위 34에 있다. `CharacterRig.setBend(degrees)`는 0~45°의 숙임을 기존 자세에 추가한다. `setBustPitch(degrees)`는 흉갑의 작은 상대 회전만 조절한다. 둘 모두 고정 스텝에서 약 .10초 시정수로 전환하며 일시정지 중에는 즉시 적용할 수 있다. 흉갑 정점은 강체 회전하고, 몸통의 경계 정점이 같은 위치를 공유한다. 몸통 밑에 같은 흉갑 그림을 중복으로 남기지 않는다.

페이지의 **허리 숙임**, **바스트·흉갑 각도**, **바로 서기**, **분리 파츠**, **뼈대·소켓**, **메시**로 사용자가 조절할 수 있게 연결했다. [30° 숙임 진입점](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle&bend=30)은 코드에 연결한 URL이며 이번 작업에서 브라우저 검수하지 않았다. `bend`와 `bust` URL 값도 같은 공통 리그 API를 사용한다. 깊이 숙일 때 총도 숙임의 .8배만큼 내려가며 개머리판은 어깨 소켓에 붙어 있다.

## 견착 대기·앉아쏴·달리기

- **견착 대기 / `idle`:** 발을 앞뒤 20씩 두고 무릎을 조금 풀도록 골반을 2.6 낮춘다. 상체는 약 4° 앞으로 두며 3.8초 주기의 작은 호흡만 더한다. 총은 기존 stock–stockPocket 접점을 유지하고 머리는 작은 기본 조정을 유지한다. 사격 입력에는 기존의 빠른 준비 기울임을 추가한다.
- **앉기 / `kneel`, 앉아쏴 / `kneel_fire`:** 골반을 (-8, -90)으로 낮추고 앞발과 뒤쪽 발끝 지지를 따로 작성했다. 다리 길이를 늘리지 않고 같은 양다리 IK와 부츠 접점 계산을 사용한다. 앉는 양이 .94를 넘고 사격 준비가 끝난 뒤 첫 발을 낸다. 앉은 상태에서는 서서쏴의 뒷발 재접지 반응을 끈다.
- **달리기 / `run`, 뛰며쏴 / `run_fire`:** 보행의 108 / 1.40초에서 달리기의 195 / .78초로 속도와 주기를 함께 전환한다. 지지 비율은 .46, 발 들림은 18이다. 골반의 착지 흡수와 전경도 달리기 프로필을 따른다. 총은 어깨 소켓을 유지하고 팔 IK는 매 프레임 같은 접점을 사용한다. Shift와 A/D 입력도 달리기에 연결했다.

## 총열 아래 받침 손

이전 C자 파지 손을 대신해 손바닥이 위를 향하고 손가락이 총열 옆으로 말리는 받침 손을 내장 image_gen으로 편집 생성했다. [원본과 제출 프롬프트](../art/characters/clone_01/motion/rig_011/README.md)를 보존한다. 생성 PNG는 변경 없이 복사했고 소스 영역과 손목·손바닥 접점만 등록했다. 이 좌표 등록은 개발 연결이며 아트 검수 통과 기록이 아니다.

새 `support_hand_underbarrel`은 원본 가로세로 비율을 유지하고 손목과 손바닥 접점을 분리한다. M16의 받침 접점은 (.66, .40)에서 **(.63, .48)**로 내려 핸드가드 하단에 두었다. 기존 개머리판·조준 소켓·탄창 각도는 이어 사용한다. 무기 바인딩은 `m16_binding_011`에 별도 저장했다. 장전 중에는 기존 임시 손을 사용하며 놓기·탄창 파지·조작부 손 3종은 여전히 미제작이다.
