# 31. 허리축·연결 천과 새 손·어깨·장전 팔 010

[문서 목록](../README.md) · [이전 09](30-body-mechanics-and-reload-views.md) · [캐릭터 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire)

사용자는 총열 받침 손을 별도로 만들고, 허리 회전축과 몸통–스커트 사이의 당겨지는 연결을 요청했다. 이어 어깨판과 장전 팔의 시점용 추가 원화를 제작하라고 지시했다. 작업 도중 **검증은 사용자가 맡고 개발만 진행**하라는 최신 지시가 있었다. 따라서 아래는 구현·등록 상태이며 최종 검수 완료 보고가 아니다.

## 새 원화 연결

[010 원화·정확한 프롬프트 목록](../art/characters/clone_01/motion/rig_010/README.md)에 원본을 모았다. 내장 image_gen으로 총열 받침 손, 측면 상완/어깨판, 장전용 전완을 생성했다. 받침 손의 첫 결과는 파지 공간이 부족해 보존만 하고, 같은 장갑을 수정한 v2를 연결했다. v2에는 투명한 파지 공간이 있으며 손목 피벗과 총열 접점을 별도로 둔다. 기존 `support_hand`는 장전 임시 손으로 남기고 사격/대기에서는 `support_hand_foregrip`을 사용한다.

측면 상완과 장전 전완에는 원본 내 두 관절의 2D 좌표를 등록한다. 이미지의 기울어진 관절축을 실제 뼈대 축에 맞춰 회전·균일 확대하므로 가로세로 비율을 바꾸지 않는다. 장전의 단축된 시점은 원화 전환과 34~40 범위의 작성된 투영 길이로 표현한다. 팔이 몸통 뒤에 있는 구간에서 바꾸며, 새 시점에 맞춰 탄창 추출/접근 경로를 16으로 줄였다. 자동으로 도달 길이를 늘려 손 도달 실패를 숨기는 방식은 사용하지 않는다.

추가 탄창 파지 손 생성은 도구의 `moderation_blocked / violence` 오류로 거부됐다. 해당 제출 원문과 실패 기록은 보존했고 다른 API/모델로 우회하지 않았다. 장전용 놓기·탄창 파지·조작부 손 3종은 미제작 상태다.

## 실제 허리축과 의복 분리

이전에는 상체의 회전 기준이 골반 가까이에 있었다. 현재 `game/animation/waist.js`의 `waistFrame`이 골반에서 34 위에 실제 회전축을 두고, 흉곽·머리·어깨·총을 이 축의 자식으로 평가한다. 골반과 허벅지는 기존 골반 축을 따른다. 숙일 때 스커트까지 상체처럼 한 판으로 기울지 않는다.

원래 의상 PNG를 다시 그리지 않고 같은 텍스처를 세 부착물로 나눴다.

| 부착물 | 원본 세로 구간 | 역할 |
|---|---|---|
| `torso_shell` | 0~.485 | 흉갑·상부 벨트는 상체를 따라 단단하게 회전 |
| `waist_cloth` | .485~.56 | 두 벨트 사이 천. 위쪽은 상체, 아래쪽은 골반에 붙어 연결 |
| `skirt_core` | .56~1 | 하부 벨트·파우치·스커트는 골반과 연결. 최하단 천만 기존 작은 보조 반응 |

연결 천은 상부와 하부의 경계 위치·접선이 이어지는 곡면이다. 앞으로 숙이면 등 쪽 연결 길이가 늘고 앞쪽은 눌려 접히는 형태가 된다. 흉갑이나 파우치 전체를 고무처럼 늘리지 않는다. 허리축을 중심으로 상체와 스커트를 상대 회전시키되, 천이 둘 사이를 잇기 때문에 빈틈을 만드는 분리는 아니다. 이는 자체 2D 메시이며 천 충돌이나 실제 재료 응력 시뮬레이션은 아니다.

뼈대·소켓 표시에서 허리축을, 하단 표시에서 연결 천 앞/뒤의 상대 길이를 볼 수 있도록 개발했다. 원화 링크도 같은 페이지에 추가했다. `body_core`는 원본 치수 기준으로만 남기고 실제 렌더에는 세 부착물을 사용한다.

## 저장과 검수 상태

- [런타임 레시피](../art/characters/clone_01/motion/rig_005/records/waist_parts_010.json)와 [개발 인계 기록](../art/characters/clone_01/motion/rig_005/records/development_handoff_010.json)에 입력·원본·변경 파일·미제작 항목을 기록한다.
- 09 코드와 파츠 정의는 `rig_005/records/runtime_snapshot_009`에 보존한다. 010 검사 결과를 과거 폴더에 쓰지 않도록 경로를 바꿨다.
- 사용자 검증 인계 이전의 시뮬레이션 기록은 `tests/waist_and_parts_010/simulation-metrics.json`에 있다. 이는 이후 UI/연결 변경의 최종 검증이나 사용자 아트 채택으로 표시하지 않는다.
- 최신 사용자 지시 이후 추가 테스트·문서/목록 검사·브라우저 캡처는 실행하지 않았다. 현재 목록의 검증 상태는 `untested`, 아트는 사용자 검수 대기다.
- 총열 받침 손 v2·새 측면 어깨·장전 전완은 연결한 개발 결과다. 사용자 시각 검수는 아직 없다. 플랜 B와 GIF는 변경하지 않았다.
