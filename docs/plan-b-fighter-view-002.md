# 플랜 B · 격투게임식 시점 002

[제작 기록](../art/characters/clone_01/motion/plan_b/fighter_view_002/README.md) · [미리보기](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=fighter_view_002)

사용자가 앞서 제안한 격투게임식 구도로 수정하라고 요청해, 이전30° 시안을 약12°의 얕은 내려보기와 카메라 쪽으로 몸을 약20° 트는 목표로 다시 그렸다. 카메라 각과 몸의 회전을 구분하고 얼굴·흉갑 앞면·양팔을 더 보여 준다. 내장 image_gen 1회이며 각도는 요청 목표이지 측정값은 아니다. 정지 기준만 만들었고 이 시점의 모션은 미제작이다.

같은 플랜 B 탭의 ‘격투게임식 · 12° 기준’에서 보고 이전30°와 비교한다. 기존30° 그림/기록/직접 주소는 유지하고 해당 버튼은 이전 버전 목록으로 옮겼다. 시점과 외형은 사용자 검수 대기다.

정확한 영어 JSON/MD 요청·두 참조·1254×1254 RGBA 원본/동일한 표시 이미지·실제 시간·해시·변경 전후 소스를 버전 폴더에 저장했다. 필요한 JS 구문·짧은 Windows Chrome에서 표시/선택/주소/복원·배경/크기·두 시점 전환/비교·500px만 확인했다. 기존 프레임·입력 사격·파츠·플랜 E·과거 검사·GIF는 변경하지 않았으며 전체 검사는 실행하지 않았다.
