# 유나 · 갸루 얼굴 전신 006

이 문서는 이전 흑발 버전의 제작 기록이다. 현재 유나 외형은 사용자 채택 [밝은 금발·새 얼굴 008](squad-character-concepts-008.md)을 따른다.

사용자는 약간 까무잡잡한 갸루 느낌의 얼굴 샘플 006을 채택하고 기존 전신 일러스트에 적용하도록 지시했다. 따뜻한 구릿빛 피부, 또렷한 아이라인과 속눈썹, 윤기 있는 입술을 얼굴 방향으로 사용한다.

유나의 기존 흑발 긴 생머리 반묶음·옆가르마, 25~26세 아시아계 성인 외형, 방호복·바지·물리 방패·권총·자세는 유지한다. 얼굴 방향은 채택됐으며 새 전신 006의 세부 일치도는 확인 대기다. 다른 대원·서사·모션·게임 기능은 변경하지 않는다.

[원본·정확한 영어 입력·생성 기록](../art/characters/yuna/concepts/illustration_006/README.md). 기존 005와 이전 얼굴 아이콘은 보존하며, 위키 전신·얼굴 아이콘과 공통 미리보기의 현재 버전을 갱신한다.
