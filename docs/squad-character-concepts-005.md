# 이렌·유나 콘셉트 005

사용자 요청에 따라 이렌은 **깔끔한 생머리 단발**과 수정한 얼굴로, 유나는 **변경한 헤어와 더 미인인 얼굴**로 제작한다. 유나의 옆가르마 긴 생머리 반묶음은 이를 구체화한 헤어 보완안이다. 두 인물은 외형상 25~26세의 아시아계 성인이며 최종 미감은 사용자 검수 대기다.

| 인물 | 최신 원화 | 헤어·얼굴 시안 |
|---|---|---|
| 이렌 | 005 | 턱선 아래의 단정한 흑발 원랭스 생머리 단발·정돈된 옆가르마·단아하고 세련된 미인상 |
| 유나 | 005 | 옆가르마 긴 흑발 생머리 반묶음·맑은 눈매와 화사한 미인상 |
| 세나 | 004 유지 | 애쉬브라운 긴 생머리 반묶음·시스루뱅 |
| 모아 | 004 유지 | 다크브라운 긴 웨이브·자연스러운 사이드 가르마 |

병과별 제복과 신형 화기를 유지한다. 가터벨트·스타킹은 이렌만 사용하고 유나는 방호 바지와 물리적 방패를 사용한다. 기존 활동 기간·전임자와 친구 사망·충원 관계는 바꾸지 않는다.
