# 호흡·허리·사격 상체와 의상 반응 · 016

[문서 목록](../README.md) · [견착 대기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle) · [이동](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=walk) · [달리기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run) · [사격](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire)

사용자는 대기에서 호흡하는 느낌, 이동·달리기에서 작은 허리 움직임, 사격에서 작은 상체 흔들림과 반응하지 않는 ‘허리·옷자락’ 체크 수정을 요청했다. 기존 공통 rig_005에 연결한 개발 결과이며 `untested`·사용자 검수 대기다. 기존 사용자 검증 인계 지시에 따라 테스트·구문/문서/목록 검사·브라우저 검수는 실행하지 않았다.

## 상체의 작은 움직임

`game/animation/secondary-motion.js`의 `BODY_MOTION`과 `bodyMotion()`을 공통 리그에서 사용한다. 3.8초 주기의 호흡으로 허리 약 ±0.8°, 흉곽 약 ±0.29°와 높이 ±0.7 논리 단위를 더한다. 걷기·달리기와 눈높이 조준 중에는 호흡량을 줄이되 끄지 않는다. 흉갑 그림을 늘리는 대신 강체 흉곽 축을 움직이고 아래쪽 몸통 메시가 허리로 이어진다.

걷기는 한 보행 주기당 작은 허리 회전과 두 번의 하중 반응을 더한다. 기본 회전 진폭은 걷기 .012rad / 달리기 .018rad이며 작은 2배 주기 성분이 함께 적용된다. 조준 중에는 줄이고 앉기에서는 대부분 줄인다. 기존 보행·달리기의 속도, 접지 기록, 골반·발 목표와 무릎 계산은 이번 작업에서 바꾸지 않았다.

사격은 실제 발사 이벤트마다 별도의 상체 스프링에 충격을 준다. 3.8Hz / 감쇠 .72 / 회전 제한 .030rad / 발당 속도 충격 -.65를 사용해 기존의 빠른 총 반동 뒤에도 상체가 조금 밀렸다 돌아온다. 앉아쏴는 줄여 적용하며 ‘반동’을 끄면 이 반응도 함께 끈다. 새 상체 움직임은 허리→흉곽→어깨→총 받침과 팔 IK 앞에 적용하므로 총·양손·총구는 같은 무기 변환을 사용한다. 실제 접촉 품질과 조준선 표시는 사용자 검수 대기다.

## ‘허리·옷자락’이 보이지 않던 원인과 수정

이벤트는 기존에도 `enabled.cloth`에 연결되어 있었다. 그러나 현재 `outfitPoint()`는 허리 스프링 값을 사용하지 않았고, 옷자락은 원본 UV의 마지막 .92~1 구간에 작은 각도만 적용했다. 허리 연결 천에는 기존의 자세 연결만 남아 있었다.

이제 허리 천 내부에 스프링을 전달하고 양쪽 부착 경계의 변위와 기울기는 0으로 둔다. 옷자락은 .88~1의 하단 구간을 사용하고 호흡·발걸음·허리와 사격의 작은 지연 반응을 더한다. 벨트·상단 파우치와 다리 뿌리는 기존 골반 부착을 유지한다. 같은 원본 그림을 재사용한 2D 메시 반응이며 실제 천 충돌이나 새 이면 원화는 없다.

천의 내부 상태는 고정 스텝에서 계속 계산하고, 체크를 끄면 `pose()` 출력의 허리 천·옷자락 값을 즉시 0으로 가린다. 다시 켜면 같은 시점의 계산 상태를 표시한다. 따라서 일시정지에서도 두 상태를 비교할 수 있고 렌더 호출이 시뮬레이션 시간을 진행시키지 않는다. 호흡과 기본 자세는 체크와 독립적으로 유지한다. 페이지에 체크 설명과 ‘켜짐/꺼짐’, 옷자락 각도 표시를 추가했다.
