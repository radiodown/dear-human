# 플랜 B · 빠른 입력 연사002

[문서 목록](../README.md) · [같은 캐릭터 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b) · [버전·검토 기록](../art/characters/clone_01/motion/plan_b/input_fire_002/README.md)

사용자가 연사가 느리다고 지적했다. 001의 발 디딤02/08 대기와 원본 반동 클립 완료 대기를 제거하고 **발사 시계를 걷기 시계에서 분리했다**. 파츠와 같은 WEAPONS.m16_basic.fireInterval=.1초를 재사용해1×에서 초당10발을 발사한다. 첫 발은 단발/연사 입력 즉시 나가며 걷기01~12는 기존95ms 간격으로 이어간다. 재생 속도 조절은 두 시간에 함께 적용된다.

SequenceFire는 발사 나이·100ms 간격·160ms 복귀를 관리한다. 누르는 동안 다음 발사 시각마다 횟수를 증가시키고, 떼면 추가 발사 없이 현재 복귀만 마친다. 앉아쏴도 같은 발사 시계를 사용하며 기존06/07·12/01의 비발사광 반동/복귀 포즈를 짧게 재사용한다. 포인터 밖 해제·키보드·포커스/페이지/탭 해제와 수동 프레임 검토의 비집계 규칙은001을 유지한다.

기존 전신 PNG를 변형하거나 새 그림으로 교체하지 않는다. 걷기 중에는 현재 보행 번호에 맞는 기존 반동 그림을 선택하고, 발사광이 이미 들어간02/08 그림은 실시간 반동 표시에서 제외해 의도하지 않은 섬광을 막는다. 원본 발사광 그림은 수동 포즈 검토에서 그대로 본다. 별도 상체 리깅이나 발사별 물리 반동을 만든 결과는 아니며 원본 포즈 전환의 윤곽 차이는 남는다.

game/animation/sequence-muzzle.js가 매 실제 발사에 Canvas 도트 섬광을 그린다. 공통 MUZZLE_LIGHT의55ms·길이/높이·색·감쇠·발사별 변화를 재사용한다. 총구점은 기존 atlas의 위쪽72%에서 가장 오른쪽인 불투명 외곽을 한 번 읽어 현재 표시 포즈에 연결한다. 현재 오른쪽 M16 이미지의 시각적 근사이며 새 무기/왼쪽 외형에 대한 일반 소켓 시스템은 아니다. 독립 총구 효과는 추가했지만 별도 캐릭터 재조명·노멀/그림자·탄약/명중·소리는 추가하지 않았다.

필요한 변경 JS 구문과 [작은 발사 시계 검사](../art/characters/clone_01/motion/plan_b/input_fire_002/tests/cadence.json)를 수행했다. [짧은 Mac Chrome 실제 측정](../art/characters/clone_01/motion/plan_b/input_fire_002/reviews/browser.json)에서 경계 걷기·기본 걷기·앉아쏴의 평균 발사 간격은 각각 약102.6/101.3/102.9ms였다. 각 약1.15초 누름에서12발을 확인했고 버튼 밖 해제 뒤 추가 발사는 없었다. 두 걷기는01~12 순서를 유지했으며 설정95ms의 프레임 간격을 확인했다. 기존 발사 지점이 아니던05에서 즉시 한 발을 쏘고 그대로 멈춰 [실제 섬광](../art/characters/clone_01/motion/plan_b/input_fire_002/reviews/immediate-walking-shot.png)을 보존했다. [500px 앉아쏴 섬광](../art/characters/clone_01/motion/plan_b/input_fire_002/reviews/narrow-kneeling-shot.png)도 확인했다. 최종 페이지 오류는 없었다.

첫 브라우저 검토의 초기 준비 대기 타임아웃은 별도 JSON으로 보존했다. 새 직접 진입 진단에서 동일 URL/atlas의 정상 로드와 활성 버튼을 확인했고, 준비 확인을 DOM locator로 변경한 뒤 위 필요한 측정을 완료했다. 이를 전체 초기화/비동기 경합 검증으로 보고하지 않는다. 전체 게임·문서/목록 검사 묶음·GIF는 실행하지 않았다.

변경 전/후 소스·실제 의존 파일 해시는 input_fire_002/records에 분리했다. 001의 지연/연사 제한 기록을 소급 수정하지 않는다. 기존 아트/manifest/카탈로그·파츠 리그와 다른 작업도 유지한다. 원본 발/머리/망토의 흔들림과 새로운 섬광 모양·전환의 자연스러움은 사용자 검수 대기다.
