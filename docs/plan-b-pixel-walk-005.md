# 플랜 B · 다리 교차 005

[문서 목록](../README.md) · [산출물·프롬프트](../art/characters/clone_01/motion/plan_b/pixel_walk_005/README.md) · [걷기 재생](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=pixel_005&motion=walk)

사용자가 004를 “다리가 전혀 교차하질않아서 엄청어색해”라고 지적했다. 004에서는 02/08과 05/11의 다리 배치가 거의 반복되고, 어느 다리가 지지/회수하는지 명암 표지가 유지되지 않았다. 기존 프레임 재생·파일 계약 통과와 다리 교대의 품질 통과를 혼동한 검수 누락이다. [반려 기록](../art/characters/clone_01/motion/plan_b/pixel_walk_005/reviews/rejection-of-004.json)을 새 버전에 저장하며 004 원본·과거 검사 파일은 그대로 보존한다.

## 실제 보정

카메라에 가까운 A 다리는 밝은 정강이 하이라이트, 먼 B 다리는 어두운 정강이/군화로 구분한 새 기준을 내장 `image_gen`으로 만들었다. 전후로 이동해도 이 명암 표지를 같은 다리에 유지한다. 몸 아래에서 겹칠 때는 가까운 A가 B 앞에 그려진다. 기존 머리·상체·M16과 화면 배치는 유지하도록 지시했다.

새 기준 네 칸 입력 보드에서 키포즈 4개를 함께 생성하고, [크기 대조](../art/characters/clone_01/motion/plan_b/pixel_walk_005/reviews/key-size-comparison.png)와 [다리 교대·교차 대조](../art/characters/clone_01/motion/plan_b/pixel_walk_005/reviews/key-leg-alternation.png)를 먼저 확인했다.

| 포즈 | 확인한 다리 역할 |
|---|---|
| 02 | 밝은 A가 앞에 접촉, 어두운 B가 뒤에 위치 |
| 05 | 밝은 A로 지지, 어두운 B의 종아리/발이 A 뒤를 지나며 교차 |
| 08 | 어두운 B가 앞에 접촉, 밝은 A가 뒤로 이동하여 02의 전후 순서 반전 |
| 11 | 어두운 B로 지지, 밝은 A의 종아리/발이 B 앞을 지나며 교차하여 05의 역할 반전 |

이 조건을 확인한 뒤 종속 중간 프레임 8개를 네 칸씩 두 호출로 새로 생성했다. 04와 10에서도 서로 다른 다리가 접지 다리를 가로질러 회수되는 것을 확인했다. 004의 반려 포즈를 재사용하거나 개별 다리를 잘라 옮기거나 미러링하지 않았다. 전체 이미지 호출은 기준 명암 1회·키포즈 1회·중간 2회다. 정확한 영어 JSON/MD·원본·도구 시간은 `records`에 보존한다.

로컬 처리는 입력 보드 복사, 전체 시트의 공통 크기 표준화, 동일 셀 분리, alpha≤8 잡음 정리, PNG 패킹과 대조판 작성뿐이다. 개별 프레임 크기/중심/발 높이 맞춤·포즈 합성·절차적 보간은 없다.

## 끊기지 않는 반복

14장 PNG 형식과 00/13의 새 기준 PNG 동일성은 유지한다. 다만 실제 걷기는 **01~12의 생성 포즈 12개만 90ms 간격으로 반복**한다. 12→01이 같은 밝은 A의 전진 회수로 이어지도록 생성했다. 00/13은 정지 기준으로만 남겨 걷다가 발을 모으고 다시 시작하는 구간을 제거했다. 기존 004와 다른 시트는 manifest에 반복 범위가 없으면 기존 전체 프레임 재생을 유지한다.

같은 페이지의 기본은 ‘도트 005 · 다리 교차’다. 두 교차 비교 버튼은 05/11에서 일시정지하여 밝은 지지 다리/어두운 지지 다리를 바로 비교한다. 004는 ‘교차 반려 기록’ 선택으로 남긴다. 예제 서버는 `./run.sh`로 실행한다.

## 필요한 확인과 남은 문제

Chrome에서 실제 canvas 변화·01~12 반복과 정지 기준 제외·05/11 비교 버튼·일시정지·느린 재생·004 경고와 버전 전환·500px 표시를 짧게 확인했다. [실제 표시의 두 교차 자세](../art/characters/clone_01/motion/plan_b/pixel_walk_005/reviews/browser-crossing-comparison.png)에서 지지/회수 다리가 바뀐 것을 확인했으며 [페이지 오류는 없었다](../art/characters/clone_01/motion/plan_b/pixel_walk_005/reviews/browser.json). 변경한 두 JS의 구문과 새 PNG 계약도 확인했다. 전체 게임·플랜 A/C/D 검사는 실행하지 않았다.

다리 교차와 양발 역할 교대는 확인했지만 최종 자연스러움과 아트 채택은 사용자 검수 대기다. 움직이는 포즈의 불투명 발 외곽은 약 3px 변하고 망토·윤곽·갑옷 세부가 조금 흔들린다. 완전한 발 고정이나 실제 물리 접촉을 뜻하지 않는다. M16은 전신 PNG에 포함되고 고정 팔레트·단일 논리 픽셀 격자로 정리한 최종 도트는 아니다.

[공식 검증기의 원시 결과](../art/characters/clone_01/motion/plan_b/pixel_walk_005/reviews/structure.json)에서 엄격한 발 기준선 일치는 통과하지 않았고, GIF는 자동 생성하지 말라는 사용자 지시로 만들지 않았다. 14장 구조·투명 모서리·기준/키프레임 동일성과 브라우저 확인을 전체 공식 납품 통과로 보고하지 않는다.
