사용자 요청으로 격투게임식12° 정지 기준의 몸통·스커트를 채택 일러스트 `reference_003_3d`와 정면 `turnaround_001`에 대조했다. 둥근 단순 흉갑에 회색 바깥 인셋·가슴 아래 스트랩·허리 세로선·벨트와 파우치를 더하고, 넓은 주름치마 형태를 겹친 짧은 장갑 패널과 중앙 하의 패널로 보완했다. 내장 image_gen 편집 1회이며 얼굴·시점·총/양손·다리 배치를 유지하도록 요청했다. 모든 픽셀의 동일성을 보장하는 국소 편집은 아니다.

같은 플랜 B의 ‘격투게임식 · 의상 보완’에서 정지 기준을 보고 채택 일러스트와 비교하거나 보완 전후를 나란히 본다. 이전12°와30°·과거 아트/검사·입력 사격·파츠·플랜 E는 유지한다. 의상 구조와 자연스러움은 사용자 검수 대기이며 새 모션은 미제작이다.

영어 JSON/MD 요청 원문·세 참조·1254×1254 RGBA 생성 원본/동일한 표시 PNG·실제 시간·해시·변경 전후 소스를 버전 폴더에 저장했다. 필요한 JS 구문·짧은 Windows Chrome 표시/주소/복원·일러스트/전후 비교·이전 버전 전환·500px만 확인했다. 전체 검사·GIF·다른 에셋 생성은 실행하지 않았다.
