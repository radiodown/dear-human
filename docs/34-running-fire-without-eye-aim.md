# 34. 뛰며쏴 · 눈높이 조준 해제 013

[문서 목록](../README.md) · [뛰며쏴 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run_fire)

사용자 요청에 따라 뛰며쏴를 눈높이 조준 자세에서 낮춰 쏘는 자세로 변경했다. 기존 파츠·달리기·손·M16·총구 조명을 재사용하며 새 원화와 GIF는 생성하지 않았다. 사용자 검증 인계 지시는 계속 유효하므로 추가 테스트·문서/목록 검사·브라우저 검수는 실행하지 않았다.

달리기에 들어가면 총의 받침 위치가 몸통 로컬 (-13.5, 4)의 견착 위치에서 **(-10.5, 20)**으로 이동한다. 개머리판·총·양손 IK·총구는 이 받침 위치를 함께 따른다. 팔 길이나 소스 비율을 늘리지 않는다. 머리는 정면을 향하고 볼을 개머리판에 붙이는 이동과 추가 숙임을 줄인다. 달리기의 기본 전경·보폭·하중은 유지하면서 조준용 상체 숙임만 별도로 해제한다.

발사 준비량 `aimAmount`와 눈높이 조준량 `eyeAim`을 분리했다. 달리기 받침 전환 `runCarryAmount`가 1이면 `eyeAim`은 0이므로, 조준을 해제해도 발사 준비 조건이 영원히 미완료로 남지 않는다. 첫 발은 기존 .12초 준비와 함께 총을 낮추는 전환이 .75를 넘은 뒤 발생한다. 달리기 자세 진입은 .07초, 복귀는 .12초 시정수로 이어진다. 걸으며쏴·서서쏴·앉아쏴의 정상 조준 목표는 유지한다.

같은 페이지의 달리기와 Shift 이동도 같은 공통 리그 경로를 사용한다. 뛰며쏴의 상태 표시는 ‘총 낮춤’이며, 눈·조준선 오차는 실제 눈높이 조준 중에만 표시한다. 낮춰 든 상태의 총 접점은 ‘총 지지 오차’로 표시한다. 총구 조명은 새 자세의 실제 총구 소켓을 이어 사용한다.
