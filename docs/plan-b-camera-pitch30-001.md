# 플랜 B · 약 30° 위에서 내려다보기 001

[제작 기록과 이미지](../art/characters/clone_01/motion/plan_b/camera_pitch30_001/README.md) · [캐릭터 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?plan=b&study=camera_pitch30_001)

사용자 요청에 따라 기존 정측면 경계 자세를 참고해, 약 30° 위에서 내려다보는 도트풍 정지 기준을 내장 image_gen 1회로 추가했다. 오른쪽 조준 방향과 검은 긴 머리·갑옷·금장 망토·M16을 유지하며 정수리·어깨/무기/군화의 윗면과 양발의 깊이를 새로 그렸다. 정확히 측정된 3D 카메라나 기존 2D 이미지를 압축한 결과는 아니다.

같은 **플랜 B · 도트 모션** 탭의 **30° 내려보기 · 기준**에서 보고 정측면과 나란히 비교한다. 배경·표시 크기 조절과 직접 주소 복원을 재사용한다. 시점 검토용 정지 이미지이며 이 시점의 걷기·사격은 미제작이다. 원본의 모든 부위 비례·고정 픽셀 격자·팔레트 일치는 보장하지 않으며 최종 아트는 사용자 검수 대기다.

1254×1254 RGBA 생성 원본과 동일한 표시 PNG, 정확한 영어 JSON/MD 도구 요청·실제 시간·해시·도구 정보를 버전 폴더에 보존한다. 기존 표시 소스와 목록은 변경 전 사본을 남겼다. 필요한 JS 구문과 짧은 로컬 Windows Chrome에서 이미지 표시·선택/주소/복원·비교·기존 경계 걷기 전환·500px를 확인했다. 앱 내 브라우저 연결 실패 후 별도 Chrome을 썼다. 과거 검사·기존 프레임/입력 사격·파츠·플랜 E·GIF는 변경하지 않았으며 전체 검사는 실행하지 않았다.
