# 13. 파츠 리그의 반동·머리 흔들림·바스트 모핑

[문서 목록](../README.md) · 공통 파츠와 무기 계약은 [16](16-modular-character-and-weapons.md)이다. 아래 값은 시작 제안이며 미검증이다.

최신 외형은 [02](02-world-and-art.md)의 검은 장발·3D풍 전술 갑옷이다. 흉갑은 rigid로 고정하고 바스트 모핑을 겉판에 전달하지 않는다. 머리·망토·안쪽 천은 soft, 다리 장갑은 segmented로 구분한다. 사용자가 새 외형을 채택해 rig_002 파츠·자체 WebGL 모션 시험을 재개했다. 실제 범위와 결과는 [24](24-motion-rig-test.md)에 기록한다. 갑옷 교체·최종 보정·사용 도구 확정은 후속이다.

## 1. 모션 구성

1. 공통 리그의 하체 걷기·몸통·기본 고개 자세.
2. 무기군 파지와 무기별 장착 오프셋.
3. 실제 발사에 대응하는 총·어깨 반동과 양팔 IK.
4. 반동·이동·피격을 따라 늦게 반응하는 고개·머리카락·가슴/의복 보조 모션.

대상은 만 24세 성인 캐릭터다. 바스트 모핑은 별도 가슴/의복 메시의 작은 지연·복원·형태 변형이다. 체형과 제복 재단을 유지한다. 천은 이 반응을 따르고 단단한 흉갑의 겉판은 변형하지 않는다. 장착 외형의 모션 모드를 [17](17-modular-armor-appearance.md)에서 선택한다. 무기를 포함한 전신 텍스처를 함께 휘게 하는 방식은 플레이어 기본안에서 제외한다.

## 2. 리그의 분리

머리 본체·머리카락 앞/뒤·가슴/의복·팔·손·총을 나눈다. 어깨와 weapon_mount는 기본 몸통을 따르고 bust_cloth의 자식으로 두지 않는다. 가슴 변형이 총구·팔 위치를 움직이지 않게 한다.

기본 제작 경로는 Spine Professional의 파츠 메시·뼈대·물리 제약이다. 공식 문서는 머리카락·의복 등의 런타임 보조 모션을 설명한다. [Spine 물리 제약](https://esotericsoftware.com/spine-physics-constraints).

자체 TypeScript 경로는 같은 파츠 트리와 2본 팔 IK, 국소 메시·감쇠 스프링을 구현한다. Phaser Mesh2D는 이 경우 분리된 파츠를 표시하는 수단이며, 한 장의 무기 포함 전신 시트로 되돌리는 수단이 아니다. [Mesh2D 소스](https://github.com/phaserjs/phaser/blob/v4.2.1/src/gameobjects/mesh2d/Mesh2D.js).

## 3. 한 틱의 자세 평가

```text
공통 하체·몸통 동작
  → 장비 fit·모션 제한
  → 무기군 파지·장착점
  → 무기 반동
  → 두 손잡이 목표와 양팔 IK
  → 고개·머리카락·가슴/의복 보조 변형
  → 좌우·월드 변환
  → 총구·배출구 좌표 확정
  → 발사 판정·표현
```

반동 전 총구로 사격하고 반동 후 총구에 화염을 붙이면 어긋난다. 저장한 최종 총구와 발사선·화염을 일치시킨다. 리그 자동 업데이트와 앱의 수동 평가가 같은 틱에 이 과정을 두 번 수행하지 않게 한다.

## 4. 반동의 소유권

매 발 WeaponController가 weapon_id에 대응하는 반동 프로필을 한 번 적용한다. 총 자체의 후퇴·짧은 각도 변화와 어깨로 전달할 양을 구분한다. 양팔은 반동 후 손잡이를 따라가므로 손과 총이 따로 움직이지 않는다.

무기 이미지·손·팔 각각에 같은 후퇴량을 독립 가산하지 않는다. 부모의 이동을 이미 받은 자식에 동일한 반동을 다시 더하지 않는다. 바스트·머리의 보조 외력도 부모 이동과 이벤트 양쪽에서 중복 입력하지 않는다.

기본 조준축은 좌우 수평이다. 총구 축·최대 시각 회전을 작게 유지하고 산포를 더하기 전 기본 조준축과 총기 외형 방향의 차이를 2도 이내로 검사한다. 실제 발사선은 [19](19-combat-feel-and-damage.md)의 명중도 산포를 적용하므로 항상 수평인 것은 아니다. 자유 각도 조준은 이번에 추가하지 않는다.

위 정렬 기준은 사격 가능한 자세에 적용한다. [22](22-weapon-reloading.md)의 장전 중에는 무기를 기울이고 보조 손을 탄창·조작부로 옮길 수 있으며 사격을 차단한다. 장전 자체는 발사 반동을 발생시키지 않고, 완료 때 공통 파지와 총구 정렬을 복원한다.

## 5. 보조 모션 상태

고개·머리카락·바스트에 서로 다른 변위·속도를 둔다. Spine 물리 제약을 사용할 때는 해당 제약이 복원을 소유하고 별도의 앱 스프링을 같은 파츠에 중복 적용하지 않는다. 자체 경로에서는 아래 감쇠 스프링을 고정 시간 간격으로 적분한다.

```text
omega = 2 * PI * frequency_hz
acceleration = -omega^2 * offset - 2 * damping_ratio * omega * velocity + external_acceleration
velocity += acceleration * dt
offset += velocity * dt
```

발사·피격은 짧은 충격, 이동 시작·정지는 루트 가속도에서 얻는 반응으로 처리한다. 장시간 연사에도 변위·속도 상한을 둔다. 항상 재생되는 sine 하나로 모든 신체 반응을 대체하지 않는다.

게임 판정 60Hz, 자체 보조 모션 내부 120Hz를 시작점으로 삼는다. Spine 경로에서는 버전에 맞는 물리 평가·시간 주기를 기록하고 같은 목표 반응으로 조정한다. 30·60·120Hz 렌더 조건에서 초 단위 반응을 비교한다.

## 6. 초기 조절값

다음은 64px 표시 인물 기준 시작 범위다. 128px 비교에서는 변위만 두 배로 하고 시간·주파수는 유지한다. 실제 프리셋은 [07](07-data-and-assets.md)에 둔다.

| 대상 | 시작 반응 | 복원 | 보호 조건 |
|---|---|---|---|
| M16·어깨 | 후퇴 1~2px, 회전 최대 2도 | 약 0.04~0.08초 | 손잡이 IK·총구 동기화 |
| 고개 | 최대 1px·1.5도 | 자체 경로 6Hz·감쇠비 0.8부터 | 목 연결·얼굴 안정 |
| 머리카락 끝 | 최대 1.5px 또는 4도 | 4.5Hz·0.65부터 | 두피·얼굴 고정 |
| 바스트/의복 | 최대 1px, 국소 스케일 ±1.5% | 5.5Hz·0.65부터 | 목선·겨드랑이·재킷 경계 고정 |

숫자는 사실적인 인체 물성치가 아니라 스타일 조절값이다. 무기 반동이 달라져도 기본 캐릭터의 복원 특성은 재사용하고 입력 충격·상체 전달량을 무기 프로필로 조절한다.

## 7. 가림·관절·표시

가슴/의복과 팔·총은 별도 파츠이므로 draw order를 관리한다. 총 본체 앞에 손바닥·손가락이 있어야 하는 위치를 명시한다. 어깨·팔꿈치·목은 회전에 필요한 겹침과 뒤쪽 그림을 준비한다.

프레임마다 바뀌는 전신 가중치 표 대신 분리 파츠 메시의 기준 정점·뼈대 가중치·보호 영역을 작성한다. 적의 시트·참고 생성물은 별도 프레임 규약을 유지한다. 무기 외부 이미지는 자체 피벗·소켓을 따른다.

Nearest에서 미세 변위가 떨리면 실제 크기·큰 원본·부드러운 보간을 비교한다. 내부 상태는 소수점을 유지하고 표시 방법만 조정한다.

## 8. 전환·초기화

보행 위상을 유지한 채 상체 hold_profile을 합성한다. 같은 소총군의 무기 변경에서는 원화·공통 보행을 교체하지 않는다. 외형 변경은 soft/rigid/segmented의 표시 모션·가림을 갱신하고, 해제하면 기본 복원값을 되돌린다. 판의 움직임과 안쪽 천 모핑을 중복 적용하지 않는다. 손잡이 위치가 달라지면 IK 목표와 손목 방향을 새 데이터에서 읽는다.

좌우 전환·무기 장착·탭 복귀에서 갑작스러운 월드 이동을 물리 충격으로 오해하지 않도록 보조 상태를 재투영하거나 초기화한다. 일시정지 중 상태와 효과 수명이 멈추며 큰 delta를 한 번에 적분하지 않는다.

## 9. Motion Lab

실제 CharacterView·무기·피격 처리 코드를 재사용하는 검증 장면을 작성한다.

- 단발·10발/초 연사·걷기·정지·방향 전환·피격.
- 반동·고개·머리카락·바스트 독립 on/off와 진폭·감쇠 조절.
- 뼈대·손잡이·팔 IK 목표·목선·총구·발사선 표시.
- M16과 길이·손잡이가 다른 진단 도형의 장착 비교.
- 몸통·어깨 진단 판과 무기를 함께 교체하고 soft/rigid의 가슴 모션·관절·손 파지를 비교.
- 64/128px·원본/확대·느린 재생·고정 입력·시드 재현.
- 100회 교체 뒤 캐릭터 파츠·공통 리그·보행 파일이 그대로인지 확인.

기본 크기에서 보조 반응이 보이고 입력 중단 후 약 0.4초 이내 안정되며, 손잡이·총구 오차 2px 이하를 목표로 한다. 실제 측정은 아직 없다. [08 검증표](08-feasibility-and-qa.md)를 따른다.
