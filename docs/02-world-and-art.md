# 02. 캐릭터·아트 설정

[문서 목록](../README.md) · 게임명은 Dear Human이다. 서사 원본은 [15](15-worldbuilding.md), 실제 외형·변경 기록은 [23](23-character-appearance-review.md)을 따른다. 최신 사용자 첨부의 검은 긴 머리·짙은 눈·전술 갑옷·망토·높은 장갑 군화와 사실적인 3D 렌더 질감이 기준이다.

## 1. 작품의 방향

**Dear Human**은 같은 우리은하 안의 먼 식민행성 베스퍼에서 인간 지휘관과 배속 클론들이 함께 전투하는 근미래 2D 횡스크롤 액션 슈터다. 베스퍼는 지상에서 호흡 가능한 자연 대기를 가진 행성이다. 화면의 중심 인물은 검은 긴 생머리의 성인 여성 클론이다. 미확인 군집생물의 근접 개체를 첫 검증용 적으로 사용하며, 적군의 제작 범위는 [11](11-enemies-and-factions.md)을 따른다.

첫 스테이지는 베스퍼 동부 개척권의 협곡 수송도로에 설치된 야외 검문소다. 주인공 클론은 M16을 들고 봉쇄 구역을 통과해 정착민 대피와 보급 통로를 확보한다. 인간 지휘관은 가까운 전진 지휘소에서 명령을 내린다.

핵심 인상은 `검은 긴 머리와 갑옷·망토 실루엣`, `어두운 배경 속 또렷한 인물`, `짧고 강한 총구 화염`, `꾸준히 압박하는 군집생물 무리`다. 캐릭터는 첨부 이미지의 성인 여성 비례와 사실적인 3D 렌더 질감으로 표현한다. 긴 서사보다 이동과 사격의 감각을 먼저 전달한다.

## 2. 세계관의 화면 적용

### 2.1. 소속과 분위기

인간 지휘관과 클론은 유나이티드 어스의 식민지 개척 부대 소속이다. 시대·통제 칩·클론전쟁·지휘관의 과거는 15번 문서에서 관리하며, 이곳에 별도 역사를 만들지 않는다. 주인공은 첨부 이미지의 성인 여성 비례와 사실적인 3D 렌더 질감을 유지하고 전장은 어둡고 위협적으로 표현한다.

유나이티드 어스의 밝은 개척 홍보물과 낡은 현장 보급, 시민 대피 안내와 클론 관리 표식의 차이로 사회의 모순을 보여준다. 유머는 행정과 보급의 부조리에서 만들며, 캐릭터 의상·화풍을 정치 체제나 별도 세력의 설정으로 설명하지 않는다.

### 2.2. 첫 스테이지의 사건

미확인 군집생물이 유입된 도로의 검문소가 봉쇄되어 대피와 보급이 막혔다. 국소적인 정전과 통신 장애가 발생했지만, 행성의 자연 대기는 그대로 호흡할 수 있다. 주인공은 부대의 구형 제식 소총인 M16을 들고 검문 구역을 돌파한다. 사건의 서사 기준은 15번 문서의 첫 임무다.

현재 검토하는 검정/건메탈 전술 갑옷으로 활동한다. 인간과 클론 모두 베스퍼의 일반적인 야외에서 헬멧·호흡기 없이 활동할 수 있다. 기밀복은 우주 작업용 별도 장비이며 기본 캐릭터를 우주복이나 상시 방독면 차림으로 바꾸지 않는다.

대피 표지판, 멈춘 수송차, 깜박이는 경광등과 갑각 파편으로 현장 상황을 보여준다. 층진 절벽·협곡 안개·먼 숲과 내해, 교량 기둥·전력선으로 베스퍼의 야외 개척지임을 드러낸다. 낯선 풍경 속 시설과 총기는 가까운 미래의 산업 제품처럼 표현한다. 초기에는 이 배경과 캐릭터 리그를 재사용해 도입·종료 컷신과 미연시식 대화를 구성한다. 모든 연출은 스킵 가능하며 전용 일러스트·영상 제작의 확대는 후속으로 둔다. [21](21-story-and-skipping.md)을 따른다.

### 3.1. 첨부 기준 전술 갑옷과 화풍

최신 첨부 이미지와 [사용자 참고 JSON](../art/characters/clone_01/concepts/reference_003_3d/records/user_reference.md)이 캐릭터·화풍의 기준이다. 이전 분홍 머리 제복과 택티컬 취소 지시를 대체한다. 삭제된 과거 시안을 복구하는 것이 아니다.

- **스타일:** 사실적인 애니메이션 인물 비례와 시네마틱 3D 렌더 질감. 자연스러운 피부·머리카락, 금속·가죽·직물의 구분, 흐린 날의 부드러운 광원, 절제된 금장과 마모를 유지한다.
- **상체:** 하이칼라, 검정/건메탈 분절 복합 장갑판, 옅은 회색 흉부 인셋, 어깨·전완 장갑과 검은 장갑. 큰 의전 견장·군모·장식 끈으로 되돌리지 않는다.
- **허리·하의:** 여러 벨트·버클·소형 파우치, 짧고 구조적인 장갑 패널 하의와 안쪽 안전 하의, 가터·허벅지 스트랩·홀스터, 어두운 반투명 스타킹.
- **다리:** 분절된 무릎·정강이 장갑과 높은 장갑 군화. 이전 낮은 부츠 제한은 해제한다.
- **망토:** 어깨에서 뒤로 내려오는 무거운 검은 망토, 금장 테두리와 날개 문양. 이전 코트의 빈 소매 구조를 자동 적용하지 않는다.
- **소품:** 한 손에 든 헬멧과 아래로 향한 소총은 기준화에서 유지한다. 실제 전투 파츠에서는 손·헬멧·무기를 분리하며 헬멧을 손에 든 채 양손 사격시키지 않는다.

참고 JSON의 장군 계급·미래형 소총·격납고 배경은 외형 참고이며 게임의 클론 신분·M16·베스퍼 스테이지를 변경하지 않는다. HUD·암호통신·센서 같은 소품 설명을 실제 구현 기능으로 표시하지 않는다. 외형은 첨부 이미지가 우선이며 불필요한 장비·새 의상을 추가하지 않는다.

### 3.2. 모션 파츠와 재질

게임은 2D 횡스크롤·공통 파츠 리그·독립 무기 방식으로 시험한다. **3D 느낌은 이미지의 화풍이며 실제 3D 모델 제작이나 3D 게임 전환을 뜻하지 않는다.** 현재 정면 전신 이미지는 전투용 측면 파츠·3D 모델·실제 리그가 아니다.

머리 본체·앞머리·뒷머리, 몸통·흉갑, 어깨·상완·전완·손, 골반·하의·허벅지·종아리·군화, 망토·장식, 무기·탄창을 나눈다. 가려진 관절 면을 보완하고 파츠별 광원·축척·재질을 맞춘다. [16](16-modular-character-and-weapons.md), [17](17-modular-armor-appearance.md)을 따른다.

**흉갑은 rigid, 다리 장갑은 segmented, 머리·망토·안쪽 천은 soft**로 구분한다. 단단한 흉갑 표면에 바스트 모핑을 전달하지 않는다. 안쪽 천의 지연·감쇠는 가림·재질 모드에 따라 제한하고 무기 장착점·팔 IK를 움직이지 않는다. [13](13-secondary-motion.md)을 따른다.

긴 머리·망토·파우치가 팔·총·장전 손 경로와 겹치는지 새 외형으로 검사한다. 고정된 3D풍 하이라이트가 파츠 회전에서 어색해지는지도 확인한다. 이전 외형의 검수 결과를 새 외형의 통과 증거로 쓰지 않는다.

### 3.3. 외형 확인과 도구 선택

사용자가 최신 첨부 기준의 외형을 채택했다. 이전 시안·중단 시험은 삭제하고 이 외형으로 rig_002 파츠 모션을 재개했다. 대기·제자리 보행·사격·이동 사격·장전 초안을 기존 통합 샘플에서 제공한다. 실제 구현·검사 결과와 남은 시각 보정은 [24](24-motion-rig-test.md)에 기록하며 도구의 최종 채택은 결과 평가 뒤 결정한다.

여러 공식 제복 중 선택할 수 있다는 세계관은 유지한다. 현재는 이 외형 하나부터 검증하며 여러 장비 UI를 추가하지 않는다. 이전 reference_002와 중단 시험은 사용자 요청으로 삭제했으며 새 원화·참고 JSON·파츠·무기·제작 기록만 유지한다.

## 4. 기본 무기 M16

무기 식별자는 `m16_basic`이다. M16으로 알아볼 수 있도록 운반 손잡이, 긴 총열, 개머리판, 탄창의 실루엣을 유지한다. 특정 세부 모델의 정확한 복제는 이번 검증 목표가 아니다.

사격 시 어깨와 총이 짧게 뒤로 밀리고 회복하며, 머리·머리카락·바스트에는 작은 시간차와 감쇠가 생긴다. 총구 화염·탄도·명중 효과가 실제 발사와 맞물린다. 무기는 캐릭터 파츠와 분리한 이미지로 장착하고 두 손을 손잡이에 맞춘다. 총구 화염은 무기 소켓에서 별도 출력한다. 캐릭터 파츠·공통 걷기는 새 무기에도 재사용한다.

게임에서는 누르고 있는 동안 연사한다. 이 동작과 발사 속도는 플레이 감각을 위한 가상 설정이며 실제 M16의 형식별 작동·성능을 재현한다는 의미가 아니다.

## 5. 초기 적군: 미확인 군집생물 근접 개체

첫 검증용 적은 초기 가칭인 **미확인 군집생물의 근접 개체 1종**이다. 현재 서사에서는 베스퍼의 토착 생물로 확정하며 낮은 갑각 몸체와 발톱으로 접근하는 위협으로 표현한다. 명칭·실루엣·팔레트는 프로젝트 제안이고 세부 지능·번식 방식은 미정이다.

도시와 생활 기반이 자리 잡은 정착권의 외곽 수송도로와 시설을 토착 생물로부터 지키는 전투가 기본이다. 중앙의 생물병기 실험이나 클론전쟁 잔당을 이 생물들의 기원으로 설정하지 않는다. 이번은 서사 전제의 구체화이며, 근접 적 1종의 제작 범위와 기존 데이터 ID·원화·런타임은 변경하지 않는다.

|---|---|
| 작업 식별자 | `swarm_creature_melee` |
| 세력 분류 | 미확인 군집생물, `faction_id=unknown_swarm`. 관측용 분류이며 정치적 조직이나 지휘 의식을 뜻하지 않는다. |
| 역할 | 무리로 접근해 근접 압박을 주는 기본 적 |
| 외형 | 앞으로 숙인 몸통, 분절된 갑각, 낫 모양 앞발톱, 긴 꼬리 |
| 색상 | 어두운 보라색 갑각, 옅은 상아색 몸체, 적갈색 발톱 |
| 움직임 | 몸을 낮춘 제자리 달리기 모션과 수평 접근 |
| 공격 | 가까운 거리에서 발톱 접촉 공격, 원거리 공격 없음 |
| 피격 | 충돌점의 진액 분사·낙하 액적, 짧은 색상 반응, 작은 밀림, 체력 감소 |

이동 속도는 48px/초, 몸통 높이는 약 48~56px로 시작한다. 실제 이동은 같은 지면 위 수평 이동이며 점프·도약·벽 타기는 구현하지 않는다. 꼬리와 발톱은 실루엣을 만들되 별도 충돌체나 독립 피해 판정을 두지 않는다.

최초 프로토타입에는 군집생물 외형 1종만 사용한다. 이 제한은 이번 제작 범위에만 적용한다. 색상 변형·방어구·돌진 능력은 추가하지 않는다. 피격 진액은 황록색의 짧은 점성 분사·액적·바닥 잔흔으로 제안하고 플레이어의 붉은 혈액과 구분한다. 이는 프로젝트의 색상 설정이며, 상세 표현은 [14](14-hit-effects.md)를 따른다.

## 6. 스테이지 1: 폐쇄된 외곽 검문소

시작은 수송차가 멈춰 선 야외 도로, 중간은 바리케이드와 경비 부스, 마지막은 비상 통로다. 전체가 자연 대기에 노출된 하나의 연결된 평면 스테이지다. 협곡과 교량의 높이 차이는 배경에 표현하며 점프나 복층 경로를 추가하지 않는다. 상세 좌표와 웨이브는 [03 게임플레이](03-gameplay-and-stage.md)를 따른다.

| 구역 | 배경 요소 | 플레이에서 전달할 정보 |
|---|---|---|
| 진입 도로 | 버려진 차량, 안내 표지 | 오른쪽으로 진행 |
| 첫 봉쇄선 | 철제 펜스, 경광등 | 첫 전투의 시작·종료 |
| 검문소 중앙 | 부스, 콘크리트 벽 | 양쪽에서 접근하는 적 |
| 비상 통로 | 출구 표지, 문 | 최종 전투 후 탈출 |

배경 차량과 부스는 장식이다. 플레이 경로를 가로막는 장애물은 전투 중 닫히는 구역 경계와 스테이지 양끝만 둔다.

## 7. 아트 기준

- 기존 64px 인물·128×128px 캔버스는 비교 기준이다. 머리·바스트 모션 가독성을 위해 더 큰 원본의 128px 인물 표시도 시험하고 최종 스타일·크기를 선택한다.
- 배경은 저채도, 플레이어 표식과 총구 화염은 높은 대비를 쓴다.
- 캐릭터는 사실적인 3D 렌더 재질을 유지한다. 굵은 외곽선·도트화를 강제하지 않는다.
- 기본 팔레트 참고값: 배경 `#171D29`, 구조물 `#3E4A56`, 머리 `#17171D`·그림자 `#101116`, 쿨톤 피부 `#F2ECF6`, 짙은 눈 `#4C4747`, 제복 `#181A20`, 금장 `#B89A62`, 코트 안감 `#34202A`, 부대 표식 `#F09543`, 군집생물 갑각 `#5E3E78`·몸체 `#D7CEB7`·발톱 `#8C3F48`, 총구 중심 `#FFF4C7`. 실제 채택 원화에서 최종 색을 확정한다.
- 검은 머리·갑옷·망토가 배경에 묻히지 않게 명도 차를 확보한다. 실제 크기에서 얼굴·장갑판·허리선·군화·보조 모션을 확인한다.
- 기본 자세와 미세한 반응을 모두 실제 크기에서 확인한다. 확대 화면에서만 보이는 흔들림은 충분한 검증으로 보지 않는다.
- 좌우 반전 시 어깨 표식과 무기 좌우 비대칭이 반전되는 것은 이번 프로토타입에서 허용한다. 왼쪽 전용 이미지는 필수가 아니다.

## 8. 최소 에셋 목록

필수는 플레이어 분리 원화 1세트·공통 리그·기본 4상태와 일반/빈 장전 합성 동작·분리 M16 본체/탄창/조작부, 군집생물 원본 1개와 접근 이동 루프, 반복 가능한 지면·배경, 출구·경계 표시, 기본 전투 이펙트, HP·탄약/장전·웨이브·슬롯 HUD다. 사망 표현은 [19](19-combat-feel-and-damage.md), 무기 하위 파츠와 장전 손동작은 [22](22-weapon-reloading.md)을 따른다.

새로운 캐릭터 디자인, 스테이지 테마, 스킬 연출을 늘리기 전에 같은 에셋의 모션 일관성과 총구 정렬을 먼저 통과시킨다.
