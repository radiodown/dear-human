# 33. 총구 빛의 캐릭터 반영 012

[문서 목록](../README.md) · [이전 자세 011](32-body-articulation-and-combat-poses.md) · [사격 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire)

사용자는 총기 사용 때 캐릭터가 총구 불빛을 받으면 더 사실적일 것이라고 요청했다. 이전 렌더러는 총구에 작은 단색 삼각형만 그렸고 캐릭터에 조명을 더하지 않았다. 현재는 공통 WebGL 파츠 렌더러에 발사 순간의 재질별 조명을 개발 연결했다. 사용자가 검증을 맡기로 했으므로 추가 테스트·문서/목록 검사·브라우저 캡처는 실행하지 않았다. 현재 상태는 `untested`·사용자 검수 대기다.

## 발사와 광원

`CharacterRig.fire()`가 실제 탄을 발사할 때 설정하는 기존 `flash` 타이머를 그대로 사용한다. 기간은 공통 `MUZZLE_LIGHT.duration`의 .055초다. 입력 후 준비 자세를 취하는 동안, 빈 탄창, 장전, 발사 대기 시간에는 광원이 켜지지 않는다. 렌더링 횟수나 벽시계 대신 고정 스텝의 남은 시간으로 감쇠한다. 일시정지와 0.25배 재생에서도 같은 발사 순간을 볼 수 있게 연결했다.

광원은 매 프레임 현재 자세의 `sockets.muzzle`을 사용한다. 서서쏴·앉아쏴·이동/달리기·허리 숙임과 좌우 반전에서도 같은 총구를 기준으로 한다. 반경은 캐릭터와 같은 논리 좌표 175, 깊이 근삿값은 38이다. 화면 확대·축소와 DPR은 거리 계산에서 제거한다. 따뜻한 색 `[1, .53, .19]`에 거리 감쇠와 시간 감쇠를 곱하고, 먼 파트는 반경 밖에서 빛이 0이 된다.

## 파트와 재질

[공통 코드](../game/animation/muzzle-light.js)의 프래그먼트 셰이더가 원본 픽셀의 RGB에 빛을 더한다. 원본 알파와 기존 파트 가림 순서를 그대로 사용하므로 캐릭터와 별개인 화면 전체 색 필터를 만들지 않는다. 원본 PNG·UV·관절·그립·모션은 조명 제작을 위해 다시 생성하지 않았다.

피부·머리카락·천·장갑·금속 갑옷·무기는 서로 다른 확산광/광택 응답을 사용한다. 금속은 좁고 선명한 반사, 천은 약하고 넓은 반응, 피부는 부드러운 밝기 증가를 목표로 값을 작성했다. 어두운 표면에도 작은 따뜻한 반응을 허용하며 텍스처 밝기 정보를 광택에 반영한다. 계산은 선형 색 공간에서 더하고 다시 화면 색으로 변환한다. 발사 광량이 0일 때는 기존 텍스처 출력 경로를 사용한다.

방향성은 파트별 구/원통 표면 근사로 계산한다. 파츠 회전과 좌우 반전을 전달하고, 흉갑은 별도 흉갑 축을 사용한다. **실제 노멀맵·3D 지오메트리·동적 투영 그림자·광선 추적은 없다.** 기존 원화에 구워진 조명은 그대로 남아 있으므로 얼굴/금속/옷의 반응과 과노출은 사용자 시각 검수가 필요하다.

총구 표시도 같은 이벤트에 동기화한 부드러운 황백색 중심과 작은 주황색 후광으로 바꿨다. 코드 기반 셰이더 효과이며 새 래스터 이미지나 PixelFX 생성물이 아니다. 별도의 전투 판정이나 명중 처리는 추가하지 않았다. 진단 도형 무기와 분리 파츠 보기에는 캐릭터 총구 조명을 적용하지 않는다.

## 같은 페이지의 비교 조절

반응 줄의 **캐릭터에 총구 빛**으로 캐릭터의 조명만 켜고 끌 수 있다. 총구 화염 표시는 계속 발사 이벤트를 보여준다. **빛 세기**는 0~200%, 기본 100%다. 설정은 URL의 `light=0`, `lightStrength=1.5`로 보존한다.

- [사격·기본 조명](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire)
- [첫 발의 정지 시점](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire&time=0.13&paused=1)
- [동일 시점·캐릭터 조명 끔](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=fire&time=0.13&paused=1&light=0)

위 주소는 구현한 진입점이며 이번 작업에서 브라우저를 열어 검수하지 않았다.
