# 총을 내린 달리기와 두 대기 자세 · carry_idle_001

사용자 요청: “총을 쏘지 않고 달릴대는 총구가 아래를 보고 달리게. 대기 두가지, 견착자세랑 완전대기”. 기존 ‘견착 대기’를 유지하고 ‘완전 대기’를 추가했다. [견착 대기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=idle) · [완전 대기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=relaxed) · [달리기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run) · [뛰며쏴](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run_fire).

비사격 달리기는 총구를 전방 수평에서 아래 35°로 내려 든다. 총 지지점을 약간 뒤로 두고 기존 양손 파지·다리 접지·전경·정면 시선을 이어 쓴다. 이때 사격용 총 전진량은 줄이며 총을 들면 원래 전진 보정이 돌아온다. 뛰며쏴와 기존 사격 자세의 총구 기본 방향은 전방 수평이다. 이번 사용자 지시가 이전 ‘모든 자세 수평’ 규칙의 비사격 달리기·완전 대기 부분을 대체한다.

견착 대기는 기존 전방 수평 총과 준비 자세다. 완전 대기는 상체의 기본 전경을 풀고, 총을 58° 아래로 내려 양팔을 몸 쪽으로 모아 든다. 개머리판의 기준은 어깨에서 벗어난 별도 지지점이며 새 손 그림이나 한 손으로 매단 무기를 만든 결과는 아니다. 원래 파츠·양손 파지·호흡을 재사용한다.

완전 대기는 `motion=relaxed`, 공통 리그의 `setRelaxed(true)`와 고정 스텝의 `relaxAmount`를 사용한다. 전환 시정수는 .18초다. 기존 `idle` 주소는 견착 대기를 그대로 가리킨다. `motion-controls.js`에 완전 대기의 기본 허리각 0°·총 낮춤 0을 추가했으며, 나머지 공통 조절 항목·반응/조명·동작별 저장·초기화는 그대로 사용한다. 기존 저장 목록에 완전 대기가 없으면 새 기본값을 채운다. 현재 조절 가능한 기본 동작은 9개다.

`firing-form.js`의 `WEAPON_CARRY`와 `weaponCarry()`가 각도와 들기 전환을 공유한다. 실제 사격 준비량 .05~.85에서 총을 들고, 기존 준비 판정 .9와 최소 약 .12초 준비가 충족된 뒤 첫 발을 허용한다. 사격 후 기존 준비 유지/복귀량을 따라 총을 다시 내린다. 실제 입력은 기존처럼 `requestFire`/`trigger`를 사용한다. 장전 조작 중에는 낮춘 각도를 줄여 기존 장전 경로로 전환한다.

총 각도와 지지점을 먼저 계산하고, 같은 무기 프레임에서 손·탄창·시선·총구를 계산한다. 총 낮춤 슬라이더는 각도와 별개로 월드 수직 이동을 더한다. 원본 비율이나 뼈 길이를 바꾸지 않았다. 플랜 B/C·원본 PNG·GIF는 이번 범위가 아니다.

필요한 변경 JS 구문 검사, 두 대기/달리기/뛰며쏴의 짧은 접점 확인과 완전 대기·달리기에서의 단발 준비/복귀를 확인했다. 측정된 첫 발은 약 .125초 뒤였고 추가 아래각은 0이었다. 손·총 지지점과 다리 도달 오차는 수치 정밀도 범위였다. Chrome에서 네 자세의 표시·달리기 중 실제 단발 입력·완전 대기의 일시정지 조절과 별도 값 복원을 짧게 확인했다.
