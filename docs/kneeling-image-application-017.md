# 정답 이미지 기준 앉아쏴 보정 · 017

[문서 목록](../README.md) · [같은 캐릭터 페이지 · 앉아쏴](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=kneel_fire) · [정측면 비교](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=kneel_fire&viewPitch=0)

사용자가 채택한 [kneeling_fire_001](../art/characters/clone_01/concepts/kneeling_fire_001/source/kneeling_fire.png)과 [문제 분석](kneeling-image-parts-analysis-001.md)을 바탕으로 파츠 앉아쏴를 수정했다. 공통 `rig_005`와 같은 페이지의 `kneel`/`kneel_fire`에 연결한 개발 인계이며 **untested·사용자 검수 대기**다. 기존 사용자 지시대로 테스트·구문/문서/목록 검사·브라우저 검수나 캡처는 실행하지 않았다.

## 전용 기준 포즈와 견착

- `game/animation/kneeling-pose.js`의 `KNEEL_ART`에 앉아쏴의 골반·앞발·접지 무릎·상체·견착·양팔 기준을 모았다. 이전의 골반 뒤쪽 무릎 목표 대신 골반 x=-12, 접지 무릎 x=14, 앞발 track=76을 사용한다. 조준 시 골반은 .6 전진한다. 실제 길이 76의 허벅지 원호와 고정 길이 정강이, 뒤쪽 발끝 접촉을 이어 사용한다. 이 수치는 이미지를 측면 리그로 옮긴 작성값이며 원본 사진에서 측정한 3D 관절 좌표가 아니다.
- 접지 무릎 높이는 임의 반지름 -16 대신 기존 정강이 UV의 관절 .13, 분할선 .28, 발목 .96과 길이 76으로 계산한 `-76*(.28-.13)/(.96-.13)`을 사용한다. 이는 무릎 장갑으로 분리한 소스 영역 하단을 바닥에 두는 기준이며 알파 실루엣의 정밀 충돌 검증은 수행하지 않았다.
- 앉기 전경 .115rad와 조준 추가 .045rad에 전용 흉곽/어깨·견착 위치를 연결했다. 양팔은 앉아쏴의 투영 길이와 팔꿈치 가이드로 전환한다. 기존 손–총 IK·014 손·M16 접점을 유지하고 팔꿈치를 앞무릎에 붙이는 조건은 넣지 않았다.
- 앉아쏴의 총신 기본각은 수평으로 분리했다. 수동 허리 숙임은 어깨 위치에 반영하지만 총신을 함께 아래로 기울이지 않는다. 기존 발사 반동과 장전 중 총 기울기는 이어 사용한다.
- 조준 시 기존 머리의 눈을 가늠자 뒤 17.5의 조준선에 유도하고 작은 머리 기울기를 적용한다. 위치 보정은 축별 최대 9로 제한하고 장전 중 풀어준다. 총 전체를 이동하거나 팔을 늘려 오차를 숨기지 않는다. 머리/머리카락 상단과 눈의 표시 깊이를 함께 조정해 견착 시 총과 같은 카메라 투영을 사용한다. 얼굴/볼의 실제 접촉 실루엣과 큰 수동 숙임에서는 사용자 검수가 남는다.

## 원본 UV를 재사용한 부착물

[rig_017](../art/characters/clone_01/motion/rig_017/README.md)의 [작성 레시피](../art/characters/clone_01/motion/rig_017/recipe/build_kneeling_parts.py)로 정의를 생성하고 현재 리그에 연결했다. 레시피 실행은 JSON 부착물 작성이며 테스트나 이미지 생성이 아니다. 원본 PNG는 수정하지 않았다.

- **무릎:** 정강이 소스의 위 28%를 독립 무릎 장갑으로, 나머지를 정강이로 분리해 중복 그림을 없앴다. 앉는 동안 장갑은 정강이와 별도로 정방향을 유지한다. 허벅지 아래쪽의 기존 스타킹 그림을 무릎 안쪽 연결 천으로 재사용하고 두 다리 뼈의 각도 사이에 배치한다. 뒤 부츠는 기존 발끝 지지·발목 계산을 따른다.
- **스커트:** 상단 v=.56~.75의 벨트·파우치는 골반에 유지한다. 하단을 앞/뒤 패널로 나누고 각 허벅지 각도에 따라 들고 접는다. 상단 행은 고정하고 내부 압축은 작은 변형으로 표현한다. 서 있을 때는 두 패널이 원래 UV 위치를 사용한다. 흉갑 015·허리 연결 메시를 다시 만들지 않는다.
- **망토:** 기존 어깨 고정·길이 유지 스트립을 사용한다. 앉는 동안 렌더러의 바닥 경로가 남는 길이를 뒤쪽으로 꺾어 펼치고, 바닥 구간의 폭을 깊이 방향으로 넘겨 같은 카메라로 투영한다. 원본 UV와 작은 접힘을 사용한 2.5D 표면 근사이며 실제 천 시뮬레이션이나 새 바닥 망토 원화는 아니다. 렌더 중 기존 스프링/접지 상태를 변경하지 않는다.

같은 페이지에 ‘앉아쏴 기준 그림 보기’를 추가했다. 페이지 방문으로 생성·검사·영상 출력을 자동 실행하지 않는다.

## 보존·등록과 남은 범위

변경 직전 작업 폴더를 `rig_005/records/runtime_snapshot_before_kneeling_image_017`에 보존했다. 현재 달리기/뛰며쏴의 총 전진·높이, 016 호흡/반동, 014 손과 M16 바인딩, 카메라 001을 이어 사용한다. 플랜 B/C·과거 검사 기록·GIF·채택 이미지와 이전 프롬프트는 변경하지 않았다.

[레시피](../art/characters/clone_01/motion/rig_005/records/kneeling_image_017/recipe.json)와 [인계](../art/characters/clone_01/motion/rig_005/records/kneeling_image_017/handoff.json)에 실제 소스·의존 버전·작성 결과와 검수 대기를 저장한다. 목록은 `parts_017`과 현재 리그의 앉기/앉아쏴 레시피를 연결하며 기존 기록을 최신 검증으로 승격하지 않는다.

이번 결과는 기존 측면 원본의 파츠 모션이다. 정답 이미지의 사선 흉갑·얼굴/어깨 이면까지 새로 그리거나 실제 3D 모델로 전환하지 않았다. 접힌 관절과 발목의 가림, 깊은 압축 주름, 망토 무늬의 바닥 투영, 전환 중 패널 경계와 실제 견착 품질은 사용자 시각 검수가 남는다. 이 보정으로 기존 원본의 이면·깊은 주름까지 완성됐다고 판단하지 않는다.

다음 검사를 별도로 요청받으면 `rig_005/tests/kneeling_image_017`과 `rig_005/reviews/kneeling_image_017`을 사용한다. 검사 도구 기본 경로는 변경하지 않았고 이번에는 해당 도구를 실행하지 않았다.
