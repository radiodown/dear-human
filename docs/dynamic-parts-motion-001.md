# 파츠 모션 활동감 보정 · dynamic_motion_001

사용자 요청: “파츠모션에서 더 역동적이었으면 함”. 기존 rig_005의 공통 게임/미리보기 코드에 추가 동작 강도를 연결했다. [달리기](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run&energy=100) · [뛰며쏴](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=run_fire&energy=100) · [기록](../art/characters/clone_01/motion/rig_005/records/dynamic_motion_001/recipe.json).

동작 강도는 0~150%, 기본 100%다. ‘이전 움직임’은 0%, ‘역동적 100%’는 새 기본값이며 일시정지에서도 같은 시점의 발·골반·상체·천 반응을 비교한다. 값은 브라우저 저장소와 `energy` 주소 인자로 복원한다. 전체 초기화는 100%로 돌아간다. API는 `CharacterRig.setMotionEnergy(0~1.5)`다.

걷기·달리기는 착지 직후 빠르게 압축하고 길게 밀어내는 골반 곡선을 추가했다. 걷기는 양발 지지가 겹치므로 추가 체공을 만들지 않고, 달리기로 바뀔 때 체공량을 점진적으로 늘린다. 발 회수 높이는 기존 궤적에 걷기 최대 4.5, 달리기 최대 12 논리 픽셀을 추가한다. 보폭·속도·접지 이력·뼈 길이는 기존 기준을 사용한다. 골반을 지나치게 들어 다리가 발에 닿지 않으면 양쪽 다리의 도달 범위로 골반 상승을 제한하고, 그 뒤 상체·무기 프레임을 계산한다.

흉곽은 골반과 다른 위상으로 따라오며 작은 반대 회전으로 충격을 흡수한다. 출발·정지의 속도 변화는 고정 스텝에서 전용 감쇠 스프링에 전달한다. 매 발사 후 상체 복귀를 강조하고, 머리 아래쪽 끝·망토·허리 천·옷자락 반응을 키웠다. 망토의 어깨 고정과 스트립 길이, 머리카락의 두피~어깨 고정은 유지한다. 추가 강도는 pose 출력에서 적용하므로 일시정지 비교가 상태나 시간을 바꾸지 않는다.

앉기/앉아쏴가 완성되면 추가 동작은 사라지고 017 자세를 유지한다. 기존 014 손·사격 허리각·총 높이·총 전진과 전방 수평 총구, 달리기 정면 시선도 이어 쓴다. 외형·원본 PNG·플랜 B/C·GIF는 이번 변경 범위에 포함하지 않았다.

필요한 변경 JS 구문 검사, 0/100/150%의 8개 자세를 각 3초간 계산한 짧은 접점/도달/바닥 검사와 6초의 이전 소스 비교를 수행했다. 0%의 골반·상체·무기·다리·망토·머리카락·옷자락 좌표는 보존 소스와 일치했다. 렌더 호출은 상태를 바꾸지 않았으며 강도 비교도 시간을 진행하지 않았다. [수치 기록](../art/characters/clone_01/motion/rig_005/tests/dynamic_motion_001/motion-smoke.json)과 [Chrome 기록](../art/characters/clone_01/motion/rig_005/reviews/dynamic_motion_001/browser.json)을 분리했다. 전체 테스트 묶음·문서/목록 검사·GIF 출력은 실행하지 않았다.

처음 발견한 다리 도달 실패 기록과 걷기의 겹친 지지 구간을 다듬기 전 결과는 같은 버전 하위에 보존했다. 변경 전 7개 런타임 파일은 `runtime_snapshot_before_dynamic_motion_001`에 있다. 과거 버전의 `untested` 기록은 그대로 유지한다.

현재는 제한된 수치·짧은 브라우저 확인을 마친 개발 버전이며 사용자 아트 채택은 대기다. 반복 보행의 리듬, 착지와 밀어내기의 자연스러움, 높은 강도에서의 무릎/부츠/스커트 겹침, 망토 문양의 변형, 큰 수동 숙임·장전·다른 총 높이를 조합한 모습은 추가 사용자 검수가 필요하다. 새 시점 원화나 실제 3D·천 충돌을 만든 결과는 아니다.
