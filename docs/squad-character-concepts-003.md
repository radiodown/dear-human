# 소대원 콘셉트 003 · 동아시아계 인상

사용자가 002의 얼굴이 너무 서양인처럼 보인다고 평가해, 세나·모아·유나·이렌 모두 **동아시아계 얼굴 인상**으로 수정한다. **25~26세의 젊은 성인 외형**, 신형 근미래 화기, 병과별 제복, **이렌만 가터벨트**라는 구성은 유지한다.

리안의 채택 원화에서 공통 화풍과 얼굴 표현 방향을 참고하되 서로 다른 얼굴을 만든다. 부드러운 타원형 윤곽·자연스러운 눈매와 얼굴 비례를 사용하고 과장된 민족적 특징을 만들지 않는다. 아트 방향을 작중 국적·혈통·생산권이나 같은 유전 원형이라는 설정으로 확장하지 않는다.

| 인물 | 유지하는 구분 | 얼굴 표현 시안 |
|---|---|---|
| 세나 | 저격·관측 / 은회색 낮은 포니테일·경량 장갑·정찰 망토·바지 | 차분한 눈매·부드럽게 좁아지는 타원형 윤곽 |
| 모아 | 분대지원화기 / 적갈색 땋은 머리·하중 지지 장비·바지 | 젊은 볼 윤곽·편안한 눈매·작은 미소 |
| 유나 | 방패·진입 / 밝은 금발 보브·전면 방호·바지 | 짧고 부드러운 타원형 윤곽·또렷한 눈매 |
| 이렌 | 돌격 / 짧은 짙은 갈색 머리·짧은 장갑 하의·가터벨트·스타킹 | 젊고 부드러운 윤곽·절제된 눈빛·노화 없는 선임의 태도 |

얼굴의 개별 형태·머리·눈·성격과 장비 세부는 사용자 검수 대기다. 이렌의 각성 후 약 7년 활동 기간과 친구·전임 지휘관 사망 이력은 바꾸지 않는다. 001·002의 피드백과 원본은 각각 기록으로 남긴다.
