# 소대원 앞뒤좌우 002

사용자 요청으로 리안을 제외한 세나·모아·유나·아렌의 현재 외형을 정면·후면·좌측면·우측면 네 장씩 적용한다. 현재 위키 프로필의 정면 전신과 독립적인 방향별 갤러리, 공통 미리보기의 개별 방향·전체 보기를 연결한다. 기존 원본과 버전은 보존한다.

| 대원 | 현재 외형 입력 | 다방향 기록 | 제작·재사용 |
|---|---|---|---|
| 세나 | 애쉬브라운 긴 생머리 반묶음·시스루뱅, 정찰·저격 제복 004 | [세나 002](../art/characters/sena/concepts/turnaround_002/README.md) | 기존 정면·후면·좌측면 세 장 재사용, 우측면 한 장 생성 |

## 적용 범위

- 위키는 인물 문서의 `turnaround` 네 항목과 위키 내부 PNG만으로 방향별 갤러리를 표시한다. 정면 전신은 프로필에도 사용한다. 별도 게임 파일을 읽거나 docs를 자동 동기화하지 않는다.
- 공통 미리보기의 새 `turnaround_002`는 기존 `preview.images`를 사용한다. 각 대원 주소는 `http://127.0.0.1:4173/#/samples/characters/<id>?rev=turnaround_002`다. `<id>`는 `sena`·`moa`·`yuna`·`iren`이다.
- 좌측면·우측면은 인물이 화면에서 바라보는 방향 기준이다. 단순 수평 반전으로 대체하지 않았으며 양쪽 장식·파우치의 세부 일치도는 사용자 검수 대기다.
- 손에 든 총·방패·헬멧을 뺀 중립 전신 보기다. 장착된 파우치·홀스터와 병과별 복장을 유지한다. 가터벨트·스타킹은 아렌만 사용한다. 무기 장비 갤러리와 게임 무장은 유지한다.
- 아렌의 작은 인물 표시는 011 초상 원본을 위키 내부에 바이트 그대로 복사해 정사각형 화면 틀의 `cover` 표시로 사용한다. 원본을 자르거나 다시 그리지 않는다. 이전 아이콘 파일은 보존한다.
- 생성은 내장 image_gen이며 정확한 영어 JSON/MD·실제 시간·입력/출력 해시·실패 초안은 각 버전 폴더에 보존한다. 표시용 PNG는 원본과 동일한 바이트다. 노출되지 않은 모델명·비용은 추측하지 않는다.

## 검수와 한계

필요한 위키 문서·메타데이터·구문 검사와 정적 빌드, 네 인물의 위키 이미지 표시·원본 링크, 공통 미리보기 네 방향 전환·주소 복원, 작은 화면을 확인한다. 각 버전의 `reviews/verification.json`에 실제 범위를 기록한다. 기록·표시 통과는 미모·체형·얼굴 일관성·후면 디자인의 사용자 아트 채택을 뜻하지 않는다.

리안 원본·위키 문서·카탈로그 항목과 기존 게임/모션은 이번 이미지 적용으로 변경하지 않는다. 기존 진행 중이던 원격 GLB 변경은 Git 병합으로 보존한다.
