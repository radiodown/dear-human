# 모든 파츠 동작의 조절 항목 통일 · motion_controls_001

사용자 요청: “각 동작에서 동일한것들을 조절할수있게 수정해줘”. [같은 파츠 모션 페이지](http://127.0.0.1:4173/#/samples/characters/clone_01?motion=walk_fire)에서 견착 대기·이동·서서쏴·이동 사격·달리기·뛰며쏴·앉기·앉아쏴의 8개 동작에 동일한 조절 패널을 사용한다.

| 항목 | 범위 | 적용 |
|---|---|---|
| 기본 허리각 | 0~45°, 0.5° 단위 | 현재 동작의 기준 숙임 조절 |
| 추가 숙임 | 0~45°, 0.5° 단위 | 기준각에 더하는 숙임 |
| 바스트·흉갑 각도 | -5~5°, 0.5° 단위 | 흉갑의 상대각 |
| 총 낮춤 | 0~18, 1 단위 | 총·양손·탄창·총구를 같은 월드 수직 방향으로 이동 |
| 동작 강도 | 0~150%, 5% 단위 | 기존 활동감 보정 강도 |
| 반동·고개·머리카락·허리/옷자락·망토 | on/off | 현재 동작의 추가 반응 |
| 캐릭터에 총구 빛·빛 세기 | on/off, 0~200% | 현재 동작의 발사 조명 |

동작을 바꾸면 해당 동작에 저장된 값과 반응 설정이 복원된다. ‘이 동작 기본값’은 현재 동작만, ‘모든 동작 초기화’는 8개 동작의 설정을 모두 기본값으로 돌린다. 시점·속도·인물 크기와 뼈대/메시 등 보기 설정은 공통이다. 일시정지 중 슬라이더는 시간을 진행하지 않고 현재 자세에 즉시 반영한다. 멈춘 상태에서 동작 선택만 바꾸면 기존처럼 자세 전환 자체는 재생/프레임 진행을 통해 이뤄진다.

기본 허리각은 대기 4°, 이동 6°, 서서쏴 12°, 이동 사격 12.5°, 달리기/뛰며쏴 15°, 앉기 6.5°, 앉아쏴 9°다. 이 값은 원래 동작의 기준값이며 실제 허리각에는 호흡·하중·반동·추가 숙임이 더해진다. 총 낮춤 기본값은 달리기/뛰며쏴 6, 나머지 0이다. 기본 설정은 기존 동작을 그대로 재현하도록 기준값과의 차이만 추가한다. 달리기 총의 원래 지지 높이는 유지하며, 총 낮춤을 증감하면 모든 동작에서 같은 월드 수직 방향으로 보정한다.

공통 리그의 `setMotionControls(mode, settings, immediate)`와 `game/animation/motion-controls.js`가 값 범위·기본값을 공유한다. 허리/총 높이 변경은 기존 .10초 시정수의 고정 스텝에서 전환하고, 일시정지에서는 값만 즉시 적용한다. 총 높이는 총 프레임을 먼저 옮긴 뒤 양팔·탄창·시선·총구를 계산한다. 총구의 기본 전방 수평, 발 접지·뼈 길이·기존 활동감과 017 앉아쏴 구조를 이어 쓴다.

동작별 설정은 `dear-human:motion-controls:v1`에 저장한다. 이전 사격 허리각·앉아쏴 총 낮춤·활동감 저장값은 처음 읽을 때 새 동작별 설정으로 가져오고 이전 저장 키는 수정하지 않는다. 주소의 `waist`, `bend`, `bust`, `weaponDrop`, `energy`, 반응/조명 값은 현재 동작에만 우선 적용한다. 기존 `fireBend`, `runFireBend`, `carryDrop`, `kneelDrop` 주소도 대응 동작에서 읽는다. 동작 선택 버튼은 이전 동작의 주소 값을 새 동작에 복사하지 않고 해당 동작의 값으로 주소를 갱신한다.

변경 전 4개 런타임은 `runtime_snapshot_before_motion_controls_001`에 보존했다. 새 레시피·인계는 `rig_005/records/motion_controls_001`, 짧은 수치 결과와 Chrome 결과는 각각 `tests/motion_controls_001`, `reviews/motion_controls_001`에 분리한다. 이전 활동감/사격/앉아쏴 기록의 `untested`나 검사 결과는 소급 변경하지 않는다. 플랜 B/C·원본 PNG·GIF는 이번 작업 대상이 아니다.

필요한 변경 JS 구문과 8개 동작의 짧은 기본값/접점 확인, Chrome에서 동일 항목·동작별 기억·저장/주소·초기화·일시정지 조절을 확인했다. 기본 설정 좌표는 보존 소스와 일치하며, 모든 동작에서 총을 3만큼 낮추면 총 프레임도 수직으로 3 이동하고 방향은 유지됐다. 큰 기본각과 추가 숙임을 동시에 적용한 조합, 최대 총 낮춤·장전·가림과 반복 리듬은 사용자 시각 검수가 남는다. 전체 테스트 묶음이나 문서/목록 검사는 실행하지 않았다.
