# 09. 모션 우선 제작 순서와 결정 기록

[문서 목록](../README.md)

## 1. 제작 원칙

**공통 파츠·분리 무기의 재사용을 전제로 웹에서 반동·머리·재질별 의복 반응·혈액/진액을 먼저 증명한다.** 전체 스테이지의 배경·HUD 폴리싱은 그 뒤다. 현재는 문서·에이전트 스킬·검사/조회 CLI, 채택 원화와 자체 WebGL 파츠 모션·독립 M16의 첫 샘플이 있다. 이전 시안·중단 시험은 삭제했으며 [23](23-character-appearance-review.md)을 따른다. 실제 범위·측정·미검수 항목은 [24](24-motion-rig-test.md)에 기록했다. 게임 전투·1스테이지는 아직 없다.

단계 상태는 미착수/작업 중/검증 중/완료로 기록한다. 프레임 생성과 가중치 작성·리깅 비용을 각각 측정한다. 임시 도형으로 전투 규칙을 시험할 수 있지만 생성 모션 검증의 증거로 사용하지 않는다.

## 5. 변경 관리

전투 판정·타격감은 [19](19-combat-feel-and-damage.md), 갑옷 외형은 [17](17-modular-armor-appearance.md), 파츠·무기 재사용 계약은 [16](16-modular-character-and-weapons.md), 전투·좌표·실제 프리셋은 [07](07-data-and-assets.md), 모션 방식은 [13](13-secondary-motion.md), 피격 재질·상한은 [14](14-hit-effects.md)을 기준으로 삼는다. 변경 시 연결된 검수 기대값도 갱신한다.

세계관·서사 변경은 [15](15-worldbuilding.md)에서 먼저 정리하고 02의 화면 표현·11의 적 구성·관련 제작 문서에 반영한다. 게임명은 Dear Human으로 통일한다. 주인공은 최신 사용자 평가와 02의 외형 기준을 따른다. 최신 첨부의 캐릭터·전술 갑옷·3D 렌더 질감으로 초안을 변경했다. 사용자가 새 외형을 채택해 기존 자료를 삭제하고 rig_002 시험을 재개했다. 실제 결과 평가 뒤 도구를 확정한다.

발사 속도 변경은 반동 누적·화염 길이·검수 발수에 영향을 준다. 캐릭터 크기 변경은 캔버스·소켓·충돌·총구 높이·적 Hurtbox·카메라에 영향을 준다. 보조 모션 변경은 뼈대 부모 관계·팔 IK·총구 계산을 다시 확인한다. 같은 소총군의 무기 추가는 무기 자산·소켓·반동·작은 파지 보정으로 제한되는지 검사한다.

## 6. 프로토타입 이후
